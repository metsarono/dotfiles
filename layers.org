* Why

DotCortex was one person's fleet: every host was Mètsàtron's, so =all/= could hold both universal machinery and personal taste (keyboard layout, git identity, agent doctrine, avatar). A second human contributor (Gillean, Linux user =gille=) now joins, and machines get assigned to users. This module adds the missing axis: *who* a stow run is for, next to *which machine* it runs on.

It also replaces "which layers does this host get" living in three places (a hard-coded loom verb per host, =INSTALL.sh= Phase 6 autodetect, and the stow target guard's alias tables) with one declared registry that =loom stow:auto= reads.

* The file-disjoint rule (read this before adding a layer)

GNU Stow has *no override semantics*. Two packages in one stow run may not ship the same path: =safe-stow= previews each package and aborts on =existing target is stowed to a different package=. A later layer therefore can never "win" over an earlier one by shipping the same file. Every layer in a stack must be file-disjoint from every other layer in that stack. Directories may be shared (Stow merges them); files may not.

Consequences:

- A user layer can only *add* files no other layer in the stack ships.
- To make something user-specific that =all/= ships today, the file must *move* out of =all/= (Phase C), or the shared file must *source* a user fragment (Phase B hook points: git =[include]=, tmux =source-file -q=, a zsh drop-in dir, kitty =globinclude=, Claude =@= imports).
- Overlap between a =user-*= layer and any other layer in the same stack is a fatal guard error (see [[*Validation (called by the stow target guard)][Validation]]), caught before Stow ever runs.
- Stow rejects slashes in package names (=stow: ERROR: Slashes are not permitted in package names=), so user layers are flat top-level packages =user-<id>/=, siblings of =all/=, never =users/<id>/=.

* Precedence order

A resolved stack is always, left to right:

| Slot    | Source column          | Examples                   |
|---------+------------------------+----------------------------|
| base    | always                 | =all=                      |
| platform| hosts.ssv =PLATFORM=   | =linux=, =termux=          |
| distro  | hosts.ssv =DISTRO=     | =debian=, =openmandriva=   |
| init    | hosts.ssv =INIT=       | =devuan= (sysv-rc session) |
| host    | hosts.ssv =HOSTPKG=    | =x230=, =t480s=, =t1700=   |
| user    | users.ssv (if active)  | =user-metsatron=           |
| local   | =DOTCORTEX_LOCAL_PKGS= | machine-local, untracked   |

Because layers are file-disjoint, "precedence" governs three things only: the order =safe-stow= processes packages, the numbered order of runtime fragments in drop-in directories (Phase B convention: =10-all-=, =30-linux-=, =40-distro-=, =50-host-=, =70-user-=, =90-local-=, last one wins), and what the guard validates. User comes after host on purpose: preferences (keys, fonts, editor, identity) belong to the person, while host facts (headless, hardware, init) are expressed as capabilities (host scope files, =host-excludes=), not as competing files. The machine-local slot is always last: it is the escape hatch for state that must survive on one box and never enters the public repo.

A =-= in a registry column means "no layer in this slot". =INIT= is only =devuan= on sysv-rc hosts; OpenRC hosts (T480, Honey) leave it empty, which is exactly what their legacy verbs already do.

* Registry: users.ssv

Columns: =ID ACCOUNTS LAYER GITLAB NOTE=.

- =ID=: DotCortex user id; the user layer package is =user-<ID>=.
- =ACCOUNTS=: comma-separated Unix account names (shell globs allowed) that map to this id when a stow runs as them.
- =LAYER=: =active= or =inactive=. An inactive user layer is never appended by the resolver. Phase A ships both inactive.
- =GITLAB=: GitLab username, for attribution.
- =NOTE=: freeform, quoted, never parsed.

Deployed to =~/.config/dotcortex/users.ssv=; the resolver reads the repo copy so a fresh host can resolve before its first stow.

* Registry: hosts.ssv

Columns: =HOST ALIASES STATUS PLATFORM DISTRO INIT HOSTPKG USERS LEGACY_VERB NOTE=.

- =HOST=: registry key (the machine overlay name where one exists). A host may have *several rows*, one per set of users, when accounts on one machine are onboarded at different times (Honey: =metsatron= active, =gille= planned). Rows sharing a =HOST= must carry the same =ALIASES=, =PLATFORM=, =DISTRO=, =INIT= and =HOSTPKG=, and their =USERS= must be disjoint; =layers:check= enforces this. The resolver picks the row whose =USERS= names the invoking user, then applies that row's =STATUS=.
- =ALIASES=: comma-separated =hostname -s= values that select this row. These mirror the stow target guard's =EXPECTED_HOSTS= exactly; =layers:check= and the tests fail if the two drift.
- =STATUS=: =active= or =planned=. The resolver refuses a planned row.
- =PLATFORM=, =DISTRO=, =INIT=, =HOSTPKG=: the layer in each precedence slot, or =-=.
- =USERS=: comma-separated user ids allowed to stow on this host.
- =LEGACY_VERB=: the loom verb this row must reproduce package-for-package, or =-=.
- =NOTE=: freeform, quoted, never parsed.

Hostnames are public by ruling; *IP addresses never appear here* (rule 21). =stow:cortex= is not a host row: it is the T1700 sanctuary projection with its own helper. The platform and family verbs (=stow=, =stow:linux=, =stow:debian=, =stow:devuan=, =stow:openmandriva=) are not hosts either: =openmandriva= is an OS family with its own package manager (DNF), exactly like =debian= (nala/apt), and is declared in the layer vocabulary below, not as a host. There are no live OpenMandriva systems at present; a future one gets a real host row with =DISTRO= =openmandriva=.

* Registry: layers.ssv (layer vocabulary)

Every non-host layer name, with the one slot it may occupy. =hosts.ssv= rows may only put a declared =platform= value in =PLATFORM=, a =distro= value in =DISTRO= and an =init= value in =INIT=; =layers:check= fails otherwise. Host layers (=HOSTPKG=) come from =hosts.ssv= itself and user layers from =users.ssv=, so together the three files declare every legitimate package name. That is what makes the planned switch of undeclared names from warning to error safe (see [[*Migration phases][Migration phases]]).

Columns: =LAYER SLOT NOTE=. =SLOT= is one of =base platform distro init=.

* Resolver: dotcortex-layers

One helper owns registry parsing, so =loom stow:auto=, the Makefile fallback, the stow target guard and the tests never re-implement it. It reads the *repo* copies of the registries (=$DOTCORTEX_ROOT=, default: the checkout this script lives in, else =~/DotCortex=), so it works on a fresh host before the first stow.

- =dotcortex-layers resolve [--host H] [--user ID] [--allow-planned] [--explain]= prints the space-separated package list for this host and invoking account (or the given ones). Refuses: unregistered host (exit 2), planned row (exit 3), account or user not assigned to the host (exit 2), a layer without a directory (exit 4). =--explain= prints the slot-by-slot stack on stderr.
- =dotcortex-layers show= is =resolve --explain= for humans (=loom layers:show=).
- =dotcortex-layers check= lints the three registries and proves every =LEGACY_VERB= resolves to exactly the package list that verb passes today (=loom layers:check=).
- =dotcortex-layers validate --packages "..."= is what the stow target guard calls; see below.

Test hooks: =DOTCORTEX_LAYERS_HOSTNAME=, =DOTCORTEX_LAYERS_ACCOUNT=, =DOTCORTEX_HOSTS_SSV=, =DOTCORTEX_USERS_SSV=, =DOTCORTEX_LAYERS_SSV= override the live hostname, account and registry paths. =DOTCORTEX_LOCAL_PKGS= appends machine-local packages (last slot).

** Validation (called by the stow target guard)

=validate= enforces what Stow alone reports too late or not at all:

1. At most one =user-*= package per stack.
2. A =user-<id>= package must be registered in =users.ssv= and must belong to the invoking account (you only ever stow your own user layer).
3. *No file overlap* between a =user-*= package and any other package in the stack (the file-disjoint rule). The walk honours the user package's own =.stow-local-ignore=, so the skeleton's README never counts.
4. Package names declared nowhere in the registries (not in =layers.ssv=, not a =hosts.ssv= =HOSTPKG=, not =user-*=) produce a *warning*, not a failure, so no existing stow invocation changes behaviour. It becomes fatal at the switch-over described under [[*Migration phases][Migration phases]].

Exit 0 means allowed (warnings go to stderr), exit 2 means blocked.

"""Resolve and validate DotCortex stow layer stacks (layers.org)."""

import argparse
import fnmatch
import os
import pwd
import re
import shlex
import socket
import sys
from pathlib import Path

# Importing the stow guard (to compare alias tables) must not leave a
# __pycache__ inside the overlay, where stow would link it into $HOME.
sys.dont_write_bytecode = True

HOST_COLUMNS = ("HOST", "ALIASES", "STATUS", "PLATFORM", "DISTRO", "INIT",
                "HOSTPKG", "USERS", "LEGACY_VERB", "NOTE")
USER_COLUMNS = ("ID", "ACCOUNTS", "LAYER", "GITLAB", "NOTE")
VOCAB_COLUMNS = ("LAYER", "SLOT", "NOTE")
# Precedence slots after the implicit base layer "all", in stack order.
SLOTS = (("platform", "PLATFORM"), ("distro", "DISTRO"),
         ("init", "INIT"), ("host", "HOSTPKG"))
# Fallback when layers.ssv is absent (fixture roots, older checkouts).
SHARED_PACKAGES = {"all", "linux", "debian", "devuan", "termux"}
VOCAB_SLOTS = {"base", "platform", "distro", "init"}
USER_PREFIX = "user-"
HOST_STATUSES = {"active", "planned"}
LAYER_STATES = {"active", "inactive"}


class LayerError(Exception):
    def __init__(self, message, code=2):
        super().__init__(message)
        self.code = code


def repo_root():
    env = os.environ.get("DOTCORTEX_ROOT")
    if env:
        return Path(env)
    # all/.local/bin/dotcortex-layers -> the checkout is three levels up.
    candidate = Path(os.path.realpath(__file__)).parents[3]
    if (candidate / "all").is_dir():
        return candidate
    return Path.home() / "DotCortex"


def registry_path(root, name, env_name):
    env = os.environ.get(env_name)
    return Path(env) if env else root / "all/.config/dotcortex" / name


def parse_ssv(path, columns):
    rows = []
    with open(path, encoding="utf-8") as handle:
        for lineno, line in enumerate(handle, 1):
            stripped = line.strip()
            if not stripped or stripped.startswith("#"):
                continue
            try:
                fields = shlex.split(stripped)
            except ValueError as exc:
                raise LayerError(f"{path}:{lineno}: {exc}") from exc
            if len(fields) != len(columns):
                raise LayerError(
                    f"{path}:{lineno}: expected {len(columns)} columns "
                    f"({' '.join(columns)}), got {len(fields)}")
            row = dict(zip(columns, fields))
            row["_line"] = lineno
            rows.append(row)
    return rows


def load_vocabulary(root):
    path = registry_path(root, "layers.ssv", "DOTCORTEX_LAYERS_SSV")
    return parse_ssv(path, VOCAB_COLUMNS) if path.is_file() else None


def split_list(value):
    return [] if value == "-" else [item for item in value.split(",") if item]


def load_registries(root):
    hosts_path = registry_path(root, "hosts.ssv", "DOTCORTEX_HOSTS_SSV")
    users_path = registry_path(root, "users.ssv", "DOTCORTEX_USERS_SSV")
    hosts = parse_ssv(hosts_path, HOST_COLUMNS) if hosts_path.is_file() else None
    users = parse_ssv(users_path, USER_COLUMNS) if users_path.is_file() else None
    return hosts, users


def live_hostname():
    return os.environ.get("DOTCORTEX_LAYERS_HOSTNAME") or socket.gethostname().split(".", 1)[0]


def live_account():
    env = os.environ.get("DOTCORTEX_LAYERS_ACCOUNT")
    if env:
        return env
    try:
        return pwd.getpwuid(os.getuid()).pw_name
    except KeyError:
        return os.environ.get("USER", "")


def find_host_rows(hosts, hostname):
    """All rows of the one host this hostname selects (a host may have one row per user set)."""
    matches = [row for row in hosts
               if row["HOST"] == hostname or hostname in split_list(row["ALIASES"])]
    keys = sorted({row["HOST"] for row in matches})
    if len(keys) > 1:
        raise LayerError(f"hostname '{hostname}' matches several hosts.ssv rows: "
                         + ", ".join(keys))
    return matches


def find_user(users, user_id):
    return next((row for row in users if row["ID"] == user_id), None)


def user_for_account(users, account):
    matches = [row for row in users
               if any(fnmatch.fnmatchcase(account, pattern)
                      for pattern in split_list(row["ACCOUNTS"]))]
    if len(matches) > 1:
        raise LayerError(f"account '{account}' matches several users.ssv rows: "
                         + ", ".join(row["ID"] for row in matches))
    return matches[0] if matches else None


def local_packages():
    return shlex.split(os.environ.get("DOTCORTEX_LOCAL_PKGS", ""))


def resolve(root, hosts, users, hostname=None, user_id=None, allow_planned=False):
    """Return (stack, host_row, user_row); stack is [(slot, package, note)]."""
    if hosts is None or users is None:
        raise LayerError("hosts.ssv or users.ssv is missing from all/.config/dotcortex/")
    hostname = hostname or live_hostname()
    rows = find_host_rows(hosts, hostname)
    if not rows:
        raise LayerError(f"host '{hostname}' is not registered in hosts.ssv; "
                         "use its legacy loom stow verb or add a row (layers.org)")
    if user_id:
        user = find_user(users, user_id)
        if user is None:
            raise LayerError(f"user '{user_id}' is not registered in users.ssv")
    else:
        account = live_account()
        user = user_for_account(users, account)
        if user is None:
            raise LayerError(f"account '{account}' maps to no user in users.ssv")
    row = next((r for r in rows if user["ID"] in split_list(r["USERS"])), None)
    if row is None:
        assigned = ",".join(r["USERS"] for r in rows)
        raise LayerError(f"user '{user['ID']}' is not assigned to host '{rows[0]['HOST']}' "
                         f"(USERS={assigned})")
    if row["STATUS"] != "active" and not allow_planned:
        raise LayerError(f"host row '{row['HOST']}' ({row['USERS']}) is {row['STATUS']}, not active; "
                         "nothing is stowed from a planned row", 3)

    stack = [("base", "all", "")]
    for slot, column in SLOTS:
        if row[column] != "-":
            stack.append((slot, row[column], ""))
    user_pkg = USER_PREFIX + user["ID"]
    if user["LAYER"] == "active":
        stack.append(("user", user_pkg, ""))
    else:
        stack.append(("user", user_pkg, "inactive: not stowed"))
    for pkg in local_packages():
        stack.append(("local", pkg, ""))

    for slot, pkg, note in stack:
        if note:
            continue
        if not (root / pkg).is_dir():
            raise LayerError(f"layer '{pkg}' ({slot} slot) has no directory in {root}", 4)
    return stack, row, user


def stack_packages(stack):
    return [pkg for _slot, pkg, note in stack if not note]


def explain(stack, row, user, hostname, stream):
    print(f"dotcortex-layers: host '{hostname}' -> row '{row['HOST']}' "
          f"({row['STATUS']}), user '{user['ID']}' ({user['LAYER']})", file=stream)
    for slot, pkg, note in stack:
        print(f"  {slot:<9}{pkg}" + (f"   ({note})" if note else ""), file=stream)


def legacy_verb_packages(root, verb):
    """Package list a legacy loom stow verb passes to safe-stow, or None."""
    maak = root / "all/.config/maak/maak.scm"
    if not maak.is_file():
        return None
    text = maak.read_text(encoding="utf-8")
    match = re.search(r"\(task '" + re.escape(verb) + r"\s(.*?)(?=\(task '|\Z)", text, re.S)
    if not match or "make safe-stow" not in match.group(1):
        return None
    pkgs = re.search(r"STOW_PKGS='([^']*)'", match.group(1))
    return pkgs.group(1).split() if pkgs else ["all"]


def guard_expected_hosts():
    guard = Path(os.path.realpath(__file__)).with_name("dotcortex-stow-target-guard")
    if not guard.is_file():
        return None
    from importlib.machinery import SourceFileLoader
    from importlib.util import module_from_spec, spec_from_loader
    loader = SourceFileLoader("dotcortex_stow_target_guard", str(guard))
    module = module_from_spec(spec_from_loader(loader.name, loader))
    loader.exec_module(module)
    return module.EXPECTED_HOSTS


def check(root, out=sys.stdout):
    problems = []
    hosts, users = load_registries(root)
    if hosts is None or users is None:
        print("!! hosts.ssv or users.ssv missing", file=out)
        return 1

    vocab = load_vocabulary(root)
    vocab_slot = {}
    if vocab is None:
        problems.append("layers.ssv (layer vocabulary) is missing")
    else:
        for entry in vocab:
            if entry["SLOT"] not in VOCAB_SLOTS:
                problems.append(f"layer '{entry['LAYER']}': SLOT must be one of {sorted(VOCAB_SLOTS)}")
            if entry["LAYER"] in vocab_slot:
                problems.append(f"layer '{entry['LAYER']}' is declared twice in layers.ssv")
            vocab_slot[entry["LAYER"]] = entry["SLOT"]
            if not (root / entry["LAYER"]).is_dir():
                problems.append(f"layer '{entry['LAYER']}' has no directory")
        for row in hosts:
            for slot, column in SLOTS:
                value = row[column]
                if value == "-":
                    continue
                if slot == "host":
                    if value in vocab_slot:
                        problems.append(f"host '{row['HOST']}': HOSTPKG '{value}' is a {vocab_slot[value]} layer, not a host overlay")
                elif vocab_slot.get(value) != slot:

            problems.append(f"host '{key}': user '{uid}' is in more than one of its rows")

    for user in users:
        if user_ids.count(user["ID"]) > 1:
            problems.append(f"user id '{user['ID']}' is declared twice")
        if user["LAYER"] not in LAYER_STATES:
            problems.append(f"user '{user['ID']}': LAYER must be one of {sorted(LAYER_STATES)}")
        if not (root / (USER_PREFIX + user["ID"])).is_dir():

        for user_id in split_list(row["USERS"]):

                problems.append(f"host '{row['HOST']}': USERS names unknown user '{user_id}'")
        if row["STATUS"] != "active":

            problems.append(f"host '{row['HOST']}': {exc}")
            continue

        if resolved == legacy:
            print(f"ok {row['HOST']}: stow:auto == {row['LEGACY_VERB']} == {' '.join(legacy)}", file=out)
        else:

            row = next((r for r in hosts if r["HOST"] == machine), None)

        print(f"!! {problem}", file=out)
    print("layers:check " + ("FAILED" if problems else "passed"), file=out)
    return 1 if problems else 0


def load_ignore(pkgdir):
    patterns = []
    ignore = pkgdir / ".stow-local-ignore"
    if ignore.is_file():
        for line in ignore.read_text(encoding="utf-8").splitlines():
            line = line.strip()
            if line and not line.startswith("#"):
                patterns.append(line)
    return patterns


def is_ignored(rel, patterns):
    base = rel.rsplit("/", 1)[-1]
    for pattern in patterns:
        try:
            if "/" in pattern:
                if re.search(r"(?:^|/)(?:" + pattern + r")(?:/|$)", "/" + rel):
                    return True
            elif re.fullmatch(pattern, base):
                return True
        except re.error:
            continue
    return False


def walk_package(pkgdir):
    """Yield (relative path, is_real_dir) for what Stow would consider."""
    patterns = load_ignore(pkgdir)
    for dirpath, dirnames, filenames in os.walk(pkgdir):
        base = Path(dirpath)
        keep = []
        for name in dirnames:
            rel = (base / name).relative_to(pkgdir).as_posix()
            if is_ignored(rel, patterns):
                continue
            if (base / name).is_symlink():
                yield rel, False
                continue
            keep.append(name)
            yield rel, True
        dirnames[:] = keep
        for name in filenames:
            rel = (base / name).relative_to(pkgdir).as_posix()
            if rel == ".stow-local-ignore" or is_ignored(rel, patterns):
                continue
            yield rel, False


def validate(root, packages, account=None):
    """Return (errors, warnings) for a STOW_PKGS stack."""
    errors, warnings = [], []
    hosts, users = load_registries(root)
    user_pkgs = [pkg for pkg in packages if pkg.startswith(USER_PREFIX)]
    if not user_pkgs and hosts is None:
        return errors, warnings

    if len(user_pkgs) > 1:
        errors.append("a stack may contain at most one user layer, got: " + " ".join(user_pkgs))
    if user_pkgs and users is None:
        errors.append("user layers requested but users.ssv is missing")
        return errors, warnings

    account = account or live_account()
    for pkg in user_pkgs:
        user = find_user(users, pkg[len(USER_PREFIX):])
        if user is None:
            errors.append(f"user layer '{pkg}' is not registered in users.ssv")
            continue
        owner = user_for_account(users, account)
        if owner is None or owner["ID"] != user["ID"]:
            errors.append(f"user layer '{pkg}' does not belong to the invoking account '{account}'")
        if user["LAYER"] != "active":
            warnings.append(f"user layer '{pkg}' is inactive in users.ssv (placeholder only)")
        pkgdir = root / pkg
        if not pkgdir.is_dir():
            errors.append(f"user layer '{pkg}' has no directory in {root}")
            continue
        overlaps = []
        for rel, is_dir in walk_package(pkgdir):
            for other in packages:
                if other == pkg:
                    continue
                target = root / other / rel
                if not os.path.lexists(target):
                    continue
                if is_dir and target.is_dir() and not target.is_symlink():
                    continue
                overlaps.append(f"{rel} (also in {other})")
        if overlaps:
            shown = "; ".join(overlaps[:10])
            more = f" ... and {len(overlaps) - 10} more" if len(overlaps) > 10 else ""
            errors.append(f"user layer '{pkg}' overlaps other layers (file-disjoint rule): {shown}{more}")

    if hosts is not None:
        vocab = load_vocabulary(root)
        known = {entry["LAYER"] for entry in vocab} if vocab is not None else set(SHARED_PACKAGES)
        known |= set(local_packages())
        for row in hosts:
            known.update(row[column] for _slot, column in SLOTS if row[column] != "-")
        for pkg in packages:
            if pkg not in known and not pkg.startswith(USER_PREFIX):
                warnings.append(f"package '{pkg}' is not declared in layers.ssv or hosts.ssv (allowed for now; see layers.org)")
    return errors, warnings

* Adopting an existing account: dotcortex-stow-adopt

A fresh account is never empty. =useradd -m= copies =/etc/skel= (on Honey that is the VendefoulWolf image's =.bashrc=, =.zshrc=, bspwm, kitty, rofi and friends), and a helper may already have dropped a file DotCortex also ships. Stow refuses every such file. =safe-stow='s legacy answer is to rename each conflict to =<file>.bak.<ts>= and stow over it, which never loses bytes but does replace whatever the person was running. For onboarding an account that is not good enough, so =safe-stow= has a second policy, =STOW_CONFLICTS=adopt=:

| Conflict                                                 | Class       | Action                                                                  |
|----------------------------------------------------------+-------------+-------------------------------------------------------------------------|
| regular file, byte-identical to the package file         | =identical= | moved into the state dir, then linked (nothing changes in effect)       |
| regular file, byte-identical to =/etc/skel/<same path>=  | =skel=      | moved into the state dir, then linked (an untouched useradd default)    |
| anything else (edited file, foreign symlink, dir vs file) | =keep=      | *STOP*: report every conflict, change nothing, exit 3                   |

It is all or nothing: every conflict is classified before anything moves, so one =keep= leaves the home exactly as it was. Every move is recorded in =~/.local/state/dotcortex/stow-adopt/<ts>/= (=manifest.tsv=, the moved files under =identical/= and =skel/=, and a =restore.sh= that unlinks the stow link and puts the original back). The default policy stays =backup=, so no existing host's =make safe-stow= or =loom stow:<host>= changes behaviour; onboarding runs pass =STOW_CONFLICTS=adopt= (Honey's accounts: [[file:agents-bots-honey.org][agents-bots-honey.org]]).

- =dotcortex-stow-adopt [--apply] [--dir ROOT] [--target DIR] [--packages "..."] [--skel DIR] [--state DIR]=
- Default packages: the =dotcortex-layers resolve= stack for this host and account. Default =--dir=: the checkout the helper lives in. Default target: =$HOME=.
- Dry-run unless =--apply=; the dry-run prints the same table and exits 3 if anything would stop.
- Some images ship root-only entries in =/etc/skel= (Honey: =.config/Thunar=, =.config/gtk-3.0=, =.config/fastfetch= are =0700 root=). The account cannot read them, so it cannot prove its copy is a default, and the helper stops with that reason. The operator who created the account hands the lane a readable snapshot instead (=cp -a /etc/skel/. <dir>= owned by the account, then =DOTCORTEX_SKEL=<dir>=); the proof is still byte equality, done by the lane.

"""Adopt a pre-existing account's files before stow (layers.org, STOW_CONFLICTS=adopt)."""

import argparse
import filecmp
import os
import re
import shlex
import shutil
import subprocess
import sys
import time
from pathlib import Path

sys.dont_write_bytecode = True

CANNOT_STOW = re.compile(r"cannot stow \S+ over existing target (.+) since neither a link nor a directory")
NOT_LINK = re.compile(r"existing target is neither a link nor a directory: (.+)$")
NOT_OWNED = re.compile(r"existing target is not owned by stow: (.+)$")
OTHER_PKG = re.compile(r"existing target is stowed to a different package: (\S+)")
BULLET = re.compile(r"^\s*\*\s+(.*)$")


def repo_root():
    env = os.environ.get("DOTCORTEX_ROOT")
    if env:
        return Path(env)
    candidate = Path(os.path.realpath(__file__)).parents[3]
    return candidate if (candidate / "all").is_dir() else Path.home() / "DotCortex"


def resolve_packages(root):
    helper = root / "all/.local/bin/dotcortex-layers"
    out = subprocess.run([sys.executable, str(helper), "resolve"], capture_output=True, text=True)
    if out.returncode != 0:
        raise SystemExit(f"dotcortex-stow-adopt: cannot resolve the stack: {out.stderr.strip()}")
    return out.stdout.split()


def stow_conflicts(root, target, packages):
    """Return [(rel, kind)] for every conflict a stow of the whole stack would hit."""
    cmd = ["stow", "-n", "-d", str(root), "-t", str(target), "--ignore=\\.bak\\.", *packages]
    # Run from the target: stow aborts if the caller's cwd is unreadable to this account.
    out = subprocess.run(cmd, capture_output=True, text=True, cwd=str(target))
    conflicts, unknown = [], []
    for line in (out.stdout + out.stderr).splitlines():
        bullet = BULLET.match(line)
        if not bullet:
            continue
        text = bullet.group(1)
        for kind, pattern in (("file", CANNOT_STOW), ("file", NOT_LINK),
                              ("foreign", NOT_OWNED), ("other-package", OTHER_PKG)):
            match = pattern.search(text)
            if match:
                conflicts.append((match.group(1).strip(), kind))
                break
        else:
            unknown.append(text)
    if out.returncode != 0 and not conflicts and not unknown:
        first = (out.stderr or out.stdout).strip().splitlines()[:1]
        unknown.append("stow failed: " + (first[0] if first else f"exit {out.returncode}"))
    return conflicts, unknown


def package_file(root, packages, rel):
    for pkg in packages:
        candidate = root / pkg / rel
        if candidate.is_file():
            return candidate
    return None


def same(a, b):
    """Byte equality; anything unreadable counts as different (fail closed: keep)."""
    try:
        return a is not None and a.is_file() and b.is_file() and filecmp.cmp(str(a), str(b), shallow=False)
    except OSError:
        return False


def classify(root, target, packages, skel, conflicts):
    rows = []
    for rel, kind in conflicts:
        path = target / rel
        source = package_file(root, packages, rel)
        if kind != "file" or path.is_symlink() or not path.is_file():
            rows.append(("keep", rel, f"stow reports {kind}; not a plain file DotCortex can adopt"))
        elif same(source, path):
            rows.append(("identical", rel, "byte-identical to the package file"))
        elif same(skel / rel, path):
            rows.append(("skel", rel, f"byte-identical to {skel / rel}"))
        elif os.path.lexists(skel / rel) and not os.access(skel / rel, os.R_OK):
            rows.append(("keep", rel, f"{skel / rel} is unreadable to this account, so it cannot be proven a "
                                      "default; pass --skel (or DOTCORTEX_SKEL) a readable snapshot of the skeleton"))
        else:
            rows.append(("keep", rel, "differs from the package and from the skeleton: someone's config"))
    return rows


def write_restore(state, target, rows):
    lines = ["#!/bin/sh", "# Generated by dotcortex-stow-adopt: put adopted files back.", "set -eu"]
    for cls, rel, _why in rows:
        dest = shlex.quote(str(target / rel))
        saved = shlex.quote(str(state / cls / rel))
        lines.append(f"if [ -L {dest} ]; then rm -f {dest}; fi")
        parent = shlex.quote(str((target / rel).parent))
        lines.append(f"[ -e {dest} ] || {{ mkdir -p {parent}; mv {saved} {dest}; }}")
    (state / "restore.sh").write_text("\n".join(lines) + "\n")
    (state / "restore.sh").chmod(0o700)


def main(argv=None):
    parser = argparse.ArgumentParser(prog="dotcortex-stow-adopt", description=__doc__)
    parser.add_argument("--apply", action="store_true")
    parser.add_argument("--dir", type=Path, default=None, help="stow dir (the DotCortex checkout)")
    parser.add_argument("--target", type=Path, default=Path.home())
    parser.add_argument("--packages", default=None, help="space-separated stack (default: dotcortex-layers resolve)")
    parser.add_argument("--skel", type=Path, default=Path(os.environ.get("DOTCORTEX_SKEL", "/etc/skel")))
    parser.add_argument("--state", type=Path, default=None)
    args = parser.parse_args(argv)
    root = (args.dir or repo_root()).resolve()
    target = args.target.resolve()
    packages = shlex.split(args.packages) if args.packages else resolve_packages(root)

    conflicts, unknown = stow_conflicts(root, target, packages)
    rows = classify(root, target, packages, args.skel, conflicts)
    rows += [("keep", text, "unrecognised stow conflict") for text in unknown]
    print(f"dotcortex-stow-adopt: {len(rows)} conflict(s) stowing '{' '.join(packages)}' into {target}")
    for cls, rel, why in rows:
        print(f"  {cls:<10} {rel}   ({why})")
    if any(cls == "keep" for cls, _rel, _why in rows):
        print("STOP: nothing was changed. Resolve the 'keep' rows by hand (merge the config into "
              "DotCortex or move it yourself), then re-run.")
        return 3
    if not rows:
        print("nothing to adopt")
        return 0
    if not args.apply:
        print("dry-run: --apply moves the identical/skel files into the state dir so stow can link them")
        return 0

    state = args.state or target / ".local/state/dotcortex/stow-adopt" / time.strftime("%Y%m%d-%H%M%S")
    state.mkdir(parents=True, exist_ok=True)
    state.chmod(0o700)
    write_restore(state, target, rows)
    with open(state / "manifest.tsv", "a", encoding="utf-8") as manifest:
        for cls, rel, why in rows:
            saved = state / cls / rel
            saved.parent.mkdir(parents=True, exist_ok=True)
            shutil.move(str(target / rel), str(saved))
            manifest.write(f"{cls}\t{rel}\t{saved}\t{why}\n")
    print(f"adopted {len(rows)} file(s); record and restore.sh in {state}")
    return 0


if __name__ == "__main__":
    sys.exit(main())

def rows(path):
    out = []
    for line in path.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if line and not line.startswith("#"):
            out.append(shlex.split(line))
    return out


def legacy_verbs():
    """Independent parse of every stow verb in the tangled maak.scm."""
    text = MAAK.read_text(encoding="utf-8")
    verbs = {}
    for match in re.finditer(r"\(task '(stow(?::[A-Za-z0-9_-]+)?)\s(.*?)(?=\(task '|\Z)", text, re.S):
        body = match.group(2)
        if "make safe-stow" not in body:
            continue
        pkgs = re.search(r"STOW_PKGS='([^']*)'", body)
        verbs[match.group(1)] = pkgs.group(1).split() if pkgs else ["all"]
    return verbs


class RegistryTests(unittest.TestCase):
    def test_check_passes(self):
        result = run([sys.executable, str(HELPER), "check"])
        self.assertEqual(result.returncode, 0, result.stdout + result.stderr)
        self.assertIn("layers:check passed", result.stdout)

    def test_stow_auto_matches_every_legacy_verb_for_every_alias(self):
        verbs = legacy_verbs()
        checked = 0
        for row in rows(HOSTS):
            host, aliases, status, *_rest, users, legacy, _note = row
            if status != "active" or legacy == "-":
                continue
            self.assertIn(legacy, verbs, f"{host}: {legacy} missing from maak.scm")
            for name in [host] + aliases.split(","):
                result = run([sys.executable, str(HELPER), "resolve"],
                             DOTCORTEX_LAYERS_HOSTNAME=name,
                             DOTCORTEX_LAYERS_ACCOUNT=users.split(",")[0])
                self.assertEqual(result.returncode, 0, f"{name}: {result.stderr}")
                self.assertEqual(result.stdout.split(), verbs[legacy],
                                 f"{name}: stow:auto diverges from {legacy}")
                checked += 1
        self.assertGreaterEqual(checked, 6)

    def test_openmandriva_is_a_distro_family_not_a_host(self):
        self.assertNotIn("openmandriva", {row[0] for row in rows(HOSTS)})

        self.assertEqual(vocab.get("openmandriva"), "distro")
        self.assertEqual(vocab.get("debian"), "distro")
        result = run([sys.executable, str(HELPER), "validate", "--packages", "all linux openmandriva"])
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(result.stderr, "")
