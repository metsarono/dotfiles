* Contract

This module owns the shared Claude PermissionRequest engine. Ordinary local
work within declared roots defaults to ALLOW after the absolute floor; a
confident Decider danger verdict may veto. A fresh Admiral presence stamp
selects a bounded Telegram hold for refusals, even during quiet hours. An
explicit authenticated human answer is the only way a held refusal becomes an
allow. Timeout or failed delivery denies with interrupt:false and leaves one
open smart queue item. The away flag always forces away. With a stale/missing
stamp, quiet hours are the fallback; daytime keeps the existing presentation
switch. Presence never broadens automatic authority.

The shared unattended runtime is in agents-approval-unattended.org. The paired
Telegram seam and complete candidate preflight are in agents-approval-telegram.org.
The tiny prompt/observer hooks are in agents-hooks.org. Private manifests and
live deployment remain separate review actions. Published files use placeholders.

* Kikin local approval gate — separate manifest with Honey readonly canary

Kikin's Claude consorts use a local-only policy surface.  It is deliberately
separate from the local Kikin policy surface: the local classes below carry
placeholders only and remain disabled until that machine-local copy is
reviewed and the hook is explicitly wired.  The one enabled SSH entry is the
Admiral-reviewed Honey readonly canary; it has its own host roots and cannot

* Unattended PermissionRequest contract and morning review

Current Claude Code hook semantics, checked 2026-10-11 against
[[https://code.claude.com/docs/en/hooks#permissionrequest-decision-control][the official PermissionRequest reference]]: return JSON on stdout and exit
zero. The decision object belongs under =hookSpecificOutput=, with
=hookEventName= set to =PermissionRequest=. =behavior: deny= refuses the
operation, =message= reaches Claude, and =interrupt: false= lets it continue.
An exit-code-two response without this decision object leaves the prompt flow
unchanged; it cannot implement unattended mode.

#+BEGIN_EXAMPLE
{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"deny","message":"deferred: queued for the Admiral's morning review; continue with other work, do not retry or rephrase this command","interrupt":false}}}
#+END_EXAMPLE

Enable =unattended.enabled= in each seat's PRIVATE manifest. The away flag
=~/.config/dotcortex/approval-away= OR the configured half-open quiet window
(default 23:00 to 08:00 Australia/Melbourne, with DST) decides away. Disabling
quiet hours leaves the flag available; removing the flag during quiet hours
still means away. A manifest without this section retains its old behavior
except for the explicit default away flag. Published templates stay disabled
until their private copies are reviewed. Away changes only a final ASK into
DENY, including floor refusals and errors/timeouts; ALLOW is unchanged.

The full original request, tool, command, cwd, session, UTC timestamp, refusal
reason and away reason append to =~/.local/state/dotcortex/approval-morning-queue.jsonl=.
It is a private 0600 regular file; symlink/hardlink destinations are refused.
A bounded lock protects append and clear. Queue failure still returns DENY,
with an honest queue-unavailable message and =morning_queued: false= in the
hashed decision ledger. =SO_APPROVAL_MORNING_QUEUE= overrides the path for
fixtures or private installations. The ordinary ledger never acquires full
commands. =approval-morning-queue= prints complete requests grouped by session;
=--clear= prints then truncates the same inode under the lock. It never
executes or replays queued requests.

While present, =gate_inversion.present_refusal= accepts =ask= or =deny= and
defaults to =ask= (also for missing or invalid values). ASK emits no decision
and preserves Claude Code's native prompt, relayed to Telegram with Allow
buttons. It does not queue or send a second notification. True-floor refusals
also follow this switch: they never become automatic allows. Keep =ask= until
the separately built Desk consumer can honour an approval once and wake the
seat; then explicitly opt into =deny=. Away/quiet hours always deny, queue and
notify regardless of this switch.

** Coordinator class boundary

Each =coordinator_ops.classes= boolean is independently enabled in a seat's
private manifest. The six new classes are disabled in public templates.
=seat_account= is that seat's own mail identity; =repo_roots= lists exact
canonical repositories; =worktree_roots= lists exact sibling roots (new additions require =<repo>-wt-*=);
=scratch_roots= belongs to that seat; =build_host= is the only remote target;
remote scratch is restricted to explicit =/tmp/<name>= roots and configured
seat prefixes (for example =YOUR_SEAT-=). These fields carry placeholders
only; no live users, hosts, home paths or endpoints are added to public source.

Exact forms: mail has only =--from=, =--to=, =--subject= and =--body-file= in
that order; recipients end in =.helm= and body inputs are owned regular scratch
files. Worktree add uses matching directory/branch names, =-b= and =master=;
remove has no force flags and must belong to a configured repository; explicit
legacy worktree roots can also be reviewed for removal/prune. Prune
requires every registered worktree to be under the configured roots. Merge
requires explicit =git -C <canonical-repo>=, =master= checkout, =--ff-only=,
and an ancestry proof. Push accepts only =git push origin master=, proves the
CURRENT push destination's master tip with =ls-remote= and =merge-base=, and
refuses effect-changing push configuration. Missing objects, unavailable
remote proofs and deadlines are ASK; Git itself still rejects a raced non-FF.

Commits take exactly one =-m= message or =-F= owned scratch file, then =--=
and nonempty literal file pathspecs within a configured repository/worktree.
Directory and Git-magic pathspecs are refused; routing environment overrides
also refuse a coordinator grant.
Codex accepts only the documented =nohup codex exec --model <model>
--approve-for-me --skip-git-repo-check "$(cat <scratch-prompt>)" < /dev/null
> <scratch-log> 2>&1 &= form. Remote dispatch wraps that whole command in
single quotes after =ssh -o BatchMode=yes -o ConnectTimeout=3 YOUR_BUILD_HOST=.
SCP accepts one owned local scratch file and one remote scratch destination.
Remote scratch endpoints receive bounded realpath proofs, including existing
symlinks; remote dispatch also proves its prompt is a regular nonsymlink file.
No requested operation runs during classification.

Only a fully proven enabled shape narrows the overlapping remote/git floor
clauses. The full original request is still scanned for protected paths,
privacy, service/package control, destructive options and unsafe writers.
Failed coordinator proofs may visit the probabilistic Decider after the
deterministic master rules have run. Existing
legacy class grants are retained. Unattended mode never broadens authority.

** Deploy after coordinator review, separately for both seats

From each reviewed checkout, tangle =agents-approval.org= with that checkout's
=tangle-one= and run the six suites (kikin-hook, bunta-honey, honey-reads,
p3-hook, unattended, desk). Set each wrapper's engine override to the candidate
engine during testing; otherwise an installed older engine may shadow it.
Create a versioned installation with the shared engine, existing wrapper and
morning reader. Back up the private manifest and hook settings before editing.
Fill all =YOUR_*= placeholders only in that seat's private manifest; enable
=unattended= and just the reviewed coordinator booleans. Preserve existing
roots, class flags and private Decider configuration. Keep the shared engine's
=SO_APPROVAL_KIKIN_MANIFEST= override on both seats. Strict-parse the manifest
and settings. Start a fresh session using the versioned engine; test an
unknown harmless fixture once while present and once with the away flag.
The latter must DENY, queue one full record, and let Claude continue. Review
and clear that fixture with =approval-morning-queue --clear=. No push, remote
pull, live settings edit or session restart is performed by this branch.

import importlib.util

def runtime():
    here = Path(__file__).resolve()
    candidates = [here.parent / 'claude_approval_runtime.py', here.parents[1] / 'lib/dotcortex/claude_approval_runtime.py']
    path = next(p for p in candidates if p.is_file())
    spec = importlib.util.spec_from_file_location('approval_runtime', path)

    spec.loader.exec_module(module)
    return module

if __name__ == '__main__':
    try:

        self.manifest['coordinator_ops']['scratch_roots'] = [str(self.root)]
        self.manifest['gate_inversion'] = {'enabled': True, 'present_refusal': 'deny'}
        self.manifest['notifications'] = {'argv': ['YOUR_SEAT_TELEGRAM_NOTIFIER']}
        self.manifest['decider'].update(enabled=False)
        self.manifest['unattended'] = {'enabled': True, 'away_flag': str(self.flag), 'quiet_hours': {'enabled': False}}
        for item in self.manifest['classes']:
            item['enabled'] = False

    def event(self, command='true', **kwargs):
        return {'hook_event_name': 'PermissionRequest', 'tool_name': 'Bash', 'tool_input': {'command': command},
                'cwd': str(self.root), 'session_id': 'YOUR_SESSION', **kwargs}

    def run_hook(self, event, *, answers=None, status='ok', side_effect=None):
        self.path.write_text(json.dumps(self.manifest))
        env = {'SO_APPROVAL_KIKIN_MANIFEST': str(self.path), 'SO_APPROVAL_KIKIN_LOG': str(self.log),
               'SO_APPROVAL_MORNING_QUEUE': str(self.queue)}
        out = io.StringIO()
        with mock.patch.dict(os.environ, env), mock.patch.object(e.sys, 'stdin', io.StringIO(json.dumps(event))), \
                contextlib.redirect_stdout(out), mock.patch.object(e, '_decider_post', return_value=(answers, status), side_effect=side_effect):
            self.assertEqual(e.main(), 0)
        if not out.getvalue().strip():
            return {'behavior': 'ask'}
        decision = json.loads(out.getvalue())['hookSpecificOutput']['decision']
        self.assertIn(decision['behavior'], ('allow', 'deny'))
        if decision['behavior'] == 'deny':
            self.assertIs(decision['interrupt'], False)
        return decision

    def enable_decider(self):
        self.manifest['decider'].update(enabled=True, honey_url='https://YOUR_DECIDER.invalid/decide',
            honey_api='r2d2d', kikin_url='https://YOUR_DECIDER.invalid/systemone', timeout_ms=500)

    def test_ordinary_local_work_defaults_to_allow_even_without_classes_or_decider(self):
        for command in ['true', 'make test', 'pytest tests/', 'git ls-files agents-approval.org', 'git tag --list',

            with self.subTest(command=command):
                self.assertEqual(self.run_hook(self.event(command))['behavior'], 'deny')
        self.assertTrue(self.queue.exists())

* Presence and smart queue superseding contract (2026-10-12)

Fresh presence overrides quiet hours and the presentation switch; the away flag
always wins. Missing/stale daytime presence retains the existing switch. With
fresh presence a refusal is HELD by the hook, relayed to the paired Telegram
plugin, and answered by the authenticated Admiral once. Timeout defaults to ten
minutes, then DENY with interrupt:false and an open smart queue item. There is
no terminal-only fallback. Use a hook timeout of hold_timeout_minutes*60+9.

One shared =agents-approval-unattended.org= body provides all presence decisions
to the engine, wrapper and helpers. A remote seat may set presence_host to the
authority SSH alias; that helper stamps and reads the authority file so a message
to ANY seat counts for all seats. Leave quiet hours disabled until both seats
can reach that authority and the Telegram hold smoke test passes. Quiet hours
then become only the fallback for a missing/stale stamp.

The private JSONL queue is a revision journal; =approval-queue list --json= folds
latest items by ID. Dedupe uses seat plus normalized request (quoting, newlines,
cwd and tool-write content preserved), or a nonempty declared intent. Exact
requests stay in history. Denial notes supply the ID and intent/resolve commands.
Later live allows and successful live PostToolUse observations resolve matching
open items with “approved live at <time>”. =resolve= requires an explicit how.

The deterministic sweep marks a removed worktree, a captured topic tip landed
on master, or ended session with explicit intent-met evidence obsolete.
Unknown state stays open. =confirm= must come from the recorded seat session on
wake; =approve= is for the authenticated Desk consumer only. =claim= rechecks its
approval, state and staleness and consumes a short-lived seat confirmation nonce. It returns the original request once, never executes it. Resolved or
obsolete approvals are audited and do nothing. The Desk must consume this live
API, not raw revision lines, and execute only a successfully claimed request.

* Desk approval gate — Admiral ruling 7874, 2026-10-17

The Desk delivery lane applies an approval through =approval-queue approve →
confirm → claim= and mails the seat: re-run that exact command. The gate now
honours that re-run (shared runtime helper =_desk_approval_consume=, wired into
the engine's =main= before any ask or deferral, on both seats). The gate allows
a request only when ALL of these hold:

- the refusal reason is in the human-decidable grey zone (=no_match_decider=,
  =syntax=, =decider_risky=, or an operator-disabled =*_disabled= class). Hard
  floors and every other hard refusal (=true_floor=, =coordinator_refused=,
  =ambiguous_shell=, compound/substitution refusals, invalid input) are never
  satisfied by a Desk approval — secrets, destructive git, the harness/settings
  floors and the whole =_admiral_floor= family keep their refusal;
- the request hash matches exactly: same seat, same tool, same absolute cwd,
  same normalized tool input. Intent-only matching never honours a Desk
  approval on this path;
- the matching queue item is =replay_claimed= with =approved_by= equal to this
  manifest's =admiral_telegram_user_id= — the claim itself proves the approval
  was approved and confirmed through the authorized verbs;
- the approval is within the window: =unattended.desk_approval_window_hours=
  (ruled default 24 h, bound 168 h). Older claims are marked obsolete with
  "desk approval expired" and never allow.

Single use: the item moves to resolved "approved from the Desk and run" on
use, so a second identical request faces the normal gate again. Every use is
logged in the decision journal with =decision_path: "desk_approval"= and the
queue item id in =queue_id=. The wrapper's engine-unavailable fallback does

the request is non-floor, so it still defers.

    def test_floor_rule_is_recorded_without_request_text(self):

            ('cat README.org && kill -TERM 123', 'kill'),

                self.assertNotIn(command, json.dumps(record))
