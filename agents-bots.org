** Claude Code (Channel Plugin)

- Plugin: =~/.claude/plugins/cache/claude-plugins-official/telegram/0.0.6/=

*** Token Conflict / Workaround

The Claude Code plugin currently shares =@dotcortex_opencode_bot='s token with the OpenCode
bot. Telegram enforces one polling consumer per token — the OpenCode bot (running since Apr 30)
holds the slot, causing 409 Conflict for the Claude plugin.

*Workaround (active):* =claude-auryn --telegram= sends SIGSTOP to the opencode-telegram process
before launching Claude, freeing the token. On session exit the wrapper sends SIGCONT to resume it.

*Proper fix (pending):* Create a dedicated bot for Auryn via @BotFather, update
=~/.claude/channels/telegram/.env= and =NEXUS/stow/linux/.claude/channels/telegram/.env=,
run =helmstow=. Then remove the SIGSTOP workaround from =claude-auryn=.

** Codex

Codex still has no native Telegram channel, but HelmCortex now supplies a
private Codex app-server adapter for HelmAstra.

- Wrapper: =codex-helmastra --telegram= ensures the adapter, then continues
  into interactive Codex when attached to a terminal; the host manager uses
  the same flag non-interactively to establish only the background adapter
- Backend: Codex =app-server= JSON-RPC, with persistent Telegram-to-thread mapping
- Startup contract: the wrapper returns success only after bot identity and the
  Codex app-server are verified and the adapter publishes its PID-owned ready marker
- Approval policy: =never= inside the workspace-write sandbox, with Codex
  =auto_review= handling eligible exceptional requests before they reach the
  operator
- Compaction: native =thread/compact/start= plus the 27-minute / 70,000-token
  idle governor inherited from =codex-luna= / =codex-warm=
- Runtime credentials: private =~/.config/codex-telegram-helmastra/.env= only
- Identity safety: the expected bot ID and username are pinned in the private
  env; a token for OpenCode, Claude, Hermes, or any other bot fails closed

The adapter is deliberately separate from Ductor: Ductor keeps its own bot
identity and remains the fleet coordinator, while HelmAstra owns this bot.

** DeepSeek Harness

DeepSeek Harness Telegram is a separate =deepseek-harness= agent. It is not
Ductor or OpenCode. Kikin owns its live process and its HelmCortex brain is the
working directory.

- CLI: =@deepseek-ai/dsh= pinned in the npm manifest
- Bridge: =xqicxx/dsh-telegram=, built from the pinned sovereign checkout at
  =~/HelmCortex/NEXUS/git/dsh-telegram=
- Runtime env: private =~/.config/deepseek-harness-telegram/env= only
- Unix user (since 2026-09-26, Agent Boundaries phase 8): the bot runs as
  =agent-deepseek= (uid 2012). The operator's non-secret
  =~/.config/deepseek-harness-telegram/run-as= names that user; with it present,
  =telegram-agent-host start|stop|status deepseek-harness= re-runs itself through
  =sudo -n -u agent-deepseek= with a clean environment, so every =$HOME=-relative
  path (env, token, Go key, DSH home, state, log, pid, readiness marker) is the
  agent's own. Delete the file to run as the operator again. The agent gets a
  =~/HelmCortex= link (helmcortex-anaconda resolves from =$HOME=), its own copy of
  the built bridge under its DSH home (NEXUS stays closed to agents: it holds
  keys and 2775 subdirs such as =clients=), and a copy of the operator's
  known-good =dsh= tree: a fresh =npm install= of 0.1.5-rc.1 pulled rc.3
  sub-packages, nested them, and dsh-sandbox-local no longer resolved from the dsh
  root. Moving an existing DSH home between users means repointing the
  =profiles/node_modules= symlink farm and the =.dsh-module-fallback= links, and
  rewriting the session header's =cwd=; a =session.v3.jsonl.zstd= must keep the
  header line alone in its first zstd frame or dsh refuses it as corrupt.
- Voice notes (local whisper as the agent user, 2026-09-26): =whisper-transcribe=
  resolves =whisper-cli= from =$HOME/.guix-extra-profiles/inference= and models from
  =$HOME/.cache/whisper-cpp/models=, both of which resolve to the agent's own home. The agent
  home therefore carries a symlink =~/.guix-extra-profiles/inference= to the operator's
  inference profile (the profile tree is world-readable and the operator home grants the
  =cortex= group traverse-only), plus root-made hard links of =ggml-small.bin= and
  =ggml-medium.bin= into its model cache: zero extra disk, and the operator's 0770 =.cache=
  stays closed. A per-agent profile was rejected because the pulled Guix no longer matches
  the operator's build, so the tuned whisper-cpp would have recompiled from source.
  Outbound voice replies go through =agent-voice-relay= (agents-hooks.org): the bridge's
  =media.voiceReply.command= drops into the operator-owned spool, and an operator watcher
  runs the unchanged =claude-hook-voice-reply=, so the agent never holds the SSH identity.
- Provider: custom OpenAI-compatible =helmcortex-opencode-go= route (OpenCode Go,
  =https://opencode.ai/zen/go/v1=), never the native =deepseek= route and never
  pi-ai's built-in =opencode-go= catalog; the only declared model is
  =deepseek-v4.1-flash=. Ruling, Mètsàtron 2026-09-26: OpenCode Go is the
  preferred gateway and NeuralWatt is not a fallback (it was the route from
  2026-09-16 to 2026-09-26; its key file stays provisioned so a revert is one
  edit, never an automatic switch).
- Session header: since 2026-09-05 OpenCode Go rejects any request without
  =x-opencode-session= (HTTP 400 =MissingSessionID=, verified 2026-09-26). The
  route sends one static value, so every conversation shares one routing
  session; that is a cache-efficiency cost, not a correctness one. dsh adds its
  own =user-agent=, which Cloudflare in front of opencode.ai requires (a bare
  Python client gets error 1010).
- Credential: =OPENCODE_GO_API_KEY= is populated at runtime from the private,
  mode-0600 HelmCortex OpenCode Go key file; no credential is stored here
- Provider boundary rule: model authorship does not identify the API provider.
  Name routes and credential variables after the actual gateway, scrub unrelated
  inherited provider credentials before preflight and launch, then verify both
  the live endpoint and the child process's credential-variable names before a
  production claim.
- Workspace and brain: =~/HelmCortex/FORGE/brain/DeepSeek=
- Workspace config: private =~/HelmCortex/FORGE/brain/DeepSeek/.pi/telegram.json=
- DSH profile/home: dedicated =helmcortex-telegram= profile under the private
  DSH home declared by the env file
- Access control: =security.allowedChatIds=[]= in the template means deny all;
  =telegram-agent-host start deepseek-harness= refuses to start until the
  private workspace config contains an explicit non-empty allowlist
- Availability: startup performs an authenticated =GET /v1/models= before
  poller ownership and refuses to start unless the exact V4 Flash model is
  visible; the Flex alias and undeclared models are never fallback candidates.
  The Python preflight uses the host CA bundle explicitly so cron does not
  depend on its inherited SSL trust environment.
- After a HelmCortex host migration, restore the pinned bridge dependencies and
  build through targeted =BUN_BUILD_ONLY=dsh-telegram loom bun:apply= before
  relying on the boot owner. A ready owned poller makes =start= idempotent;
  the detached poller must not inherit the short-lived startup lock.
- Ownership: one long-polling process, owned by the PID file under
  =~/.local/state/telegram-agents=, verified by exact DSH profile cmdline before
  status or stop; no broad process kill is used

** HelmCortex Nano

Nanobot runs from an isolated uv environment inside its HelmCortex brain and is
owned by =telegram-agent-host=. DotCortex pins and repairs the package through
=loom nanobot:apply=; =loom nanobot:update= applies the version declared in
=package-pip.org=.

- Workspace: =~/HelmCortex/FORGE/brain/nanobot=
- Runtime: =~/HelmCortex/FORGE/brain/nanobot/.venv=
- Private config, OAuth, sessions, and logs: =~/.config/nanobot-telegram/=
- Token: =TELEGRAM_BOT_TOKEN= in =~/.config/nanobot-telegram/env=
- Model: =openai-codex/gpt-5.6-sol= through Nanobot's Codex OAuth provider
- Transport: Telegram long polling, pairing-only until a user is approved
- Trusted-endpoint access: while Nano uses the same OpenAI/Codex endpoint as
  HelmAstra and HelmDuctor, Nanobot's workspace restriction and exec sandbox are
  disabled. He runs as =metsatron= and receives the same host filesystem access
  as those agents, including read-write HelmCortex and DotCortex access.
- MCP parity: TimeArk, Recall, and Agentify are provisioned in the managed
  Nanobot config. These are the same local MCP surfaces exposed to HelmAstra.
- Global-model lane: =~/.config/nanobot-telegram/run-as= is the migration seam.
  When it names a provisioned agent user, =telegram-agent-host= delegates
  Nano's start, stop, and status into that sealed home exactly like OpenCode and
  DeepSeek Harness. Do not use a global-model provider in the trusted operator
  lane; stop Nano and activate the run-as lane first.

this file used to give. Do not install that one. Both packages ship a =pi= binary,

** DeepSeek Harness OpenCode Go Settings Template

Copy this exact file to =$DSH_HOME/settings.yaml=. The custom route is required:
the built-in =deepseek= provider owns DeepSeek's public endpoint and catalog,
whereas OpenCode Go is a separate OpenAI-compatible gateway. The route id is
deliberately not =opencode-go=, so pi-ai's installed Go catalog (which lacks
V4.1 Flash) never merges in; the single-model catalog makes model drift fail
closed instead of selecting another route. The Go endpoint returns reasoning in
=reasoning_content=, which is the =deepseek= thinking format.
=input: [text, image]= (2026-09-26): V4.1 Flash through Go answered an image probe directly; without the declaration dsh-llm replaces every photo with an "image omitted because this model accepts text only" placeholder.

#+BEGIN_SRC yaml :tangle all/.bots/templates/deepseek-harness-settings.yaml :comments no
llm-pi-ai:
  providers:
    helmcortex-opencode-go:
      displayName: HelmCortex OpenCode Go
      apiKeyEnv: OPENCODE_GO_API_KEY
      api: openai-completions
      baseURL: https://opencode.ai/zen/go/v1
      headers:
        x-opencode-session: helmcortex-deepseek-harness
      models:
        - id: deepseek-v4.1-flash
          contextWindow: 1000000
          maxTokens: 384000
          input: [text, image]
          compat:
            thinkingFormat: deepseek
#+END_SRC

** DeepSeek Harness Credential-Containment Patch Template

=$DSH_HOME/profiles/$DSH_TELEGRAM_PROFILE/cordis.patch.yml= under the sealed
agent user. The result is identical except that =@DSH_RECALL_MCP_URL@= becomes
the Recall MCP URL. The URL comes from =DSH_RECALL_MCP_URL= in the private env
file, or else from this host's own tailnet address (=tailscale ip -4=) on the

OpenCode Go credential to DeepSeek's public endpoint. The native DeepSeek chat
and search providers are disabled, as is their web tool consumer; the Harness
default is pinned to the custom OpenCode Go V4.1 Flash route.

The profile also mounts HelmCortex's read-only Fleet Health MCP and its narrow
DeepSeek memory-submission MCP. The latter exposes one create-only submission
operation into a fixed private review inbox. It provides no caller-selected
path, read/list/overwrite, shell, or execution surface.

This helper deliberately discovers nothing by process-name search.  The state
file is an ownership claim, and every operation revalidates PID, Linux start
ticks, cwd, and argv against that claim before declaring or stopping a process.

import json

import signal

BOT = "opencode"

def json_out(value: object) -> None:
    print(json.dumps(value, sort_keys=True))


def read_json(path: Path) -> dict | None:
    try:
        value = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return None
    return value if isinstance(value, dict) else None


def pid_info(pid: int) -> dict | None:
    proc = Path("/proc") / str(pid)
    try:
        stat = (proc / "stat").read_text(encoding="utf-8")
        after_comm = stat[stat.rfind(")") + 2 :].split()
        start_ticks = int(after_comm[19])
        argv = [part.decode(errors="replace") for part in (proc / "cmdline").read_bytes().split(b"\0") if part]
        cwd = os.path.realpath(proc / "cwd")
    except (OSError, ValueError, IndexError, UnicodeError):
        return None
    if not argv:
        return None
    return {"pid": pid, "start_ticks": start_ticks, "cwd": cwd, "argv": argv}


def state_path(value: str | None) -> Path:
    return Path(value or os.environ.get("OPENCODE_STATE_FILE", str(Path.home() / ".local/state/telegram-agents/opencode.json")))


def project_path(value: str | None) -> str:
    return os.path.realpath(value or os.environ.get("OPENCODE_PROJECT_ROOT", DEFAULT_PROJECT))


def port_value(value: str | None) -> int:
    return int(value or os.environ.get("OPENCODE_PORT", str(DEFAULT_PORT)))


def expected_backend_argv(host: str, port: int) -> list[str]:
    return ["opencode", "serve", "--hostname", host, "--port", str(port)]


def argv_has_backend_contract(argv: list[str], host: str, port: int) -> bool:
    if len(argv) < 6:
        return False
    # The executable may be absolute after a launcher resolves it.  Everything
    # after it must be the exact serve contract, with no broad substring match.
    return os.path.basename(argv[0]) == "opencode" and argv[1:] == expected_backend_argv(host, port)[1:]


def argv_has_poller_contract(argv: list[str], entrypoint: str | None) -> bool:
    if not argv or not entrypoint:
        return False
    expected = os.path.realpath(entrypoint)
    for index, item in enumerate(argv):
        if os.path.realpath(item) == expected:
            return argv[index + 1 :] == ["start", "--mode", "installed"]
    return False


def check_record(state: dict, role: str, expected_project: str, host: str, port: int) -> tuple[dict | None, list[str]]:
    pid_key = f"{role}_pid"
    ticks_key = f"{role}_start_ticks"
    argv_key = f"{role}_argv"
    cwd_key = f"{role}_cwd"
    reasons: list[str] = []
    try:
        pid = int(state.get(pid_key))
    except (TypeError, ValueError):
        return None, [f"{role}-pid-missing"]
    current = pid_info(pid)
    if current is None:
        return None, [f"{role}-down"]
    if str(state.get(ticks_key)) != str(current["start_ticks"]):
        reasons.append(f"{role}-start-ticks-mismatch")
    if os.path.realpath(str(state.get(cwd_key) or "")) != expected_project or current["cwd"] != expected_project:
        reasons.append(f"{role}-wrong-cwd")
    recorded_argv = state.get(argv_key)
    if not isinstance(recorded_argv, list) or [str(x) for x in recorded_argv] != current["argv"]:
        reasons.append(f"{role}-argv-mismatch")
    if role == "backend" and not argv_has_backend_contract(current["argv"], host, port):
        reasons.append("backend-argv-contract-mismatch")
    if role == "poller" and not argv_has_poller_contract(current["argv"], state.get("poller_entrypoint")):
        reasons.append("poller-identity-mismatch")
    return current, reasons


def native_poller_status(entrypoint: str | None) -> dict:
    if not entrypoint:
        return {"status": "unavailable", "reason": "poller-entrypoint-unknown"}
    try:
        result = subprocess.run(
            [entrypoint, "status"], capture_output=True, text=True, timeout=5, check=False
        )
    except (OSError, subprocess.TimeoutExpired) as exc:
        return {"status": "unavailable", "reason": type(exc).__name__}
    text = (result.stdout + result.stderr).strip()
    status = "running" if "Service status: running" in text else "stopped" if "Service status: stopped" in text else "unknown"
    return {"status": status, "exit": result.returncode, "output": text[-500:]}

def inspect(args: argparse.Namespace) -> int:
    state = read_json(state_path(args.state))
    result = {"status": "stopped", "backend": None, "poller": None, "reasons": []}
    if not state:
        result["reasons"] = ["owner-state-missing"]
        json_out(result)
        return 1
    project = project_path(args.project or state.get("project"))
    host = args.host or str(state.get("host") or DEFAULT_HOST)
    port = port_value(args.port or str(state.get("port") or DEFAULT_PORT))
    backend, backend_reasons = check_record(state, "backend", project, host, port)
    poller, poller_reasons = check_record(state, "poller", project, host, port)
    if backend is not None:
        backend["valid"] = not backend_reasons
        backend["reasons"] = backend_reasons
    if poller is not None:
        poller["valid"] = not poller_reasons
        poller["reasons"] = poller_reasons
    result["backend"] = backend
    result["poller"] = poller
    result["reasons"] = backend_reasons + poller_reasons
    if state.get("owner") != OWNER:
        result["reasons"].append("foreign-owner")
    if state.get("bot") != BOT:
        result["reasons"].append("bot-identity-mismatch")
    if project != os.path.realpath(DEFAULT_PROJECT):
        result["reasons"].append("wrong-project")
    if host != DEFAULT_HOST or port != DEFAULT_PORT:
        result["reasons"].append("wrong-listen-boundary")
    result["native_poller"] = native_poller_status(state.get("poller_entrypoint"))
    binding = settings_binding(project)
    result["session"] = binding
    if state.get("session_binding") != binding:
        # Session/project metadata is safe to refresh.  Credentials and package
        # settings remain outside this owner file.
        state["session_binding"] = binding
        path = state_path(args.state)

        temp.write_text(json.dumps(state, indent=2) + "\n", encoding="utf-8")
        os.replace(temp, path)
    result["project"] = project
    result["host"] = host
    result["port"] = port
    result["status"] = "running" if not result["reasons"] else "degraded"
    json_out(result)
    return 0 if result["status"] == "running" else 1

def stop(args: argparse.Namespace) -> int:
    state = read_json(state_path(args.state))
    if not state:
        print("opencode: STOPPED (owner state absent)")
        return 0
    project = project_path(args.project or state.get("project"))
    host = args.host or str(state.get("host") or DEFAULT_HOST)
    port = port_value(args.port or str(state.get("port") or DEFAULT_PORT))
    boundary_reasons: list[str] = []
    if state.get("schema") != "helmcortex.opencode-owner.v2":
        boundary_reasons.append("schema-mismatch")
    if state.get("owner") != OWNER:
        boundary_reasons.append("foreign-owner")
    if state.get("bot") != BOT:
        boundary_reasons.append("bot-identity-mismatch")
    if project != os.path.realpath(DEFAULT_PROJECT):
        boundary_reasons.append("wrong-project")
    if host != DEFAULT_HOST or port != DEFAULT_PORT:
        boundary_reasons.append("wrong-listen-boundary")
    if boundary_reasons:
        print(f"refusing stale-state cleanup: {','.join(boundary_reasons)}", file=sys.stderr)
        return 1
    owned: list[int] = []
    refused = 0
    stale = 0
    for role in ("poller", "backend"):
        current, reasons = check_record(state, role, project, host, port)
        if current is None and reasons == [f"{role}-down"]:
            stale += 1
            continue
        if reasons:
            refused += 1
            print(f"refusing to stop {role}: {','.join(reasons)}", file=sys.stderr)
            continue
        if current:
            owned.append(current["pid"])
    for pid in owned:
        try:
            os.kill(pid, signal.SIGTERM)
        except ProcessLookupError:
            pass
    deadline = time.monotonic() + 5
    while owned and time.monotonic() < deadline:
        if all(pid_info(pid) is None for pid in owned):
            break
        time.sleep(0.1)
    remaining = [pid for pid in owned if pid_info(pid) is not None]
    if remaining:
        for pid in remaining:
            try:
                os.kill(pid, signal.SIGKILL)
            except ProcessLookupError:
                pass
    if not remaining and refused == 0:
        try:
            state_path(args.state).unlink()
        except FileNotFoundError:
            pass
    print(f"opencode: stopped_owned={len(owned)} stale={stale} refused={refused}")
    return 0 if not remaining and refused == 0 else 1

* Nano NFS wedge watchdog

Nano's gateway owner record is local to Kikin. The watchdog reads only that
record, the exact local gateway log, and =/proc=; it never opens HelmCortex or
loads Nano's NFS-resident Python runtime. A persistent NFS/RPC D-state on the

def alert_route(config_dir: Path) -> tuple[str, str]:

    if isinstance(recipient, bool) or not isinstance(recipient, (str, int)) or not str(recipient).strip():
        raise ValueError("telegram-recipient-invalid")
    return token, str(recipient)


def send_alert(config_dir: Path, message: str, timeout: float) -> None:
    token, recipient = alert_route(config_dir)
    payload = urlencode({"chat_id": recipient, "text": message}).encode("utf-8")
    request = Request(f"https://api.telegram.org/bot{token}/sendMessage",
                      data=payload, method="POST")
    with urlopen(request, timeout=timeout) as response:
        if response.status != 200 or json.load(response).get("ok") is not True:
            raise ValueError("telegram-send-rejected")


def alert(args: argparse.Namespace, state: dict, event_path: Path,
          kind: str, message: str) -> None:
    # Record the attempt before network I/O so failed delivery is rate-limited.
    now = time.time()
    recent = state.get("last_alert", {})
    if not isinstance(recent, dict):
        recent = {}
    try:
        last = float(recent.get(kind, 0))
    except (TypeError, ValueError):
        last = 0
    if now - last < args.alert_cooldown:
        return
    recent[kind] = now
    state["last_alert"] = recent
    try:
        save_json(args.state_path, state)
        ledger(event_path, "alert-attempted", kind=kind, telegram_delivery="attempted")
        send_alert(args.config_dir, message, args.alert_timeout)
    except Exception as exc:
        # Never serialize exception text: HTTP errors can embed the token URL.
        try:
            ledger(event_path, "alert-failed", kind=kind, telegram_delivery="failed",
                   error_class=type(exc).__name__)
        except OSError:
            pass
    else:
        try:
            ledger(event_path, "alert-sent", kind=kind, telegram_delivery="sent")
        except OSError:
            pass


def proc_start_ticks(stat_text: str) -> int:
    # /proc/<pid>/stat field 22; comm can contain spaces and parentheses.
    return int(stat_text.rsplit(") ", 1)[1].split()[19])


def proc_identity(proc: Path) -> dict:
    fields = (proc / "stat").read_text(encoding="utf-8").rsplit(") ", 1)[1].split()
    return {
        "pid": int(proc.name),
        "ppid": int(fields[1]),
        "pgrp": int(fields[2]),
        "session": int(fields[3]),
        "ticks": int(fields[19]),
    }


def blocked_task(proc: Path) -> dict | None:
    task_root = proc / "task"
    tasks = sorted((entry for entry in task_root.iterdir() if entry.name.isdigit()),
                   key=lambda entry: int(entry.name))
    for task in tasks:
        status = (task / "status").read_text(encoding="utf-8")
        state_match = re.search(r"^State:\s*([A-Z])", status, re.M)
        wchan = (task / "wchan").read_text(encoding="utf-8").strip()
        if state_match and state_match.group(1) == "D" and NFS_WAIT.search(wchan):
            return {"tid": int(task.name), "state": "D", "wchan": wchan}
    return None


def descendant_of(pid: int, root_pid: int, parents: dict[int, int]) -> bool:
    seen: set[int] = set()
    current = pid
    while current > 1 and current not in seen:
        seen.add(current)
        current = parents.get(current, 0)
        if current == root_pid:
            return True
    return False


def blocked_search_workers(proc_root: Path, gateway_pid: int) -> list[dict]:
    identities: dict[int, dict] = {}
    for proc in proc_root.iterdir():
        if not proc.name.isdigit():
            continue
        try:
            identity = proc_identity(proc)
        except (OSError, ValueError):
            continue
        identities[identity["pid"]] = identity
    parents = {pid: value["ppid"] for pid, value in identities.items()}
    blocked = []
    for pid, identity in identities.items():
        proc = proc_root / str(pid)
        try:
            comm = (proc / "comm").read_text(encoding="utf-8").strip()
            wait = blocked_task(proc)
        except OSError:
            continue
        if (comm != "nanobot-search" or identity["pgrp"] != pid
                or identity["session"] != pid
                or not descendant_of(pid, gateway_pid, parents) or wait is None):
            continue
        blocked.append({**identity, **wait})
    return sorted(blocked, key=lambda value: (value["ticks"], value["pid"], value["tid"]))


def inspect(config_dir: Path, proc_root: Path) -> tuple[dict | None, str]:
    if (config_dir / "run-as").exists():
        return None, "run-as-lane"
    run_dir = config_dir / "run"
    owners = [p for p in run_dir.iterdir() if OWNER_NAME.fullmatch(p.name)] if run_dir.is_dir() else []
    if len(owners) != 1:
        return None, "owner-cardinality"
    owner = read_json(owners[0])
    try:
        pid = int(owner["pid"])
        if pid <= 1:
            raise ValueError("invalid pid")
        command = owner["command"]
        expected_config = str(config_dir / "config.json")
        expected_log = config_dir / "logs" / (owners[0].stem + ".log")
        if (not isinstance(command, list) or command[:3] != [
                command[0], "-m", "nanobot"] or "gateway" not in command
                or "--foreground" not in command or "--config" not in command
                or command[command.index("--config") + 1] != expected_config
                or owner["config_path"] != expected_config
                or owner["log_path"] != str(expected_log)):
            return None, "owner-command-mismatch"
        proc = proc_root / str(pid)
        ticks = proc_start_ticks((proc / "stat").read_text(encoding="utf-8"))
        if owner["identity"] != f"{pid}:{ticks}":
            return None, "owner-pid-reused"
        cmdline = (proc / "cmdline").read_bytes().replace(b"\0", b" ").strip()
        if cmdline != b"nanobot-gateway":
            return None, "process-command-mismatch"
        status = (proc / "task" / str(pid) / "status").read_text(encoding="utf-8")
        state_match = re.search(r"^State:\s*([A-Z])", status, re.M)
        wchan = (proc / "task" / str(pid) / "wchan").read_text(encoding="utf-8").strip()
        log = expected_log.stat()
    except (KeyError, IndexError, OSError, TypeError, ValueError):
        return None, "owner-or-proc-unreadable"
    if not state_match:
        return None, "process-state-unreadable"
    workers = blocked_search_workers(proc_root, pid)
    return {"pid": pid, "ticks": ticks, "state": state_match.group(1),
            "wchan": wchan, "log_mtime_ns": log.st_mtime_ns,
            "log_size": log.st_size, "log_inode": log.st_ino,
            "blocked_worker": workers[0] if workers else None,
            "owner": str(owners[0])}, "ok"


def fingerprint(value: dict) -> list[object]:
    worker = value.get("blocked_worker")
    if isinstance(worker, dict):
        return ["worker", value["pid"], value["ticks"], *[
            worker[key] for key in ("pid", "ticks", "pgrp", "session", "tid", "wchan")
        ]]
    return ["gateway", *[value[key] for key in (
        "pid", "ticks", "log_inode", "log_mtime_ns", "log_size"
    )]]


def assess(current: dict | None, reason: str, state: dict, now: float,
           confirm_seconds: float, cooldown: float, max_failures: int) -> tuple[dict, dict]:
    if current is None:
        state.pop("suspect", None)
        return {"status": "skip", "reason": reason}, state
    blocked_worker = current.get("blocked_worker")
    gateway_blocked = current["state"] == "D" and NFS_WAIT.search(current["wchan"])
    if not isinstance(blocked_worker, dict) and not gateway_blocked:
        state.pop("suspect", None)
        return {"status": "healthy", "reason": "no-nfs-d-state"}, state
    mark = fingerprint(current)
    suspect = state.get("suspect")
    if not isinstance(suspect, dict) or suspect.get("fingerprint") != mark:
        state["suspect"] = {"fingerprint": mark, "since": now}
        return {"status": "suspect", "reason": "confirmation-pending"}, state
    if now - float(suspect["since"]) < confirm_seconds:
        return {"status": "suspect", "reason": "confirmation-pending"}, state
    if now - float(state.get("last_attempt", 0)) < cooldown:
        return {"status": "skip", "reason": "cooldown"}, state
    if int(state.get("failures", 0)) >= max_failures:
        return {"status": "alert", "reason": "failure-cap"}, state
    return {"status": "terminate-worker" if isinstance(blocked_worker, dict) else "recover",
            "reason": "confirmed-search-worker-wedge" if isinstance(blocked_worker, dict)
                      else "confirmed-nfs-wedge",
            "pid": blocked_worker["pid"] if isinstance(blocked_worker, dict) else current["pid"],
            "fingerprint": mark}, state


def run_manager(manager: Path, verb: str, timeout: float) -> subprocess.CompletedProcess[str]:
    return subprocess.run([str(manager), verb, "nanobot"], capture_output=True,
                          text=True, timeout=timeout, check=False)


def terminate_worker(args: argparse.Namespace, before: dict, state: dict,
                     event_path: Path) -> dict:
    fresh, reason = inspect(args.config_dir, args.proc_root)
    worker = fresh.get("blocked_worker") if isinstance(fresh, dict) else None
    if (fresh is None or fingerprint(fresh) != fingerprint(before)
            or not isinstance(worker, dict)):
        return {"status": "skip", "reason": f"worker-changed-before-signal:{reason}"}
    state["last_attempt"] = time.time()
    state.pop("suspect", None)
    try:
        os.killpg(worker["pgrp"], signal.SIGKILL)
    except OSError as exc:
        state["failures"] = int(state.get("failures", 0)) + 1
        save_json(args.state_path, state)
        ledger(event_path, "worker-termination-failed", pid=worker["pid"],
               error_class=type(exc).__name__)
        alert(args, state, event_path, "worker-termination-failed",
              f"Nano watchdog on {socket.gethostname()}: isolated search worker could not be signalled; operator review needed.")
        return {"status": "alert", "reason": "search-worker-signal-failed"}
    state["failures"] = 0
    save_json(args.state_path, state)
    ledger(event_path, "worker-termination-requested", pid=worker["pid"],
           pgrp=worker["pgrp"], tid=worker["tid"], gateway_pid=before["pid"])
    alert(args, state, event_path, "worker-termination-requested",
          f"Nano watchdog on {socket.gethostname()}: isolated search worker termination requested; gateway left online.")
    return {"status": "worker-termination-requested",
            "reason": "confirmed-search-worker-wedge", "pid": worker["pid"]}


def recover(args: argparse.Namespace, before: dict, state: dict, event_path: Path) -> dict:
    fresh, reason = inspect(args.config_dir, args.proc_root)
    if fresh is None or fingerprint(fresh) != fingerprint(before) or fresh["state"] != "D" or not NFS_WAIT.search(fresh["wchan"]):
        return {"status": "skip", "reason": f"changed-before-restart:{reason}"}
    state["last_attempt"] = time.time()
    save_json(args.state_path, state)
    ledger(event_path, "recovery-attempt", pid=before["pid"])
    try:
        stopped = run_manager(args.manager, "stop", args.command_timeout)
    except subprocess.TimeoutExpired:
        stopped = None
    if stopped is None or stopped.returncode != 0 or (args.proc_root / str(before["pid"])).exists():
        state["failures"] = int(state.get("failures", 0)) + 1
        save_json(args.state_path, state)
        ledger(event_path, "recovery-failed", pid=before["pid"], phase="stop")
        alert(args, state, event_path, "recovery-failed",
              f"Nano watchdog on {socket.gethostname()}: recovery failed at stop; operator review needed.")
        return {"status": "alert", "reason": "nano-did-not-stop"}
    try:
        started = run_manager(args.manager, "start", args.command_timeout)
    except subprocess.TimeoutExpired:
        started = None
    after, _ = inspect(args.config_dir, args.proc_root)
    success = (started is not None and started.returncode == 0 and after is not None
               and [after["pid"], after["ticks"]] != [before["pid"], before["ticks"]])
    state["failures"] = 0 if success else int(state.get("failures", 0)) + 1
    state.pop("suspect", None)
    save_json(args.state_path, state)
    ledger(event_path, "recovered" if success else "recovery-failed",
           old_pid=before["pid"], new_pid=after["pid"] if after else None,
           phase="start")
    alert(args, state, event_path, "recovered" if success else "recovery-failed",
          f"Nano watchdog on {socket.gethostname()}: "
          + ("nanobot recovered." if success else "recovery failed at start; operator review needed."))
    return {"status": "recovered" if success else "alert",
            "reason": "nano-restarted" if success else "nano-did-not-start"}


def run(args: argparse.Namespace, now: float | None = None) -> dict:
    if socket.gethostname() != args.expected_host:
        return {"status": "skip", "reason": "wrong-host"}
    now = time.time() if now is None else now
    if not args.dry_run:
        args.state_path.parent.mkdir(parents=True, exist_ok=True, mode=0o700)
    lock_path = args.state_path.with_name("watchdog.lock")
    with lock_path.open("a+", encoding="utf-8") if not args.dry_run else open(os.devnull) as lock:
        if not args.dry_run:
            try:
                fcntl.flock(lock.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
            except BlockingIOError:
                return {"status": "skip", "reason": "already-running"}
        before, reason = inspect(args.config_dir, args.proc_root)
        state = read_json(args.state_path)
        decision, state = assess(before, reason, state, now, args.confirm_seconds,
                                 args.cooldown, args.max_failures)
        if args.dry_run:
            return {**decision, "status": "dry-run" if decision["status"] == "recover" else decision["status"]}
        save_json(args.state_path, state)
        if decision["status"] == "terminate-worker" and before is not None:
            return terminate_worker(args, before, state,
                                    args.state_path.with_name("events.jsonl"))
        if decision["status"] == "recover" and before is not None:
            return recover(args, before, state, args.state_path.with_name("events.jsonl"))
        if decision["status"] == "alert":
            event_path = args.state_path.with_name("events.jsonl")
            ledger(event_path, "failure-cap")
            alert(args, state, event_path, "failure-cap",
                  f"Nano watchdog on {socket.gethostname()}: recovery failure cap reached; operator review needed.")
        return decision

* OpenCode survival watchdog

The OpenCode pair is a host-managed headless service on Kikin. This watchdog is
scheduled outside OpenCode and therefore must never be launched as a synchronous
child of the session it may need to restart. It checks the versioned owner claim,
the exact backend and poller identities, and a bounded loopback API probe. It
only heals an existing owner state whose failure is limited to a missing backend,
missing poller, or unreachable local API; missing owner state and identity
mismatches remain operator-visible skips, so an intentional stop is not undone.
The first observation is persisted and must survive the confirmation interval.
Recovery is dispatched with a new session and recorded under the private XDG
state directory. The cron installer is explicit and dry-run capable; tangling
does not install a privileged schedule.

Turn health is assisted separately from process health. When the owner and API
are healthy, the watchdog reads the bound session's status and newest
incomplete assistant message over the same bounded loopback probe. A turn whose
part fingerprint has not moved for the stall interval is aborted once — the
line between thinking and wedged is time, so the interval is generous and the
only default action is an abort. Escalation is deliberate: if stalls abort
twice inside the escalation window, the same detached worker used for process
faults is dispatched, because a poisoned turn can survive the abort inside the
running process.

def read_json(path: pathlib.Path) -> dict | None:
    try:
        value = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return None
    return value if isinstance(value, dict) else None


def atomic_json(path: pathlib.Path, value: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, temporary = tempfile.mkstemp(prefix=f".{path.name}.", dir=path.parent)
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as stream:
            json.dump(value, stream, sort_keys=True, separators=(",", ":"))
            stream.write("\n")
            stream.flush()
            os.fsync(stream.fileno())
        os.chmod(temporary, 0o600)
        os.replace(temporary, path)
    finally:
        try:
            os.unlink(temporary)
        except FileNotFoundError:
            pass


def log_event(path: pathlib.Path, **fields: object) -> None:
    try:
        path.parent.mkdir(parents=True, exist_ok=True)
        with path.open("a", encoding="utf-8") as stream:
            stream.write(json.dumps({"timestamp": time.time(), **fields}, sort_keys=True) + "\n")
        os.chmod(path, 0o600)
    except OSError:
        pass


def emit(value: dict, json_output: bool) -> None:
    if json_output:
        print(json.dumps(value, sort_keys=True, separators=(",", ":")))
    else:
        print(f"OpenCode watchdog: {value.get('status')} ({value.get('reason')})")


def host_matches(expected: str) -> bool:

def owner_inspect(args: argparse.Namespace) -> tuple[dict | None, int, str]:
    command = [
        str(pathlib.Path(args.owner).expanduser()),
        "inspect",
        "--state", str(pathlib.Path(args.owner_state).expanduser()),
        "--project", str(pathlib.Path(args.project).expanduser()),
        "--host", "127.0.0.1",
        "--port", str(args.port),
    ]
    try:
        completed = subprocess.run(command, capture_output=True, text=True, timeout=args.command_timeout)
    except (OSError, subprocess.TimeoutExpired) as error:
        return None, 124, type(error).__name__
    try:
        payload = json.loads(completed.stdout)
    except (TypeError, ValueError):
        return None, completed.returncode, "owner-invalid-json"
    if not isinstance(payload, dict):
        return None, completed.returncode, "owner-invalid-document"
    return payload, completed.returncode, completed.stderr.strip()


def api_probe(port: int, timeout: float) -> dict:
    request = Request(f"http://127.0.0.1:{port}/", headers={"Accept": "application/json"})
    try:
        with urlopen(request, timeout=timeout) as response:
            return {"status": "healthy" if response.status == 200 else "unhealthy", "http_status": response.status}
    except HTTPError as error:
        return {"status": "unhealthy", "http_status": error.code, "reason": "api-unreachable"}
    except (OSError, URLError, TimeoutError) as error:
        return {"status": "unhealthy", "reason": "api-unreachable", "error": type(error).__name__}


def api_json(port: int, path: str, timeout: float, method: str = "GET") -> tuple[int, object | None]:
    """Bounded loopback JSON call; transport errors propagate to the caller."""
    data = b"" if method != "GET" else None
    request = Request(
        f"http://127.0.0.1:{port}{path}",
        data=data,
        headers={"Accept": "application/json"},
        method=method,
    )
    try:
        with urlopen(request, timeout=timeout) as response:
            raw = response.read()
            status = int(response.status)
    except HTTPError as error:
        raw = error.read()
        status = int(error.code)
    if not raw:
        return status, None
    try:
        return status, json.loads(raw.decode("utf-8"))
    except (UnicodeDecodeError, ValueError):
        return status, None


def owner_session(owner_state: pathlib.Path) -> str | None:
    owner = read_json(owner_state)
    if not isinstance(owner, dict):
        return None
    binding = owner.get("session_binding")
    if not isinstance(binding, dict) or binding.get("status") != "bound":
        return None
    session_id = binding.get("session_id")
    if not isinstance(session_id, str) or not SESSION_RE.fullmatch(session_id):
        return None
    return session_id


def session_busy(payload: object, session_id: str) -> bool | None:
    if not isinstance(payload, dict):
        return None
    if session_id not in payload:
        return False
    row = payload.get(session_id)
    kind = row.get("type", row.get("status")) if isinstance(row, dict) else None
    if not isinstance(kind, str):
        return None
    normalized = kind.lower()
    if normalized == "idle":
        return False
    if normalized in {"busy", "retry", "working", "running", "compacting"}:
        return True
    return None


def turn_state(payload: object) -> dict | None:
    """Describe the newest incomplete assistant turn's progress fingerprint."""
    if not isinstance(payload, list):
        return None
    latest = None
    for row in payload:
        if not isinstance(row, dict):
            continue
        info = row.get("info") if isinstance(row.get("info"), dict) else row
        if info.get("role") != "assistant":
            continue
        timing = info.get("time") if isinstance(info.get("time"), dict) else {}
        if timing.get("completed") is not None:
            continue
        latest = (row, info)
    if latest is None:
        return None
    row, info = latest
    parts = row.get("parts") if isinstance(row.get("parts"), list) else []
    material: list[list[object]] = []
    running_tools = 0
    for part in parts:
        if not isinstance(part, dict):
            continue
        kind = part.get("type")
        entry: list[object] = [kind]
        if kind == "tool":
            block = part.get("state") if isinstance(part.get("state"), dict) else {}
            timing = block.get("time") if isinstance(block.get("time"), dict) else {}
            entry.extend((part.get("tool"), block.get("status"), timing.get("start"), timing.get("end")))
            if block.get("status") == "running":
                running_tools += 1
        elif kind in {"text", "reasoning"}:
            entry.append(len(part.get("text") or ""))
        else:
            timing = part.get("time") if isinstance(part.get("time"), dict) else {}
            entry.extend((timing.get("start"), timing.get("end")))
        material.append(entry)
    fingerprint = hashlib.sha256(
        json.dumps([info.get("id"), material], sort_keys=True, separators=(",", ":")).encode()
    ).hexdigest()
    return {
        "message_id": info.get("id"),
        "fingerprint": fingerprint,
        "parts": len(parts),
        "running_tools": running_tools,
    }


def assess_turn_stall(args: argparse.Namespace, state: dict, state_path: pathlib.Path) -> dict:
    """Abort one confirmed stalled turn; escalate when stalls repeat."""
    if not args.turn_stall:
        return {"status": "disabled"}
    session_id = owner_session(pathlib.Path(args.owner_state).expanduser())
    if session_id is None:
        return {"status": "skip", "reason": "session-binding-unavailable"}
    try:
        status_code, status_payload = api_json(args.port, "/session/status", args.api_timeout)
        if status_code != 200:
            return {"status": "skip", "reason": "session-status-unavailable"}
        busy = session_busy(status_payload, session_id)
        if busy is None:
            return {"status": "skip", "reason": "session-status-unknown"}
        if not busy:
            cleared = any(
                key in state for key in ("stall_fingerprint", "stall_since", "stall_message_id")
            )
            state.pop("stall_fingerprint", None)
            state.pop("stall_since", None)
            state.pop("stall_message_id", None)
            if cleared and not args.dry_run:
                atomic_json(state_path, state)
            return {"status": "clear"}
        message_code, messages = api_json(
            args.port,
            f"/session/{quote(session_id, safe='')}/message",
            args.api_timeout,
        )
        if message_code != 200:
            return {"status": "skip", "reason": "session-messages-unavailable"}
        turn = turn_state(messages)
    except (OSError, URLError, TimeoutError) as error:
        return {"status": "skip", "reason": f"session-probe-{type(error).__name__}"}
    if turn is None:
        return {"status": "skip", "reason": "no-incomplete-assistant-message"}
    now = time.time()
    if state.get("stall_fingerprint") != turn["fingerprint"]:
        state.update({
            "stall_fingerprint": turn["fingerprint"],
            "stall_since": now,
            "stall_message_id": turn["message_id"],
        })
        if not args.dry_run:
            atomic_json(state_path, state)
        return {
            "status": "progress",
            "message_id": turn["message_id"],
            "running_tools": turn["running_tools"],
        }
    try:
        first_seen = float(state.get("stall_since", 0) or 0)
    except (TypeError, ValueError):
        first_seen = now
    stalled_for = max(0.0, now - first_seen)
    if stalled_for < args.turn_stall_seconds:
        return {
            "status": "waiting",
            "stalled_for": round(stalled_for, 1),
            "threshold": args.turn_stall_seconds,
        }
    if args.dry_run:
        return {
            "status": "would-abort",
            "stalled_for": round(stalled_for, 1),
            "message_id": turn["message_id"],
        }
    try:
        abort_code, _ = api_json(
            args.port,
            f"/session/{quote(session_id, safe='')}/abort",
            args.api_timeout,
            method="POST",
        )
    except (OSError, URLError, TimeoutError):
        abort_code = None
    window = args.stall_escalate_window
    aborts = [
        float(item)
        for item in state.get("stall_aborts", [])
        if isinstance(item, (int, float))
        and not isinstance(item, bool)
        and now - float(item) <= window
    ]
    aborts.append(now)
    escalate = len(aborts) >= args.stall_escalate_count
    state.update({
        "stall_aborts": [] if escalate else aborts[-8:],
        "last_stall_abort": now,
        "last_stall_abort_status": abort_code,
        "stall_since": now,
    })
    if escalate:
        state["last_stall_escalation"] = now
    atomic_json(state_path, state)
    events = state_path.with_name("events.jsonl")
    log_event(
        events, action="turn-stall-abort", abort_status=abort_code,
        stalled_for=round(stalled_for, 1), message_id=turn["message_id"],
        running_tools=turn["running_tools"], escalate=escalate,
    )
    result = {
        "status": "stalled-escalated" if escalate else "stalled-aborted",
        "abort_status": abort_code,
        "stalled_for": round(stalled_for, 1),
        "message_id": turn["message_id"],
        "running_tools": turn["running_tools"],
    }
    if escalate:
        dispatch_worker(args, state_path.with_name("recovery.log"))
        log_event(events, action="turn-stall-escalation", result="dispatched",
                  message_id=turn["message_id"])
        result["escalation"] = "worker-restart-dispatched"
    return result

def run_command(command: list[str], args: argparse.Namespace, stream) -> subprocess.CompletedProcess:
    stream.write(f"command={json.dumps(command)}\n")
    stream.flush()
    try:
        completed = subprocess.run(
            command,
            stdin=subprocess.DEVNULL,
            stdout=stream,
            stderr=subprocess.STDOUT,
            text=True,
            timeout=args.command_timeout,
            env=args.environment,
        )
    except (OSError, subprocess.TimeoutExpired) as error:
        stream.write(f"error={type(error).__name__}\n")
        stream.flush()
        return subprocess.CompletedProcess(command, 124)
    stream.write(f"returncode={completed.returncode}\n")
    stream.flush()
    return completed


def worker(args: argparse.Namespace) -> int:
    state_path = pathlib.Path(args.watchdog_state).expanduser()
    event_path = state_path.with_name("events.jsonl")
    log_path = state_path.with_name("recovery.log")
    manager = str(pathlib.Path(args.manager).expanduser())
    with log_path.open("a", encoding="utf-8") as stream:
        stream.write(f"worker-start={time.time()}\n")
        stop = run_command([manager, "stop", "opencode"], args, stream)
        start = run_command([manager, "start", "opencode"], args, stream)
        payload, inspect_code, detail = owner_inspect(args)
        probe = api_probe(args.port, args.api_timeout) if payload and payload.get("status") == "running" else {"status": "not-probed"}
        healthy = inspect_code == 0 and payload is not None and payload.get("status") == "running" and probe.get("status") == "healthy"
        stream.write(f"worker-result={'success' if healthy else 'failed'}\n")
    state = read_json(state_path) or {"schema": SCHEMA, "failures": 0}
    state.update({"last_worker": time.time(), "last_result": "recovered" if healthy else "failed"})
    state["failures"] = 0 if healthy else int(state.get("failures", 0)) + 1
    if healthy:
        state.pop("degraded_since", None)
        state.pop("degraded_fingerprint", None)
        state.pop("last_alert", None)
    atomic_json(state_path, state)
    log_event(event_path, action="recovery", result=state["last_result"], stop=stop.returncode, start=start.returncode, inspect=detail)
    return 0 if healthy else 1

def assess_and_dispatch(args: argparse.Namespace, state_path: pathlib.Path) -> int:
    event_path = state_path.with_name("events.jsonl")
    state = read_json(state_path) or {"schema": SCHEMA, "failures": 0}
    payload, inspect_code, detail = owner_inspect(args)
    if payload is None:
        value = {"schema": SCHEMA, "status": "skip", "reason": detail, "inspect_code": inspect_code}
        emit(value, args.json)
        return 0

    probe = api_probe(args.port, args.api_timeout) if payload.get("status") == "running" else {"status": "not-probed"}
    reasons = set(str(reason) for reason in payload.get("reasons", []))
    if probe.get("reason") == "api-unreachable":
        reasons.add("api-unreachable")
    if not reasons:
        state.update({"last_healthy": time.time(), "failures": 0})
        state.pop("degraded_since", None)
        state.pop("degraded_fingerprint", None)
        state.pop("last_alert", None)
        if not args.dry_run:
            atomic_json(state_path, state)
        turn = assess_turn_stall(args, state, state_path)
        if turn.get("status") in {"stalled-aborted", "stalled-escalated"}:
            emit({
                "schema": SCHEMA,
                "status": "turn-stall-escalated" if turn["status"] == "stalled-escalated" else "turn-stall-aborted",
                "reason": "turn-stall",
                "probe": probe,
                "turn": turn,
            }, args.json)
            return 0
        value = {"schema": SCHEMA, "status": "healthy", "reason": "owner-and-api-healthy", "probe": probe}
        if turn.get("status") not in {"clear", "disabled", "skip"}:
            value["turn"] = turn
        emit(value, args.json)
        return 0

    if not reasons.issubset(SAFE_REASONS) or payload.get("status") == "stopped":
        emit({"schema": SCHEMA, "status": "skip", "reason": "owner-not-safe-to-restart", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0

    now = time.time()
    current_fingerprint = fingerprint(payload, probe)
    if state.get("degraded_fingerprint") != current_fingerprint:
        state.update({"degraded_since": now, "degraded_fingerprint": current_fingerprint})
        if not args.dry_run:
            atomic_json(state_path, state)
        emit({"schema": SCHEMA, "status": "suspect", "reason": "confirmation-pending", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0
    if now - float(state.get("degraded_since", now)) < args.confirm_seconds:
        emit({"schema": SCHEMA, "status": "suspect", "reason": "confirmation-pending", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0
    if now - float(state.get("last_attempt", 0)) < args.cooldown:
        emit({"schema": SCHEMA, "status": "skip", "reason": "cooldown", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0
    if int(state.get("failures", 0)) >= args.max_failures:
        if now - float(state.get("last_alert", 0)) < args.alert_cooldown:
            emit({"schema": SCHEMA, "status": "alert", "reason": "failure-alert-cooldown", "failures": state.get("failures", 0)}, args.json)
            return 0
        state["last_alert"] = now
        if not args.dry_run:
            atomic_json(state_path, state)
        emit({"schema": SCHEMA, "status": "alert", "reason": "recovery-failure-threshold", "failures": state.get("failures", 0)}, args.json)
        return 0
    if args.dry_run:
        emit({"schema": SCHEMA, "status": "dry-run", "reason": "would-dispatch-recovery", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0

    state.update({"last_attempt": now, "last_reason": sorted(reasons)})
    atomic_json(state_path, state)
    dispatch_worker(args, state_path.with_name("recovery.log"))
    log_event(event_path, action="dispatch", result="dispatched", reasons=sorted(reasons), fingerprint=current_fingerprint)
    emit({"schema": SCHEMA, "status": "dispatched", "reason": "detached-recovery", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
    return 0


def run(args: argparse.Namespace) -> int:
    if not host_matches(args.expected_host):
        value = {"schema": SCHEMA, "status": "skip", "reason": "wrong-host", "expected_host": args.expected_host}
        emit(value, args.json)
        return 0
    args.environment = runtime_environment()
    if args.worker:
        return worker(args)

    state_path = pathlib.Path(args.watchdog_state).expanduser()
    if args.dry_run:
        return assess_and_dispatch(args, state_path)
    state_path.parent.mkdir(parents=True, exist_ok=True)
    lock_path = state_path.with_name("watchdog.lock")
    with lock_path.open("a+", encoding="utf-8") as lock:
        try:
            fcntl.flock(lock.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
        except BlockingIOError:
            emit({"schema": SCHEMA, "status": "skip", "reason": "watchdog-already-running"}, args.json)
            return 0
        return assess_and_dispatch(args, state_path)

* Telegram agent boot owner

The host manager already owns exact enabled-agent selection and readiness.  This
boot wrapper adds only bounded initial launch, per-agent retry, locking, receipts,
and log retention; one failed agent cannot suppress the other enabled agents.
The installed cron owner supplies the Guix core profile explicitly, while the
manager binds Ductor to its canonical supervisor path and OpenCode to the core
Node runtime.  Cold boot therefore does not depend on an interactive shell's
ambient =PATH= and never duplicates agent-specific process ownership.

The boot lock (fd 9 on =boot.lock=) must never be inherited by the agents this
wrapper spawns.  An flock is released only when every fd on its open-file-description
closes, and the daemonized agents never exit — so a leaked fd 9 pins the lock for
the life of the machine.  Once pinned, every later boot run (including the periodic
self-heal cron) fails =flock -n= and silently skips the entire spawn, so an agent
that failed at first boot is never retried and must be relaunched by hand.  The
=start= call therefore closes fd 9 in the child (=9>&-=): the lock stays held by this
short-lived boot process alone and is released cleanly when the boot run exits.
(Root-caused 2026-09-18 after a kikin-kushi reboot where ductor/hermes/gemma/codex
were all still holding =boot.lock=.)

    def test_boot_lock_not_inherited_by_spawned_child(self) -> None:
        # A daemonized agent must never inherit the boot lock (fd 9). If it does,
        # the flock stays held for the agent's whole lifetime and every later boot
        # -- including the self-heal cron -- fails flock -n and skips the spawn.
        # The manager is a shell that backgrounds a lingering child WITHOUT closing
        # fds (mimicking the real host); Python's own Popen would auto-close fds and
        # hide the very leak this guards against.
        self.state.mkdir(parents=True)
        pid_file = self.root / "child.pid"
        self.manager.write_text(
            "#!/usr/bin/env bash\n"
            'case "$1" in\n'
            "  enabled) echo one ;;\n"
            # Detach the child's stdio from the captured pipe (else run_boot blocks
            # on it for 30s); fd 9 is untouched, so the inheritance check stays valid.
            f'  start) sleep 30 </dev/null >/dev/null 2>&1 & echo "$!" > {str(pid_file)!r} ;;\n'
            "esac\n",
            encoding="utf-8",
        )
        self.manager.chmod(self.manager.stat().st_mode | stat.S_IXUSR)
        result = self.run_boot("--attempts", "1")
        self.assertEqual(result.returncode, 0, result.stderr)
        child = int(pid_file.read_text().strip())
        try:
            fd_dir = Path("/proc") / str(child) / "fd"
            holders = []
            if fd_dir.exists():
                for fd in fd_dir.iterdir():
                    try:
                        target = os.readlink(str(fd))
                    except OSError:
                        continue
                    if target.rsplit("/", 1)[-1] == "boot.lock":
                        holders.append((fd.name, target))
            self.assertEqual(holders, [], "spawned child inherited the boot lock: %r" % (holders,))
        finally:
            try:
                os.kill(child, 9)
            except ProcessLookupError:
                pass

pid_file_has_command() {
    local pid_file="$1" expected="$2" pid argument
    [ -r "$pid_file" ] || return 1
    IFS= read -r pid < "$pid_file" || return 1
    case "$pid" in ''|*[!0-9]*) return 1 ;; esac

    while IFS= read -r -d '' argument; do
        [ "${argument##*/}" = "$expected" ] && return 0
    done < "/proc/$pid/cmdline"
    return 1
}

# Hermes records its own gateway identity as JSON (pid, kernel start-time ticks,
# argv) in $HERMES_HOME/gateway.pid. That record, checked against /proc, is the
# authority for "is the gateway up": matching the process name (pgrep -x hermes)
# misses a gateway launched through the managed Python launcher (it runs as
# python3) and false-positives on any other process named hermes, such as an
# interactive session.
HERMES_GATEWAY_PID_FILE="${HERMES_GATEWAY_PID_FILE:-${HERMES_HOME:-$HOME/.hermes}/gateway.pid}"

hermes_gateway_pid() {
    python3 - "$HERMES_GATEWAY_PID_FILE" <<'PY'
import json
import sys

try:
    with open(sys.argv[1], encoding="utf-8") as handle:
        record = json.load(handle)
    pid = int(record["pid"])
    with open(f"/proc/{pid}/stat", encoding="utf-8") as handle:
        fields = handle.read().rsplit(")", 1)[1].split()
    # A zombie has exited; only its parent has yet to reap it.
    if fields[0] != "Z" and str(record["start_time"]) == fields[19]:
        print(pid)
except (OSError, ValueError, KeyError, IndexError, TypeError):
    pass
PY
}

# Privilege drop (Agent Boundaries phase 8, 2026-09-26). When the operator's
# non-secret run-as file names an agent user, start/stop/status re-run this
# script as that user, so every path it resolves from $HOME (env, token, key,
# DSH home, state dir, log, pid, readiness marker) lives in the agent's home and
# the operator's home stays sealed. Returns 3 when no delegation applies.
#
# Generic form: agent_run_as_delegate VERB AGENT RUN_AS_FILE [EXTRA_PATH [ENV...]].
# EXTRA_PATH is appended after the agent's own bins (read-only operator tool
# profiles, never anything under a sealed home); ENV entries are NAME=VALUE
# pairs passed explicitly through the clean environment.
agent_run_as_delegate() {
    local verb="$1" agent="$2" run_as_file="$3" extra_path="${4:-}" target thome self runtime_path
    shift 4 2>/dev/null || shift $#
    [ -r "$run_as_file" ] || return 3
    target="$(head -n1 "$run_as_file" | tr -d '[:space:]')"
    [ -n "$target" ] || return 3
    [ "$(id -un)" != "$target" ] || return 3
    thome="$(getent passwd "$target" | cut -d: -f6)"
    if [ -z "$thome" ]; then
        echo "$agent run-as user is missing: $target" >&2
        return 1
    fi
    self="$(readlink -f "$0")"
    runtime_path="$thome/.guix-extra-profiles/agent/agent/bin:$thome/.npm-global/bin${extra_path:+:$extra_path}:/usr/local/bin:/usr/bin:/bin"
    # cwd /tmp: sudo keeps the caller's cwd, which the sealed home refuses.
    (cd /tmp && sudo -n -u "$target" -H env -i \
        HOME="$thome" USER="$target" LOGNAME="$target" LANG=C.UTF-8 \
        PATH="$runtime_path" AGENT_RUNTIME_PATH="$runtime_path" \
        DOTCORTEX_AGENTS_DIR="$AGENTS_DIR" "$@" \
        bash "$self" "$verb" "$agent")
}

deepseek_harness_delegate() {

        "${DSH_TELEGRAM_RUN_AS_FILE:-$HOME/.config/deepseek-harness-telegram/run-as}" ""
}

deepseek_harness_acquire_start_lock() {
    local lock_fd
    command -v flock >/dev/null 2>&1 || {
        echo "DeepSeek Harness start lock requires flock" >&2
        return 1
    }
    exec {lock_fd}>"$DSH_TELEGRAM_START_LOCK"
    if ! flock -n "$lock_fd"; then
        eval "exec ${lock_fd}>&-"
        echo "Refusing DeepSeek Harness start: another DeepSeek Harness starter holds the launch lock" >&2
        return 1
    fi
    DSH_TELEGRAM_START_LOCK_FD="$lock_fd"
}

deepseek_harness_release_start_lock() {
    if [ -n "${DSH_TELEGRAM_START_LOCK_FD:-}" ]; then
        eval "exec ${DSH_TELEGRAM_START_LOCK_FD}>&-"
        DSH_TELEGRAM_START_LOCK_FD=""
    fi
}

deepseek_harness_kill_owned() {
    local pid="$1" expected_ticks="$2" current_ticks pgid
    deepseek_harness_pid_matches "$pid" || return 1
    current_ticks="$(deepseek_harness_start_ticks "$pid" 2>/dev/null)" || return 1
    [ "$current_ticks" = "$expected_ticks" ] || return 1
    pgid="$(ps -o pgid= -p "$pid" 2>/dev/null | tr -d ' ' || true)"
    if [ "$pgid" = "$pid" ]; then
        kill -TERM -- "-$pgid" 2>/dev/null || true
    else
        kill -TERM "$pid" 2>/dev/null || true
    fi
    for _ in {1..20}; do
        deepseek_harness_pid_matches "$pid" || return 0
        sleep 0.25
    done
    if [ "$pgid" = "$pid" ]; then
        kill -KILL -- "-$pgid" 2>/dev/null || true
    else
        kill -KILL "$pid" 2>/dev/null || true
    fi
    ! deepseek_harness_pid_matches "$pid"
}

deepseek_harness_wait_ready() {

    for ((i = 0; i < attempts; i += 1)); do

            deepseek_harness_ready && return 0
        fi
        sleep 0.5
    done
    if deepseek_harness_ready; then
        sleep 0.1
        deepseek_harness_ready
    else
        return 1
    fi
}

deepseek_harness_find_unowned() {
    python3 - "$$" "$DSH_TELEGRAM_PROFILE" "$DSH_TELEGRAM_PID_FILE" <<'PY'
from pathlib import Path
import sys

self_pid = int(sys.argv[1])
profile = sys.argv[2]
pid_file = Path(sys.argv[3])
owned = None
try:
    owned = int(pid_file.read_text().strip())
except Exception:
    pass

for proc in Path("/proc").iterdir():
    if not proc.name.isdigit():
        continue
    pid = int(proc.name)
    if pid in {self_pid, owned}:
        continue
    try:
        raw = (proc / "cmdline").read_bytes().split(b"\0")
    except OSError:
        continue
    argv = [part.decode("utf-8", "replace") for part in raw if part]
    if not argv:
        continue
    if "dsh" not in {Path(arg).name for arg in argv}:
        continue
    for idx, arg in enumerate(argv[:-1]):
        if arg == "--profile" and argv[idx + 1] == profile:
            print(pid)
            raise SystemExit(0)
raise SystemExit(1)
PY
}

deepseek_harness_rotate_log() {
    local log="$DSH_TELEGRAM_LOG_FILE" max="$DSH_TELEGRAM_LOG_MAX_BYTES" keep="$DSH_TELEGRAM_LOG_KEEP"
    case "$max" in ''|*[!0-9]*) max=10485760 ;; esac
    case "$keep" in ''|*[!0-9]*) keep=5 ;; esac
    [ -f "$log" ] || return 0
    local size
    size=$(wc -c < "$log" 2>/dev/null || printf '0')
    [ "$size" -le "$max" ] && return 0
    local i prev
    i="$keep"
    while [ "$i" -gt 1 ]; do
        prev=$((i - 1))
        [ -f "$log.$prev" ] && mv "$log.$prev" "$log.$i"
        i="$prev"
    done
    mv "$log" "$log.1"
}

deepseek_harness_load_env() {
    local env_file="$DSH_TELEGRAM_ENV_FILE" mode key value
    if [ ! -f "$env_file" ]; then
        echo "DeepSeek Harness private env file is missing: $env_file" >&2
        return 1
    fi
    mode=$(stat -c '%a' "$env_file" 2>/dev/null || printf '000')
    if [ "$mode" != "600" ]; then
        echo "DeepSeek Harness private env file must be mode 0600: $env_file" >&2
        return 1
    fi
    while IFS='=' read -r key value; do
        key="${key#export }"
        key="${key%$'\r'}"
        value="${value%$'\r'}"
        case "$key" in ''|\#*) continue ;; esac
        case "$key" in
            TELEGRAM_BOT_TOKEN_FILE|OPENCODE_GO_API_KEY_FILE|\
            DSH_HOME|DSH_TELEGRAM_PROFILE|DSH_TELEGRAM_WORKSPACE|DSH_TELEGRAM_PLUGIN_ROOT|\
            DSH_TELEGRAM_MODEL_PROVIDER|DSH_TELEGRAM_MODEL|DSH_TELEGRAM_PROVIDER_BASE_URL|\
            DSH_RECALL_MCP_URL)
                value="${value%\"}"
                value="${value#\"}"
                value="${value%\'}"
                value="${value#\'}"
                export "$key=$value"
                ;;
        esac
    done < "$env_file"
}

        if [ -z "$recall_url" ]; then

            return 1

        sed "s|@DSH_RECALL_MCP_URL@|$recall_url|g" "$DSH_TELEGRAM_PROFILE_PATCH_TEMPLATE" > "$output"
    else
        cp "$DSH_TELEGRAM_PROFILE_PATCH_TEMPLATE" "$output"
    fi
}

    fi
    if [ "$(stat -c '%a' "$token_file" 2>/dev/null || printf '000')" != "600" ]; then
        echo "DeepSeek Harness token file must be mode 0600: $token_file" >&2
        return 1
    fi
    if [ ! -s "$token_file" ]; then
        echo "DeepSeek Harness token file is empty: $token_file" >&2
        return 1
    fi

    key_file="${OPENCODE_GO_API_KEY_FILE:-}"

        return 1

        echo "DeepSeek Harness OpenCode Go settings template is missing: $DSH_TELEGRAM_SETTINGS_TEMPLATE" >&2

deepseek_harness_preflight_model() {
    env -u DEEPSEEK_API_KEY -u DEEPSEEK_API_KEY_FILE -u NEURALWATT_API_KEY -u OPENCODE_API_KEY -u OPENCODE_GO_API_KEY \
        OPENCODE_GO_API_KEY_FILE="$OPENCODE_GO_API_KEY_FILE" \
        DSH_TELEGRAM_PROVIDER_BASE_URL="$DSH_TELEGRAM_PROVIDER_BASE_URL" \
        DSH_TELEGRAM_MODEL="$DSH_TELEGRAM_MODEL" \
        python3 - <<'PY'
import json
import os
import ssl
import sys
from urllib.error import HTTPError, URLError
from urllib.request import Request, urlopen

from pathlib import Path

base_url = os.environ["DSH_TELEGRAM_PROVIDER_BASE_URL"].rstrip("/")
model = os.environ["DSH_TELEGRAM_MODEL"]
api_key = Path(os.environ["OPENCODE_GO_API_KEY_FILE"]).read_text(encoding="utf-8").splitlines()[0]
request = Request(
    f"{base_url}/models",
    headers={"Authorization": f"Bearer {api_key}", "User-Agent": "telegram-agent-host/preflight"},
)
try:
    # Cron's Python trust path may differ from the interactive shell's. Pin the
    # system CA bundle instead of relying on ambient SSL_CERT_FILE/SSL_CERT_DIR.
    context = ssl.create_default_context(cafile="/etc/ssl/certs/ca-certificates.crt")
    with urlopen(request, timeout=15, context=context) as response:
        payload = json.load(response)
except HTTPError as exc:
    print(f"OpenCode Go model visibility preflight failed: HTTP {exc.code}", file=sys.stderr)
    raise SystemExit(1)
except (URLError, TimeoutError, OSError, ValueError) as exc:
    print(f"OpenCode Go model visibility preflight failed: {exc}", file=sys.stderr)
    raise SystemExit(1)

visible = set()
data = payload.get("data") if isinstance(payload, dict) else None
if isinstance(data, list):
    visible.update(item.get("id") for item in data if isinstance(item, dict) and isinstance(item.get("id"), str))
models = payload.get("models") if isinstance(payload, dict) else None
if isinstance(models, dict):
    visible.update(key for key in models if isinstance(key, str))
if model not in visible:
    print(
        f"OpenCode Go does not expose required model {model}; refusing undeclared fallback and poller start",
        file=sys.stderr,
    )
    raise SystemExit(1)
print(f"OpenCode Go model visibility preflight passed: {model}")
PY
}

codex_telegram_supervisor_matches() {
    local pid="${1:-}" expected_ticks="${2:-}" current_ticks argument supervisor_match=0
    case "$pid" in ''|*[!0-9]*) return 1 ;; esac

    while IFS= read -r -d '' argument; do
        case "$argument" in */FORGE/scripts/codex_supervisor.py) supervisor_match=1 ;; esac
    done < "/proc/$pid/cmdline"
    [ "$supervisor_match" = 1 ] || return 1
    if [ -n "$expected_ticks" ]; then
        current_ticks="$(codex_telegram_start_ticks "$pid" 2>/dev/null)" || return 1
        [ "$current_ticks" = "$expected_ticks" ] || return 1

}

codex_telegram_running() {

    pid=$(cat "$pid_file")
    ready=$(cat "$ready_file")
    child=$(cat "$child_file")
    case "$pid:$child" in *[!0-9:]*|:*|*:) return 1 ;; esac
    [ "$ready" = "$pid" ] || return 1
    codex_telegram_supervisor_matches "$pid" || return 1
    [ -r "/proc/$child/cmdline" ] || return 1
    while IFS= read -r -d '' argument; do
        case "$argument" in */FORGE/scripts/codex_telegram.py) adapter_match=1 ;; esac
    done < "/proc/$child/cmdline"
    [ "$adapter_match" = 1 ] || return 1
    parent=$(awk '/^PPid:/ {print $2}' "/proc/$child/status" 2>/dev/null) || return 1
    [ "$parent" = "$pid" ]
}

stop_pi_agent() {
    if ! gemma_telegram_running; then
        echo "pi-agent: not running"
        return 0
    fi
    local pid pgid
    pid="$(cat "$GEMMA_TELEGRAM_PID_FILE" 2>/dev/null)"
    pgid=$(ps -o pgid= -p "$pid" 2>/dev/null | tr -d ' ' || true)
    if [ "$pgid" = "$pid" ]; then
        kill -TERM -- "-$pgid" 2>/dev/null || true
    else
        kill -TERM "$pid" 2>/dev/null || true
    fi
    for _ in {1..20}; do
        gemma_telegram_running || break
        sleep 0.25
    done
    if gemma_telegram_running; then
        echo "Gemma Telegram did not stop gracefully; forcing verified process group" >&2
        if [ "$pgid" = "$pid" ]; then
            kill -KILL -- "-$pgid" 2>/dev/null || true
        else
            kill -KILL "$pid" 2>/dev/null || true
        fi
    fi
    gemma_telegram_running && return 1
    rm -f "$GEMMA_TELEGRAM_PID_FILE"
}

start_nanobot() {
    local log_file log_start=0 log_size
    nanobot_private_config_ready || return 1
    if nanobot_running; then
        echo "nanobot is already running"
        return 0
    fi
    # Bind readiness to this launch. Gateway logs are append-only, so an old
    # successful connection must not make a new broken launch look healthy.
    log_file="$(nanobot_log_file 2>/dev/null || true)"
    if [ -n "$log_file" ] && [ -r "$log_file" ]; then
        log_start="$(wc -c < "$log_file" | tr -d '[:space:]')"
        case "$log_start" in ''|*[!0-9]*) log_start=0 ;; esac
    fi
    echo "Starting HelmCortex Nano Telegram gateway..."
    "$NANOBOT_WRAPPER" gateway --background
    for _ in {1..30}; do
        if nanobot_running; then
            log_file="$(nanobot_log_file 2>/dev/null || true)"
            if [ -n "$log_file" ] && [ -r "$log_file" ]; then
                log_size="$(wc -c < "$log_file" | tr -d '[:space:]')"
                case "$log_size" in ''|*[!0-9]*) log_size=0 ;; esac
                [ "$log_size" -ge "$log_start" ] || log_start=0
                if grep -q 'telegram | bot @helmcortex_nano_bot connected' \
                    < <(tail -c "+$((log_start + 1))" "$log_file"); then
                    echo "nanobot connected as @helmcortex_nano_bot"
                    return 0
                fi
            fi
        fi
        sleep 1
    done
    echo "Nanobot failed Telegram readiness; stopping the scoped gateway" >&2
    "$NANOBOT_WRAPPER" gateway stop >/dev/null 2>&1 || true
    return 1
}

stop_nanobot() {
    if ! nanobot_running; then

    "$NANOBOT_WRAPPER" gateway stop
    for _ in {1..20}; do
        nanobot_running || return 0
        sleep 0.25
    done
    echo "Nanobot gateway did not stop through its owned instance state" >&2
    return 1
}

enable_agent() {
    local agent="$1"
    validate_agent "$agent"
    local host
    host=$(get_hostname)

    if [ ! -f "$HOSTS_FILE" ]; then
        echo "Error: hosts.conf not found at $HOSTS_FILE"
        exit 1
    fi

    local line
    line=$(grep -i "^${host}|" "$HOSTS_FILE" 2>/dev/null || true)
    if [ -z "$line" ]; then
        echo "Error: host '$host' not found in hosts.conf"
        exit 1
    fi

    local current_agents
    current_agents=$(echo "$line" | cut -d'|' -f2)

    if echo "$current_agents" | grep -qw "$agent"; then
        echo "$agent is already enabled on $host"
        return
    fi

    local new_agents
    if [ -z "$current_agents" ]; then
        new_agents="$agent"
    else
        new_agents="$current_agents,$agent"
    fi

    local tmp_hosts
    tmp_hosts="${HOSTS_FILE}.tmp.$$"
    awk -F'|' -v host="$host" -v agents="$new_agents" '
        BEGIN { OFS = FS }
        tolower($1) == tolower(host) { $2 = agents }
        { print }
    ' "$HOSTS_FILE" > "$tmp_hosts"
    mv "$tmp_hosts" "$HOSTS_FILE"
    echo "Enabled $agent on $host"
    echo "Run 'telegram-agent-host sync' to apply, then 'telegram-agent-host start'"
}

disable_agent() {
    local agent="$1"
    validate_agent "$agent"
    local host
    host=$(get_hostname)

    if [ ! -f "$HOSTS_FILE" ]; then
        echo "Error: hosts.conf not found at $HOSTS_FILE"
        exit 1
    fi

    local line
    line=$(grep -i "^${host}|" "$HOSTS_FILE" 2>/dev/null || true)
    if [ -z "$line" ]; then
        echo "Error: host '$host' not found in hosts.conf"
        exit 1
    fi

    local current_agents
    current_agents=$(echo "$line" | cut -d'|' -f2)

    if ! echo "$current_agents" | grep -qw "$agent"; then
        echo "$agent is not enabled on $host"
        return
    fi

    local new_agents
    new_agents=$(echo "$current_agents" | tr ',' '\n' | grep -v "^${agent}$" | tr '\n' ',' | sed 's/,$//' | sed 's/^,//')

    local tmp_hosts
    tmp_hosts="${HOSTS_FILE}.tmp.$$"
    awk -F'|' -v host="$host" -v agents="$new_agents" '
        BEGIN { OFS = FS }
        tolower($1) == tolower(host) { $2 = agents }
        { print }
    ' "$HOSTS_FILE" > "$tmp_hosts"
    mv "$tmp_hosts" "$HOSTS_FILE"
    echo "Disabled $agent on $host"
    echo "Run 'telegram-agent-host stop $agent' to stop it"
}

    if [ ! -e "$NANOBOT_ENV_FILE" ]; then

start_agent() {

                return 1

                echo "OpenCode Telegram package seam is not ready; refusing start" >&2
                return 1
            fi

                if check_opencode >/dev/null 2>&1; then
                    echo "opencode is already running"
                    return 0
                fi
                echo "Existing OpenCode owner state is not healthy; validating and stopping only its owned processes..."
                "$OPENCODE_OWNER_HELPER" stop --state "$OPENCODE_STATE_FILE" --project "$OPENCODE_PROJECT_ROOT" --host 127.0.0.1 --port "$OPENCODE_PORT" || true
            fi

                cd "$OPENCODE_PROJECT_ROOT"

                backend_pid=$(cat "$OPENCODE_BACKEND_PID_FILE")
                kill -TERM "$backend_pid" 2>/dev/null || true
                rm -f "$OPENCODE_BACKEND_PID_FILE" "$OPENCODE_POLLER_PID_FILE"
                echo "OpenCode backend/poller did not produce a complete owner state" >&2
                return 1

            python3 -c 'import json,sys; print(json.load(open(sys.argv[1]))["pid"])' "$OPENCODE_TELEGRAM_HOME/run/bot-service.json" > "$OPENCODE_POLLER_PID_FILE"
            ;;

                        return 1

                    echo "ductor started"
                else

                    if ! wait_ductor_ready; then
                        echo "ductor failed supervised readiness" >&2
                        return 1
                    fi
                    echo "ductor started"
                fi

                echo "ductor or its canonical supervisor is unavailable"
                return 1
            fi
            ;;
        claudecode)
            echo "claudecode Telegram runs inline via the PTY-supervised claude-auryn launcher."
            echo "Launch Claude with: claude-auryn --telegram"
            echo "Access control: ~/.claude/channels/telegram/access.json"
            ;;
        hermes)
            start_hermes
            ;;
        codex)
            local wrapper="${CODEX_HELMASTRA_WRAPPER:-$HOME/HelmCortex/FORGE/bin/codex-helmastra}"
            if [ ! -x "$wrapper" ]; then
                echo "codex-helmastra wrapper not found at $wrapper"
                return 1
            fi
            if codex_telegram_running; then
                echo "HelmAstra Telegram is already running"
            else
                echo "Starting HelmAstra Codex Telegram adapter..."
                # Managed starts are governed by the private dotenv. A restart
                # launched from inside the old adapter inherits that adapter's
                # model/policy environment; clear it here so stale values cannot
                # outrank the newly authored private configuration.
                if ! env \
                    -u CODEX_HELMASTRA_MODEL \
                    -u CODEX_TELEGRAM_MODEL \
                    -u CODEX_HELMASTRA_EFFORT \
                    -u CODEX_TELEGRAM_EFFORT \

                    echo "HelmAstra Telegram adapter failed readiness; inspect $STATE_DIR/codex-helmastra-telegram.log"
                    return 1
                fi
                if ! codex_telegram_running; then
                    echo "HelmAstra Telegram adapter reported ready but is not running"
                    return 1
                fi
            fi
            ;;
        deepseek-harness)
            local delegated=0
            deepseek_harness_delegate start || delegated=$?
            [ "$delegated" -eq 3 ] || return "$delegated"
            mkdir -p "$STATE_DIR"
            deepseek_harness_acquire_start_lock || return 1
            deepseek_harness_validate_private_config || { deepseek_harness_release_start_lock; return 1; }
            deepseek_harness_validate_install || { deepseek_harness_release_start_lock; return 1; }
            if deepseek_harness_ready; then
                deepseek_harness_release_start_lock
                echo "deepseek-harness already has a ready owned poller"
                return 0
            fi
            if deepseek_harness_running; then
                deepseek_harness_release_start_lock
                echo "DeepSeek Harness has a legacy PID-only poller; stop it before starting under the readiness contract" >&2
                return 1
            fi
            deepseek_harness_clear_stale_marker || { deepseek_harness_release_start_lock; return 1; }
            deepseek_harness_retire_stale_owner || { deepseek_harness_release_start_lock; return 1; }
            local other_pid
            other_pid="$(deepseek_harness_find_unowned 2>/dev/null || true)"
            if [ -n "$other_pid" ]; then
                deepseek_harness_release_start_lock
                echo "Refusing DeepSeek Harness start: another dsh poller already uses profile $DSH_TELEGRAM_PROFILE (pid $other_pid)" >&2
                return 1
            fi
            deepseek_harness_preflight_model || { deepseek_harness_release_start_lock; return 1; }
            deepseek_harness_rotate_log
            local launch_generation launch_marker
            launch_generation="$(deepseek_harness_write_generation)" || {
                deepseek_harness_release_start_lock
                echo "DeepSeek Harness could not publish a launch generation" >&2
                return 1
            }
            launch_marker="${DSH_TELEGRAM_READY_MARKER}.${launch_generation}"
            printf '\n=== deepseek-harness launch %s ===\n' "$(date -u +%Y-%m-%dT%H:%M:%SZ)" >> "$DSH_TELEGRAM_LOG_FILE"
            echo "Starting DeepSeek Harness Telegram profile $DSH_TELEGRAM_PROFILE..."
            (
                # Keep the launch lock in the short-lived owner only; the
                # detached poller must not pin it across future boot checks.
                deepseek_harness_release_start_lock
                cd "$DSH_TELEGRAM_WORKSPACE"
                exec nohup setsid env -u TELEGRAM_BOT_TOKEN -u DEEPSEEK_API_KEY -u DEEPSEEK_API_KEY_FILE -u NEURALWATT_API_KEY -u OPENCODE_API_KEY -u OPENCODE_GO_API_KEY \
                    PATH="$AGENT_RUNTIME_PATH" \
                    NODE_OPTIONS="$DSH_TELEGRAM_NODE_OPTIONS" \
                    DSH_HOME="$DSH_HOME" \
                    DSH_TELEGRAM_PROFILE="$DSH_TELEGRAM_PROFILE" \
                    DSH_TELEGRAM_READY_GENERATION="$launch_generation" \
                    DSH_TELEGRAM_READY_MARKER="$launch_marker" \
                    DSH_TELEGRAM_LOG_FILE="$DSH_TELEGRAM_LOG_FILE" \
                    TELEGRAM_BOT_TOKEN_FILE="$TELEGRAM_BOT_TOKEN_FILE" \
                    OPENCODE_GO_API_KEY_FILE="$OPENCODE_GO_API_KEY_FILE" \
                    bash -c '
                        IFS= read -r OPENCODE_GO_API_KEY < "$OPENCODE_GO_API_KEY_FILE"
                        export OPENCODE_GO_API_KEY
                        exec dsh --profile "$DSH_TELEGRAM_PROFILE" > >(
                            sed -u -E \
                                -e '\''s#bot[0-9]{8,}:[A-Za-z0-9_-]{30,}#bot[REDACTED]#g'\'' \
                                -e '\''s#chatId=-?[0-9]+#chatId=[REDACTED]#g'\'' \
                                -e '\''s#bar-sync\(-?[0-9]+\)#bar-sync([REDACTED])#g'\'' \
                                -e '\''s#([?&]token=)[A-Za-z0-9_-]+#\1[REDACTED]#g'\'' \
                                >> "$DSH_TELEGRAM_LOG_FILE"
                        ) 2>&1 </dev/null
                    '
            ) &
            local launched_pid="$!" launched_ticks
            launched_ticks="$(deepseek_harness_start_ticks "$launched_pid" 2>/dev/null || true)"
            printf '%s\n' "$launched_pid" > "$DSH_TELEGRAM_PID_FILE"
            if [ -z "$launched_ticks" ] || ! deepseek_harness_wait_ready; then
                echo "DeepSeek Harness Telegram readiness timeout; refusing PID-only health" >&2
                if [ -n "$launched_ticks" ] && deepseek_harness_kill_owned "$launched_pid" "$launched_ticks"; then
                    rm -f "$DSH_TELEGRAM_PID_FILE"
                else
                    echo "DeepSeek Harness Telegram owner changed; preserving state and refusing unverified stop" >&2
                fi
                deepseek_harness_release_start_lock
                return 1
            fi
            deepseek_harness_release_start_lock
            ;;
        pi-agent)
            start_pi_agent
            ;;
        nanobot)
            local delegated=0
            nanobot_delegate start || delegated=$?
            [ "$delegated" -eq 3 ] || return "$delegated"
            start_nanobot
            ;;
        *)
            echo "Unknown agent: $agent"
            exit 1
            ;;
    esac
    echo "$agent started"
}

stop_agent() {
    local agent="$1"
    validate_agent "$agent"
    case "$agent" in
        opencode)
            local delegated=0
            opencode_delegate stop || delegated=$?
            [ "$delegated" -eq 3 ] || return "$delegated"
            if [ -x "$OPENCODE_OWNER_HELPER" ]; then
                "$OPENCODE_OWNER_HELPER" stop \
                    --state "$OPENCODE_STATE_FILE" \
                    --project "$OPENCODE_PROJECT_ROOT" \
                    --host 127.0.0.1 --port "$OPENCODE_PORT"
            else
                echo "OpenCode owner helper unavailable; refusing unscoped stop" >&2
                return 1
            fi
            ;;
        ductor)
            stop_ductor_owned
            ;;
        claudecode)
            pkill -f "claude.*channels.*telegram" 2>/dev/null || true
            ;;
        hermes)
            stop_hermes
            ;;
        codex)
            local codex_pid codex_pgid codex_ticks
            codex_pid="$(cat "$STATE_DIR/codex-helmastra-telegram.pid" 2>/dev/null || true)"
            if codex_telegram_supervisor_matches "$codex_pid"; then
                codex_ticks="$(codex_telegram_start_ticks "$codex_pid" 2>/dev/null)" || {
                    echo "HelmAstra Telegram supervisor start ticks unavailable; refusing stop" >&2
                    return 1
                }
                codex_pgid=$(ps -o pgid= -p "$codex_pid" 2>/dev/null | tr -d ' ' || true)
                codex_telegram_supervisor_matches "$codex_pid" "$codex_ticks" || {
                    echo "HelmAstra Telegram supervisor identity changed before signal; refusing stop" >&2
                    return 1
                }
                # Self-kill guard (2026-09-30): the stop signals the supervisor's
                # whole process group, and a HelmAstra turn runs its tools inside
                # that group. A stop issued from within the group kills its own
                # caller before the matching start can run. Refuse instead.
                local guard_pid="$$" guard_pgid
                while [ -n "$guard_pid" ] && [ "$guard_pid" -gt 1 ] 2>/dev/null; do
                    guard_pgid=$(ps -o pgid= -p "$guard_pid" 2>/dev/null | tr -d ' ' || true)
                    if [ "$guard_pid" = "$codex_pid" ] || { [ "$codex_pgid" = "$codex_pid" ] && [ "$guard_pgid" = "$codex_pgid" ]; }; then
                        echo "HelmAstra Telegram host cannot stop itself from inside its own turn; run the stop from outside it (another session or Nurse Joy)" >&2
                        return 1
                    fi
                    guard_pid=$(ps -o ppid= -p "$guard_pid" 2>/dev/null | tr -d ' ' || true)
                done
                if [ "$codex_pgid" = "$codex_pid" ]; then
                    kill -TERM -- "-$codex_pgid" 2>/dev/null || true
                else
                    kill -TERM "$codex_pid" 2>/dev/null || true
                fi
                # Readiness can disappear before the supervisor releases its
                # exclusive launch lock. Wait for the exact captured process,
                # not the composite ready predicate, before permitting restart.
                for _ in {1..20}; do
                    codex_telegram_supervisor_matches "$codex_pid" "$codex_ticks" || break
                    sleep 0.25
                done
                if codex_telegram_supervisor_matches "$codex_pid" "$codex_ticks"; then
                    echo "HelmAstra Telegram did not stop gracefully; forcing its verified process group" >&2
                    if [ "$codex_pgid" = "$codex_pid" ]; then
                        kill -KILL -- "-$codex_pgid" 2>/dev/null || true
                    else
                        kill -KILL "$codex_pid" 2>/dev/null || true
                    fi
                    for _ in {1..20}; do
                        codex_telegram_supervisor_matches "$codex_pid" "$codex_ticks" || break
                        sleep 0.25
                    done
                fi
                if codex_telegram_supervisor_matches "$codex_pid" "$codex_ticks"; then
                    echo "HelmAstra Telegram failed to stop its verified supervisor" >&2
                    return 1
                fi
            fi
            ;;
        deepseek-harness)
            local dsh_pid dsh_ticks dsh_marker delegated=0
            deepseek_harness_delegate stop || delegated=$?
            [ "$delegated" -eq 3 ] || return "$delegated"
            dsh_marker="$(deepseek_harness_marker_path 2>/dev/null || true)"
            if [ ! -e "$DSH_TELEGRAM_PID_FILE" ] && [ ! -e "$DSH_TELEGRAM_READY_MARKER" ] && \
               [ ! -e "$DSH_TELEGRAM_GENERATION_FILE" ] && \
               { [ -z "$dsh_marker" ] || [ ! -e "$dsh_marker" ]; }; then
                return 0
            fi
            dsh_pid="$(cat "$DSH_TELEGRAM_PID_FILE" 2>/dev/null || true)"
            if deepseek_harness_ready || deepseek_harness_pid_matches "$dsh_pid"; then
                dsh_ticks="$(deepseek_harness_start_ticks "$dsh_pid" 2>/dev/null)" || {
                    echo "DeepSeek Harness process start ticks unavailable; refusing stop" >&2
                    return 1
                }
                if ! deepseek_harness_kill_owned "$dsh_pid" "$dsh_ticks"; then
                    echo "DeepSeek Harness Telegram failed to stop its verified owner" >&2
                    return 1
                fi
            elif [ -n "$(deepseek_harness_find_unowned 2>/dev/null || true)" ]; then
                echo "DeepSeek Harness owner state is stale but an unowned poller uses this profile; refusing cleanup" >&2
                return 1
            fi
            rm -f "$DSH_TELEGRAM_PID_FILE" "$DSH_TELEGRAM_READY_MARKER" "$DSH_TELEGRAM_GENERATION_FILE"
            [ -z "$dsh_marker" ] || rm -f "$dsh_marker"
            ;;
        pi-agent)
            stop_pi_agent
            ;;
        nanobot)
            local delegated=0
            nanobot_delegate stop || delegated=$?
            [ "$delegated" -eq 3 ] || return "$delegated"
            stop_nanobot
            ;;
        *)
            echo "Unknown agent: $agent"
            exit 1
            ;;
    esac
    echo "$agent stopped"
}

start_all() {
    local host
    host=$(get_hostname)
    local agents
    agents=$(get_enabled_agents "$host")

    if [ -z "$agents" ]; then
        echo "No agents enabled for $host. Run 'telegram-agent-host enable <agent>' first."
        exit 1
    fi

    echo "Starting enabled agents for $host: $agents"
    local failed=0
    for agent in $agents; do
        if start_agent "$agent"; then
            clear_intentional_stop "$agent"
        else
            echo "Failed to start enabled agent: $agent" >&2
            failed=1
        fi
    done
    return "$failed"
}

# Intentional-stop markers: telegram-agent-watchdog skips an enabled agent whose
# marker exists, so an operator stop is not fought. Written only after a
# successful stop, cleared by a successful start.
INTENT_DIR="$STATE_DIR/intentional-stop"
mark_intentional_stop() { mkdir -p "$INTENT_DIR" && : > "$INTENT_DIR/$1"; }
clear_intentional_stop() { rm -f "$INTENT_DIR/$1"; }

stop_all() {
    for agent in opencode ductor claudecode hermes codex deepseek-harness pi-agent nanobot; do
        { stop_agent "$agent" 2>/dev/null && mark_intentional_stop "$agent"; } || true
    done
    echo "All agents stopped"
}

switch_to_machine() {
    local target="$1"
    local current_host
    current_host=$(get_hostname)

    if [ "$current_host" = "$target" ]; then
        echo "Already on $target"
        return
    fi

    local target_agents
    target_agents=$(get_enabled_agents "$target")

    if [ -z "$target_agents" ]; then
        echo "No agents configured for $target"
        exit 1
    fi

    local target_ssh
    target_ssh=$(grep -i "^${target}|" "$HOSTS_FILE" 2>/dev/null | cut -d'|' -f3)

    echo "Switching from $current_host to $target"

    echo "Stopping all agents on $current_host..."
    stop_all

    echo "Stopping agents on $target before restart..."
    if [ -n "$target_ssh" ]; then
        ssh "$target_ssh" "systemctl --user stop hermes-gateway.service 2>/dev/null || pkill -x hermes 2>/dev/null || true; pkill -f 'ductor' 2>/dev/null || true" 2>/dev/null || true
        sleep 1
    fi

    echo "Starting agents on $target via SSH..."
    if [ -n "$target_ssh" ]; then
        ssh "$target_ssh" "\$HOME/.local/bin/telegram-agent-remote-start $target_agents"
        echo "Switched to $target"
    else
        echo "No SSH config for $target. Manually start on target machine:"
        echo " ssh $target"
        echo " telegram-agent-host start"
    fi
    echo ""
    echo "Enabled on $target: $target_agents"
}

bring_here() {
    local current_host
    current_host=$(get_hostname)
    local agents
    agents=$(get_enabled_agents "$current_host")

    if [ -z "$agents" ]; then
        echo "No agents configured for $current_host"
        exit 1
    fi

    echo "Bringing agents to $current_host..."

    for host_line in $(grep -v '^#' "$HOSTS_FILE" | grep -v '^$'); do
        local other_host
        other_host=$(echo "$host_line" | cut -d'|' -f1)
        if [ "$other_host" != "$current_host" ]; then
            local other_ssh
            other_ssh=$(echo "$host_line" | cut -d'|' -f3)
            if [ -n "$other_ssh" ]; then
                echo "Stopping agents on $other_host..."
                ssh "$other_ssh" "systemctl --user stop hermes-gateway.service 2>/dev/null || pkill -x hermes 2>/dev/null || true; pkill -f 'ductor' 2>/dev/null || true" 2>/dev/null || true
            fi
        fi
    done

    sleep 1
    echo "Starting agents locally..."
    start_all
}

* Remote Start Helper

This script runs on the target machine via SSH. It kills existing processes,
starts new ones, waits for confirmation, then exits cleanly.

On hosts without a user service manager, Hermes ownership is recorded in
=telegram-agents/hermes.pid=.  A restart waits for every matching old gateway
to exit, then requires the exact newly launched PID to remain a =gateway run=
process for five consecutive checks.  A generic surviving Hermes process is
not startup evidence, and failure returns a nonzero status to the caller.

#+BEGIN_SRC bash :tangle all/.local/bin/telegram-agent-remote-start :shebang "#!/usr/bin/env bash"
# ~/DotCortex/all/.local/bin/telegram-agent-remote-start
# Run on target machine via SSH to start agents.
# Usage: telegram-agent-remote-start <agent> [agent ...]

set -euo pipefail

STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/telegram-agents"
KNOWN_AGENTS="ductor hermes"
DUCTOR_HOME_DIR="${DUCTOR_HOME_DIR:-$HOME/HelmCortex/FORGE/brain/ductor}"
HERMES_PID_FILE="$STATE_DIR/hermes.pid"
overall_status=0
mkdir -p "$STATE_DIR"

validate_agent() {
    local agent="${1:-}"
    case " $KNOWN_AGENTS " in
        *" $agent "*) ;;
        *)
            echo "Agent $agent not yet supported for remote start"
            return 1
            ;;
    esac
}

pid_file_has_command() {
    local pid_file="$1" expected="$2" pid argument
    [ -r "$pid_file" ] || return 1
    IFS= read -r pid < "$pid_file" || return 1
    case "$pid" in ''|*[!0-9]*) return 1 ;; esac
    [ -r "/proc/$pid/cmdline" ] || return 1
    while IFS= read -r -d '' argument; do
        [ "${argument##*/}" = "$expected" ] && return 0
    done < "/proc/$pid/cmdline"
    return 1
}

ductor_running() {
    pid_file_has_command "$STATE_DIR/ductor-supervise.pid" ductor-supervise
}

ductor_ready() {
    ductor_running && pid_file_has_command "$STATE_DIR/ductor-child.pid" ductor
}

stop_ductor_owned() {
    local supervisor_pid child_pid
    if ductor_running; then
        IFS= read -r supervisor_pid < "$STATE_DIR/ductor-supervise.pid"
        kill -TERM "$supervisor_pid"
        for _ in {1..15}; do
            [ ! -r "/proc/$supervisor_pid/cmdline" ] && break
            sleep 1
        done
        [ ! -r "/proc/$supervisor_pid/cmdline" ] || return 1
    elif pid_file_has_command "$STATE_DIR/ductor-child.pid" ductor; then
        IFS= read -r child_pid < "$STATE_DIR/ductor-child.pid"
        kill -TERM "$child_pid"
    fi
    rm -f "$STATE_DIR/ductor-supervise.pid" "$STATE_DIR/ductor-child.pid"
}

hermes_service_unit() {
    printf '%s\n' "${XDG_CONFIG_HOME:-$HOME/.config}/systemd/user/hermes-gateway.service"
}

hermes_service_installed() {
    command -v systemctl >/dev/null 2>&1 && [ -f "$(hermes_service_unit)" ]
}

hermes_running() {
    if hermes_service_installed && systemctl --user is-active --quiet hermes-gateway.service; then
        return 0
    fi
    if hermes_gateway_pid_matches_file "$HERMES_PID_FILE"; then
        return 0
    fi
    pgrep -x hermes >/dev/null 2>&1
}

hermes_gateway_pid_matches() {
    local pid="$1" argument saw_hermes=0 saw_gateway=0
    case "$pid" in ''|*[!0-9]*) return 1 ;; esac
    [ -r "/proc/$pid/cmdline" ] || return 1
    while IFS= read -r -d '' argument; do
        if [ "$saw_hermes" -eq 0 ] && [ "${argument##*/}" = hermes ]; then
            saw_hermes=1
            continue
        fi
        if [ "$saw_hermes" -eq 1 ] && [ "$saw_gateway" -eq 0 ] && [ "$argument" = gateway ]; then
            saw_gateway=1
            continue
        fi
        if [ "$saw_gateway" -eq 1 ] && [ "$argument" = run ]; then
            return 0
        fi
    done < "/proc/$pid/cmdline"
    return 1
}

hermes_gateway_pid_matches_file() {
    local pid_file="$1" pid
    [ -r "$pid_file" ] || return 1
    IFS= read -r pid < "$pid_file" || return 1
    hermes_gateway_pid_matches "$pid"
}

stop_hermes_fallback_owned() {
    local pid owned_pid remaining seen
    local -a pids=()
    if [ -r "$HERMES_PID_FILE" ]; then
        IFS= read -r owned_pid < "$HERMES_PID_FILE" || owned_pid=
        hermes_gateway_pid_matches "$owned_pid" && pids+=("$owned_pid")
    fi
    while IFS= read -r pid; do
        hermes_gateway_pid_matches "$pid" || continue
        seen=0
        for owned_pid in "${pids[@]}"; do
            [ "$owned_pid" = "$pid" ] && seen=1
        done
        [ "$seen" -eq 1 ] || pids+=("$pid")
    done < <(pgrep -x hermes 2>/dev/null || true)

    if [ "${#pids[@]}" -eq 0 ]; then
        rm -f "$HERMES_PID_FILE"
        return 0
    fi

    kill -TERM "${pids[@]}"
    for _ in {1..30}; do
        remaining=0
        for pid in "${pids[@]}"; do
            hermes_gateway_pid_matches "$pid" && remaining=1
        done
        [ "$remaining" -eq 0 ] && break
        sleep 1
    done

    for pid in "${pids[@]}"; do
        if hermes_gateway_pid_matches "$pid"; then
            echo "hermes gateway: FAILED TO STOP OWNED PID $pid"
            return 1
        fi
    done
    rm -f "$HERMES_PID_FILE"
}

for agent in "$@"; do
    validate_agent "$agent" || continue
    case "$agent" in
    ductor)
        echo "Stopping existing ductor process..."
        if ! stop_ductor_owned; then
            echo "ductor: FAILED TO STOP OWNED PROCESS"
            continue
        fi
        rm -f "$STATE_DIR/ductor-supervise.pid" "$STATE_DIR/ductor-child.pid"
        echo "Starting ductor (supervised)..."
        nohup setsid env DUCTOR_HOME="$DUCTOR_HOME_DIR" ductor-supervise > "$STATE_DIR/ductor-supervise.log" 2>&1 </dev/null &
        for _ in {1..15}; do
            ductor_ready && break
            sleep 1
        done
        if ductor_ready; then
            echo "ductor: STARTED OK"
        else
            echo "ductor: FAILED TO START"
        fi
        ;;
    hermes)
        if ! command -v hermes >/dev/null 2>&1; then
            echo "hermes not found in PATH"
            overall_status=1
            continue
        fi
        if hermes_service_installed; then
            echo "Restarting supervised Hermes gateway..."
            systemctl --user restart hermes-gateway.service
            systemctl --user enable hermes-gateway.service >/dev/null
        elif command -v systemctl >/dev/null 2>&1 && systemctl --user show-environment >/dev/null 2>&1; then
            echo "Installing supervised Hermes gateway service..."
            hermes gateway install --start-now --start-on-login
        else
            echo "No user service manager available; restarting Hermes gateway with nohup..."
            if ! stop_hermes_fallback_owned; then
                overall_status=1
                continue
            fi
            nohup setsid hermes gateway run > "$STATE_DIR/hermes.log" 2>&1 </dev/null &
            hermes_pid=$!
            printf '%s\n' "$hermes_pid" > "$HERMES_PID_FILE"
            disown
        fi
        hermes_stable=0
        for _ in {1..20}; do
            if hermes_service_installed; then
                if systemctl --user is-active --quiet hermes-gateway.service; then
                    hermes_stable=$((hermes_stable + 1))
                else
                    hermes_stable=0
                fi
            elif hermes_gateway_pid_matches_file "$HERMES_PID_FILE"; then
                hermes_stable=$((hermes_stable + 1))
            else
                hermes_stable=0
            fi
            [ "$hermes_stable" -ge 5 ] && break
            sleep 1
        done
        if [ "$hermes_stable" -ge 5 ]; then
            echo "hermes gateway: STARTED OK"
        else
            hermes_gateway_pid_matches_file "$HERMES_PID_FILE" || rm -f "$HERMES_PID_FILE"
            echo "hermes gateway: FAILED TO START"
            overall_status=1
        fi
        ;;
    *)
        echo "Agent $agent not yet supported for remote start"
        ;;
    esac
done
exit "$overall_status"
#+END_SRC
