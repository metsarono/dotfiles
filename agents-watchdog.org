* Telegram agent watchdog

Sealed 2026-09-30 after HelmAstra ran =telegram-agent-host stop codex= from inside her own Telegram turn, killed her own process group, and stayed down until Mètsàtron noticed. The boot owner (=telegram-agent-boot=, in =agents-bots.org=) only fires =@reboot=; nothing watched the agents afterwards.

The watchdog is a deterministic cron job with no model in it, so the Nested One-Shot Claude law is untouched. Every few minutes it asks =telegram-agent-host= which agents are enabled on this host and reads each agent's own liveness line from =telegram-agent-host status=, so a new agent needs no watchdog change beyond a label pattern. A dead agent is relaunched through =telegram-agent-host start <agent>= from the cron process, which sits outside every agent's process group, with an increasing backoff and a hard attempt cap so a crash loop cannot hammer Telegram or the model provider.

Three things keep it from fighting the operator. An agent that is not in =enabled= is never touched, which covers =disable=, =switch= and =bring=. An agent with an intentional-stop marker is skipped: the host writes =$STATE_DIR/intentional-stop/<agent>= after a successful =stop= and clears it on a successful =start=. And the watchdog stands down entirely while the boot owner holds =boot.lock=, so a cold boot is never doubled.

An unknown reading (no status line, unparsable line, or a failed =status= call) is never treated as down. It is reported as a probe failure and nothing is relaunched, because a wrong negative from the detector must not restart a healthy agent.

Alerts publish =helmcortex.notification.v1= events into the same spool the fleet-health collector uses (=~/.local/state/helmcortex-notifications/spool=), with source =agent_watchdog=. The spool is the transport; delivery to Telegram belongs to the spool consumer, so the pending alerts-bot token ruling gates delivery, not detection or relaunch. Every run writes =receipt.json= so a silent watchdog is itself detectable.

** Warm Claude sessions

Added 2026-10-08 after a user-wide SIGTERM on Kikin killed the Fable, Opus and Haiku warm sessions together. Cron brought every daemon back, but nothing revived the warm sessions, because =telegram-agent-host status= reports Claude only as one =claudecode= line that reads RUNNING while any Claude Telegram session is alive. The watchdog now also supervises the warm sessions named in a private, machine-local list (=~/.config/telegram-agent-watchdog/warm-sessions=, one name per line, =#= comments allowed; absent means none), so the fleet roster stays out of this public source. Each session's state comes from =nurse-joy status --json=: verdict =field= or =degraded= (alive, for example running stale agent code) is up, =down= is down, and any other verdict, a missing member, or unreadable output is unknown and never acted on, with one exception sealed after the 2026-10-09 02:26 kill left all three down for seven hours: when =tmux ls= reports that no tmux server is running at all, every unknown warm session is down, because every warm session lives in tmux. A down session is revived with =nurse-joy revive --no-visit <name>=, the sanctioned bounce path, under the same backoff, attempt cap, alerts and boot-lock stand-down as the Telegram agents. Its state key and intentional-stop marker are =warm-<name>=: to keep a session down on purpose, touch =~/.local/state/telegram-agents/intentional-stop/warm-<name>= first.

** Self-revive request lane

An agent cannot safely stop and start itself, because the stop kills the caller's own process group before the start runs. A Telegram agent runs =telegram-agent-watchdog request [AGENT]=; a warm Claude seat runs =telegram-agent-watchdog request warm-$CLAUDE_WARM_HERDR_AGENT= (for example, =telegram-agent-watchdog request warm-fable=) and returns. The command only queues =requests/<agent>.json= under the watchdog state dir and never signals anything. A later watchdog run performs the restart from cron, outside the requesting seat's process group.

The lane is idempotent (one pending file per target, a second request reports "already pending"). Telegram agents remain self-targeted by =$TELEGRAM_AGENT_SELF=, with =--other= required to target another Telegram agent. Warm seats use =CLAUDE_WARM_HERDR_AGENT= when present; an explicit =warm-<name>= target is also accepted, but only if the seat is in the private =--warm-file= roster. Warm requests record the claude-warm supervisor pid and kernel start-time from its live runtime state, plus the newest-by-mtime transcript path and its session id. The request is dropped as stale if that supervisor generation has since changed. The transcript file is authoritative: idle compaction can fork a newer JSONL transcript, so a stale =--resume= command-line argument is never used. Telegram requests with a supervisor pid file (codex today, see =PID_FILES=) use the same pid and kernel start-time fence; other Telegram agents are unfenced.

The watchdog waits until the requester's pid (default: the parent shell of the request command) has exited, and drops a request after =--request-timeout= seconds if it never does. A cooldown (=--revive-cooldown=, default 600 s) refuses a second revive of the same target. Before a warm revive runs, the resume id is checked with =nurse-joy live-session= (the shared live-session guard): an id already held by another live process — a bg-pty host, per the 2026-10-17 Fable seat incident — records =revive_rejected= instead of killing the tmux supervisor, and the request is dropped; an unavailable check refuses the same way (fail closed, never a second writer). Warm requests run =nurse-joy revive --no-visit --resume <live-session> <name>=. The normal request first gives the warm seat 30 seconds to exit gracefully; only a self-requested warm revive escalates to =--force= after that bounded wait, since the seat itself asked to bounce. The watchdog re-reads =nurse-joy status --json= to verify readiness (=field= or =degraded= means up) and includes code staleness in the receipt. Telegram requests retain their existing stop/start path. The spool records =revive_done=, =revive_failed=, =revive_stale= or =revive_rejected=; a failed revive clears the intentional-stop marker so the normal relaunch loop takes over.

def atomic_write(path: Path, data: bytes) -> None:
    path.parent.mkdir(mode=0o700, parents=True, exist_ok=True)
    fd, temporary = tempfile.mkstemp(prefix=".tmp-", dir=str(path.parent))
    try:
        with os.fdopen(fd, "wb") as handle:
            handle.write(data)
            handle.flush()
            os.fsync(handle.fileno())
        os.chmod(temporary, 0o600)
        os.replace(temporary, path)
    except BaseException:
        try:
            os.unlink(temporary)
        except OSError:
            pass
        raise


def load_state(path: Path) -> dict:
    try:
        value = json.loads(path.read_text(encoding="utf-8"))
    except FileNotFoundError:
        return {"schema": STATE_SCHEMA, "agents": {}}
    except (OSError, ValueError):
        return {"schema": STATE_SCHEMA, "agents": {}}
    if not isinstance(value, dict) or not isinstance(value.get("agents"), dict):
        return {"schema": STATE_SCHEMA, "agents": {}}
    return value


def child_env() -> dict[str, str]:
    """Cron carries no XDG_RUNTIME_DIR. A tmux server or warm session started from here inherits
    this environment, and claude-warm refuses to supervise without it (2026-10-09: every warm
    revive failed after a kill until the tmux global env was fixed by hand)."""
    env = dict(os.environ)
    env.setdefault("XDG_RUNTIME_DIR", "/run/user/%d" % os.getuid())
    return env


def run_manager(manager: str, args: list[str], timeout: int) -> subprocess.CompletedProcess:

def classify(agent: str, status_text: str) -> str:
    """Return up, down, or unknown from the agent's own status line."""
    pattern = STATUS_LABELS.get(agent)
    if pattern is None:
        return "unknown"
    verdicts = set()
    for line in status_text.splitlines():
        if re.match(r"^\s*" + pattern, line):
            if re.search(r"\bRUNNING\b", line):
                verdicts.add("up")
            elif re.search(r"\bSTOPPED\b", line):
                verdicts.add("down")
    return verdicts.pop() if len(verdicts) == 1 else "unknown"


def read_warm_sessions(path: Path) -> list[str]:
    """Warm Claude sessions to supervise, from a private machine-local list (topology stays out of source)."""
    try:
        lines = path.read_text(encoding="utf-8").splitlines()
    except OSError:
        return []
    names: list[str] = []
    for line in lines:
        name = line.split("#", 1)[0].strip()
        if name and re.fullmatch(r"[A-Za-z][A-Za-z0-9_-]*", name) and name.lower() not in [n.lower() for n in names]:
            names.append(name)
    return names


def tmux_server_running(tmux: str) -> bool | None:
    """True or False when tmux answers clearly; None when the probe itself fails."""
    try:
        run = subprocess.run([tmux, "ls"], stdin=subprocess.DEVNULL, stdout=subprocess.DEVNULL,
                             stderr=subprocess.PIPE, text=True, timeout=15, close_fds=True)
    except (OSError, subprocess.SubprocessError):
        return None
    if run.returncode == 0:
        return True
    if re.search(r"no server running|error connecting to .*No such file or directory", run.stderr or ""):
        return False
    return None


def warm_verdicts(nurse: str, names: list[str], timeout: int, tmux: str | None = None) -> dict[str, str]:
    """Map each warm session to up, down, or unknown from nurse-joy's own verdict; anything unreadable is unknown."""
    verdicts = {name: "unknown" for name in names}
    if not names:
        return verdicts
    try:
        run = subprocess.run([nurse, "status", "--json"], stdin=subprocess.DEVNULL, stdout=subprocess.PIPE,
                             stderr=subprocess.DEVNULL, text=True, timeout=timeout, close_fds=True)
        members = json.loads(run.stdout).get("members", [])
    except (OSError, subprocess.SubprocessError, ValueError, AttributeError):
        return verdicts
    seen = {str(m.get("name", "")).lower(): m.get("verdict") for m in members if isinstance(m, dict)}
    for name in names:
        verdict = seen.get(name.lower())
        # field and degraded (alive, e.g. stale agent code) are up; only down drives action.
        verdicts[name] = "up" if verdict in ("field", "degraded") else "down" if verdict == "down" else "unknown"
    # Every warm session lives in tmux. When the tmux server itself is gone (a user-wide kill took it),
    # nurse-joy can only report "unknown"; that is not ambiguity, every warm session is down.
    if tmux and "unknown" in verdicts.values() and tmux_server_running(tmux) is False:
        verdicts = {name: ("down" if verdict == "unknown" else verdict) for name, verdict in verdicts.items()}
    return verdicts


def warm_members(nurse: str, timeout: int) -> dict[str, dict]:
    """Return nurse-joy's reported warm-seat members, or an empty map on unreadable status."""
    try:
        run = subprocess.run([nurse, "status", "--json"], stdin=subprocess.DEVNULL, stdout=subprocess.PIPE,
                             stderr=subprocess.DEVNULL, text=True, timeout=timeout, close_fds=True)
        value = json.loads(run.stdout)
    except (OSError, subprocess.SubprocessError, ValueError):
        return {}
    members = value.get("members", []) if isinstance(value, dict) else []
    return {str(m.get("name", "")).lower(): m for m in members
            if isinstance(m, dict) and isinstance(m.get("name"), str)}


def warm_state(name: str, member: dict | None = None) -> dict:
    """Read the live claude-warm runtime state for a label, resolving its channel privately."""
    state_root = state_home() / "claude-idle-compaction"
    label = name.replace(" ", "-")
    last_path = state_root / ("last-session.%s.json" % label)
    try:
        last = json.loads(last_path.read_text(encoding="utf-8"))
        channel = last.get("channel")
        if not isinstance(channel, str) or not re.fullmatch(r"claude-[0-9a-f]{32}", channel):
            return {}
        runtime_root = Path(os.environ.get("XDG_RUNTIME_DIR") or ("/run/user/%d" % os.getuid()))
        state = json.loads((runtime_root / "claude-idle-compaction" / channel / "state.json").read_text(encoding="utf-8"))
    except (OSError, ValueError, AttributeError):
        return {}
    if not isinstance(state, dict):
        return {}
    if member:
        # nurse-joy's live report is the seat roster; reject a mismatched supervisor
        # rather than trusting an old label record after that label has been rebound.
        reported_pid = member.get("supervisor_pid")
        if reported_pid is not None and str(reported_pid) != str(state.get("supervisor_pid")):
            return {}
    return state


def proc_generation(pid: object) -> str | None:
    """Return pid and Linux kernel start-time for a live process, or None."""
    try:
        number = int(pid)
        fields = Path("/proc/%d/stat" % number).read_text().rsplit(")", 1)[1].split()
        if fields[0] == "Z":
            return None
        return "%d:%s" % (number, fields[19])
    except (OSError, ValueError, IndexError, TypeError):
        return None


def warm_resume_identity(name: str, member: dict | None = None) -> tuple[str | None, str | None]:
    """Return supervisor generation and newest reported transcript's session id."""
    state = warm_state(name, member)
    pid = state.get("supervisor_pid")
    generation = proc_generation(pid)
    if generation is None:
        return None, None
    candidates: list[Path] = []
    for value in (state.get("transcript_path"), (member or {}).get("transcript_path"), (member or {}).get("transcript")):
        if isinstance(value, str) and value:
            candidates.append(Path(value).expanduser())
    transcripts = (member or {}).get("transcripts")
    if isinstance(transcripts, list):
        candidates.extend(Path(item).expanduser() for item in transcripts if isinstance(item, str))
    existing: list[tuple[float, Path]] = []
    for candidate in candidates:
        try:
            existing.append((candidate.stat().st_mtime, candidate))
        except OSError:
            pass
    if not existing:
        return generation, None
    transcript = max(existing, key=lambda item: item[0])[1]
    session_id = transcript.name[:-6] if transcript.name.endswith(".jsonl") else transcript.stem
    if not re.fullmatch(r"[A-Fa-f0-9-]{16,64}", session_id):
        return generation, None
    return generation, session_id


def live_session_refusal(nurse: str, name: str, session_id: str) -> str | None:
    """The shared live-session guard (nurse-joy `live-session` verb): the
    refusal message when the resume id is live in another process, else None.

    2026-10-17, Fable seat diagnosis Part 2: a warm revive must never relaunch
    onto a conversation already held by a live pty host — the 2026-10-17
    incident /exit-ed the tmux supervisor for nothing and every relaunch was
    refused by the token preflight. The check itself lives in nurse-joy (one
    copy); this lane only consumes its JSON. Fails CLOSED: an unavailable or
    unreadable check refuses too, because a second writer on a live session is
    the one failure this guard exists to prevent."""
    try:
        proc = subprocess.run([nurse, "live-session", name, session_id], stdin=subprocess.DEVNULL,
                              stdout=subprocess.PIPE, stderr=subprocess.DEVNULL, text=True,
                              timeout=30, close_fds=True, env=child_env())
    except (OSError, subprocess.TimeoutExpired):
        return ("live-session check unavailable (nurse-joy live-session did not run); "
                "refusing rather than risk a second writer on session %s" % session_id)
    if proc.returncode != 0:
        return ("live-session check unavailable (nurse-joy live-session failed); "
                "refusing rather than risk a second writer on session %s" % session_id)
    try:
        payload = json.loads(proc.stdout)
    except ValueError:
        return ("live-session check unreadable; refusing rather than risk a second writer on session %s" % session_id)
    if payload.get("live") is True:
        return str(payload.get("message") or "session %s is live in another process" % session_id)
    return None


def make_event(host: str, agent: str, kind: str, severity: str, title: str, body: str, payload: dict, when: dt.datetime) -> dict:
    return {
        "schema": SCHEMA,
        "source": SOURCE,
        "kind": kind,
        "severity": severity,
        "dedupe_key": "agent_watchdog:%s:%s:%s:%s" % (host, agent, kind, when.strftime("%Y%m%dT%H%M%S")),
        "title": title,
        "body": body,
        "link": None,
        "audience": ["metsatron"],
        "occurred_at": when.isoformat(timespec="seconds"),
        "expires_at": None,
        "payload": dict(payload, host=host, agent=agent),
    }


def publish(event: dict, spool: Path, when: dt.datetime) -> None:
    token = uuid.uuid4().hex
    # Nanoseconds after the second keep same-second events in emission order for a consumer that sorts by name.
    name = "%s-%s-%09d-%s.json" % (SOURCE, when.astimezone(dt.timezone.utc).strftime("%Y%m%dT%H%M%SZ"), time.time_ns() % 10**9, token)
    atomic_write(spool / name, (json.dumps(event, sort_keys=True, separators=(",", ":")) + "\n").encode("utf-8"))


def boot_owns_lock(path: Path) -> bool:
    try:
        fd = os.open(str(path), os.O_RDWR)
    except OSError:
        return False
    try:
        fcntl.flock(fd, fcntl.LOCK_EX | fcntl.LOCK_NB)
    except OSError:
        return True
    finally:
        os.close(fd)
    return False


def generation_of(agent: str, pid_dir: Path) -> str | None:
    """Identity of the agent's supervisor: pid plus kernel start-time, or None when unfenced."""
    name = PID_FILES.get(agent)
    if name is None:
        return None
    try:
        pid = int((pid_dir / name).read_text().strip())
        stat = Path("/proc/%d/stat" % pid).read_text()
    except (OSError, ValueError):
        return "absent"
    # Field 22 (starttime) counted after the parenthesised command name.
    fields = stat.rsplit(")", 1)[1].split()
    return "%d:%s" % (pid, fields[19])


def pid_alive(pid: int) -> bool:
    try:
        os.kill(pid, 0)
    except ProcessLookupError:
        return False
    except PermissionError:
        return True
    return True


def request_main(argv: list[str]) -> int:
    """Agent-side entry: ask the external watchdog to restart an agent, then return."""
    default_agent = os.environ.get("TELEGRAM_AGENT_SELF")
    if not default_agent and os.environ.get("CLAUDE_WARM_HERDR_AGENT"):
        default_agent = WARM_PREFIX + os.environ["CLAUDE_WARM_HERDR_AGENT"]
    parser = argparse.ArgumentParser(
        prog="telegram-agent-watchdog request",
        description="Request an external restart of an agent. Returns immediately and never signals any process group.",
    )
    parser.add_argument("agent", nargs="?", default=default_agent,
                        help="agent to restart; defaults to $TELEGRAM_AGENT_SELF or $CLAUDE_WARM_HERDR_AGENT")
    parser.add_argument("--other", action="store_true", help="allow targeting an agent other than $TELEGRAM_AGENT_SELF")
    parser.add_argument("--requester-pid", type=int, default=os.getppid(),
                        help="process whose exit means the requesting turn has detached (default: parent)")
    parser.add_argument("--state-dir", default=str(state_home() / "telegram-agent-watchdog"))
    parser.add_argument("--pid-dir", default=str(state_home() / "telegram-agents"))
    parser.add_argument("--warm-file", default=str(Path.home() / ".config/telegram-agent-watchdog/warm-sessions"))
    parser.add_argument("--nurse", default=shutil.which("nurse-joy") or str(Path.home() / ".local/hx/bin/nurse-joy"))
    args = parser.parse_args(argv)
    warm_target = bool(args.agent and args.agent.startswith(WARM_PREFIX))
    warm_name = args.agent[len(WARM_PREFIX):] if warm_target else ""
    warm_names = read_warm_sessions(Path(args.warm_file)) if warm_target else []
    if warm_target and (not re.fullmatch(r"[A-Za-z][A-Za-z0-9_-]*", warm_name) or warm_name.lower() not in {n.lower() for n in warm_names}):
        print("telegram-agent-watchdog request: warm seat must be listed in --warm-file", file=sys.stderr)
        return 2
    if warm_target:
        warm_name = next(name for name in warm_names if name.lower() == warm_name.lower())
    if not args.agent or (not warm_target and args.agent not in STATUS_LABELS):
        print("telegram-agent-watchdog request: name a known agent (%s) or listed warm-<name>" % ", ".join(sorted(STATUS_LABELS)), file=sys.stderr)
        return 2
    self_name = os.environ.get("TELEGRAM_AGENT_SELF")
    warm_self = os.environ.get("CLAUDE_WARM_HERDR_AGENT")
    is_self = bool(warm_target and warm_self and warm_name.lower() == warm_self.lower()) or bool(not warm_target and self_name and args.agent == self_name)
    if self_name and not warm_target and args.agent != self_name and not args.other:
        print("telegram-agent-watchdog request: %s is not this agent (%s); pass --other to target it" % (args.agent, self_name), file=sys.stderr)
        return 2
    if warm_self and warm_target and warm_name.lower() != warm_self.lower() and not args.other:
        print("telegram-agent-watchdog request: %s is not this warm seat (%s); pass --other to target it" % (warm_name, warm_self), file=sys.stderr)
        return 2
    os.umask(0o077)
    canonical_agent = WARM_PREFIX + warm_name.lower() if warm_target else args.agent
    path = Path(args.state_dir) / "requests" / ("%s.json" % canonical_agent)
    if path.exists():
        print("telegram-agent-watchdog request: revive of %s already pending" % args.agent)
        return 0
    generation = generation_of(args.agent, Path(args.pid_dir)) if not warm_target else None
    resume_session = None
    if warm_target:
        member = warm_members(args.nurse, 30).get(warm_name.lower())
        generation, resume_session = warm_resume_identity(warm_name, member)
        if generation is None or resume_session is None:
            print("telegram-agent-watchdog request: live warm supervisor or transcript is unavailable", file=sys.stderr)
            return 2
    body = {
        "schema": REQUEST_SCHEMA,
        "id": uuid.uuid4().hex,
        "agent": canonical_agent,
        "requester_pid": args.requester_pid,
        "generation": generation,
        "self_requested": is_self,
        "requested_at": int(time.time()),
    }
    if warm_target:
        body["resume_session"] = resume_session
    atomic_write(path, (json.dumps(body, sort_keys=True) + "\n").encode("utf-8"))
    print("telegram-agent-watchdog request: revive of %s queued; the watchdog restarts it after this turn detaches" % args.agent)
    return 0


def process_requests(args: argparse.Namespace, host: str, state: dict, when: dt.datetime, now: float) -> list[dict]:
    """Execute pending self-revive requests from outside the requesting process group."""
    events: list[dict] = []
    request_dir = Path(args.state_dir) / "requests"
    revive = state.setdefault("revive", {})
    for path in sorted(request_dir.glob("*.json")):
        try:
            request = json.loads(path.read_text(encoding="utf-8"))
            agent = request["agent"]
            warm_target = isinstance(agent, str) and agent.startswith(WARM_PREFIX)
            if request.get("schema") != REQUEST_SCHEMA or not isinstance(agent, str) or (agent not in STATUS_LABELS and not warm_target):
                raise ValueError("bad request")
        except (OSError, ValueError, KeyError):
            path.unlink(missing_ok=True)
            events.append(make_event(host, "*", "revive_rejected", "warning", "Malformed revive request dropped",
                                     "A revive request in the watchdog queue was unreadable and was dropped", {}, when))
            continue
        requester = int(request.get("requester_pid") or 0)
        age = now - float(request.get("requested_at", now))
        if requester > 1 and pid_alive(requester):
            if age > args.request_timeout:
                path.unlink(missing_ok=True)
                events.append(make_event(host, agent, "revive_rejected", "warning", "%s revive request timed out" % agent,
                                         "The requesting turn never detached within %ss; nothing was restarted" % args.request_timeout,
                                         {"request": request.get("id")}, when))
            continue  # wait until the requesting turn has detached
        warm_name = agent[len(WARM_PREFIX):] if warm_target else None
        warm_names = read_warm_sessions(Path(args.warm_file)) if warm_target else []
        if warm_target and (not warm_name or warm_name.lower() not in {name.lower() for name in warm_names}):
            path.unlink(missing_ok=True)
            events.append(make_event(host, agent, "revive_rejected", "warning", "%s is not an approved warm seat" % agent,
                                     "The requested warm seat is not in the private warm-session roster; no restart was attempted",
                                     {"request": request.get("id")}, when))
            continue
        if warm_target:
            warm_name = next(name for name in warm_names if name.lower() == warm_name.lower())
            current_member = warm_members(args.nurse, 30).get(warm_name.lower())
            current_generation, _ = warm_resume_identity(warm_name, current_member)
        else:
            current_generation = generation_of(agent, Path(args.pid_dir))
        fence = request.get("generation")
        if warm_target and not isinstance(fence, str):
            path.unlink(missing_ok=True)
            events.append(make_event(host, agent, "revive_stale", "notice", "%s revive request has no generation fence" % agent,
                                     "The warm request did not record a supervisor generation; no restart was attempted",
                                     {"request": request.get("id")}, when))
            continue
        if fence is not None and fence != current_generation:
            path.unlink(missing_ok=True)
            events.append(make_event(host, agent, "revive_stale", "notice", "%s revive request is stale" % agent,
                                     "%s was already restarted since the request; no second restart" % agent,
                                     {"request": request.get("id")}, when))
            continue
        if now - float(revive.get(agent, 0)) < args.revive_cooldown:
            path.unlink(missing_ok=True)
            events.append(make_event(host, agent, "revive_rejected", "warning", "%s revive is cooling down" % agent,
                                     "%s was self-revived less than %ss ago; request refused" % (agent, args.revive_cooldown),
                                     {"request": request.get("id")}, when))
            continue
        if warm_target:
            # Live-session guard before anything is killed: a warm revive whose
            # resume id is live in another process (a bg-pty host) is refused as
            # revive_rejected instead of /exit-ing the tmux supervisor for nothing.
            warm_session = request.get("resume_session")
            if isinstance(warm_session, str) and re.fullmatch(r"[A-Fa-f0-9-]{16,64}", warm_session):
                refusal = live_session_refusal(args.nurse, warm_name, warm_session)
                if refusal is not None:
                    path.unlink(missing_ok=True)
                    events.append(make_event(host, agent, "revive_rejected", "warning",
                                             "%s revive refused: the resume session is live in another process" % agent,
                                             refusal, {"request": request.get("id"), "resume_session": warm_session}, when))
                    continue
        if args.dry_run:
            continue
        path.unlink(missing_ok=True)
        revive[agent] = int(now)
        marker = Path(args.intent_dir) / agent
        force_escalated = False
        code_staleness = "not-applicable"
        try:
            if warm_target:
                session_id = request.get("resume_session")
                if not isinstance(session_id, str) or not re.fullmatch(r"[A-Fa-f0-9-]{16,64}", session_id):
                    raise ValueError("missing or invalid live resume session")
                cmd = [args.nurse, "revive", "--no-visit", "--resume", session_id, warm_name]
                try:
                    started = subprocess.run(cmd, stdin=subprocess.DEVNULL, stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
                                             text=True, timeout=args.warm_revive_grace, close_fds=True, env=child_env())
                except subprocess.TimeoutExpired:
                    if not request.get("self_requested"):
                        raise
                    force_escalated = True
                    started = subprocess.run([args.nurse, "revive", "--no-visit", "--force", "--resume", session_id, warm_name],
                                             stdin=subprocess.DEVNULL, stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
                                             text=True, timeout=args.start_timeout, close_fds=True, env=child_env())
                detail = (started.stdout or "").strip()[-300:]
                fresh = warm_members(args.nurse, 60).get(warm_name.lower())
                verdict = fresh.get("verdict") if fresh else None
                ok = started.returncode == 0 and verdict in ("field", "degraded")
                code_stale = bool(fresh and (fresh.get("code_stale") is True or fresh.get("generation_loaded") is False or verdict == "degraded"))
                code_staleness = "stale" if code_stale else "fresh" if ok else "unknown"
                if not ok:
                    detail = detail or "readiness not confirmed by nurse-joy status"
            else:
                stopped = run_manager(args.manager, ["stop", agent], args.start_timeout)
                started = run_manager(args.manager, ["start", agent], args.start_timeout) if stopped.returncode == 0 else stopped
                ok = stopped.returncode == 0 and started.returncode == 0
                detail = (started.stdout or "").strip()[-300:]
        except (OSError, ValueError, subprocess.SubprocessError) as exc:
            ok, detail = False, type(exc).__name__
        if ok and not warm_target:
            probe = run_manager(args.manager, ["status"], 60)
            ok = classify(agent, probe.stdout) == "up"
            detail = detail or "readiness not confirmed by status"
        if not ok:
            marker.unlink(missing_ok=True)  # a failed revive must not leave the agent parked as operator-stopped
        events.append(make_event(host, agent, "revive_done" if ok else "revive_failed",
                                 "notice" if ok else "critical",
                                 "%s self-revive %s" % (agent, "completed" if ok else "failed"),
                                 "%s was restarted externally on request and verified up" % agent if ok else
                                 "%s self-revive did not verify; the normal relaunch loop takes over: %s" % (agent, detail),
                                 {"request": request.get("id"), "requester_pid": requester,
                                  "code_staleness": code_staleness, "force_escalated": force_escalated}, when))
    return events


def main(argv: list[str]) -> int:
    if argv and argv[0] == "request":
        return request_main(argv[1:])
    args = parse_args(argv)
    host = socket.gethostname()
    if host != args.expected_host:
        print("telegram-agent-watchdog: refusing host %s; expected %s" % (host, args.expected_host), file=sys.stderr)
        return 1
    os.umask(0o077)
    state_dir = Path(args.state_dir)
    state_dir.mkdir(mode=0o700, parents=True, exist_ok=True)
    lock_fd = os.open(str(state_dir / "watchdog.lock"), os.O_CREAT | os.O_RDWR, 0o600)
    try:
        fcntl.flock(lock_fd, fcntl.LOCK_EX | fcntl.LOCK_NB)
    except OSError:
        print("telegram-agent-watchdog: another run owns the lock")
        return 0
    if boot_owns_lock(Path(args.boot_lock)):
        print("telegram-agent-watchdog: boot owner is running; standing down")
        return 0

    when = dt.datetime.now().astimezone()
    now = time.time()
    spool = Path(args.spool)
    state_path = state_dir / "state.json"
    state = load_state(state_path)
    agents_state: dict = state["agents"]
    outcomes: dict[str, str] = {}
    events: list[dict] = []
    try:
        events.extend(process_requests(args, host, state, when, now))
    except (OSError, subprocess.SubprocessError) as exc:
        print("telegram-agent-watchdog: revive request processing failed: %s" % type(exc).__name__, file=sys.stderr)

    try:
        enabled_run = run_manager(args.manager, ["enabled"], 30)
        status_run = run_manager(args.manager, ["status"], 60)
    except (OSError, subprocess.SubprocessError) as exc:
        enabled_run = status_run = None
        print("telegram-agent-watchdog: manager probe failed: %s" % type(exc).__name__, file=sys.stderr)
    if enabled_run is None or enabled_run.returncode != 0 or not enabled_run.stdout.split():
        events.append(make_event(host, "*", "probe_failed", "warning", "Agent watchdog cannot read the enabled list",
                                 "telegram-agent-host enabled failed or returned nothing on %s" % host, {}, when))
        enabled = []
    else:
        enabled = enabled_run.stdout.split()
    # telegram-agent-host status exits nonzero when any agent is degraded, so its output is
    # read whatever the exit code; a probe that printed nothing still reads as unknown per agent.
    status_text = status_run.stdout if status_run is not None else ""

    # Telegram agents relaunch through the host manager; warm Claude sessions through nurse-joy.
    targets = [(agent, classify(agent, status_text), [args.manager, "start", agent]) for agent in enabled]
    warm = read_warm_sessions(Path(args.warm_file))
    warm_status = warm_verdicts(args.nurse, warm, 60, args.tmux)
    targets += [("warm-" + name.lower(), warm_status[name], [args.nurse, "revive", "--no-visit", name.lower()]) for name in warm]
    supervised = {agent for agent, _, _ in targets}

    for agent, verdict, start_cmd in targets:
        entry = agents_state.setdefault(agent, {})
        marker = Path(args.intent_dir) / agent
        if verdict == "up":
            if entry.get("down_since"):
                events.append(make_event(host, agent, "recovered", "notice", "%s is back" % agent,
                                         "%s is running again on %s after %s relaunch attempt(s)" % (agent, host, entry.get("attempts", 0)),
                                         {"attempts": entry.get("attempts", 0), "down_since": entry["down_since"]}, when))
            agents_state[agent] = {}
            outcomes[agent] = "up"
            continue
        if verdict == "unknown":
            if entry.get("probe") != "unknown":
                events.append(make_event(host, agent, "probe_unknown", "warning", "%s liveness unreadable" % agent,
                                         "The watchdog could not read a liveness line for %s on %s; it did not relaunch anything" % (agent, host), {}, when))
            entry["probe"] = "unknown"
            outcomes[agent] = "unknown"
            continue
        entry.pop("probe", None)
        if marker.exists():
            outcomes[agent] = "stopped-by-operator"
            continue
        if not entry.get("down_since"):
            entry.update(down_since=int(now), attempts=0, last_attempt=0, gave_up=False)
            events.append(make_event(host, agent, "down", "warning", "%s is down" % agent,
                                     "%s is enabled but not running on %s; the watchdog will relaunch it" % (agent, host), {}, when))
        attempts = int(entry.get("attempts", 0))
        if attempts >= args.max_attempts:
            if not entry.get("gave_up"):
                entry["gave_up"] = True
                events.append(make_event(host, agent, "relaunch_failed", "critical", "%s will not come back" % agent,
                                         "%s stayed down after %s relaunch attempts on %s; it needs a hand" % (agent, attempts, host),
                                         {"attempts": attempts}, when))
            outcomes[agent] = "gave-up"
            continue
        wait = args.backoff * (2 ** attempts)
        if now - float(entry.get("last_attempt", 0)) < wait:
            outcomes[agent] = "backing-off"
            continue
        if args.dry_run:
            outcomes[agent] = "would-relaunch"
            continue
        entry["attempts"] = attempts + 1
        entry["last_attempt"] = int(now)
        try:
            started = run_manager(start_cmd[0], start_cmd[1:], args.start_timeout)
            outcomes[agent] = "relaunched" if started.returncode == 0 else "relaunch-failed"
            entry["last_result"] = started.returncode
        except (OSError, subprocess.SubprocessError) as exc:
            outcomes[agent] = "relaunch-failed"
            entry["last_result"] = type(exc).__name__

    agents_state_out = {name: value for name, value in agents_state.items() if name in supervised or value}
    if not args.dry_run:
        for event in events:
            try:
                publish(event, spool, when)
            except OSError as exc:
                print("telegram-agent-watchdog: spool write failed: %s" % type(exc).__name__, file=sys.stderr)
        atomic_write(state_path, (json.dumps({"schema": STATE_SCHEMA, "agents": agents_state_out, "revive": state.get("revive", {})}, sort_keys=True) + "\n").encode("utf-8"))
        request_receipts = [dict(e["payload"], result=e["kind"]) for e in events if e["kind"].startswith("revive_")]
        atomic_write(state_dir / "receipt.json", (json.dumps({"schema": STATE_SCHEMA, "host": host, "timestamp": int(now), "outcomes": outcomes, "events": [e["kind"] + ":" + e["payload"]["agent"] for e in events], "request_receipts": request_receipts}, sort_keys=True) + "\n").encode("utf-8"))
    for name, outcome in sorted(outcomes.items()):
        print("telegram-agent-watchdog: %s=%s" % (name, outcome))
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))

** Watchdog cron deployment helper

Installs =/etc/cron.d/dotcortex-telegram-agent-watchdog=, every three minutes as the operator, with the Guix core profile on =PATH= like the boot owner. It refuses any host but the named one.

#+BEGIN_SRC bash :tangle all/.local/bin/telegram-agent-watchdog-cron-apply :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755) :comments no

TARGET="/etc/cron.d/dotcortex-telegram-agent-watchdog"

DRY=0
REMOVE=0

while [ "$#" -gt 0 ]; do
  case "$1" in
    --host) [ "$#" -ge 2 ] || { echo "$TAG: --host requires a value" >&2; exit 2; }; EXPECTED_HOST="$2"; shift ;;
    --dry-run) DRY=1 ;;
    --remove) REMOVE=1 ;;
    -h|--help|help) echo "Usage: $TAG --host EXACT_HOST [--dry-run] [--remove]"; exit 0 ;;
    *) echo "$TAG: unknown argument: $1" >&2; exit 2 ;;
  esac
  shift
done

run_priv() { if [ "$(id -u)" = 0 ]; then "$@"; else sudo -n "$@"; fi; }

if [ "$REMOVE" = 1 ]; then
  if [ "$DRY" = 1 ]; then echo "remove $TARGET"; else run_priv rm -f "$TARGET"; echo "$TAG: removed $TARGET"; fi
  exit 0
fi

[ -n "$EXPECTED_HOST" ] || { echo "$TAG: --host EXACT_HOST is required" >&2; exit 2; }

USER_NAME="$(id -un)"

[ "$DRY" = 1 ] || [ -x "$WATCHDOG" ] || { echo "$TAG: missing $WATCHDOG; tangle and stow first" >&2; exit 1; }

** Watchdog contract tests

The tests drive the real watchdog against a fake =telegram-agent-host=. They assert intent, not activity: a relaunch happens only for a down, enabled, unmarked agent; an unreadable status line relaunches nothing; the attempt cap holds; recovery publishes a notice.

#+BEGIN_SRC python :tangle all/.local/share/dotcortex/tests/test-telegram-agent-watchdog.py :comments no

class WatchdogTests(unittest.TestCase):
    def setUp(self) -> None:
        self.tmp = tempfile.TemporaryDirectory()
        self.root = Path(self.tmp.name)
        self.manager = self.root / "manager"
        self.manager.write_text(FAKE_MANAGER)
        self.manager.chmod(self.manager.stat().st_mode | stat.S_IXUSR)
        (self.root / "enabled").write_text("ductor codex\n")
        self.set_status("RUNNING", "RUNNING")
        self.nurse = self.root / "nurse"
        self.nurse.write_text(FAKE_NURSE)
        self.nurse.chmod(self.nurse.stat().st_mode | stat.S_IXUSR)
        self.set_warm({})
        self.tmux = self.root / "tmux"
        self.tmux.write_text(FAKE_TMUX)
        self.tmux.chmod(self.tmux.stat().st_mode | stat.S_IXUSR)

    def tearDown(self) -> None:
        self.tmp.cleanup()

    def set_status(self, ductor: str, codex: str) -> None:
        (self.root / "status").write_text(
            "Host: x\nRunning processes:\n  ductor: %s\n  codex-helmastra (--telegram): %s\n" % (ductor, codex)
        )

    def run_watchdog(self, *extra: str, backoff: str = "0") -> subprocess.CompletedProcess:
        return subprocess.run(
            [str(WATCHDOG), "--expected-host", HOST, "--manager", str(self.manager),
             "--state-dir", str(self.root / "state"), "--intent-dir", str(self.root / "intent"),
             "--boot-lock", str(self.root / "boot.lock"), "--spool", str(self.root / "spool"),
             "--pid-dir", str(self.root / "pids"), "--backoff", backoff,
             "--warm-file", str(self.root / "warm"), "--nurse", str(self.nurse), "--tmux", str(self.tmux), *extra],
            env=dict(os.environ, FAKE_ROOT=str(self.root), XDG_STATE_HOME=str(self.root / "xdg-state"),
                     XDG_RUNTIME_DIR=str(self.root / "xdg-runtime")), text=True, capture_output=True, timeout=30,
        )

    def starts(self) -> list[str]:
        path = self.root / "starts"
        return path.read_text().split() if path.exists() else []

    def events(self) -> list[dict]:
        return [json.loads(p.read_text()) for p in sorted((self.root / "spool").glob("*.json"))]

    def test_healthy_agents_are_left_alone(self) -> None:
        result = self.run_watchdog()
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.starts(), [])
        self.assertEqual(self.events(), [])

    def test_down_agent_is_relaunched_and_alerted(self) -> None:
        self.set_status("RUNNING", "STOPPED")
        self.run_watchdog()
        self.assertEqual(self.starts(), ["codex"])
        self.assertEqual([e["kind"] for e in self.events()], ["down"])
        self.set_status("RUNNING", "RUNNING")
        self.run_watchdog()
        self.assertEqual([e["kind"] for e in self.events()], ["down", "recovered"])
        self.assertEqual(self.events()[1]["severity"], "notice")

    def test_operator_stop_marker_is_respected(self) -> None:
        (self.root / "intent").mkdir()
        (self.root / "intent" / "codex").write_text("")
        self.set_status("RUNNING", "STOPPED")
        self.run_watchdog()
        self.assertEqual(self.starts(), [])

    def test_disabled_agent_is_never_touched(self) -> None:
        (self.root / "enabled").write_text("ductor\n")
        self.set_status("RUNNING", "STOPPED")
        self.run_watchdog()
        self.assertEqual(self.starts(), [])

    def test_unreadable_status_never_relaunches(self) -> None:
        (self.root / "status").write_text("Host: x\nnothing useful here\n")
        self.run_watchdog()
        self.assertEqual(self.starts(), [])
        self.assertEqual({e["kind"] for e in self.events()}, {"probe_unknown"})

    def test_empty_status_output_never_relaunches(self) -> None:
        (self.root / "status").write_text("")
        (self.root / "status_fail").write_text("")
        self.run_watchdog()
        self.assertEqual(self.starts(), [])

    def test_status_lines_are_read_even_when_the_status_call_exits_nonzero(self) -> None:
        # The real host exits 1 when any agent is degraded; the other agents' lines still count.
        self.set_status("RUNNING", "STOPPED")
        (self.root / "status_fail").write_text("")
        self.run_watchdog()
        self.assertEqual(self.starts(), ["codex"])

    def test_attempt_cap_holds_and_alerts_once(self) -> None:
        self.set_status("RUNNING", "STOPPED")
        (self.root / "start_fail").write_text("")
        for _ in range(6):
            self.run_watchdog("--max-attempts", "2")

* Session anchor

Sealed 2026-10-09 after two user-wide SIGTERMs on Kikin (2026-10-08 21:01 and 2026-10-09 01:16). Each one fired the moment the user's last live elogind login ended: all week the only live login had been one long-running SSH connection from a laptop, and when it dropped, every process the user owned died with it: tmux, herdr, the Telegram agents, the warm Claude sessions. The kernel log orders it each time: =Removed session N=, then the kill. elogind reports =KillUserProcesses=false=, so the exact mechanism is not the textbook one, but the trigger is reproducible: the user dropping to zero live sessions.

The anchor keeps one live login open at all times, independent of any laptop. It is a loopback SSH session with a dedicated key that sshd confines to =from="127.0.0.1,::1",restrict,command="/bin/sleep infinity"=, so the key can do nothing but hold a session open. The host key is pinned from the machine's own =/etc/ssh= public key in a private known_hosts file, never accepted on first use. A cron entry starts the supervisor every minute; =flock= keeps exactly one alive, and the supervisor reconnects with a short backoff if the session ever drops.

Machine-local setup (private, never tracked): generate =~/.ssh/session-anchor= (ed25519, no passphrase), append the restricted line above with its public key to =~/.ssh/authorized_keys=, and write =~/.config/session-anchor/known_hosts= as =127.0.0.1 <type> <key>= taken from =/etc/ssh/ssh_host_ed25519_key.pub=. The supervisor refuses to start without all three.

# session-anchor: hold one permanent loopback SSH login so the user never drops to zero live elogind sessions.
set -uo pipefail

TAG="session-anchor"
KEY="${SESSION_ANCHOR_KEY:-$HOME/.ssh/session-anchor}"
KNOWN_HOSTS="${SESSION_ANCHOR_KNOWN_HOSTS:-$HOME/.config/session-anchor/known_hosts}"
STATE_DIR="${SESSION_ANCHOR_STATE_DIR:-${XDG_STATE_HOME:-$HOME/.local/state}/session-anchor}"
SSH_BIN="${SESSION_ANCHOR_SSH_BIN:-ssh}"
BACKOFF="${SESSION_ANCHOR_BACKOFF:-10}"
ONCE=0

usage() { echo "Usage: $TAG [--once] [--check]  (holds a loopback SSH session; see agents-watchdog.org)"; }

CHECK=0
while [ "$#" -gt 0 ]; do
  case "$1" in
    --once) ONCE=1 ;;
    --check) CHECK=1 ;;
    -h|--help|help) usage; exit 0 ;;
    *) echo "$TAG: unknown argument: $1" >&2; usage >&2; exit 2 ;;
  esac
  shift
done

[ -r "$KEY" ] || { echo "$TAG: missing key $KEY (machine-local setup not done)" >&2; exit 69; }
[ -s "$KNOWN_HOSTS" ] || { echo "$TAG: missing pinned known_hosts $KNOWN_HOSTS" >&2; exit 69; }
[ "$CHECK" = 0 ] || { echo "$TAG: setup present"; exit 0; }

mkdir -p "$STATE_DIR"
exec 9>"$STATE_DIR/anchor.lock"
if ! flock -n 9; then
  exit 0  # another supervisor already holds the anchor
fi

while :; do
  date +%s > "$STATE_DIR/last-connect"
  "$SSH_BIN" -i "$KEY" -o IdentitiesOnly=yes -o BatchMode=yes \
    -o UserKnownHostsFile="$KNOWN_HOSTS" -o StrictHostKeyChecking=yes -o GlobalKnownHostsFile=/dev/null \
    -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -o ControlMaster=no -o ControlPath=none \
    -T 127.0.0.1 9>&- </dev/null >>"$STATE_DIR/anchor.log" 2>&1
  echo "$(date -Is) $TAG: session ended (rc=$?); reconnecting in ${BACKOFF}s" >>"$STATE_DIR/anchor.log"
  [ "$ONCE" = 0 ] || exit 0
  sleep "$BACKOFF"
done

set -euo pipefail

TAG="session-anchor-cron-apply"
TARGET="/etc/cron.d/dotcortex-session-anchor"
EXPECTED_HOST=""
DRY=0
REMOVE=0

while [ "$#" -gt 0 ]; do
  case "$1" in
    --host) [ "$#" -ge 2 ] || { echo "$TAG: --host requires a value" >&2; exit 2; }; EXPECTED_HOST="$2"; shift ;;
    --dry-run) DRY=1 ;;
    --remove) REMOVE=1 ;;
    -h|--help|help) echo "Usage: $TAG --host EXACT_HOST [--dry-run] [--remove]"; exit 0 ;;
    *) echo "$TAG: unknown argument: $1" >&2; exit 2 ;;
  esac
  shift
done

run_priv() { if [ "$(id -u)" = 0 ]; then "$@"; else sudo -n "$@"; fi; }

if [ "$REMOVE" = 1 ]; then
  if [ "$DRY" = 1 ]; then echo "remove $TARGET"; else run_priv rm -f "$TARGET"; echo "$TAG: removed $TARGET"; fi
  exit 0
fi

[ -n "$EXPECTED_HOST" ] || { echo "$TAG: --host EXACT_HOST is required" >&2; exit 2; }
[ "$(hostname)" = "$EXPECTED_HOST" ] || { echo "$TAG: refusing installation on $(hostname); expected $EXPECTED_HOST" >&2; exit 1; }

USER_NAME="$(id -un)"
TARGET_HOME="$HOME"
ANCHOR="$TARGET_HOME/.local/bin/session-anchor"
[ "$DRY" = 1 ] || "$ANCHOR" --check || { echo "$TAG: machine-local setup missing; see agents-watchdog.org" >&2; exit 1; }

TMP="$(mktemp)"
trap 'rm -f "$TMP"' EXIT
cat >"$TMP" <<EOF
# DotCortex session anchor; managed by $TAG.
,* * * * * ${USER_NAME} HOME=${TARGET_HOME} PATH=/usr/local/bin:/usr/bin:/bin ${ANCHOR} >/dev/null 2>&1
EOF

if [ "$DRY" = 1 ]; then
  cat "$TMP"
else
  run_priv install -o root -g root -m 0644 "$TMP" "$TARGET"
  echo "$TAG: installed $TARGET"
fi

#+BEGIN_SRC python :tangle all/.local/share/dotcortex/tests/test-session-anchor.py :comments no
from __future__ import annotations

import os
from pathlib import Path
import stat
import subprocess
import tempfile
import time
import unittest

ANCHOR = Path(__file__).resolve().parents[3] / "bin" / "session-anchor"

FAKE_SSH = """#!/usr/bin/env bash
printf '%s\\n' "$@" > "$FAKE_ROOT/ssh-args"
sleep "${FAKE_SSH_HOLD:-0}"
"""


class SessionAnchorTests(unittest.TestCase):
    def setUp(self) -> None:
        self.tmp = tempfile.TemporaryDirectory()
        self.root = Path(self.tmp.name)
        self.ssh = self.root / "ssh"
        self.ssh.write_text(FAKE_SSH)
        self.ssh.chmod(self.ssh.stat().st_mode | stat.S_IXUSR)
        (self.root / "key").write_text("k")
        (self.root / "known").write_text("127.0.0.1 ssh-ed25519 AAAA\n")

    def tearDown(self) -> None:
        self.tmp.cleanup()

    def env(self, **extra: str) -> dict:
        return dict(os.environ, FAKE_ROOT=str(self.root), SESSION_ANCHOR_KEY=str(self.root / "key"),
                    SESSION_ANCHOR_KNOWN_HOSTS=str(self.root / "known"), SESSION_ANCHOR_STATE_DIR=str(self.root / "state"),
                    SESSION_ANCHOR_SSH_BIN=str(self.ssh), **extra)

    def run_anchor(self, *args: str, **extra: str) -> subprocess.CompletedProcess:
        return subprocess.run([str(ANCHOR), *args], env=self.env(**extra), text=True, capture_output=True, timeout=30)

    def test_refuses_without_machine_local_setup(self) -> None:
        (self.root / "key").unlink()
        result = self.run_anchor("--once")
        self.assertEqual(result.returncode, 69)
        self.assertFalse((self.root / "ssh-args").exists())

    def test_connects_loopback_with_pinned_host_key_only(self) -> None:
        result = self.run_anchor("--once")
        self.assertEqual(result.returncode, 0, result.stderr)
        args = (self.root / "ssh-args").read_text().split("\n")
        self.assertEqual(args[-2], "127.0.0.1")  # loopback only
        joined = " ".join(args)
        for required in ("IdentitiesOnly=yes", "BatchMode=yes", "StrictHostKeyChecking=yes",
                         "UserKnownHostsFile=%s" % (self.root / "known"), "GlobalKnownHostsFile=/dev/null", "-T"):
            self.assertIn(required, joined)
        self.assertNotIn("accept-new", joined)
        self.assertNotIn("StrictHostKeyChecking=no", joined)

    def test_second_supervisor_stands_down(self) -> None:
        first = subprocess.Popen([str(ANCHOR), "--once"], env=self.env(FAKE_SSH_HOLD="3"))
        try:
            time.sleep(0.5)
            second = self.run_anchor("--once")
            self.assertEqual(second.returncode, 0)
        finally:
            first.wait(timeout=30)
        self.assertEqual(first.returncode, 0)

    def test_help_is_side_effect_free(self) -> None:
        result = subprocess.run([str(ANCHOR), "--help"], text=True, capture_output=True, timeout=30)
        self.assertEqual(result.returncode, 0)


if __name__ == "__main__":
    unittest.main()
