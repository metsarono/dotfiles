* HelmCortex remote workbench

This module extends [[file:agents-users.org][Agent Users]] with the approved
Lane-1 exception for a worker that cannot write the canonical repo over NFS.
The canonical branch is =master=. Landing belongs to its coordinator.

** Scope and local layout

=helmcortex-remote-lane= is a Category-B, Lane-1 command run as the worker's
own Unix user. Its default local root is =$HOME/helmcortex-lane=:
=repo/= is a partial clone cache, =wt/<task>/= is the disposable job worktree,
and =tasks/<task>.json= records the base, sparse paths and successful pushed SHA.
The agent owns this directory; it must be on local disk, never an NFS mount.
The helper checks ownership and an explicit local-filesystem allowlist and
serializes its commands with a nonblocking lock. Requires existing =git=,
=python3=, =findmnt= and =/usr/bin/ssh=; it installs nothing.

This is the approved exception to =agents-users.org='s shared-worktree pattern.
The canonical branch is =master= on the canonical machine. A clone necessarily
creates one local snapshot =master=; the helper immediately detaches its cache
HEAD without checking out or updating that branch, and refuses later operations
if the snapshot changes. All job commits belong to fresh task branches.

** Verbs and failure recovery

- =init=: set =HELMCORTEX_LANE_REMOTE= to the private SSH URL first. Clone with
  =--filter=blob:none --no-checkout= and remote name =x230=, then enable sparse
  cone mode. =HELMCORTEX_LANE_ROOT= optionally selects another agent-owned local
  root. These are process settings; no private config is tangled into this repo.
- =start TASK [--paths PATH...]=: fetch current =x230/master=, refuse reused local
  or remote task names, then create =wt/TASK= and branch =TASK= from that tip.
  Paths are repo-relative directories. A named file selects its containing
  directory. With no paths, only root files are selected. Cone mode always
  includes root metadata and files beside selected directories' ancestors.
  Each worktree has independent sparse settings; no full checkout precedes it.
- =push TASK=: require the matching task branch and a clean worktree (including
  staged and untracked files), fetch current canonical =master=, and require
  commits beyond it. Push one pinned SHA to =refs/heads/TASK=, without force,
  mirror, tags or deletion, and verify the remote SHA before recording a receipt.
- =done TASK=: require that receipt to match the clean worktree's current SHA
  and query the canonical repo again for the identical remote branch SHA.
  Run plain =git worktree remove=, then =git branch -D= locally. The published
  branch stays on the canonical machine. Git refuses dirty, locked or otherwise
  unsafe removals; the helper never uses =--force= or recursively removes a tree.
- =status=: check local lane ownership, cache HEAD, immutable clone snapshot
  and fetch/push URLs, then report fetch age, worktrees and push receipts.
  This is a local health check; it does not claim current remote reachability.

Flat task names must be valid Git branch names and cannot be =master=. Sparse
paths cannot escape the repo or name Git administration. Failed transport,
rejected pushes, missing refs, changed SHAs and incomplete init all fail loud.
A failed init/start retains its artifacts for inspection; nothing is rolled back
or swept away. Stop the worker before push/done. The lock serializes helper
commands, not a model's independent Git commands. One writer owns each task.
Ignored build artifacts can make plain removal fail: review and handle those
inside the task before retrying. If removal succeeds but local branch deletion
fails, the local branch and task record remain recoverable; inspect them.

Landing stays with the coordinator on the canonical machine. There is no remote
checkout, merge, pull, rebase, deletion, or update of canonical =master= here.

** One-time administrator setup (documentation only)

All =YOUR_*= values below are placeholders, replaced only in machine-local
commands/files. =YOUR_AGENT_USER= is the existing worker Unix user;
=YOUR_AGENT_HOST= is its generating host. =YOUR_X230_ALIAS= is the worker's
private SSH alias. =YOUR_CANONICAL_USER= and =YOUR_CANONICAL_HOST= identify the
canonical account and host. No key generation, key installation, SSH config
change, sudoers change or deployment is performed by tangling this module.

Install the verified generated command from the root-owned system checkout
as =/usr/local/bin/helmcortex-remote-lane=, owner/group =root:root=, mode =0755=.
If the dispatcher currently may sudo only through its Codex wrapper, its
administrator must also authorize this exact root-owned helper as
=YOUR_AGENT_USER= (the five documented verbs). The helper itself needs no sudo,
and the worker receives no root access. Keep key/config setup with the human
administrator rather than granting the dispatcher an arbitrary shell as root.

The administrator runs this *on the worker machine*, as the worker. It creates
a dedicated ed25519 transport key, never overwrites an existing pair, and prints
only the public half. The comment identifies user, host and purpose.

=blob:none= without changing repo config; receive permits only branch refs,

** Dispatcher: one Luna job end to end

After administrator setup, initialize once; =-H= uses the worker's own home.
The remote stays named =x230= even when the private SSH alias differs.

#+BEGIN_SRC sh :tangle no
sudo -n -H -u YOUR_AGENT_USER /usr/bin/env \
  HELMCORTEX_LANE_REMOTE=YOUR_X230_ALIAS:/home/YOUR_CANONICAL_USER/HelmCortex \
  /usr/local/bin/helmcortex-remote-lane init
#+END_SRC

For every job, the coordinator supplies an already schema-validated TaskHandoff
JSON file and verifies its exact repo-relative build paths on current canonical
=master=. =NEXUS/= and =LOGS/= stay outside scope. The JSON names the local job
worktree as workdir, the task branch, allowed source paths, tests and commit
requirement; it prohibits changing other refs, remote writes and landing.
The schema's historic location is named in =agents.org=: resolve the live owner
before preparing the handoff rather than inventing or copying a stale schema.
The dispatcher sends the JSON to the wrapper once, through stdin.

#+BEGIN_SRC sh :tangle no
set -eu
task=YOUR_TASK
lane=/home/YOUR_AGENT_USER/helmcortex-lane
handoff=YOUR_VALIDATED_TASKHANDOFF_JSON
sudo -n -H -u YOUR_AGENT_USER /usr/local/bin/helmcortex-remote-lane \
  start "$task" --paths YOUR_REPO_PATH
sudo -n -H -u YOUR_AGENT_USER /usr/local/bin/codex-gillean exec \
  --model gpt-6-luna --sandbox workspace-write --approve-for-me \
  --cd "$lane/wt/$task" --add-dir "$lane/repo/.git" - < "$handoff"
sudo -n -H -u YOUR_AGENT_USER /usr/local/bin/helmcortex-remote-lane push "$task"
sudo -n -H -u YOUR_AGENT_USER /usr/local/bin/helmcortex-remote-lane done "$task"
sudo -n -H -u YOUR_AGENT_USER /usr/local/bin/helmcortex-remote-lane status
#+END_SRC

=--add-dir= exposes the local shared Git administration required to commit in
a linked worktree. It does not add an NFS checkout. The helper's =master= guard
and server-side forced command complement the coordinator's scoped handoff.
The example stops on any failure and leaves the worktree for review. It uses
the existing Codex wrapper; this module neither defines nor changes its login,
credentials or model mapping. Model access and the wrapper's target-machine
CLI flags must be confirmed by the coordinator at dispatch.

#+BEGIN_SRC python :tangle all/.local/bin/helmcortex-remote-lane :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""Disposable local sparse worktrees; publish only task branches to x230."""
from __future__ import annotations

import argparse
import fcntl
import json
import os
import re
import subprocess
import sys
import time
from pathlib import Path


class LaneError(Exception):
    pass


def require(condition, message):
    if not condition:
        raise LaneError(message)


def run(*args, cwd=None, allowed=(0,), input=None):
    result = subprocess.run(args, cwd=cwd, text=True, input=input,
                            stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    if result.returncode not in allowed:
        raise LaneError(f"{args[0]} failed ({result.returncode}): "
                        + (result.stderr or result.stdout).strip())
    if result.stderr:
        print(result.stderr.rstrip(), file=sys.stderr)
    if "--filter=blob:none" in args and "filtering not recognized by server" in result.stderr:
        raise LaneError("server did not support partial clone; incomplete clone retained for inspection")
    return result.stdout.strip()


def local_owned(path):
    """Probe an exact existing path; never walk an ancestor tree or an NFS mount."""
    require(path == path.resolve(), f"symlink path refused: {path}")
    probe = path
    while not probe.exists():
        probe = probe.parent
    fs = run("findmnt", "--noheadings", "--output", "FSTYPE", "--target", str(probe))
    require(fs in {"ext2", "ext3", "ext4", "xfs", "btrfs", "zfs", "tmpfs", "overlay", "f2fs"},
            f"local disk required; filesystem {fs!r} refused at {probe}")
    require(probe.stat().st_uid == os.getuid(), f"invoking user must own {probe}")
    return fs


def atomic_json(path, data):
    temporary = path.with_suffix(".tmp")
    with temporary.open("x") as stream:
        json.dump(data, stream, sort_keys=True)
        stream.write("\n")
        stream.flush()
        os.fsync(stream.fileno())
    temporary.replace(path)


class Lane:
    def __init__(self, root):
        self.root = root
        self.repo = root / "repo"
        self.tasks = root / "tasks"

    def git(self, *args, cwd=None, **kwargs):
        return run("git", "-C", str(cwd or self.repo), *args, **kwargs)

    def load(self):
        self.state = json.loads((self.root / "lane.json").read_text())
        require(self.state["version"] == 1, "unknown lane version")
        local_owned(self.repo)
        local_owned(self.tasks)
        local_owned(self.root / "wt")
        require(self.git("rev-parse", "--show-toplevel") == str(self.repo), "wrong cache root")
        require(self.git("rev-parse", "refs/heads/master") == self.state["clone_master"],
                "immutable clone master changed; inspect lane before continuing")
        require(self.git("symbolic-ref", "-q", "HEAD", allowed=(0, 1)) == "",
                "cache HEAD must remain detached")
        require(self.git("remote", "get-url", "--all", "x230") == self.state["remote"],
                "fetch remote changed; inspect lane")
        require(self.git("remote", "get-url", "--push", "--all", "x230") == self.state["remote"],
                "push remote changed; inspect lane")

    def init(self):
        require(not (self.root / "lane.json").exists(), "lane already initialized")
        require(not self.repo.exists(), "incomplete/existing clone retained; inspect it before retrying")
        remote = os.environ.get("HELMCORTEX_LANE_REMOTE", "")
        require(remote and "YOUR_" not in remote and not remote.startswith("-"),
                "set HELMCORTEX_LANE_REMOTE to the private canonical Git URL before init")
        require(remote.startswith(("file://", "ssh://", "/")) or
                re.fullmatch(r"[A-Za-z0-9_.@-]+:[A-Za-z0-9_./~-]+", remote),
                "only SSH or local fixture Git URLs are supported")
        if remote.startswith("/"):
            remote = Path(remote).as_uri()
        run("git", "clone", "--filter=blob:none", "--no-checkout", "--single-branch",
            "--branch", "master", "--no-tags", "--origin", "x230", remote, str(self.repo))
        sha = self.git("rev-parse", "refs/remotes/x230/master")
        # Clone creates a local snapshot master. Detach without checking it out
        # or changing that ref; every later write targets a task branch only.
        self.git("update-ref", "--no-deref", "HEAD", sha)
        self.git("config", "push.default", "nothing")
        self.git("config", "push.followTags", "false")
        self.git("sparse-checkout", "init", "--cone", "--no-sparse-index")
        self.git("sparse-checkout", "set", "--cone", "--no-sparse-index", "--stdin", input="")
        for directory in (self.tasks, self.root / "wt"):
            directory.mkdir(mode=0o700)
        atomic_json(self.root / "lane.json", {"version": 1, "remote": remote,
                    "clone_master": sha, "fetched": time.time()})
        print(f"initialized: {self.root}")

    def fetch(self):
        # An explicit refspec cannot update a local branch, fetch task refs or
        # inherit a broad user configured fetch. No prune or remote deletion.
        self.git("fetch", "--no-tags", "x230",
                 "refs/heads/master:refs/remotes/x230/master")
        self.state["fetched"] = time.time()
        atomic_json(self.root / "lane.json", self.state)
        return self.git("rev-parse", "refs/remotes/x230/master")

    def remote_sha(self, task):
        ref = f"refs/heads/{task}"
        output = self.git("ls-remote", "--refs", "x230", ref)
        rows = [row.split() for row in output.splitlines() if row]
        require(not rows or (len(rows) == 1 and rows[0][1] == ref),
                "unexpected remote branch response")
        return rows[0][0] if rows else None

    def task_path(self, task):
        require(task.lower() != "master" and
                re.fullmatch(r"[A-Za-z0-9][A-Za-z0-9_.-]*", task),
                "task must be a flat branch name other than master")
        self.git("check-ref-format", f"refs/heads/{task}")
        return self.root / "wt" / task

    def sparse_directories(self, paths, base):
        directories = set()
        for value in paths:
            parts = value.split("/")
            require(value and not value.startswith(("/", "-")) and
                    all(p not in ("", ".", "..", ".git") and
                        re.fullmatch(r"[A-Za-z0-9_. -]+", p) for p in parts),
                    f"unsafe repo-relative sparse path: {value!r}")
            kind = self.git("cat-file", "-t", f"{base}:{value}")
            require(kind in ("tree", "blob"), f"unsupported sparse path: {value}")
            if kind == "tree":
                directories.add(value)
            elif len(parts) > 1:
                directories.add("/".join(parts[:-1]))
        return sorted(directories)

    def start(self, task, paths):
        worktree = self.task_path(task)
        require(not worktree.exists() and not worktree.is_symlink(), "task worktree already exists")
        require(not (self.tasks / f"{task}.json").exists(), "task record already exists")
        require(not self.git("for-each-ref", "--format=%(refname)", f"refs/heads/{task}"),
                "local task branch already exists")
        base = self.fetch()
        require(self.remote_sha(task) is None, "remote task branch already exists; choose a fresh task")
        directories = self.sparse_directories(paths, base)
        self.git("worktree", "add", "--no-checkout", "--no-track", "-b", task,
                 str(worktree), "x230/master")
        self.git("sparse-checkout", "set", "--cone", "--no-sparse-index", "--stdin",
                 cwd=worktree, input="".join(p + "\n" for p in directories))
        # A worktree created with --no-checkout needs its initial index populated.
        self.git("read-tree", "-mu", "HEAD", cwd=worktree)
        atomic_json(self.tasks / f"{task}.json", {"base": base, "paths": directories,
                    "pushed": None})
        print(worktree)

    def inspect_task(self, task):
        worktree = self.task_path(task)
        require(worktree.is_dir(), "task worktree missing")
        local_owned(worktree)
        require(self.git("rev-parse", "--show-toplevel", cwd=worktree) == str(worktree),
                "wrong task worktree root")
        common = self.git("rev-parse", "--path-format=absolute", "--git-common-dir", cwd=worktree)
        require(Path(common).resolve() == self.repo / ".git", "task belongs to another repository")
        require(self.git("symbolic-ref", "-q", "HEAD", cwd=worktree, allowed=(0, 1)) ==
                f"refs/heads/{task}", "task worktree is detached or on a different branch")
        require(not self.git("status", "--porcelain=v1", "--untracked-files=all", cwd=worktree),
                "task worktree is dirty (tracked, staged or untracked files)")
        sha = self.git("rev-parse", "HEAD", cwd=worktree)
        record = json.loads((self.tasks / f"{task}.json").read_text())
        return worktree, sha, record

    def push(self, task):
        worktree, sha, record = self.inspect_task(task)
        base = self.fetch()
        require(int(self.git("rev-list", "--count", f"{base}..{sha}")) > 0,
                "no commits beyond current x230/master")
        # Pin the reviewed commit, disable mirror/tags even if user config drifted.
        # There is deliberately no force option, '+' refspec, or deletion refspec.
        self.git("-c", "remote.x230.mirror=false", "-c", "push.followTags=false",
                 "push", "--porcelain", "--recurse-submodules=no", "x230",
                 f"{sha}:refs/heads/{task}")
        require(self.remote_sha(task) == sha, "push not verified at the same remote SHA; worktree retained")
        require(self.git("rev-parse", "HEAD", cwd=worktree) == sha,
                "task changed during push; worktree retained")
        record["pushed"] = sha
        atomic_json(self.tasks / f"{task}.json", record)
        print(f"pushed {task} {sha}")

    def done(self, task):
        worktree, sha, record = self.inspect_task(task)
        require(record["pushed"] == sha, "no successful lane push recorded for current task SHA")
        require(self.remote_sha(task) == sha, "remote task branch missing or SHA changed; worktree retained")
        # Git's plain removal is the final dirty/locked/submodule safety gate.
        self.git("worktree", "remove", str(worktree))
        self.git("branch", "-D", task)
        (self.tasks / f"{task}.json").unlink()
        print(f"removed local task {task}; remote branch retained at {sha}")

    def status(self):
        age = max(0, int(time.time() - self.state["fetched"]))
        print(f"health: ok (local ownership, detached cache, remote URL and master snapshot verified)")
        print(f"lane: {self.root}")
        print(f"fetch age: {age}s (last successful fetch; no network probe)")
        print("active worktrees:")
        print(self.git("worktree", "list", "--porcelain"))
        for record_path in sorted(self.tasks.glob("*.json")):
            record = json.loads(record_path.read_text())
            print(f"task: {record_path.stem} pushed: {record['pushed'] or 'none'}")


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    verbs = parser.add_subparsers(dest="verb", required=True)
    for verb in ("init", "status"):
        verbs.add_parser(verb)
    start = verbs.add_parser("start")
    start.add_argument("task")
    start.add_argument("--paths", nargs="+", default=[])
    for verb in ("push", "done"):
        verbs.add_parser(verb).add_argument("task")
    args = parser.parse_args()
    # Caller Git variables must not redirect any operation outside this lane.
    for name in list(os.environ):
        if name.startswith("GIT_") and name not in {
            "GIT_CONFIG_GLOBAL", "GIT_CONFIG_NOSYSTEM", "GIT_AUTHOR_NAME", "GIT_AUTHOR_EMAIL",
            "GIT_COMMITTER_NAME", "GIT_COMMITTER_EMAIL"}:
            del os.environ[name]
    os.environ["GIT_TERMINAL_PROMPT"] = "0"
    os.environ["LC_ALL"] = "C"
    os.environ["GIT_SSH_COMMAND"] = (
        "/usr/bin/ssh -o BatchMode=yes -o PasswordAuthentication=no "
        "-o KbdInteractiveAuthentication=no -o PreferredAuthentications=publickey "
        "-o ConnectTimeout=10 -o ConnectionAttempts=1 -o IdentitiesOnly=yes "
        "-o StrictHostKeyChecking=yes -o ForwardAgent=no -o ClearAllForwardings=yes")
    os.umask(0o077)
    root = Path(os.path.abspath(os.path.expanduser(os.environ.get(
        "HELMCORTEX_LANE_ROOT", str(Path.home() / "helmcortex-lane")))))
    local_owned(root)
    if args.verb == "init":
        root.mkdir(mode=0o700, exist_ok=True)
    require(root.is_dir(), "lane not initialized; run init after key setup")
    lock_path = root / "lane.lock"
    require(not lock_path.is_symlink(), "symlink lock refused")
    with lock_path.open("a") as lock:
        try:
            fcntl.flock(lock, fcntl.LOCK_EX | fcntl.LOCK_NB)
        except BlockingIOError as error:
            raise LaneError("another lane command is running; retry after it finishes") from error
        lane = Lane(root)
        if args.verb == "init":
            lane.init()
        else:
            lane.load()
            if args.verb == "start":
                lane.start(args.task, args.paths)
            elif args.verb == "status":
                lane.status()
            else:
                getattr(lane, args.verb)(args.task)


if __name__ == "__main__":
    try:
        main()
    except (LaneError, OSError, ValueError, KeyError) as error:
        print(f"helmcortex-remote-lane: FATAL: {error}", file=sys.stderr)
        sys.exit(1)

    def forced_command(self):
        source = (ROOT / "agents-users-remote-lane.org").read_text()
        line = next(line for line in source.splitlines() if line.startswith('restrict,command="'))
        match = re.fullmatch(r'restrict,command="((?:\\.|[^"\\])*)" ssh-ed25519 YOUR_PUBLIC_KEY_BLOB YOUR_AGENT_USER@YOUR_AGENT_HOST helmcortex-lane', line)
        self.assertIsNotNone(match, "documented authorized_keys line must parse exactly")
        command = match[1].replace('\\"', '"').replace('\\\\', '\\')
        command = command.replace("/home/YOUR_CANONICAL_USER/HelmCortex", str(self.remote))
        result = subprocess.run(["/bin/sh", "-n", "-c", command], capture_output=True)
        self.assertEqual(result.returncode, 0, result.stderr)
        return command
