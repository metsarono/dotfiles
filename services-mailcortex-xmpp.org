* Boundary

XMPP is a face on MailCortex, not a second messaging backbone. MailCortex keeps the one seat registry, the durable Maildir record and the only agent wake path (=services-mailcortex.org=). This module adds two things on the single host that serves the fleet's XMPP:

- A private Prosody server running as the user, not as the Debian system service. Server-to-server federation is disabled, in-band registration is off, client connections require TLS, and the component port listens on loopback only. Mobile clients (Conversations on Android) connect over the tailnet; the TLS certificate is the host's own Tailscale certificate, so there is no public domain and no public CA dependency beyond Tailscale's.
- =mailcortex-xmpp-bridge=, a Prosody external component (XEP-0114). Every mapped seat gets an address =<seat>@<component>=. A chat message from an allowlisted owner becomes one MailCortex mail into that seat's Maildir, and mail delivered to the bridge's own seat goes back out as a chat message from the agent that sent it.

Why a component: the server stamps the sender of every stanza after SASL authentication, federation is off and registration is closed, so the =from= address the bridge sees is authenticated by the server itself. One connection serves every seat address, and no seat needs a password.

No hostnames, addresses, domains, owner identities or secrets live in this public file. The private site layer lives only on the serving host:

- =~/.config/mailcortex/xmpp-private/local.cfg.lua=: the =VirtualHost=, the bridge =Component= with its secret, the client listen interfaces, and the group-room component (=Component "rooms.<domain>" "muc"= with =restrict_room_creation = "local"=, members-only and non-public rooms by default, =muc_mam= history). A component added at runtime is brought up with =prosodyctl shell 'host:activate("<jid>")'=, so no restart is needed.
- =~/.config/mailcortex/xmpp-private/bridge.json=: the owner allowlist, the seat map, the bridge's own MailCortex address and the path of the component secret file.
- =~/.config/mailcortex/xmpp-private/certs/=: the Tailscale certificate and key, named =<domain>.crt= and =<domain>.key=.

The private layer is a sibling directory, never inside =~/.config/mailcortex/xmpp/=: stow folds that directory into a symlink to this repository's tangled tree, so anything written there would land in the public working tree. Nothing starts until both private files exist (the readiness gate in =mailcortex-xmpp-service=).

Push notifications: no push module is enabled. Conversations holds its own connection, so no message metadata reaches a third-party push relay. This is a deliberate first-slice choice, not an omission.

* Narrow additive package apply

The manifest is sourced in =package-nala.org= (=debian/.nala/manifest/mailcortex-xmpp.ssv=). The default is a read-only apt simulation. =--apply= installs only the two manifest packages, refuses removals and upgrades, then stops and disables the Debian =prosody= system service: the fleet's Prosody runs as the user under =mailcortex-xmpp-service=, and the packaged default configuration (federation on, all interfaces) must never stay running. The package's postinst may start that service for a few seconds before it is stopped; it has no accounts in that window.

#+BEGIN_SRC bash :tangle debian/.local/bin/mailcortex-xmpp-package :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

usage() {
  cat <<'EOF'
Usage: mailcortex-xmpp-package [--dry-run|--apply|-h|--help]
Plan the isolated MailCortex XMPP package transaction (default).
--apply explicitly authorizes the simulated, additive transaction, then
stops and disables the Debian prosody system service.
EOF
}

case "${1:---dry-run}" in
  -h|--help) usage; exit 0 ;;
  --dry-run) mode=dry-run ;;
  --apply) mode=apply ;;
  *) usage >&2; exit 2 ;;
esac
[ "$#" -le 1 ] || { usage >&2; exit 2; }

manifest="${MAILCORTEX_TEST_MANIFEST:-$HOME/.nala/manifest/mailcortex-xmpp.ssv}"
[ -r "$manifest" ] || { echo "mailcortex-xmpp-package: missing manifest: $manifest" >&2; exit 1; }
expected=" prosody python3-slixmpp "
packages=()
while read -r pkg version category scope extra trailing; do
  case "${pkg:-}" in ''|\#*) continue ;; esac
  if [ "${expected#* "$pkg" }" = "$expected" ] || [ "$version" != '""' ] \
     || [ "$category" != network ] || [ "$scope" != mailcortex-xmpp ] \
     || [ "$extra" != '""' ] || [ -n "${trailing:-}" ]; then
    echo "mailcortex-xmpp-package: unexpected manifest row: $pkg" >&2
    exit 2
  fi
  packages+=("$pkg")
done < "$manifest"
[ "${#packages[@]}" -eq 2 ] || { echo "mailcortex-xmpp-package: expected exactly the prosody and python3-slixmpp rows" >&2; exit 2; }

if ! simulation="$(apt-get -s "${flags[@]}" install "${packages[@]}" 2>&1)"; then
  printf '%s\n' "$simulation" >&2
  echo 'mailcortex-xmpp-package: apt simulation failed' >&2
  exit 3
fi
printf '%s\n' "$simulation"
if printf '%s\n' "$simulation" | grep -Eq '^(Remv|Purg) '; then
  echo 'mailcortex-xmpp-package: refused removal or purge' >&2

if [ "$mode" = dry-run ]; then
  echo 'mailcortex-xmpp-package: dry-run only; use --apply for this exact manifest'
  exit 0
fi

for pkg in "${packages[@]}"; do
  [ "$(dpkg-query -W -f='${db:Status-Abbrev}' "$pkg" 2>/dev/null || true)" = 'ii ' ] || {
    echo "mailcortex-xmpp-package: install returned but $pkg is not installed" >&2

** Voice upload activation (C2)

The bundled =http_file_share= module stores uploads locally with a 25 MiB
per-file cap, one-day expiry, 250 MiB daily and 1 GiB global quotas. HTTP is
disabled; HTTPS is disabled until the private layer binds only the tailnet
interface and supplies the existing Tailscale certificate. Do not set
=http_file_share_base_url=: that switches off the built-in storage HTTP
provider and pruning. Advertise the local service with =http_external_url=.

The following is a proposed additive private =local.cfg.lua= stanza, not a
live apply. Keep existing VirtualHost/component/room declarations; put the
listener settings in global scope and the host settings inside the existing
VirtualHost. Replace every =YOUR_*= value privately before activation.

Add ="upload_base_url": "https://YOUR_UPLOAD_HOST:YOUR_UPLOAD_HTTPS_PORT/file_share/"=
to the private =bridge.json=. Absent that key, plain chat still works but voice

GET URLs are bearer capabilities: keep them on the tailnet and out of logs.

** Reply voice activation (C3)

After successful voice-mail delivery, the original owner receives the transcript
from the addressed seat in reply shape: a => Re: <name>= line, then the
transcript wrapped in double quotes with every line quoted. =<name>= comes from
the optional private =display_names= map (owner bare JID to a one-line name),
falling back to the JID's local part. =Message.reply= preserves an
existing thread and its parent; absent a thread, this is an ordinary quote.
Outbound Markdown is translated conservatively to XEP-0393; escaped syntax,
inline code, fenced/indented code and ambiguous constructs remain opaque.

Voice out is opt-in per seat through the private =voices= map. Styled text goes
to every owner first. One worker sends the original Markdown through the shared
=voice-text-normalize= boundary, then renders that plain speech through
=pvox render --agent --no-play=, capped at 4000 spoken characters (truncation logged),
and encodes mono Ogg/Opus at 24 kbit/s. Render/encode timeouts are 600/60 seconds.
The async slot IQ targets =upload_service_jid=, the existing upload VirtualHost
JID, NOT the bridge component or a guessed =upload.= component. Its =from= is
the mapped seat JID. The HTTPS PUT runs in a worker with a 30-second timeout;
slot URLs must match the same origin/path allowlist as voice in. No redirects
or environment proxies are permitted. The URL-only chat carries an XEP-0066
OOB URL for the client's inline player. Private temporary audio is removed on
success/failure. Polling is serial, so at most one outbound render/upload runs.
A voice failure logs a redacted reason and sends one failure line to each owner;
the already-sent text is retained. Absent/unmapped =voices= means text only.

Prosody 13's bundled =mod_http_file_share.lua= authorizes a bare uploader via
its role, exact JID, or uploader domain in =http_file_share_access=. The following
additive grant covers only identities stamped by the existing shared-secret
seat component; local registered owners keep their existing role permission.
The 250 MiB daily quota is per bare JID, not a component-wide quota. Add inside
the existing private VirtualHost, preserving every existing declaration:

#+NAME: c3-private-upload-grant
#+BEGIN_SRC lua :tangle no
http_file_share_access = { "seats.YOUR_DOMAIN" }
#+END_SRC

Merge these keys into the existing private =bridge.json= (replace placeholders
privately). The upload service JID and HTTPS upload hostname need not be equal.
No private/site file is written by this module, and nothing is restarted here.

{
  "upload_service_jid": "YOUR_VIRTUALHOST_DOMAIN",
  "voices": { "YOUR_SEAT_LOCAL_PART": "YOUR_PVOX_AGENT" },

** Squadron rooms (C5)

Squadron rooms are configured privately in =bridge.json=; the bridge never
creates a room or changes its affiliations. In Conversations, create the
group chat with these settings: members-only, not public, non-anonymous, and
=whois= set to =moderators=. Add each seat's bare JID as a member, then give
the matching bridge seat occupants moderator rights. Non-anonymous presence
lets the bridge authenticate the sender's real JID; =whois= set to =anyone=
would disclose every occupant's JID, so seat-moderator visibility is the
narrower choice.

Merge the matching private keys into =bridge.json=, replacing every
=YOUR_*= value only on the serving host:

#+BEGIN_SRC json :tangle no
{
  "rooms": {
    "YOUR_SQUADRON_ROOM": {
      "jid": "YOUR_ROOM_LOCAL@YOUR_MUC_DOMAIN",
      "lead": "YOUR_SEAT_LOCAL",
      "seats": ["YOUR_SEAT_LOCAL", "YOUR_OTHER_SEAT_LOCAL"]
    }
  },
  "nicks": {
    "YOUR_SEAT_LOCAL": "YOUR_SEAT_NICK",
    "YOUR_OTHER_SEAT_LOCAL": "YOUR_OTHER_SEAT_NICK"
  }
}
#+END_SRC

=rooms= maps a room name to its bare room JID, lead seat, and known seats;
=nicks= is optional and overrides the per-seat occupant nickname. Without an
override, a seat uses its =voices= agent name when present, otherwise its
local part. Nicknames must be unique within each room. The room JID must use
the same MUC domain as every other configured room.

In the room, a plain line goes to the lead. Prefixing one or more configured
nicknames (or =@all=) addresses selected seats, and the bridge strips that
prefix before mailing. Replies with an =In-Reply-To= that names a room mail
return to that room from the replying seat's occupant. A join error is sent
once to the owners from the room lead; a failed room post falls back to the
owners' 1:1 chat.

** Permission relay and ad-hoc commands (C7)

Permission relay is opt-in per seat. The channel receives a private mode-600
secret through =--permission-secret= and the bridge reads the same private file
from =permission_secrets=. The channel also receives =--bridge-address= and
must list that address in =--allow-from=. The secret never belongs in this
public source. A signed decision contains the seat, five-letter request ID,
behaviour and Unix timestamp; the HMAC covers exactly
=seat | request_id | behavior | timestamp= and expires after ten minutes.
Unsigned, stale, replayed, wrong-seat and wrong-secret mail remains ordinary
mail and is logged as refused. A successful decision is the only path that
emits =claude/channel/permission=.

Merge these optional keys into the private =bridge.json=, replacing every
=YOUR_*= value only on the serving host:

#+BEGIN_SRC json :tangle no
{
  "permission_secrets": {
    "YOUR_SEAT_LOCAL_PART": "YOUR_PRIVATE_PERMISSION_SECRET_FILE"
  },
  "bots": {
    "YOUR_SEAT_LOCAL_PART": "YOUR_NURSE_JOY_BOT_NAME"
  }
}
#+END_SRC

The =bots= map is also the fixed-argument command map. Every seat advertises
owner-only =status= and =seats= through XEP-0050. A mapped seat additionally
advertises =revive=, which runs =nurse-joy revive <bot> --no-visit= only after
the form's confirmation field is true. If the existing =claude-warmctl=
control path is present, it also advertises =compact= and runs the fixed
=claude-warmctl inject <bot> /compact= argv after confirmation; no compact
command is invented when that path is absent. =status= uses the read-only
=nurse-joy status --json= projection for the mapped bot, and =seats= reads
each mapped mailbox's last delivery timestamp. Every command records owner,
seat, command and result in the bridge log. Unknown owners and continuation
sessions owned by another owner are rejected before a command handler runs.

* Certificate refresh

=tailscale cert= needs root on this fleet, so the helper writes through =sudo -n= into a private temporary directory, then installs the pair into the certs directory owned by the user with mode 600. =--check= reports the days left without touching anything. The bridge does not use TLS (loopback component), so only the client-facing domain needs a certificate.

#+BEGIN_SRC bash :tangle linux/.local/bin/mailcortex-xmpp-cert :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

usage() {
  cat <<'EOF'
Usage: mailcortex-xmpp-cert DOMAIN [--check]
Fetch or renew the host's Tailscale TLS certificate for DOMAIN into
~/.config/mailcortex/xmpp-private/certs/DOMAIN.{crt,key} (mode 600).
--check prints the days of validity left and changes nothing.
EOF
}

case "${1:-}" in
  ''|-h|--help) usage; [ -n "${1:-}" ]; exit $? ;;
esac
domain="$1"; shift
case "$domain" in
  *[!a-z0-9.-]*|.*|*..*) echo "mailcortex-xmpp-cert: invalid domain" >&2; exit 2 ;;
esac
certs="$HOME/.config/mailcortex/xmpp-private/certs"
crt="$certs/$domain.crt"; key="$certs/$domain.key"

if [ "${1:-}" = --check ]; then
  [ -r "$crt" ] || { echo "mailcortex-xmpp-cert: no certificate for $domain" >&2; exit 1; }
  end="$(openssl x509 -noout -enddate -in "$crt" | cut -d= -f2)"
  echo "$(( ( $(date -d "$end" +%s) - $(date +%s) ) / 86400 )) days left ($end)"
  exit 0
fi
[ "$#" -eq 0 ] || { usage >&2; exit 2; }

install -d -m 700 "$certs"
work="$(mktemp -d)"
trap 'sudo -n rm -rf "$work" 2>/dev/null || rm -rf "$work"' EXIT
sudo -n tailscale cert --cert-file "$work/c" --key-file "$work/k" "$domain"
sudo -n chown "$(id -u):$(id -g)" "$work/c" "$work/k"
install -m 600 "$work/c" "$crt.new"
install -m 600 "$work/k" "$key.new"
mv -f "$crt.new" "$crt"
mv -f "$key.new" "$key"
echo "mailcortex-xmpp-cert: installed certificate for $domain"
#+END_SRC

* The bridge

=mailcortex-xmpp-bridge= imports =slixmpp= only when it runs, so =-h= and the fixture tests work on machines without it. All mailbox state changes go through the =mailcortex= CLI (=send=, =inbox=, =read=, =receipt=); the bridge never writes a Maildir itself.

Inbound (chat to mail):
1. The server-stamped sender must be an allowlisted owner (bare address). Anyone else gets no mail, only an error stanza and a log line.
2. A sliding-window rate limit per owner (default 20 per minute) and a persisted stanza-id dedupe stop floods and reconnect replays.
3. The target local part must be a mapped seat; unknown addresses get =item-not-found=.
4. One mail is sent from the bridge's own seat address to the seat's MailCortex address. The body carries the XMPP sender and the reply instruction, so a woken agent answers with =mailcortex send --to <bridge address>=.
5. XEP-0066 OOB URLs (including bodyless stanzas) enter the voice lane and
   retain strict refusal for foreign URLs, HTTP or an unconfigured upload.
   A URL-only body enters that lane only if the configured HTTPS upload
   origin/path accepts it; all other bare links remain ordinary text mail.
   The upload allowlist is checked again before fetching; redirects are refused.
   Downloads have a 25 MiB streaming cap, 5-second socket timeout and
   30-second elapsed budget (at most one socket timeout to observe expiry).
   =~/HelmCortex/FORGE/bin/whisper-transcribe= runs in a worker thread with a
   600-second subprocess timeout (absolute path, independent of cron's PATH). Only nonempty, clean transcripts are mailed with =[xmpp voice]=
   subjects and the original audio via =mailcortex send --attach=.
   Private temporary copies are removed on success and failure. At most two
   voice jobs run concurrently; excess jobs receive a resend diagnostic.
   Failures log and reply once to the owner, never mail an empty transcript.

Outbound (mail to chat):
1. The bridge polls its own seat (=mailcortex inbox=) and handles only =new= messages, oldest first.
2. The mail's =From= must resolve to a mapped seat's mailbox. Matching uses the local part only, because a =.helm= domain is provenance (the machine that sent it), not identity: =seat+x@x230.helm= and =seat+x@kikin-kushi.helm= are one Maildir. The chat message is sent from that seat's XMPP address to every owner. Mail from an unmapped address is marked =handling_rejected= and never relayed.
3. =mailcortex read= marks the mail seen BEFORE relay; after relay, =mailcortex receipt= records =handling_completed=. This existing read-before-send ordering has no automatic retry if chat sending fails; durable outbound retry is a separate transport task, not supplied by C3's optional voice lane.

    return str(jid).split("/", 1)[0].strip().lower()


def is_bare_jid(value: str) -> bool:
    if not isinstance(value, str) or value.count("@") != 1 or "/" in value:
        return False
    local, host = value.split("@")
    return bool(LOCAL_RE.match(local)) and bool(HOST_RE.match(host))


def one_line(value: object, limit: int = 64) -> bool:
    return (isinstance(value, str) and 1 <= len(value) <= limit
            and value == value.strip()
            and not any(ord(char) < 32 or ord(char) == 127 for char in value))


def load_config(path: Path) -> dict:
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as error:
        raise BridgeError(f"cannot read config {path}: {error}") from error
    if not isinstance(data, dict):
        raise BridgeError("config must be a JSON object")
    component = data.get("component_jid")
    if not isinstance(component, str) or "@" in component or not HOST_RE.match(component):
        raise BridgeError("component_jid must be a bare domain")
    owners = data.get("owner_jids")
    if not isinstance(owners, list) or not owners or not all(is_bare_jid(o) for o in owners):
        raise BridgeError("owner_jids must be a non-empty list of bare JIDs")
    address = data.get("bridge_address")
    match = ADDRESS_RE.match(address) if isinstance(address, str) else None
    if not match or match.group(1) != "seat":
        raise BridgeError("bridge_address must be a seat+NAME@HOST.helm address")
    seats = data.get("seats")
    if not isinstance(seats, dict) or not seats:
        raise BridgeError("seats must map XMPP local parts to MailCortex addresses")
    reverse: dict[str, str] = {}
    for local, target in seats.items():
        if not isinstance(local, str) or not LOCAL_RE.match(local):
            raise BridgeError(f"invalid seat local part: {local!r}")
        if not isinstance(target, str) or not ADDRESS_RE.match(target):
            raise BridgeError(f"invalid MailCortex address for {local}: {target!r}")
        if target == address:
            raise BridgeError("a seat may not map to the bridge's own address")
        mailbox = target.split("@")[0]
        if mailbox in reverse:
            raise BridgeError(f"mailbox mapped twice: {mailbox}")
        reverse[mailbox] = local
    secret_file = Path(str(data.get("component_secret_file", ""))).expanduser()
    if not str(data.get("component_secret_file", "")):
        raise BridgeError("component_secret_file is required")
    rate = data.get("rate_per_minute", 20)
    poll = data.get("poll_seconds", 2)
    port = data.get("port", 5347)
    if not isinstance(rate, int) or not 1 <= rate <= 600:
        raise BridgeError("rate_per_minute must be an integer from 1 to 600")
    if not isinstance(poll, (int, float)) or not 0.5 <= poll <= 60:
        raise BridgeError("poll_seconds must be between 0.5 and 60")
    if not isinstance(port, int) or not 1 <= port <= 65535:
        raise BridgeError("port must be a TCP port")
    upload = data.get("upload_base_url", "")
    if not isinstance(upload, str):
        raise BridgeError("upload_base_url must be an HTTPS upload directory")
    if upload:
        parsed = split_upload_url(upload)
        if not parsed.path.endswith("/") or parsed.path == "/":
            raise BridgeError("upload_base_url must name an upload directory")
    voices = data.get("voices", {})
    if (not isinstance(voices, dict) or any(
            local not in seats or not isinstance(agent, str)
            or not re.fullmatch(r"[A-Za-z0-9][A-Za-z0-9 ._-]{0,63}", agent)
            or agent != agent.strip() for local, agent in voices.items())):
        raise BridgeError("voices must map known seat local parts to pvox agent names")
    service = data.get("upload_service_jid", "")
    if (not isinstance(service, str) or (service and (
            not HOST_RE.fullmatch(service) or service == component))):
        raise BridgeError("upload_service_jid must be the upload VirtualHost domain")
    if voices and (not upload or not service):
        raise BridgeError("voices requires upload_base_url and upload_service_jid")
    names = data.get("display_names", {})
    owner_set = {bare(o) for o in owners}
    if (not isinstance(names, dict) or any(
            bare(jid) not in owner_set or not isinstance(name, str)
            or not re.fullmatch(r"[^\x00-\x1f\x7f]{1,64}", name)
            or name != name.strip() for jid, name in names.items())):
        raise BridgeError("display_names must map owner JIDs to one-line names")
    permission_data = data.get("permission_secrets", {})
    if (not isinstance(permission_data, dict) or any(
            local not in seats or not isinstance(path, str) or not path.strip()
            for local, path in permission_data.items())):
        raise BridgeError("permission_secrets must map known seats to secret files")
    bots_data = data.get("bots", {})
    if (not isinstance(bots_data, dict) or any(
            local not in seats or not isinstance(bot, str) or not BOT_RE.fullmatch(bot)
            for local, bot in bots_data.items())):
        raise BridgeError("bots must map known seats to one-line bot names")
    rooms_data = data.get("rooms", {})
    if not isinstance(rooms_data, dict):
        raise BridgeError("rooms must map room names to room definitions")
    nick_overrides = data.get("nicks", {})
    if not isinstance(nick_overrides, dict) or any(
            local not in seats or not one_line(nick) or "/" in nick
            for local, nick in nick_overrides.items()):
        raise BridgeError("nicks must map known seat local parts to one-line nicknames")
    room_domains: set[str] = set()
    rooms: dict[str, dict] = {}
    room_by_jid: dict[str, dict] = {}
    for room_name, definition in rooms_data.items():
        if not one_line(room_name):
            raise BridgeError(f"invalid room name: {room_name!r}")
        if not isinstance(definition, dict):
            raise BridgeError(f"room {room_name} must be an object")
        room_jid = definition.get("jid")
        if not is_bare_jid(room_jid):
            raise BridgeError(f"room {room_name} jid must be a bare JID")
        room_jid = bare(room_jid)
        room_domain = room_jid.split("@", 1)[1]
        room_domains.add(room_domain)
        room_seats = definition.get("seats")
        if (not isinstance(room_seats, list) or not room_seats
                or any(not isinstance(local, str) for local in room_seats)
                or len(set(room_seats)) != len(room_seats)
                or any(local not in seats for local in room_seats)):
            raise BridgeError(f"room {room_name} seats must be known and unique")
        lead = definition.get("lead")
        if lead not in room_seats:
            raise BridgeError(f"room {room_name} lead must be one of its seats")
        if room_jid in room_by_jid:
            raise BridgeError(f"room JID used twice: {room_jid}")
        effective_nicks = {
            local: nick_overrides.get(local, voices.get(local, local))
            for local in room_seats
        }
        if any(not one_line(nick) or "/" in nick for nick in effective_nicks.values()):
            raise BridgeError(f"room {room_name} has an invalid nickname")
        folded = [nick.casefold() for nick in effective_nicks.values()]
        if len(set(folded)) != len(folded):
            raise BridgeError(f"room {room_name} has duplicate nicknames")
        room = {
            "name": room_name,
            "jid": room_jid,
            "domain": room_domain,
            "lead": lead,
            "seats": list(room_seats),
            "nicks": effective_nicks,
            "nick_to_seat": {nick.casefold(): local for local, nick in effective_nicks.items()},
        }
        rooms[room_name] = room
        room_by_jid[room_jid] = room
    if len(room_domains) > 1:
        raise BridgeError("all rooms must use one MUC domain")
    return {
        "display_names": {bare(jid): name for jid, name in names.items()},
        "voices": dict(voices),
        "upload_service_jid": service,
        "upload_base_url": upload,
        "component_jid": component,
        "owner_jids": [bare(o) for o in owners],
        "bridge_address": address,
        "bridge_seat": match.group(2),
        "seats": dict(seats),
        "reverse": reverse,
        "rooms": rooms,
        "room_by_jid": room_by_jid,
        "permission_secrets": {
            local: Path(path).expanduser() for local, path in permission_data.items()
        },
        "bots": dict(bots_data),
        "component_secret_file": secret_file,
        "server": str(data.get("server", "127.0.0.1")),
        "port": port,
        "rate_per_minute": rate,
        "poll_seconds": float(poll),
    }


def read_secret(path: Path, label: str = "component secret") -> str:
    try:
        info = path.lstat()
    except OSError as error:
        raise BridgeError(f"{label} missing: {error}") from error
    if not stat.S_ISREG(info.st_mode) or info.st_mode & 0o077:
        raise BridgeError(f"{label} must be a regular file with mode 600")
    try:
        secret = path.read_text(encoding="utf-8").strip()
    except (OSError, UnicodeError) as error:
        raise BridgeError(f"{label} is unreadable: {error}") from error
    if len(secret) < 24:
        raise BridgeError(f"{label} is too short")
    return secret


def permission_digest(secret: str, seat: str, request_id: str,
                      behavior: str, timestamp: str) -> str:
    material = f"{seat} | {request_id} | {behavior} | {timestamp}".encode("utf-8")
    return hmac.new(secret.encode("utf-8"), material, hashlib.sha256).hexdigest()


def permission_auth_value(secret: str, seat: str, request_id: str,
                          behavior: str, timestamp: int) -> str:
    stamp = str(timestamp)
    return (f"seat={seat};request_id={request_id};behavior={behavior};"
            f"timestamp={stamp};hmac={permission_digest(secret, seat, request_id, behavior, stamp)}")


def parse_permission_auth(value: str) -> dict[str, str] | None:
    match = PERMISSION_AUTH_RE.fullmatch(value.strip())
    return match.groupdict() if match else None


def normalize_permission_text(text: str) -> str:
    """Normalize deterministic voice/text replies without guessing words."""
    words = re.sub(r"[^a-z0-9]+", " ", text.casefold()).split()
    normalized: list[str] = []
    letters: list[str] = []
    for word in words:
        if len(word) == 1 and word.isalpha():
            letters.append(word)
            continue
        if letters:
            normalized.append("".join(letters))
            letters = []
        normalized.append(word)
    if letters:
        normalized.append("".join(letters))
    return " ".join(normalized)


def permission_reply(text: str) -> tuple[str, str] | None:
    match = re.fullmatch(r"(yes|no) ([a-km-z]{5})", normalize_permission_text(text))
    if not match:
        return None
    return ("allow" if match[1] == "yes" else "deny", match[2])


def permission_request(rendered: str) -> tuple[str, str, str] | None:
    message = Parser(policy=policy.default).parsestr(rendered)
    subject = str(message.get("Subject", "")).strip()
    if not subject.startswith("[permission] "):
        return None
    body = (message.get_payload() or "").strip()
    match = re.search(r"(?m)^request_id:\s*([a-km-z]{5})\s*$", body, re.IGNORECASE)
    if not match:
        raise BridgeError("permission request has no valid request_id")
    request_id = match[1].lower()
    if not PERMISSION_ID_RE.fullmatch(request_id):
        raise BridgeError("permission request has an invalid request_id")
    tool_name = subject[len("[permission] "):].strip()
    if not tool_name or any(ord(char) < 32 for char in tool_name):
        raise BridgeError("permission request has an invalid tool name")
    return request_id, tool_name, body


def decision_mail(cfg: dict, local: str, request_id: str, behavior: str,
                  secret: str, timestamp: int,
                  run=subprocess.run) -> str:
    target = cfg["seats"].get(local)
    if target is None:
        raise BridgeError(f"unknown seat: {local}")
    auth = permission_auth_value(secret, local, request_id, behavior, timestamp)
    text = (f"Permission decision: {'Allowed' if behavior == 'allow' else 'Denied'} "
            f"{request_id}\n")
    return mailcortex([
        "send", "--from", cfg["bridge_address"], "--to", target,
        "--subject", f"[permission] {'Allowed' if behavior == 'allow' else 'Denied'} {request_id}",
        "--body", text, "--permission-auth", auth,
    ], run).strip()


class Gate:
    """Owner allowlist plus a per-sender sliding-window rate limit."""

    def __init__(self, owners: list[str], per_minute: int) -> None:
        self.owners = set(owners)
        self.per_minute = per_minute
        self.windows: dict[str, collections.deque] = {}

    def admit(self, sender: str, now: float) -> str | None:
        sender = bare(sender)
        if sender not in self.owners:
            return "unauthorized"
        window = self.windows.setdefault(sender, collections.deque())
        while window and now - window[0] >= 60:
            window.popleft()
        if len(window) >= self.per_minute:
            return "rate_limited"
        window.append(now)
        return None


class Seen:
    """Persisted stanza-id dedupe so reconnect replays never send mail twice."""

    def __init__(self, path: Path) -> None:
        self.path = path
        self.keys: list[str] = []
        if path.exists():
            try:
                loaded = json.loads(path.read_text(encoding="utf-8"))
                if isinstance(loaded, list):
                    self.keys = [str(k) for k in loaded][-SEEN_CAP:]
            except (OSError, json.JSONDecodeError):
                LOG.warning("dedupe state unreadable; starting empty")
        self.index = set(self.keys)

    def check_and_add(self, key: str | None) -> bool:
        """Return True when the key is new (and record it)."""
        if not key:
            return True
        if key in self.index:
            return False
        self.keys.append(key)
        self.index.add(key)
        if len(self.keys) > SEEN_CAP:
            dropped = self.keys[:-SEEN_CAP]
            self.keys = self.keys[-SEEN_CAP:]
            self.index.difference_update(dropped)
        self.path.parent.mkdir(mode=0o700, parents=True, exist_ok=True)
        temporary = self.path.with_name(f".{self.path.name}.{os.getpid()}.tmp")
        temporary.write_text(json.dumps(self.keys), encoding="utf-8")
        os.chmod(temporary, 0o600)
        os.replace(temporary, self.path)
        return True


class RoomMap:
    """Persisted Message-ID -> room JID routing for room replies."""

    def __init__(self, path: Path) -> None:
        self.path = path
        self.entries: dict[str, str] = {}
        self.order: list[str] = []
        if path.exists():
            try:
                if path.is_symlink() or not path.is_file():
                    raise OSError("room map is not a regular file")
                loaded = json.loads(path.read_text(encoding="utf-8"))
                if isinstance(loaded, dict):
                    for message_id, room_jid in loaded.items():
                        if (isinstance(message_id, str) and MESSAGE_ID_RE.fullmatch(message_id)
                                and isinstance(room_jid, str) and is_bare_jid(room_jid)):
                            self.entries[message_id] = bare(room_jid)
                    self.order = list(self.entries)[-SEEN_CAP:]
                    self.entries = {key: self.entries[key] for key in self.order}
            except (OSError, json.JSONDecodeError):
                LOG.warning("room map unreadable; starting empty")

    def get(self, message_id: str) -> str | None:
        return self.entries.get(message_id)

    def add(self, message_id: str, room_jid: str) -> None:
        if not MESSAGE_ID_RE.fullmatch(message_id) or not is_bare_jid(room_jid):
            raise BridgeError("cannot persist an invalid room mapping")
        if message_id in self.entries:
            self.order.remove(message_id)
        self.entries[message_id] = bare(room_jid)
        self.order.append(message_id)
        while len(self.order) > SEEN_CAP:
            dropped = self.order.pop(0)
            self.entries.pop(dropped, None)
        self.path.parent.mkdir(mode=0o700, parents=True, exist_ok=True)
        temporary = self.path.with_name(f".{self.path.name}.{os.getpid()}.tmp")
        temporary.write_text(json.dumps(
            {key: self.entries[key] for key in self.order},
            separators=(",", ":")), encoding="utf-8")
        os.chmod(temporary, 0o600)
        os.replace(temporary, self.path)


def diagnostic(error) -> str:
    """One line, no bearer URLs or Authorization values in owner replies/logs."""
    text = re.sub(r"https?://\S+", "[upload URL redacted]", str(error))
    text = re.sub(r"(?i)\bBearer\s+\S+", "Bearer [redacted]", text)
    return " ".join(text.split())[:200] or "unspecified error"


def mailcortex(args: list[str], run=subprocess.run) -> str:
    result = run(["mailcortex", *args], capture_output=True, text=True)
    if result.returncode != 0:
        reason = result.stderr.strip() or f"exit status {result.returncode} (no stderr)"
        raise BridgeError(f"mailcortex {args[0]} failed: {diagnostic(reason)}")
    return result.stdout


def parse_print_id(output: str) -> tuple[str, str]:
    filename, separator, message_id = output.strip().partition("\t")
    if not separator or not filename or not MESSAGE_ID_RE.fullmatch(message_id):
        raise BridgeError("mailcortex send --print-id returned an invalid Message-ID")
    return filename, message_id


def inbound_mail(cfg: dict, sender: str, local: str, body: str,
                 run=subprocess.run, capture_id: bool = False,
                 room: dict | None = None) -> str | tuple[str, str]:
    """Deliver one owner chat message into a seat's Maildir; return the filename."""
    target = cfg["seats"].get(local)
    if target is None:
        raise BridgeError(f"unknown seat: {local}")
    text = body.strip()
    if not text:
        raise BridgeError("empty message")
    if len(text) > MAX_BODY:
        raise BridgeError("message too long")
    first = text.splitlines()[0].strip()
    prefix = f"[xmpp #{room['name']}] " if room is not None else "[xmpp] "
    subject = prefix + (first[:70] + "…" if len(first) > 70 else first)
    room_header = f"XMPP-Room: {room['jid']}\n" if room is not None else ""
    framed = (
        f"XMPP-From: {bare(sender)}\n"
        f"XMPP-To: {local}@{cfg['component_jid']}\n"
        f"{room_header}"
        f"Reply-Via: mailcortex send --from <your address> --to {cfg['bridge_address']}\n"
        "\n"
        f"{text}\n"
    )
    args = ["send", "--from", cfg["bridge_address"], "--to", target,
            "--subject", subject, "--body", framed]
    if capture_id:
        args.append("--print-id")
        return parse_print_id(mailcortex(args, run))
    return mailcortex(args, run).strip()


def split_upload_url(value: str):
    try:
        parsed = urllib.parse.urlsplit(value)
        port = parsed.port
    except ValueError as error:
        raise BridgeError("invalid upload URL") from error
    if (parsed.scheme != "https" or not parsed.hostname or parsed.username
            or parsed.password or parsed.query or parsed.fragment
            or any(c.isspace() or ord(c) < 32 for c in value)):
        raise BridgeError("upload URL must be HTTPS without credentials or query")
    return parsed


def validate_upload_url(cfg: dict, url: str) -> None:
    base = cfg.get("upload_base_url", "")
    if not base:
        raise BridgeError("voice upload is not configured")
    allowed, candidate = split_upload_url(base), split_upload_url(url)
    if ((candidate.hostname, candidate.port or 443) !=
            (allowed.hostname, allowed.port or 443)):
        raise BridgeError("foreign upload host or port refused")
    path = urllib.parse.unquote(candidate.path)
    if (not path.startswith(allowed.path) or path == allowed.path
            or "\\" in path or any(p in {".", ".."} for p in path.split("/"))):
        raise BridgeError("URL is outside the upload directory")


def voice_url(cfg: dict, msg) -> str | None:
    """OOB declares an upload; a bare link needs the upload allowlist first."""
    element = msg.xml.find("{jabber:x:oob}x/{jabber:x:oob}url")
    if element is not None and element.text:
        return element.text.strip()
    body = str(msg["body"]).strip()
    if re.fullmatch(r"https?://\S+", body):
        try:
            validate_upload_url(cfg, body)
        except BridgeError:
            return None  # Ordinary links keep the pre-voice text-mail route.
        return body
    return None


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        raise BridgeError("upload redirects refused")


def download_voice(cfg: dict, url: str, destination: Path, opener=None) -> None:
    validate_upload_url(cfg, url)
    opener = opener or urllib.request.build_opener(
        urllib.request.ProxyHandler({}), NoRedirect()).open
    deadline = time.monotonic() + DOWNLOAD_SECONDS
    request = urllib.request.Request(url, headers={"Accept-Encoding": "identity"})
    try:
        with opener(request, timeout=5) as response:
            if response.status != 200:
                raise BridgeError("upload fetch returned a non-success status")
            length = response.headers.get("Content-Length")
            if length is not None and (int(length) < 0 or int(length) > VOICE_LIMIT):
                raise BridgeError("voice upload exceeds 25 MiB")
            descriptor = os.open(destination, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
            with os.fdopen(descriptor, "wb") as stream:
                total = 0
                while True:
                    if time.monotonic() >= deadline:
                        raise BridgeError("voice download timed out")
                    # read1 does not wait to fill a large buffer on trickle streams.
                    chunk = response.read1(min(65536, VOICE_LIMIT - total + 1))
                    if time.monotonic() >= deadline:
                        raise BridgeError("voice download timed out")
                    if not chunk:
                        break
                    total += len(chunk)
                    if total > VOICE_LIMIT:
                        raise BridgeError("voice upload exceeds 25 MiB")
                    stream.write(chunk)
                if not total or (length is not None and total != int(length)):
                    raise BridgeError("voice upload is empty or incomplete")
    except BridgeError:
        raise
    except (OSError, ValueError, urllib.error.URLError) as error:
        raise BridgeError("voice download failed (network, TLS or invalid response)") from error


def transcribe_voice(audio: Path, run=subprocess.run) -> str:
    output = audio.parent / "transcript.md"
    try:
        command = Path.home() / "HelmCortex/FORGE/bin/whisper-transcribe"
        result = run([str(command), str(audio), "--out", str(output)],
                     capture_output=True, text=True, timeout=TRANSCRIBE_SECONDS)
        if result.returncode != 0:
            raise BridgeError("whisper transcription failed or was quality-suspect")
        raw = output.read_text(encoding="utf-8")
    except subprocess.TimeoutExpired as error:
        raise BridgeError("whisper transcription timed out") from error
    except (OSError, UnicodeError) as error:
        raise BridgeError("whisper-transcribe or its transcript is unavailable") from error
    metadata, separator, text = raw.partition("\n---\n")
    text = text.strip()
    if (not metadata.startswith("---\n") or not separator
            or "whisper_quality: clean" not in metadata.splitlines()
            or not text or text in {"[non-speech audio]", "[transcription unavailable]"}):
        raise BridgeError("whisper returned no clean speech transcript")
    if len(text) > MAX_BODY:
        raise BridgeError("voice transcript exceeds the message limit")
    return text


def inbound_voice(cfg: dict, sender: str, local: str, url: str,
                  run=subprocess.run, download=None, transcribe=None,
                  capture_id: bool = False,
                  room: dict | None = None) -> tuple[str, str] | tuple[str, str, str]:
    target = cfg["seats"].get(local)
    if target is None:
        raise BridgeError("unknown seat")
    validate_upload_url(cfg, url)  # Before even an injected downloader is called.
    filename = re.sub(r"[^A-Za-z0-9._-]", "_",
                      urllib.parse.unquote(urllib.parse.urlsplit(url).path.rsplit("/", 1)[-1]))
    filename = "voice-" + filename[-100:]
    with tempfile.TemporaryDirectory(prefix="mailcortex-voice.") as directory:
        audio = Path(directory) / filename
        (download or download_voice)(cfg, url, audio)
        text = (transcribe or transcribe_voice)(audio).strip()
        if not text or len(text) > MAX_BODY:
            raise BridgeError("voice transcript is empty or too long")
        room_header = f"XMPP-Room: {room['jid']}\n" if room is not None else ""
        framed = (f"XMPP-From: {bare(sender)}\n"
                  f"XMPP-To: {local}@{cfg['component_jid']}\n"
                  f"{room_header}"
                  f"Reply-Via: mailcortex send --from <your address> --to {cfg['bridge_address']}\n"
                  "Voice-Note: original audio attached\n\n" + text + "\n")
        args = ["send", "--from", cfg["bridge_address"], "--to", target,
                "--subject", (f"[xmpp #{room['name']}] " if room is not None else "[xmpp voice] ")
                + text.splitlines()[0][:70],

def echo_quote(cfg: dict, sender: str, transcript: str) -> str:
    """Reply-shaped echo: '> Re: <name>' then the transcript in quotes, every line quoted."""
    name = cfg.get("display_names", {}).get(bare(sender)) or bare(sender).split("@")[0]
    lines = ('"' + transcript + '"').split("\n")
    return "\n".join(["> Re: " + name] + ["> " + line for line in lines])


def xml_local(tag: object) -> str:

def has_xml_element(msg, name: str) -> bool:

def stanza_key(msg, prefix: str = "") -> str | None:
    identifiers = []
    for element in msg.xml.iter():
        if xml_local(element.tag) in {"stanza-id", "origin-id"} and element.get("id"):
            identifiers.append(f"{xml_local(element.tag)}:{element.get('id')}")
    if identifiers:
        return prefix + identifiers[0]
    identifier = str(msg["id"] or "")
    return prefix + identifier if identifier else None

def address_room(room: dict, body: str) -> tuple[list[str], str, str | None]:
    """Return target seats, prefix-stripped body, and an unknown nickname."""
    text = body.lstrip()
    if not text:
        return [room["lead"]], "", None
    lower = text.casefold()
    if lower == "@all" or lower.startswith("@all ") or lower.startswith("@all:") \
            or lower.startswith("@all,"):
        remainder = text[4:].lstrip(" :,")
        return list(room["seats"]), remainder, None

    targets: list[str] = []
    cursor = text
    first = True
    while cursor:
        cursor = cursor.lstrip()
        if not cursor:
            break
        at = cursor.startswith("@")
        if at:
            match = re.match(r"@([^\s,:]+)(?:[:,])?(?:\s+|$)", cursor)
            if match is None:
                break
            nickname = match.group(1)
            consumed = match.end()
        elif first:
            match = re.match(r"([^\s,:]+)(?:[:,])(?:\s+|$)", cursor)
            if match is None:
                break
            nickname = match.group(1)
            consumed = match.end()
        else:
            match = re.match(r"([^\s,:]+)(?:[:,])(?:\s+|$)", cursor)
            if match is None:
                break
            nickname = match.group(1)
            consumed = match.end()
        seat = room["nick_to_seat"].get(nickname.casefold())
        if seat is None:
            return [], text, nickname
        if seat not in targets:
            targets.append(seat)
        cursor = cursor[consumed:]
        first = False
        if not at and cursor.startswith("@"):
            continue
        if not cursor:
            break
        if at and not cursor.startswith("@") and not re.match(r"[^\s,:]+[:,]", cursor):
            break
    if not targets:
        unknown = None
        unknown_match = re.match(r"@([^\s,:]+)|([^\s,:]+)[:,]", text)
        if unknown_match:
            unknown = unknown_match.group(1) or unknown_match.group(2)
        return [room["lead"]], text, unknown
    stripped = cursor.strip()
    return targets, stripped, None

async def deliver_inbound(cfg: dict, msg, sender: str, local: str, url: str | None,
                          body: str | None = None, room: dict | None = None,
                          room_map: RoomMap | None = None) -> str | None:
    try:
        if url is not None:
            if room is not None:
                result = await asyncio.to_thread(
                    inbound_voice, cfg, sender, local, url, capture_id=True, room=room)
            else:
                result = await asyncio.to_thread(inbound_voice, cfg, sender, local, url)
            if room is not None:
                name, transcript, message_id = result
            else:
                name, transcript = result
        else:
            if room is not None:
                result = await asyncio.to_thread(
                    inbound_mail, cfg, sender, local,
                    msg["body"] if body is None else body, capture_id=True, room=room)
            else:
                result = await asyncio.to_thread(
                    inbound_mail, cfg, sender, local,
                    msg["body"] if body is None else body)
            if room is not None:
                name, message_id = result
            else:
                name = result
    except (BridgeError, OSError) as error:
        reason = diagnostic(error)
        LOG.error("delivery failed for %s: %s", local, reason)
        prefix = "Voice note could not be transcribed: " if url is not None else "Not delivered: "
        msg.reply(prefix + reason).send()
        return None
    if room is not None:
        if room_map is None:
            raise BridgeError("room delivery has no room map")
        room_map.add(message_id, room["jid"])
    LOG.info("delivered %s -> %s as %s", sender, local, name)
    if url is not None and room is None:
        # slixmpp Message.reply swaps the original seat/owner and preserves thread.
        try:
            msg.reply(echo_quote(cfg, sender, transcript)).chat().send()
        except Exception as error:
            LOG.error("transcript delivered but echo failed for %s: %s", local, diagnostic(error))
    return transcript if url is not None else None

def markdown_to_styling(text: str) -> str:
    """Conservative Markdown -> XEP-0393, with code and escapes opaque."""
    span = None
    def inline(line, bold_context=False):
        nonlocal span
        if "\x00" in line:
            return line
        protected, pieces, index = [], [], 0
        while index < len(line):
            start = index
            if line[index] == "\\" and index + 1 < len(line):
                index += 2
            elif line[index] == "`":
                run = re.match(r"`+", line[index:])[0]
                end = re.search(r"(?<!`)" + re.escape(run) + r"(?!`)", line[index + len(run):])
                if end is None:
                    span = run
                    return line  # Preserve multiline spans until their closing run.
                index += len(run) + end.end()
            else:
                link = re.match(r"(!?)\[([^\[\]\n\\`]+)\]\(([^()\s]+)\)", line[index:]) if line[index] in "![" else None
                url = re.match(r"https?://\S+", line[index:]) if line[index] == "h" else None
                if link or url:
                    token = link[0] if link else url[0]
                    value = token if not link or link[1] else inline(link[2], bold_context) + " (" + link[3] + ")"
                    pieces.append(f"\x00{len(protected)}\x00")
                    protected.append(value)
                    index += len(token)
                    continue
                pieces.append(line[index])
                index += 1
                continue
            pieces.append(f"\x00{len(protected)}\x00")
            protected.append(line[start:index])
        line = "".join(pieces)
        # Single-star italics first, so newly converted bold is not restyled.
        line = re.sub(r"(?<![\w*])\*([^\s*](?:[^*\n]*?[^\s*])?)\*(?![\w*])", r"_\1_", line)
        for token, replacement in (("**", "*"), ("__", "*"), ("~~", "~")):
            marker = re.escape(token)
            char = re.escape(token[0])
            pattern = (rf"(?<![\w{char}]){marker}([^\s{char}]"
                       rf"(?:[^{char}\n]*?[^\s{char}])?){marker}(?![\w{char}])")
            wrapper = "" if bold_context and token in {"**", "__"} else replacement
            line = re.sub(pattern, lambda m: wrapper + m[1] + wrapper, line)
        return re.sub(r"\x00(\d+)\x00", lambda m: protected[int(m[1])], line)

    result, fence = [], None
    for line in text.splitlines(keepends=True):
        if span:
            result.append(line)
            if re.search(r"(?<!`)" + re.escape(span) + r"(?!`)", line):
                span = None
            continue
        marker = re.match(r"^ {0,3}(`{3,}|~{3,})([^\r\n]*)", line)
        if fence:
            result.append(line)
            if (marker and marker[1][0] == fence[0] and len(marker[1]) >= fence[1]
                    and not marker[2].strip()):
                fence = None
            continue
        if marker:
            fence = (marker[1][0], len(marker[1]))
            result.append(line)
            continue
        if line.startswith(("    ", "\t")):
            result.append(line)  # Indented code, not a guessed nested list.
            continue
        heading = re.match(r"^( {0,3})#{1,6} +([^\r\n]+)(\r?\n)?$", line)
        if heading:
            content = re.sub(r" +#+ *$", "", heading[2])
            styled = inline(content, bold_context=True)
            result.append(line if span else heading[1] + "*" + styled + "*" + (heading[3] or ""))
        else:
            styled = inline(line)
            if not span:
                styled = re.sub(r"^( {0,3})[-+*] +(?!\[[ xX]\])(?=\S)", r"\1• ", styled)
            result.append(styled)
    return "".join(result)


def normalize_voice_text(text: str) -> str:
    normalizer = Path(os.environ.get(
        "VOICE_TEXT_NORMALIZER", Path(__file__).resolve().with_name("voice-text-normalize")))
    try:
        result = subprocess.run(
            [str(normalizer), "--format", "markdown"], input=text,
            capture_output=True, text=True, timeout=10)
    except subprocess.TimeoutExpired as error:
        raise BridgeError("voice text normalizer timed out") from error
    except OSError as error:
        raise BridgeError("voice text normalizer is unavailable") from error
    if result.returncode:
        raise BridgeError(f"voice text normalizer failed with exit status {result.returncode}")
    spoken = result.stdout.strip()
    if not spoken:
        raise BridgeError("voice reply contains no spoken text")
    return spoken


def render_voice(text: str, agent: str, directory: Path, run=subprocess.run) -> Path:
    """Worker-only rendering/encoding. Never play audio, never invoke a rule."""
    spoken = normalize_voice_text(text)
    if len(spoken) > VOICE_TEXT_LIMIT:
        LOG.info("voice reply truncated from %d to %d characters", len(spoken), VOICE_TEXT_LIMIT)
    source, wav, ogg = (directory / name for name in ("reply.md", "reply.wav", "reply.ogg"))
    source.write_text(spoken[:VOICE_TEXT_LIMIT], encoding="utf-8")
    source.chmod(0o600)
    pvox = Path.home() / "HelmCortex/FORGE/VoxForge/bin/pvox"
    commands = (
        ("render", [str(pvox), "render", "--agent", agent, "--no-play", str(source), str(wav)], RENDER_SECONDS, wav),
        ("encode", ["ffmpeg", "-nostdin", "-hide_banner", "-loglevel", "error", "-n", "-i", str(wav),
                    "-vn", "-ac", "1", "-c:a", "libopus", "-b:a", "24k", "-application", "voip", str(ogg)], ENCODE_SECONDS, ogg),
    )
    for stage, argv, timeout, output in commands:
        try:
            result = run(argv, capture_output=True, text=True, timeout=timeout)
        except subprocess.TimeoutExpired as error:
            raise BridgeError(f"{stage} timed out") from error
        except OSError as error:
            raise BridgeError(f"{stage} unavailable: {diagnostic(error)}") from error
        if result.returncode:
            reason = result.stderr.strip() or f"exit status {result.returncode} (no stderr)"
            raise BridgeError(f"{stage} failed: {diagnostic(reason)}")
        if not output.is_file() or not output.stat().st_size:
            raise BridgeError(f"{stage} produced no audio")
        output.chmod(0o600)
    if ogg.stat().st_size > VOICE_LIMIT:
        raise BridgeError("encoded voice exceeds 25 MiB")
    return ogg


def parse_slot(cfg: dict, iq) -> tuple[str, str, dict]:
    slot = iq.xml.find("{" + UPLOAD_NS + "}slot")
    put = slot.find("{" + UPLOAD_NS + "}put") if slot is not None else None
    get = slot.find("{" + UPLOAD_NS + "}get") if slot is not None else None
    if put is None or get is None:
        raise BridgeError("upload service returned an incomplete slot")
    put_url, get_url = put.get("url", ""), get.get("url", "")
    validate_upload_url(cfg, put_url)
    validate_upload_url(cfg, get_url)
    headers = {}
    for header in put.findall("{" + UPLOAD_NS + "}header"):
        name, value = header.get("name", ""), header.text or ""
        if (name.lower() not in {"authorization", "cookie", "expires"}
                or name.lower() in headers or "\r" in value or "\n" in value):
            raise BridgeError("upload slot contains an unsafe header")
        headers[name.lower()] = value
    return put_url, get_url, headers


def put_voice(cfg: dict, url: str, audio: Path, headers: dict, opener=None) -> None:
    validate_upload_url(cfg, url)
    payload = audio.read_bytes()
    if not 0 < len(payload) <= VOICE_LIMIT:
        raise BridgeError("voice upload is empty or exceeds 25 MiB")
    request = urllib.request.Request(url, data=payload, method="PUT", headers={
        **headers, "Content-Type": "audio/ogg", "Content-Length": str(len(payload))})
    opener = opener or urllib.request.build_opener(
        urllib.request.ProxyHandler({}), NoRedirect()).open
    try:
        with opener(request, timeout=UPLOAD_SECONDS) as response:
            if not 200 <= response.status < 300:
                raise BridgeError(f"upload PUT failed: HTTP {response.status}")
    except urllib.error.HTTPError as error:
        raise BridgeError(f"upload PUT failed: HTTP {error.code}") from error
    except (OSError, urllib.error.URLError) as error:
        raise BridgeError("upload PUT failed (network or TLS)") from error


async def voice_worker(function, *args):
    # Cancellation must not remove private audio while a thread still owns it.
    task = asyncio.create_task(asyncio.to_thread(function, *args))
    try:
        return await asyncio.shield(task)
    except asyncio.CancelledError as cancelled:
        while not task.done():
            try:
                await asyncio.shield(task)
            except asyncio.CancelledError:
                continue
            except Exception:
                break
        if not task.cancelled() and task.exception():
            LOG.error("cancelled voice worker failed: %s", diagnostic(task.exception()))
        raise cancelled


def room_occupant(room: dict, local: str) -> str:
    return f"{room['jid']}/{room['nicks'][local]}"


async def relay_reply(component, cfg: dict, local: str, text: str,
                      room: dict | None = None, joined: set[tuple[str, str]] | None = None) -> None:
    """Post to a mapped room when possible; direct 1:1 is the safe fallback."""
    jid = f"{local}@{cfg['component_jid']}"
    if room is not None:
        if local not in room["seats"] or (room["jid"], local) not in (joined or set()):
            note = f"Room reply not posted: {local} is not an occupant of {room['name']}."
            await relay_reply(component, cfg, local, note + "\n\n" + text)
            return
        routes = [{"mto": room["jid"], "mfrom": room_occupant(room, local),
                   "mtype": "groupchat"}]
    else:
        routes = [{"mto": owner, "mfrom": jid, "mtype": "chat"}
                  for owner in cfg["owner_jids"]]
    try:
        for route in routes:
            component.send_message(**route, mbody=markdown_to_styling(text))
    except Exception as error:
        if room is None:
            raise
        reason = diagnostic(error)
        LOG.error("room reply failed for %s in %s: %s", local, room["name"], reason)
        note = f"Room reply failed; sent 1:1: {reason}"
        await relay_reply(component, cfg, local, note + "\n\n" + text)
        return
    agent = cfg.get("voices", {}).get(local)
    if agent is None:
        return
    try:
        with tempfile.TemporaryDirectory(prefix="mailcortex-reply.") as directory:
            audio = await voice_worker(render_voice, text, agent, Path(directory))
            try:
                iq = await component["xep_0363"].request_slot(
                    cfg["upload_service_jid"], audio.name, audio.stat().st_size,
                    "audio/ogg", ifrom=jid, timeout=UPLOAD_SECONDS)
            except Exception as error:
                # IqError.__str__ includes the whole XML (and potentially bearer URLs).
                condition = getattr(error, "condition", "") or type(error).__name__
                raise BridgeError("upload slot request failed: " + diagnostic(condition)) from error
            put_url, get_url, headers = parse_slot(cfg, iq)
            await voice_worker(put_voice, cfg, put_url, audio, headers)
            for route in routes:
                message = component.make_message(**route, mbody=get_url)
                ET.SubElement(ET.SubElement(message.xml, "{jabber:x:oob}x"),
                              "{jabber:x:oob}url").text = get_url
                message.send()
    except Exception as error:
        reason = diagnostic(error)
        LOG.error("voice reply failed for %s: %s", local, reason)
        for route in routes:
            component.send_message(**route, mbody="Voice reply failed: " + reason)

                            sender, recipient_local(iq), iq["command"]["node"])

                    LOG.warning("adhoc owner=%s seat=%s command=%s result=session-owner-mismatch",
                                sender, recipient_local(iq), iq["command"]["node"])

                except (BridgeError, OSError) as error:
                    failed = True
                    rows.append(f"{local}: unavailable ({diagnostic(error)})")
            return not failed, "\n".join(rows)

        def execute_command(self, owner: str, local: str, name: str) -> tuple[bool, str]:
            if name == "status":
                success, output = self.nurse_status(local)
            elif name == "seats":
                success, output = self.seats_status()
            elif name == "revive":
                bot = cfg["bots"].get(local)
                if bot is None:
                    success, output = False, "revive is not mapped for this seat"
                else:
                    argv = ["nurse-joy", "revive", bot, "--no-visit"]
                    try:
                        result = subprocess.run(argv, capture_output=True, text=True, timeout=900)
                        success = result.returncode == 0
                        output = self.command_text(result.stdout or result.stderr,
                                                   f"exit status {result.returncode}")
                    except (OSError, subprocess.TimeoutExpired) as error:
                        success, output = False, f"revive failed: {diagnostic(error)}"
            elif name == "compact":
                bot = cfg["bots"].get(local)
                if bot is None or not shutil.which("claude-warmctl"):
                    success, output = False, "compact has no safe control path for this seat"
                else:
                    argv = ["claude-warmctl", "inject", bot, "/compact"]
                    try:
                        result = subprocess.run(argv, capture_output=True, text=True, timeout=30)
                        success = result.returncode == 0
                        output = self.command_text(result.stdout or result.stderr,
                                                   f"exit status {result.returncode}")
                    except (OSError, subprocess.TimeoutExpired) as error:
                        success, output = False, f"compact failed: {diagnostic(error)}"
            else:
                success, output = False, f"unknown command {name}"
            LOG.info("adhoc owner=%s seat=%s command=%s result=%s",
                     owner, local, name, "ok: " + self.command_text(output))
            return success, output

        @staticmethod
        def confirmation_form(name: str, bot: str) -> Form:
            form = Form()
            form["type"] = "form"
            form["title"] = f"Confirm {name}"
            form["instructions"] = f"Run {name} for {bot}. Set confirm to true to continue."
            form.add_field(var="confirm", ftype="boolean", label="Confirm",
                           desc="This command changes state.", required=True, value=False)
            return form

        async def begin_command(self, iq, session: dict, local: str, name: str) -> dict:
            owner = bare(str(iq["from"]))
            if owner not in gate.owners:
                raise XMPPError("forbidden")
            if name not in self.command_names(local):
                raise XMPPError("item-not-found")
            if name in {"revive", "compact"}:
                bot = cfg["bots"].get(local)
                session.update({"seat": local, "command_name": name, "owner": owner,
                                "payload": [self.confirmation_form(name, bot)],
                                "has_next": True, "allow_complete": False,
                                "next": self.finish_command})
                return session
            success, output = await asyncio.to_thread(self.execute_command, owner, local, name)
            session.update({"payload": [], "notes": [("info" if success else "error", output)],
                            "has_next": False, "next": None})
            return session

        async def finish_command(self, payload, session: dict) -> dict:
            confirmed = False
            try:
                values = payload.get_values()
                confirmed = bool(values.get("confirm"))
            except (AttributeError, TypeError, ValueError):
                confirmed = False
            owner = session["owner"]
            local = session["seat"]
            name = session["command_name"]
            if not confirmed:
                output = "cancelled: confirmation was not given"
                LOG.info("adhoc owner=%s seat=%s command=%s result=%s",
                         owner, local, name, output)
                session.update({"payload": [], "notes": [("warning", output)],
                                "has_next": False, "next": None})
                return session
            success, output = await asyncio.to_thread(
                self.execute_command, owner, local, name)
            session.update({"payload": [], "notes": [("info" if success else "error", output)],
                            "has_next": False, "next": None})
            return session

        def room_send(self, room: dict, local: str, body: str) -> None:
            self.send_message(mto=room["jid"], mfrom=room_occupant(room, local),
                              mbody=body, mtype="groupchat")

        def join_room(self, room: dict, local: str) -> None:
            occupant = room_occupant(room, local)
            presence = self.make_presence(pto=occupant, pfrom=self.seat_jid(local))
            history = ET.SubElement(ET.SubElement(presence.xml, "{" + MUC_NS + "}x"),
                                    "{" + MUC_NS + "}history")
            history.set("maxstanzas", "0")
            presence.send()
            self.joined.add((room["jid"], local))

        def join_failure(self, room: dict, local: str, reason: str) -> None:
            marker = (room["jid"], local)
            self.joined.discard(marker)
            if marker in self.join_failures:
                return
            self.join_failures.add(marker)
            LOG.error("room join failed for %s in %s: %s", local, room["name"], reason)
            message = f"Room join failed for {room['name']} ({local}): {diagnostic(reason)}"
            for owner in cfg["owner_jids"]:
                self.send_message(mto=owner, mfrom=self.seat_jid(room["lead"]),
                                  mbody=message, mtype="chat")

        async def permission_text(self, msg, local: str, url: str | None) -> str | None:
            if local not in permission_secrets:
                return None
            if url is not None:
                try:
                    return await asyncio.to_thread(transcribe_permission_voice, cfg, url)
                except (BridgeError, OSError) as error:
                    LOG.warning("permission voice was not transcribed for %s: %s",
                                local, diagnostic(error))
                    return None
            return str(msg["body"] or "")

        async def handle_permission(self, msg, sender: str, local: str,
                                    url: str | None) -> bool:
            text = await self.permission_text(msg, local, url)
            if text is None:
                return False
            decision = permission_reply(text)
            if decision is None:
                return False
            behavior, request_id = decision
            key = (local, request_id)
            if key in self.answered_permissions:
                self.send_message(mto=sender, mfrom=self.seat_jid(local),
                                  mbody=f"Permission request {request_id} was already answered.",
                                  mtype="chat")
                LOG.warning("permission owner=%s seat=%s request=%s result=already-answered",
                            sender, local, request_id)
                return True
            pending = self.pending_permissions.get(key)
            if pending is None:
                self.send_message(mto=sender, mfrom=self.seat_jid(local),
                                  mbody=f"Unknown permission request {request_id}.",
                                  mtype="chat")
                LOG.warning("permission owner=%s seat=%s request=%s result=unknown",
                            sender, local, request_id)
                return True
            timestamp = int(time.time())
            try:
                await asyncio.to_thread(
                    decision_mail, cfg, local, request_id, behavior,
                    permission_secrets[local], timestamp)
            except (BridgeError, OSError) as error:
                LOG.error("permission owner=%s seat=%s request=%s result=mail-failed: %s",
                          sender, local, request_id, diagnostic(error))
                self.send_message(mto=sender, mfrom=self.seat_jid(local),
                                  mbody=f"Permission decision {request_id} failed; it remains pending.",
                                  mtype="chat")
                return True
            self.pending_permissions.pop(key, None)
            self.answered_permissions.add(key)
            label = "Allowed" if behavior == "allow" else "Denied"
            self.send_message(mto=sender, mfrom=self.seat_jid(local),
                              mbody=f"{label} {request_id}", mtype="chat")
            LOG.info("permission owner=%s seat=%s request=%s result=%s",
                     sender, local, request_id, behavior)
            return True

        def on_presence(self, presence) -> None:
            room_jid = bare(str(presence["from"]))
            room = cfg["room_by_jid"].get(room_jid)
            if room is None:
                return
            nick = occupant_nick(str(presence["from"]))
            local = room["nick_to_seat"].get(nick.casefold())
            ptype = str(presence["type"] or "")
            if ptype in {"unavailable", "error"}:
                if local is None:
                    self.room_occupants.get(room_jid, {}).pop(nick, None)
                    return
                reason = "presence error" if ptype == "error" else "occupant left"
                if ptype == "error":
                    for element in presence.xml.iter():
                        if xml_local(element.tag) == "text" and element.text:
                            reason = element.text
                self.join_failure(room, local, reason) if ptype == "error" else self.joined.discard((room_jid, local))
                self.room_occupants.get(room_jid, {}).pop(nick, None)
                return
            real = None
            for element in presence.xml.iter():
                if (xml_local(element.tag) == "item" and
                        str(element.tag).startswith("{" + MUC_USER_NS + "}") and
                        element.get("jid")):
                    real = bare(element.get("jid"))
                    break
            if real:
                self.room_occupants.setdefault(room_jid, {})[nick] = real

        async def on_room_message(self, msg) -> None:
            room = cfg["room_by_jid"].get(bare(str(msg["from"])))
            if room is None:
                return
            local = recipient_local(msg)
            if local not in room["seats"] or (room["jid"], local) not in self.joined:
                return
            nick = occupant_nick(str(msg["from"]))
            if any(nick.casefold() == room["nicks"][seat].casefold()
                   for seat in room["seats"]):
                return
            sender = self.room_occupants.get(room["jid"], {}).get(nick)
            if sender not in gate.owners or has_xml_element(msg, "delay"):
                return
            url = voice_url(cfg, msg)
            body = str(msg["body"] or "")
            if not body and url is None:
                return
            refusal = gate.admit(sender, time.monotonic())
            if refusal:
                LOG.warning("refused %s from room occupant %s", refusal, nick)
                if refusal == "rate_limited":
                    self.room_send(room, room["lead"], "Rate limited; message not delivered.")
                return
            key = stanza_key(msg, room["jid"] + "|")
            if not seen.check_and_add(key):
                LOG.info("duplicate room stanza ignored")
                return
            targets, stripped, unknown = address_room(room, body)
            if unknown is not None:
                self.room_send(room, room["lead"],
                               f"Unknown nickname {unknown}. Known nicknames: {known_nicknames(room)}")
                return
            if url is not None and self.voice_jobs >= VOICE_JOBS:
                self.room_send(room, room["lead"],
                               "Voice note not delivered: transcription capacity reached; resend later.")
                return
            if url is not None:
                self.voice_jobs += 1
            echoed = False
            try:
                for target in targets:
                    transcript = await deliver_inbound(
                        cfg, msg, sender, target, url, body=stripped,
                        room=room, room_map=room_map)
                    if url is not None and transcript and not echoed:
                        self.room_send(room, target, echo_quote(cfg, sender, transcript))
                        echoed = True
            finally:
                if url is not None:
                    self.voice_jobs -= 1

        async def on_start(self, _event) -> None:
            LOG.info("component online: %s (%d seats)", cfg["component_jid"], len(cfg["seats"]))
            self.joined.clear()
            self.room_occupants.clear()
            self.join_failures.clear()
            self.install_commands()
            for local in cfg["seats"]:
                for owner in cfg["owner_jids"]:
                    self.send_presence(pfrom=self.seat_jid(local), pto=owner)
            for room in cfg["rooms"].values():
                for local in room["seats"]:
                    try:
                        self.join_room(room, local)
                    except Exception as error:
                        self.join_failure(room, local, diagnostic(error))
            if self.poller is None:
                self.poller = asyncio.ensure_future(self.poll_outbound())

        def on_subscribe(self, presence) -> None:
            local = presence["to"].user
            if bare(presence["from"]) in gate.owners and local in cfg["seats"]:
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare, ptype="subscribed")
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare)
            else:
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare, ptype="unsubscribed")

        def on_probe(self, presence) -> None:
            if bare(presence["from"]) in gate.owners and presence["to"].user in cfg["seats"]:
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare)

        async def on_message(self, msg) -> None:
            if msg["type"] == "groupchat":
                await self.on_room_message(msg)
                return
            if msg["type"] not in ("chat", "normal"):
                return
            url = voice_url(cfg, msg)
            if not msg["body"] and url is None:
                return
            sender = bare(msg["from"])
            local = msg["to"].user
            refusal = gate.admit(sender, time.monotonic())
            if refusal:
                LOG.warning("refused %s from %s to %s", refusal, sender, local)
                if refusal == "rate_limited":
                    msg.reply("Rate limited; message not delivered.").send()
                return
            if local not in cfg["seats"]:
                LOG.warning("unknown seat %s from %s", local, sender)
                msg.reply("No such seat.").send()
                return
            if await self.handle_permission(msg, sender, local, url):
                return
            key = f"{sender}|{local}|{msg['id']}" if msg["id"] else None
            if not seen.check_and_add(key):
                LOG.info("duplicate stanza %s ignored", key)
                return
            if url is not None and self.voice_jobs >= VOICE_JOBS:
                LOG.warning("voice capacity reached for %s", local)
                msg.reply("Voice note not delivered: transcription capacity reached; resend later.").send()
                return
            if url is not None:
                self.voice_jobs += 1
            try:
                await deliver_inbound(cfg, msg, sender, local, url)
            finally:
                if url is not None:
                    self.voice_jobs -= 1

        async def poll_outbound(self) -> None:
            while True:
                try:
                    await self.relay_outbound()
                except (BridgeError, OSError) as error:
                    LOG.error("outbound poll failed: %s", diagnostic(error))
                await asyncio.sleep(cfg["poll_seconds"])

        async def relay_outbound(self) -> None:
            for name in await asyncio.to_thread(pending_outbound, cfg):
                rendered = await asyncio.to_thread(mailcortex, ["read", cfg["bridge_address"], name])
                local, text, message_id = render_outbound(cfg, rendered)
                if local is None:
                    LOG.warning("rejected outbound mail %s from an unmapped sender", name)
                    if message_id:
                        await asyncio.to_thread(mailcortex, ["receipt", cfg["bridge_seat"], message_id, "handling_rejected"])
                    continue
                if local in permission_secrets:
                    try:
                        permission = permission_request(rendered)
                    except BridgeError as error:
                        LOG.error("permission mail %s refused: %s", name, diagnostic(error))
                        if message_id:
                            await asyncio.to_thread(mailcortex, ["receipt", cfg["bridge_seat"], message_id, "handling_rejected"])
                        continue
                    if permission is not None:
                        request_id, tool_name, body = permission
                        key = (local, request_id)
                        self.pending_permissions[key] = {
                            "tool_name": tool_name,
                            "body": body,
                        }
                        owner_text = f"Permission request {request_id}\n{body}"
                        await relay_reply(self, cfg, local, owner_text)
                        if message_id:
                            await asyncio.to_thread(mailcortex, ["receipt", cfg["bridge_seat"], message_id, "handling_completed"])
                        LOG.info("permission request owner relay seat=%s request=%s", local, request_id)
                        continue
                parent = reply_parent(rendered)
                mapped_room_jid = room_map.get(parent) if parent else None
                room = cfg["room_by_jid"].get(mapped_room_jid) if mapped_room_jid else None
                if mapped_room_jid and room is None:
                    text = (f"Room reply not posted: the mapped room is not configured.\n\n{text}")
                if mapped_room_jid:
                    await relay_reply(self, cfg, local, text, room, self.joined)
                else:
                    await relay_reply(self, cfg, local, text)
                if message_id:
                    await asyncio.to_thread(mailcortex, ["receipt", cfg["bridge_seat"], message_id, "handling_completed"])
                LOG.info("relayed %s from %s", name, local)

    component = Component()
    component.connect()
    asyncio.get_event_loop().run_until_complete(component.disconnected)
    return 1


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(
        prog="mailcortex-xmpp-bridge",
        description="Bridge MailCortex seats to XMPP through a Prosody component.")
    parser.add_argument("--check", action="store_true",
                        help="validate the private config and secret, then exit")
    parser.add_argument("--config", type=Path, default=None,
                        help="bridge.json path (default ~/.config/mailcortex/xmpp-private/bridge.json)")
    args = parser.parse_args(argv)
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
    try:
        cfg = load_config(args.config or config_path())
        if args.check:
            read_secret(cfg["component_secret_file"])

            return 0
        return run_bridge(cfg)
    except BridgeError as error:
        print(f"mailcortex-xmpp-bridge: {error}", file=sys.stderr)
        return 1

* Service owner

=mailcortex-xmpp-service= owns both processes on the serving host: Prosody (user instance, this module's configuration) and the bridge. =ensure= is idempotent and is what the boot and self-heal cron lines call; it starts only what is not running and refuses to start anything until the private site files exist. After Prosody is alive, =ensure= reads the private listener arrays without exposing their values, checks every c2s and optional HTTPS endpoint with =ss=, and distinguishes a missing local address (restart Prosody once) from an address that Tailscale has not assigned yet (log and defer). Processes are identified by pidfile plus a command-line check, never by name alone. =renew-cert= reads the client domain from the private =cert-domain= file, refreshes the Tailscale certificate (Tailscale reissues only inside its renewal window) and sends Prosody =SIGHUP= when the certificate changed, so it reloads without dropping clients. =install-cron= adds the tagged =@reboot=, five-minute self-heal and weekly renewal lines to the user crontab once; its PATH includes the system networking helpers; =remove-cron= deletes only those tagged lines.

alive() { # pidfile pattern
  local pid
  [ -r "$1" ] || return 1
  pid="$(cat "$1" 2>/dev/null)"
  case "$pid" in ''|*[!0-9]*) return 1 ;; esac
  [ -r "/proc/$pid/cmdline" ] && tr '\0' ' ' < "/proc/$pid/cmdline" | grep -q -- "$2"
}

start_prosody() {
  alive "$prosody_pid" "$config" && return 0
  install -d -m 700 "$data" "$data/data"
  nohup prosody --config "$config" >>"$data/prosody.stdout" 2>&1 &
  for _ in $(seq 1 20); do alive "$prosody_pid" "$config" && return 0; sleep 0.5; done
  echo "mailcortex-xmpp-service: prosody did not come up (see $data/prosody.err)" >&2
  return 1
}

# Read only quoted list members from one top-level Lua assignment. The output
# is consumed by a private process substitution; it never reaches this
# service's stdout, stderr or log.
private_lua_strings() {
  awk -v want="$1" '
    {
      line = $0
      if (!inside) {
        if (line !~ "^[[:space:]]*" want "[[:space:]]*=[[:space:]]*[{]") next
        inside = 1
        sub(/^[^{]*[{]/, "", line)
      }
      while (match(line, /"[^"]*"|\047[^\047]*\047/)) {
        token = substr(line, RSTART, RLENGTH)
        print substr(token, 2, RLENGTH - 2)
        line = substr(line, RSTART + RLENGTH)
      }
      if (index(line, "}") > 0) exit
    }
  ' "$site/local.cfg.lua"
}

private_lua_numbers() {
  awk -v want="$1" '
    {
      line = $0
      if (!inside) {
        if (line !~ "^[[:space:]]*" want "[[:space:]]*=[[:space:]]*[{]") next
        inside = 1
        sub(/^[^{]*[{]/, "", line)
      }
      while (match(line, /[0-9]+/)) {
        print substr(line, RSTART, RLENGTH)
        line = substr(line, RSTART + RLENGTH)
      }
      if (index(line, "}") > 0) exit
    }
  ' "$site/local.cfg.lua"
}

load_expected_listeners() {
  local -a c2s_interfaces=() c2s_ports=() https_interfaces=() https_ports=()
  local interface port
  expected_listeners=()
  while IFS= read -r interface; do
    [ -n "$interface" ] && c2s_interfaces+=("$interface")
  done < <(private_lua_strings c2s_interfaces)
  [ "${#c2s_interfaces[@]}" -gt 0 ] || {
    echo "mailcortex-xmpp-service: private c2s_interfaces is missing or empty" >&2
    return 1
  }
  while IFS= read -r port; do
    [ -n "$port" ] && c2s_ports+=("$port")
  done < <(private_lua_numbers c2s_ports)
  [ "${#c2s_ports[@]}" -gt 0 ] || c2s_ports=(5222)
  for interface in "${c2s_interfaces[@]}"; do
    for port in "${c2s_ports[@]}"; do
      expected_listeners+=("$interface|$port")
    done
  done

  while IFS= read -r interface; do
    [ -n "$interface" ] && https_interfaces+=("$interface")
  done < <(private_lua_strings https_interfaces)
  [ "${#https_interfaces[@]}" -eq 0 ] && return 0
  while IFS= read -r port; do
    [ -n "$port" ] && https_ports+=("$port")
  done < <(private_lua_numbers https_ports)
  [ "${#https_ports[@]}" -gt 0 ] || {
    echo "mailcortex-xmpp-service: private https_interfaces has no https_ports" >&2
    return 1
  }
  for interface in "${https_interfaces[@]}"; do
    for port in "${https_ports[@]}"; do
      expected_listeners+=("$interface|$port")
    done
  done
}

listener_has_endpoint() {
  local address="$1" port="$2" endpoint candidate
  while read -r _ _ _ endpoint _; do
    case "$endpoint" in
      *":$port") candidate="${endpoint%:$port}" ;;
      *) continue ;;
    esac
    candidate="${candidate#[}"
    candidate="${candidate%]}"
    [ "$candidate" = "$address" ] && return 0
  done <<< "$listener_snapshot"
  return 1
}

interface_has_address() {
  local address="$1" cidr
  while read -r _ _ _ cidr _; do
    [ "${cidr%%/*}" = "$address" ] && return 0
  done <<< "$interface_snapshot"
  return 1
}

check_prosody_listeners() {
  local expected address port missing_local=0 missing_absent=0
  load_expected_listeners || return 1
  command -v ss >/dev/null 2>&1 || {
    echo "mailcortex-xmpp-service: ss is unavailable; cannot verify Prosody listeners" >&2
    return 1
  }
  command -v ip >/dev/null 2>&1 || {
    echo "mailcortex-xmpp-service: ip is unavailable; cannot verify local interfaces" >&2
    return 1
  }
  if ! listener_snapshot="$(ss -H -ltn 2>/dev/null)"; then
    echo "mailcortex-xmpp-service: ss listener probe failed" >&2
    return 1
  fi
  if ! interface_snapshot="$(ip -o address show 2>/dev/null)"; then
    echo "mailcortex-xmpp-service: local interface probe failed" >&2
    return 1
  fi
  for expected in "${expected_listeners[@]}"; do
    address="${expected%%|*}"
    port="${expected#*|}"
    listener_has_endpoint "$address" "$port" && continue
    if interface_has_address "$address"; then
      missing_local=1
    else
      missing_absent=1
    fi
  done
  if [ "$missing_absent" -eq 1 ]; then
    echo "mailcortex-xmpp-service: expected listener address is not present yet; retrying" >&2
  fi
  [ "$missing_local" -eq 0 ] || return 11
  [ "$missing_absent" -eq 0 ] || return 10
  return 0
}

ensure_prosody() {
  local rc
  start_prosody
  if check_prosody_listeners; then
    return 0
  else
    rc=$?
  fi
  case "$rc" in
    10) return 10 ;;
    11)
      echo "mailcortex-xmpp-service: expected Prosody listener is missing; restarting Prosody" >&2
      stop_one "$prosody_pid" "$config"
      start_prosody
      if check_prosody_listeners; then
        return 0
      else
        rc=$?
      fi
      [ "$rc" -eq 10 ] && return 10
      echo "mailcortex-xmpp-service: Prosody listener check still failed after restart" >&2
      return 1
      ;;
    *) return "$rc" ;;
  esac
}

}

}

class RoutingTests(unittest.TestCase):
    def setUp(self):
        tmp = Path(tempfile.mkdtemp())
        path = tmp / "bridge.json"
        path.write_text(json.dumps(base_config(tmp)))
        self.cfg = bridge.load_config(path)

    def test_inbound_sends_from_bridge_to_seat(self):
        run = FakeRun({"send": "123.msg\n"})
        name = bridge.inbound_mail(self.cfg, "owner@example.test/phone", "fable", "Hello there\nsecond line", run)
        self.assertEqual(name, "123.msg")
        argv = run.calls[0]
        self.assertEqual(argv[:6], ["mailcortex", "send", "--from", "seat+xmpp-bridge@host.helm", "--to", "fable@host.helm"])
        self.assertEqual(argv[argv.index("--subject") + 1], "[xmpp] Hello there")
        body = argv[argv.index("--body") + 1]
        self.assertIn("XMPP-From: owner@example.test\n", body)
        self.assertIn("--to seat+xmpp-bridge@host.helm", body)

    def test_inbound_unknown_seat_sends_nothing(self):
        run = FakeRun()
        with self.assertRaises(bridge.BridgeError):
            bridge.inbound_mail(self.cfg, "owner@example.test", "ghost", "hi", run)
        self.assertEqual(run.calls, [])

    def test_pending_only_new(self):
        run = FakeRun({"inbox": "cur\told\td\tf\ts\nnew\tfresh\td\tf\ts\n"})
        self.assertEqual(bridge.pending_outbound(self.cfg, run), ["fresh"])

    def test_outbound_maps_sender_and_keeps_subject(self):
        rendered = ("Date: x\nFrom: fable@host.helm\nTo: seat+xmpp-bridge@host.helm\n"
                    "Subject: Build finished\nMessage-ID: <1@host.helm>\n\nAll green.\n")
        local, text, mid = bridge.render_outbound(self.cfg, rendered)
        self.assertEqual((local, mid), ("fable", "<1@host.helm>"))
        self.assertEqual(text, "Build finished\n\nAll green.")

    def test_outbound_reply_subject_dropped(self):
        rendered = ("From: seat+worker@host.helm\nSubject: Re: [xmpp] Hello\n"
                    "Message-ID: <2@host.helm>\n\nDone.\n")
        self.assertEqual(bridge.render_outbound(self.cfg, rendered)[:2], ("worker", "Done."))

    def test_outbound_sender_from_another_machine_maps(self):
        rendered = ("From: seat+worker@other-node.helm\nSubject: Re: [xmpp] Hey\n"
                    "Message-ID: <4@other-node.helm>\n\nOn it.\n")
        self.assertEqual(bridge.render_outbound(self.cfg, rendered)[:2], ("worker", "On it."))

    def test_outbound_unmapped_sender(self):
        rendered = "From: stranger@host.helm\nSubject: x\nMessage-ID: <3@host.helm>\n\nhi\n"
        self.assertIsNone(bridge.render_outbound(self.cfg, rendered)[0])


class RoomTests(unittest.TestCase):
    def setUp(self):
        self.tmp = Path(tempfile.mkdtemp())
        data = base_config(self.tmp) | {
            "upload_base_url": "https://uploads.example.test/file_share/",
            "upload_service_jid": "example.test",
            "voices": {"fable": "Fable"},
            "rooms": {
                "comms": {
                    "jid": "comms@rooms.example.test",
                    "lead": "fable",
                    "seats": ["fable", "worker"],
                }
            },
            "nicks": {"worker": "Orca"},
        }
        path = self.tmp / "rooms.json"
        path.write_text(json.dumps(data))
        self.cfg = bridge.load_config(path)
        self.room = self.cfg["rooms"]["comms"]

    def test_room_config_defaults_and_validation(self):
        self.assertEqual(self.room["nicks"], {"fable": "Fable", "worker": "Orca"})
        self.assertEqual(self.cfg["room_by_jid"][self.room["jid"]], self.room)
        cases = []
        cases.append({"rooms": {"comms": {"jid": "comms@rooms.example.test/occupant",
                                             "lead": "fable", "seats": ["fable"]}}})
        cases.append({"rooms": {"comms": {"jid": "comms@rooms.example.test",
                                             "lead": "ghost", "seats": ["fable"]}}})
        cases.append({"rooms": {"comms": {"jid": "comms@rooms.example.test",
                                             "lead": "fable", "seats": ["ghost"]}}})
        cases.append({"nicks": {"fable": "Same", "worker": "same"}, "rooms": {
            "comms": {"jid": "comms@rooms.example.test", "lead": "fable",
                      "seats": ["fable", "worker"]}
        }})
        cases.append({"rooms": {
            "comms": {"jid": "comms@rooms.example.test", "lead": "fable", "seats": ["fable"]},
            "ops": {"jid": "ops@other.example.test", "lead": "fable", "seats": ["fable"]},
        }})
        for change in cases:
            with self.subTest(change=change):
                data = json.loads(json.dumps(base_config(self.tmp)))
                data.update(change)
                path = self.tmp / "invalid-room.json"
                path.write_text(json.dumps(data))
                with self.assertRaises(bridge.BridgeError):
                    bridge.load_config(path)

    def test_room_addressing_and_prefix_stripping(self):
        cases = (
            ("Fable: hello", ["fable"], "hello", None),
            ("@Fable @Orca hello", ["fable", "worker"], "hello", None),
            ("@all hello", ["fable", "worker"], "hello", None),
            ("plain line", ["fable"], "plain line", None),
            ("Unknown: hello", [], "Unknown: hello", "Unknown"),
        )
        for raw, seats, body, unknown in cases:
            with self.subTest(raw=raw):
                self.assertEqual(bridge.address_room(self.room, raw), (seats, body, unknown))

    def test_room_mail_has_room_header_subject_and_id_capture(self):
        run = FakeRun({"send": "room.msg\t<room@example.test>\n"})
        name, message_id = bridge.inbound_mail(
            self.cfg, "owner@example.test/phone", "fable", "briefing",
            run, capture_id=True, room=self.room)
        self.assertEqual((name, message_id), ("room.msg", "<room@example.test>"))
        argv = run.calls[0]
        self.assertEqual(argv[argv.index("--subject") + 1], "[xmpp #comms] briefing")
        self.assertIn("XMPP-Room: comms@rooms.example.test\n", argv[argv.index("--body") + 1])
        self.assertIn("--print-id", argv)

    def test_room_map_is_capped_and_private(self):
        path = self.tmp / "state" / "room-map.json"
        mapping = bridge.RoomMap(path)
        for index in range(bridge.SEEN_CAP + 1):
            mapping.add(f"<{index}@example.test>", self.room["jid"])
        self.assertIsNone(mapping.get("<0@example.test>"))
        self.assertEqual(mapping.get(f"<{bridge.SEEN_CAP}@example.test>"), self.room["jid"])
        self.assertEqual(path.stat().st_mode & 0o777, 0o600)

    def test_room_reply_is_groupchat_only_and_unjoined_falls_back(self):
        class Component:
            def __init__(self):
                self.messages = []
            def send_message(self, **kwargs):
                self.messages.append(kwargs)
        cfg = dict(self.cfg, voices={})
        component = Component()
        asyncio.run(bridge.relay_reply(component, cfg, "fable", "**reply**",
                                        self.room, {(self.room["jid"], "fable")}))
        self.assertEqual(len(component.messages), 1)
        self.assertEqual(component.messages[0]["mtype"], "groupchat")
        self.assertEqual(component.messages[0]["mto"], self.room["jid"])
        component.messages.clear()
        asyncio.run(bridge.relay_reply(component, cfg, "fable", "reply", self.room, set()))
        self.assertEqual([message["mtype"] for message in component.messages], ["chat"])
        self.assertIn("not posted", component.messages[0]["mbody"])

    def test_history_and_origin_identifiers_are_recognized(self):
        message = FakeMessage("hello", mid="stanza")
        ET.SubElement(message.xml, "{urn:xmpp:delay}delay")
        ET.SubElement(message.xml, "{urn:xmpp:sid:0}origin-id", {"id": "origin"})
        self.assertTrue(bridge.has_xml_element(message, "delay"))
        self.assertEqual(bridge.stanza_key(message, "room|"), "room|origin-id:origin")

class ServiceEnsureTests(unittest.TestCase):
    LOCAL = "YOUR_LOCAL_INTERFACE"
    TAILNET = "YOUR_TAILNET_INTERFACE"
    C2S_PORT = "5222"
    HTTPS_PORT = "1"

    def setUp(self):
        self.temporary = tempfile.TemporaryDirectory()
        self.addCleanup(self.temporary.cleanup)
        self.home = Path(self.temporary.name)
        self.fakebin = self.home / "fakebin"
        self.fakebin.mkdir()
        self.base = self.home / ".config/mailcortex/xmpp"
        self.site = self.home / ".config/mailcortex/xmpp-private"
        self.data = self.home / ".local/share/mailcortex/xmpp"
        self.state = self.home / ".local/state/mailcortex/xmpp"
        self.base.mkdir(parents=True)
        self.site.mkdir(parents=True)
        self.data.mkdir(parents=True)
        self.state.mkdir(parents=True)
        (self.base / "prosody.cfg.lua").write_text("-- fixture\n")
        (self.site / "bridge.json").write_text("{}\n")
        (self.site / "local.cfg.lua").write_text(
            f'c2s_interfaces = {{ "{self.LOCAL}", "{self.TAILNET}" }}\n'
            f'c2s_ports = {{ {self.C2S_PORT} }}\n'
            f'https_interfaces = {{ "{self.TAILNET}" }}\n'
            f'https_ports = {{ {self.HTTPS_PORT} }}\n')
        self.prosody_starts = self.home / "prosody-starts"
        self.bridge_starts = self.home / "bridge-starts"
        self.current_ss = self.home / "ss-current"
        self.healthy_ss = self.home / "ss-healthy"
        self.ip_output = self.home / "ip-output"
        self.current_ss.write_text(self.ss_rows(
            self.LOCAL, self.C2S_PORT, self.TAILNET, self.C2S_PORT,
            self.TAILNET, self.HTTPS_PORT))
        self.healthy_ss.write_text(self.current_ss.read_text())
        self.ip_output.write_text(self.ip_rows(self.LOCAL, self.TAILNET))
        self.write_fake("ss", """starts=$(wc -l < "$MAILCORTEX_TEST_PROSODY_STARTS" 2>/dev/null || printf '0')
if [ "$starts" -ge 2 ]; then cat "$MAILCORTEX_TEST_SS_HEALTHY"; else cat "$MAILCORTEX_TEST_SS_CURRENT"; fi
""")
        self.write_fake("ip", """cat "$MAILCORTEX_TEST_IP_OUTPUT"
""")
        self.write_fake("prosody", """printf '%s\\n' "$$" > "$MAILCORTEX_TEST_PROSODY_PID"
printf '%s\\n' start >> "$MAILCORTEX_TEST_PROSODY_STARTS"
trap 'exit 0' TERM INT
while :; do sleep 0.05; done
""")
        self.write_fake("mailcortex-xmpp-bridge", """if [ "$1" = --check ]; then exit 0; fi
if [ "$1" != --fixture ]; then printf '%s\\n' start >> "$MAILCORTEX_TEST_BRIDGE_STARTS"; fi
printf '%s\\n' "$$" > "$MAILCORTEX_TEST_BRIDGE_PID"
trap 'exit 0' TERM INT
while :; do sleep 0.05; done
""")
        self.env = os.environ.copy() | {
            "HOME": str(self.home),
            "PATH": str(self.fakebin) + ":" + os.environ.get("PATH", "/usr/bin:/bin"),
            "MAILCORTEX_TEST_PROSODY_PID": str(self.data / "prosody.pid"),
            "MAILCORTEX_TEST_PROSODY_STARTS": str(self.prosody_starts),
            "MAILCORTEX_TEST_BRIDGE_PID": str(self.state / "bridge.pid"),
            "MAILCORTEX_TEST_BRIDGE_STARTS": str(self.bridge_starts),
            "MAILCORTEX_TEST_SS_CURRENT": str(self.current_ss),
            "MAILCORTEX_TEST_SS_HEALTHY": str(self.healthy_ss),
            "MAILCORTEX_TEST_IP_OUTPUT": str(self.ip_output),
        }
        self.service = Path(__file__).resolve().parents[5] / "linux/.local/bin/mailcortex-xmpp-service"
        self.processes = []
        self.start_fixture("prosody", "--config", str(self.base / "prosody.cfg.lua"))
        self.start_fixture("mailcortex-xmpp-bridge", "--fixture")

    def tearDown(self):
        for process in self.processes:
            if process.poll() is None:
                process.send_signal(signal.SIGTERM)
                try:
                    process.wait(timeout=2)
                except subprocess.TimeoutExpired:
                    process.kill()
                    process.wait()

    def write_fake(self, name, body):
        path = self.fakebin / name
        path.write_text("#!/bin/sh\n" + body)
        path.chmod(0o755)

    @staticmethod
    def ss_rows(*pairs):
        return "".join(
            f"LISTEN 0 128 {address}:{port} peer:*\n"
            for address, port in zip(pairs[::2], pairs[1::2]))

    @staticmethod
    def ip_rows(*addresses):
        return "".join(
            f"2: fixture0 inet {address}/32 scope global\n"
            for address in addresses)

    def start_fixture(self, command, *args):
        process = subprocess.Popen(
            [str(self.fakebin / command), *args], env=self.env,
            stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        self.processes.append(process)
        deadline = time.monotonic() + 2
        pidfile = self.data / "prosody.pid" if command == "prosody" else self.state / "bridge.pid"
        while time.monotonic() < deadline and not pidfile.exists():
            time.sleep(0.01)
        self.assertTrue(pidfile.exists(), f"{command} fixture did not write its pid")
        self.assertIsNone(process.poll(), f"{command} fixture exited")

    def run_ensure(self):
        return subprocess.run(
            [str(self.service), "ensure"], env=self.env,
            text=True, capture_output=True, check=False)

    def assert_private_values_are_silent(self, result):
        output = result.stdout + result.stderr
        for value in (self.LOCAL, self.TAILNET):
            self.assertNotIn(value, output)
        for log in self.home.rglob("*.log"):
            content = log.read_text()
            self.assertNotIn(self.LOCAL, content)
            self.assertNotIn(self.TAILNET, content)

    def test_healthy_listeners_are_a_noop(self):
        result = self.run_ensure()
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.prosody_starts.read_text().splitlines(), ["start"])
        self.assertFalse(self.bridge_starts.exists())
        self.assert_private_values_are_silent(result)

    def test_present_but_missing_tailnet_listener_restarts_once(self):
        self.current_ss.write_text(self.ss_rows(self.LOCAL, self.C2S_PORT))
        result = self.run_ensure()
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.prosody_starts.read_text().splitlines(), ["start", "start"])
        self.assertFalse(self.bridge_starts.exists())
        self.assertIn("restarting Prosody", result.stderr)
        self.assert_private_values_are_silent(result)

    def test_absent_tailnet_address_defers_without_restart(self):
        self.current_ss.write_text(self.ss_rows(self.LOCAL, self.C2S_PORT))
        self.ip_output.write_text(self.ip_rows(self.LOCAL))
        result = self.run_ensure()
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.prosody_starts.read_text().splitlines(), ["start"])
        self.assertFalse(self.bridge_starts.exists())
        self.assertIn("not present yet", result.stderr)
        self.assert_private_values_are_silent(result)
