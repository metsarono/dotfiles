* Why

Honey (hostname =beelink=) is Gillean's machine and runs her clinical stack. Mètsàtron wants three Telegram Claude bots there that work like the kikin ones: one append-only =claude-warm= session each, compacted in idle windows, so the prompt cache survives between turns. His ruling (2026-09-25, "Option A"): they run as a Unix user other than =gille=, so the clinical boundary is real file permissions (the bot user cannot enter =/home/gille= or read the Secret Vault), and they log in with Gillean's Claude account.

*Revised 2026-09-26 (his ruling): the bots run as =agent-claude=*, the canonical Claude agent user (uid 2002, [[file:agents.org][agents.org]]), mirroring the agent-user pattern rather than his own =metsatron= account. =agent-claude= is provisioned like the other agent users: node from its own Guix profile (=agent-guix-apply=, Guix bootstrapped on Honey by =guix-foreign-bootstrap=, [[file:package-guix.org][package-guix.org]]), =claude= and =bun= in its own =~/.npm-global= (=agent-cli-install=), its own anonymous DotCortex checkout at =~/DotCortex= (the OpenRC services run the launchers from there, since an agent account is not stowed), and a copy of Gillean's Claude credential (his choice, 2026-09-26, over a separate =setup-token=; the known cost is that both copies share one refresh token). The =metsatron= account work below (stow, npm lane, guard bindings) stays for his own account on Honey.

The kikin launchers (=HelmCortex/FORGE/bin/claude-{fable,opus,haiku}=) are bound to HelmCortex paths =metsatron= on Honey does not have, so this module ports their behaviour into the =honey/= host overlay:

On kikin a bot carries its persona in two places: its brain's =CLAUDE.md= (=# CLAUDE.md - <Name>=, =## Identity=, =## Telegram=) and a consort row in =all/.config/agent-session/scope-gazetteer.json=. The gazetteer is sealed and each row carries a partner chosen by ceremony, so this module does *not* add rows; the three rows wait for Mètsàtron. The identity lives in each bot's working-directory =CLAUDE.md= (below).

- =honey/.local/bin/honey-{opus,sonnet,haiku}=: the launchers.
- =honey/.local/share/honey-claude/lib/=: the shared launcher library and the Telegram preflight (a port of kikin's =claude-telegram-preflight.bash=).
- =honey/.local/share/honey-claude/openrc/=: the three OpenRC services, *staged in the overlay*. Stow only links them into =$HOME=; installing them into =/etc/init.d= is a separate, reviewed root step (=install -m 755=), never a symlink into a user's home.
- =honey/.local/share/honey-claude/CLAUDE.{opus,sonnet,haiku}.md=: each bot's identity plus the Honey boundary law, copied into its working directory =~/honey-work/<bot>/CLAUDE.md=.
- =honey/.local/share/honey-claude/lib/preservation.bash=: Gillean's usage guard (below).

The =honey= row in =hosts.ssv= is =active= for =metsatron= only ([[file:layers.org][layers.org]]); Gillean's row stays =planned=. =claude= and =bun= come from metsatron's own npm lane ([[file:package-npm.org][package-npm.org]], "Account lane: metsatron on Honey"). That lane needs Node >= 22, which in this fleet comes from Guix, and Honey has no Guix yet: the proposed route is in [[file:package-host-gates.org][package-host-gates.org]] ("Honey's provisioning lanes"). The account is stowed with =STOW_CONFLICTS=adopt= ([[file:layers.org][layers.org]], "Adopting an existing account"), so its =/etc/skel= defaults and identical files are recorded and linked, and anything else stops the run.

* What differs from kikin

- *Always the Telegram bot.* The launchers keep kikin's =--telegram= switch, so a plain run is an interactive warm session in the same directory, but the services always pass =--telegram=.
- *Gillean's usage guard, same mechanism.* The launchers bind =claude-warm='s preservation guard exactly as kikin's =claude-preservation.bash= does, but the pool is Gillean's account (see "Usage guard" below).
- *Herdr agent names are machine-prefixed and distinct from Honey's existing warm consort.* =/etc/init.d/claude-warm= (as =gille=) already registers as =honey-opus=, so the bots register as =honey-opus-bot=, =honey-sonnet-bot= and =honey-haiku-bot=.
- *A pid file.* Three =claude-warm= supervisors run under one account, so the OpenRC service cannot find "its" supervisor by command line. The launcher writes =$XDG_RUNTIME_DIR/<name>.pid= just before it =exec='s =claude-warm= (same pid), and each service owns its own =XDG_RUNTIME_DIR= (=/run/honey-<bot>=).

* Launcher library

#+BEGIN_SRC bash :tangle honey/.local/share/honey-claude/lib/telegram-preflight.bash
# honey/.local/share/honey-claude/lib/telegram-preflight.bash (generated by agents-bots-honey.org)
# Port of kikin's FORGE/bin/lib/claude-telegram-preflight.bash for Honey.
#
# The official Telegram integration is not a daemon: the plugin's .mcp.json
# starts server.ts through Claude Code's MCP stdio client. This preflight
# validates that inline server and reserves the per-token state directory;
# it never daemonizes server.ts or starts an unrelated Telegram service.
# The token itself never lands in a path, a log or the environment.

honey_telegram_preflight() {
    local wrapper_name="${1:-}"
    local state_dir="${2:-}"
    local settings="${CLAUDE_SETTINGS_FILE:-$HOME/.claude/settings.json}"
    local plugin_cache="$HOME/.claude/plugins/cache/claude-plugins-official/telegram"
    local plugin_root="" candidate plugin_command pid pid_command pid_state_dir
    local runtime_root lock_path token_fingerprint

    if [[ ! "$wrapper_name" =~ ^honey-(opus|sonnet|haiku)$ ]]; then
        printf '%s\n' "honey Telegram launch refused: invalid wrapper identity" >&2
        return 1
    fi
    if [[ ! "$state_dir" =~ ^$HOME/\.claude/channels/[a-z0-9-]+$ ]]; then
        printf '%s\n' "$wrapper_name: Telegram launch refused: invalid channel state path" >&2
        return 1
    fi
    command -v jq >/dev/null 2>&1 || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: jq is required for plugin preflight" >&2
        return 1
    }
    [[ -f "$settings" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: settings are missing at $settings" >&2
        return 1
    }
    jq -e '.enabledPlugins["telegram@claude-plugins-official"] == true' "$settings" >/dev/null 2>&1 || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: Telegram plugin is not enabled in $settings" >&2
        return 1
    }
    [[ -d "$plugin_cache" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: official Telegram plugin cache is missing" >&2
        return 1
    }
    while IFS= read -r candidate; do
        plugin_root="$candidate"
    done < <(find "$plugin_cache" -mindepth 1 -maxdepth 1 -type d -print 2>/dev/null | sort -V)
    [[ -n "$plugin_root" && -f "$plugin_root/.mcp.json" && -f "$plugin_root/server.ts" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: no complete official plugin server was found" >&2
        return 1
    }
    plugin_command="$(jq -r '.mcpServers.telegram.command // empty' "$plugin_root/.mcp.json" 2>/dev/null || true)"
    # Plugin 0.0.6 declares a bare "bun"; on Honey bun lives in metsatron's npm prefix.
    if [[ "$plugin_command" != /* ]]; then
        plugin_command="$(command -v -- "$plugin_command" 2>/dev/null || true)"
    fi
    [[ "$plugin_command" = /* && -x "$plugin_command" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: plugin MCP command is unavailable" >&2
        return 1
    }
    [[ -f "$state_dir/.env" ]] && grep -Eq '^TELEGRAM_BOT_TOKEN=[^[:space:]].*$' "$state_dir/.env" || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: bot token state is missing at $state_dir/.env" >&2
        return 1
    }
    command -v sha256sum >/dev/null 2>&1 || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: sha256sum is required for token locking" >&2
        return 1
    }
    token_fingerprint="$(grep '^TELEGRAM_BOT_TOKEN=' "$state_dir/.env" | sha256sum | awk '{print substr($1,1,16)}')"
    if [[ ! "$token_fingerprint" =~ ^[0-9a-f]{16}$ ]]; then
        printf '%s\n' "$wrapper_name: Telegram launch refused: bot token state could not be fingerprinted" >&2
        return 1
    fi

    # One getUpdates consumer per token: hold a per-token lock across the exec.
    runtime_root="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}/claude-idle-compaction"
    mkdir -p "$runtime_root"
    lock_path="$runtime_root/telegram-token-${token_fingerprint}.launch.lock"
    exec 9>"$lock_path"
    if ! flock -n 9; then
        printf '%s\n' "$wrapper_name: Telegram launch refused: another session owns this bot token" >&2
        return 1
    fi

    # Never kill or replace a live plugin server; a stale pid file is the plugin's to recover.
    if [[ -f "$state_dir/bot.pid" ]]; then
        pid="$(tr -d '[:space:]' < "$state_dir/bot.pid" 2>/dev/null || true)"
        if [[ "$pid" =~ ^[1-9][0-9]*$ && -r "/proc/$pid/cmdline" ]]; then
            pid_command="$(tr '\0' ' ' < "/proc/$pid/cmdline" 2>/dev/null || true)"
            pid_state_dir="$(tr '\0' '\n' < "/proc/$pid/environ" 2>/dev/null \
                | sed -n 's/^TELEGRAM_STATE_DIR=//p' | head -1 || true)"
            if [[ "$pid_state_dir" == "$state_dir" && "$pid_command" == *server.ts* ]]; then
                printf '%s\n' "$wrapper_name: Telegram launch refused: an active inline plugin server already owns $state_dir" >&2
                return 1
            fi
        fi
    fi
    return 0
}
#+END_SRC

#+BEGIN_SRC bash :tangle honey/.local/share/honey-claude/lib/launch.bash
# honey/.local/share/honey-claude/lib/launch.bash (generated by agents-bots-honey.org)
# Shared body of honey-opus / honey-sonnet / honey-haiku.

honey_claude_path_append() {
    local dir
    for dir in "$@"; do
        [[ -d "$dir" ]] || continue
        case ":$PATH:" in *":$dir:"*) ;; *) PATH="${PATH:+$PATH:}$dir" ;; esac
    done
    export PATH
}

# honey_claude_launch <bot> <model> [--telegram] [claude args...]
honey_claude_launch() {
    local bot="$1" model="$2"
    shift 2
    local name="honey-$bot"
    local agent="honey-$bot-bot"
    local state_dir="$HOME/.claude/channels/telegram-$bot"
    local work_dir="${HONEY_CLAUDE_WORK_ROOT:-$HOME/honey-work}/$bot"
    local telegram=0 arg
    local passthrough=()

    for arg in "$@"; do
        case "$arg" in
            --telegram) telegram=1 ;;
            *) passthrough+=("$arg") ;;
        esac
    done

    # The bot user's own npm prefix (claude, bun), agent Guix profile (node), stowed
    # bin, and this checkout's all/.local/bin (claude-warm for an unstowed agent
    # account); appended, never replacing PATH.
    local repo_bin=""
    [[ -n "${LIB_DIR:-}" ]] && repo_bin="$(cd -- "$LIB_DIR/../../../../../all/.local/bin" 2>/dev/null && pwd || true)"
    honey_claude_path_append "$HOME/.local/bin" "${NPM_CONFIG_PREFIX:-$HOME/.npm-global}/bin" \
        "$HOME/.guix-extra-profiles/agent/agent/bin" ${repo_bin:+"$repo_bin"} \
        ${LIB_DIR:+"$LIB_DIR/../bin"}

    [[ -d "$work_dir" ]] || {
        printf '%s\n' "$name: refused: working directory $work_dir is missing (see agents-bots-honey.org)" >&2
        return 1
    }
    [[ -f "$work_dir/CLAUDE.md" ]] || {
        printf '%s\n' "$name: refused: $work_dir/CLAUDE.md (the Honey boundary law) is missing" >&2
        return 1
    }
    cd "$work_dir" || return 1

    if [[ "$telegram" -eq 1 ]]; then
        honey_telegram_preflight "$name" "$state_dir" || return 1
    fi
    # Gillean's usage guard (preservation.bash); inert with a reason if it cannot bind.
    honey_claude_preservation_bindings "$name"
    # The OpenRC service finds this supervisor by pid: exec keeps the pid.
    if [[ -n "${XDG_RUNTIME_DIR:-}" && -d "$XDG_RUNTIME_DIR" ]]; then
        printf '%s\n' "$$" > "$XDG_RUNTIME_DIR/$name.pid"
    fi
    if [[ "$telegram" -eq 1 ]]; then
        # Voice lane (see "Voice lane"): each bot's Kitten seat, the Honey whisper
        # subset for inbound notes, and the hooks in claude-settings.json.
        local voice_var="HONEY_${bot^^}_VOICE" voice
        case "$bot" in opus) voice=Jasper ;; sonnet) voice=Luna ;; haiku) voice=Kiki ;; esac
        export HONEY_VOICE="${!voice_var:-$voice}"
        [[ -n "${LIB_DIR:-}" ]] && export WHISPER_TRANSCRIBE="$LIB_DIR/../bin/honey-whisper-transcribe"
        # acceptEdits (auto) mode: plan mode blocks unattended bot work (as on kikin).
        exec env CLAUDE_WARM_HERDR_AGENT="$agent" TELEGRAM_STATE_DIR="$state_dir" \
            claude-warm --model "$model" --permission-mode acceptEdits \
            --allowedTools=mcp__plugin_telegram_telegram \
            ${LIB_DIR:+--settings="$LIB_DIR/../claude-settings.json"} \
            --channels plugin:telegram@claude-plugins-official "${passthrough[@]+"${passthrough[@]}"}"
    fi
    exec env CLAUDE_WARM_HERDR_AGENT="$agent" \
        claude-warm --model "$model" "${passthrough[@]+"${passthrough[@]}"}"
}

* Usage guard (Gillean's account, kikin-central telemetry)

=claude-warm= carries the fleet's preservation guard: it reserves quota headroom with a central authority before it compacts, so no session burns a pool dry. The authority and its telemetry live on kikin (=HelmCortex/FORGE/scripts/fleet_preservation=, "Kikin is the single shared-pool authority"; it moves to tamamuri later). A caller binds it with the fourteen =CLAUDE_WARM_PRESERVATION_*= variables; if any is missing or invalid the guard stays inert with a reason and the session still runs. kikin's =claude-preservation.bash= binds Mètsàtron's pool; this library binds *Gillean's* pool with the same mechanism:

| Binding             | kikin launchers                           | Honey bots                                                      |
|---------------------+-------------------------------------------+-----------------------------------------------------------------|
| bridge (caller)     | =~/HelmCortex/FORGE/bin/fleet-preservation= | same file from the HelmCortex skills mirror (=helmcortex-skills-mirror.org= carries it) |
| authority host      | =kikin= (=kikin-kushi= on kikin itself)   | =kikin= (override: =CLAUDE_WARM_PRESERVATION_AUTHORITY_HOST=)    |
| authority executable | =/home/metsatron/HelmCortex/FORGE/bin/fleet-preservation= on kikin | same                                            |
| ledger root         | =.../fleet-preservation/claude=            | =.../fleet-preservation/claude-gillean= (one telemetry cache per pool) |
| telemetry sensor    | =t480s= (reads Mètsàtron's account)       | =honey-metsatron= (=ai-usage= as metsatron, logged in as Gillean) |
| account hash        | sha256 of the =~/.claude.json= oauth identity | same rule, on metsatron's =~/.claude.json= (Gillean's login) |
| pool, estimates     | =shared-subscription=, 5 / 1 / 0.5 / 0.5, protection on, nudge off | same                                  |

The hash is computed at launch and never stored; no account id, token or address is in this repo.

*Before the guard can go live (kikin side, Mètsàtron's):* (1) metsatron on Honey needs an SSH key and a =kikin= alias that kikin accepts for =fleet-preservation authority=; (2) kikin needs a =honey-metsatron= alias and key that may run =ai-usage --json --no-remote --providers claude= on Honey; (3) as the fleet-preservation README requires, kikin must return fresh =state=ok= telemetry from that sensor (=fleet-preservation observe --root .../claude-gillean --expected-authority-hostname kikin-kushi --telemetry-host honey-metsatron --provider claude --account-hash <hash> --model-pool shared-subscription=), and a disposable owner-poll canary must prove the installed generation. Until then the bindings are exported but every poll fails closed (no reservation, no compaction directive) and the bots still answer.

# honey/.local/share/honey-claude/lib/preservation.bash (generated by agents-bots-honey.org)
# Gillean's usage guard: kikin's claude-preservation.bash bindings, pointed at her pool.

honey_claude_preservation_bindings() {
    local name="${1:-honey-claude}"
    local account_file="${CLAUDE_WARM_PRESERVATION_ACCOUNT_FILE:-$HOME/.claude.json}"
    local mirror="${HONEY_HELMCORTEX_MIRROR:-$HOME/.local/share/helmcortex/skills-mirror}"
    local account_identity account_digest

    if [[ -n "${CLAUDE_WARM_PRESERVATION_ACCOUNT_HASH:-}" ]]; then
        account_digest="$CLAUDE_WARM_PRESERVATION_ACCOUNT_HASH"
    else
        if ! command -v jq >/dev/null 2>&1 || ! command -v sha256sum >/dev/null 2>&1; then
            printf '%s\n' "$name: usage guard inert: jq and sha256sum are required" >&2
            return 0
        fi
        account_identity="$({ jq -er \
            '.oauthAccount.organizationUuid // .oauthAccount.accountUuid // .oauthAccount.userID // empty' \
            "$account_file" 2>/dev/null || true; } | tr -d '\n')"
        if [[ -z "$account_identity" ]]; then
            printf '%s\n' "$name: usage guard inert: no Claude account identity in $account_file (run claude /login)" >&2
            return 0
        fi
        account_digest="sha256:$(printf '%s' "$account_identity" | sha256sum | awk '{print $1}')"
        unset account_identity
    fi

    export CLAUDE_WARM_PRESERVATION_BRIDGE="${CLAUDE_WARM_PRESERVATION_BRIDGE:-$mirror/FORGE/bin/fleet-preservation}"
    export CLAUDE_WARM_PRESERVATION_BRIDGE_ADAPTER="${CLAUDE_WARM_PRESERVATION_BRIDGE_ADAPTER:-federated_preservation.SshAuthorityTransport}"
    export CLAUDE_WARM_PRESERVATION_AUTHORITY_HOST="${CLAUDE_WARM_PRESERVATION_AUTHORITY_HOST:-kikin}"
    export CLAUDE_WARM_PRESERVATION_AUTHORITY_IDENTITY="${CLAUDE_WARM_PRESERVATION_AUTHORITY_IDENTITY:-kikin-kushi}"
    export CLAUDE_WARM_PRESERVATION_AUTHORITY_EXECUTABLE="${CLAUDE_WARM_PRESERVATION_AUTHORITY_EXECUTABLE:-/home/metsatron/HelmCortex/FORGE/bin/fleet-preservation}"
    export CLAUDE_WARM_PRESERVATION_LEDGER_ROOT="${CLAUDE_WARM_PRESERVATION_LEDGER_ROOT:-/home/metsatron/.local/state/fleet-preservation/claude-gillean}"
    export CLAUDE_WARM_PRESERVATION_TELEMETRY_SOURCE="${CLAUDE_WARM_PRESERVATION_TELEMETRY_SOURCE:-authority:${CLAUDE_WARM_PRESERVATION_AUTHORITY_HOST}}"
    export CLAUDE_WARM_PRESERVATION_TELEMETRY_HOST="${CLAUDE_WARM_PRESERVATION_TELEMETRY_HOST:-honey-metsatron}"
    export CLAUDE_WARM_PRESERVATION_TRANSPORT="${CLAUDE_WARM_PRESERVATION_TRANSPORT:-ssh}"
    export CLAUDE_WARM_PRESERVATION_PROVIDER="${CLAUDE_WARM_PRESERVATION_PROVIDER:-claude}"
    export CLAUDE_WARM_PRESERVATION_ACCOUNT_HASH="$account_digest"
    export CLAUDE_WARM_PRESERVATION_MODEL_POOL="${CLAUDE_WARM_PRESERVATION_MODEL_POOL:-shared-subscription}"
    # Same calibration as kikin: 5 percent per 500k input tokens.
    export CLAUDE_WARM_PRESERVATION_ESTIMATE_PERCENT="${CLAUDE_WARM_PRESERVATION_ESTIMATE_PERCENT:-5}"
    export CLAUDE_WARM_PRESERVATION_ESTIMATE_UNCERTAINTY_PERCENT="${CLAUDE_WARM_PRESERVATION_ESTIMATE_UNCERTAINTY_PERCENT:-1}"
    export CLAUDE_WARM_PRESERVATION_IN_FLIGHT_RESERVE_PERCENT="${CLAUDE_WARM_PRESERVATION_IN_FLIGHT_RESERVE_PERCENT:-0.5}"
    export CLAUDE_WARM_PRESERVATION_CONTROL_RESERVE_PERCENT="${CLAUDE_WARM_PRESERVATION_CONTROL_RESERVE_PERCENT:-0.5}"
    export CLAUDE_WARM_PRESERVATION_PROTECTION_ENABLED="${CLAUDE_WARM_PRESERVATION_PROTECTION_ENABLED:-1}"
    export CLAUDE_WARM_PRESERVATION_NUDGE_ENABLED="${CLAUDE_WARM_PRESERVATION_NUDGE_ENABLED:-0}"
}

* Voice lane

Mètsàtron's ask (2026-09-26): the tanuki bots hear his voice notes and answer with voice notes too, in the Kitten seats pvox gives their kikin counterparts: Bunta Jasper (the Opus seat), Sasuke Luna (Fable's), Shoukichi Kiki (Haiku's), each at speed 1.2 on =kitten-tts-nano-0.8-int8=. """PostToolUse hook (Telegram reply tool): send the reply back as a voice note.

Renders the reply text with Kitten TTS in this bot's voice, encodes Opus with
ffmpeg, and posts it to the same chat with the Bot API's sendVoice, so every
answer also arrives as a playable file. The hook detaches at once and never
blocks or fails the reply; problems go to ~/.cache/honey-voice-reply.log
(never the text). The token is read from $TELEGRAM_STATE_DIR/.env and never
appears in argv or the log.
"""
import json
import os
import subprocess
import sys
import tempfile
import time
import urllib.request
import uuid

LOG = os.path.expanduser("~/.cache/honey-voice-reply.log")
KITTEN_PY = os.path.expanduser("~/kitten-venv/bin/python")
MODEL = os.environ.get("HONEY_VOICE_MODEL", "KittenML/kitten-tts-nano-0.8-int8")
VOICE = os.environ.get("HONEY_VOICE", "")
SPEED = os.environ.get("HONEY_VOICE_SPEED", "1.2")
MAX_CHARS = int(os.environ.get("HONEY_VOICE_MAX_CHARS", "0") or 0)  # 0 = speak the whole reply (2026-10-07)
SYNTH = r"""
import sys
import numpy as np
from kittentts import KittenTTS
model_id, voice, speed, out = sys.argv[1], sys.argv[2], float(sys.argv[3]), sys.argv[4]
audio = KittenTTS(model_id).generate(sys.stdin.read(), voice=voice, speed=speed)
open(out, "wb").write((np.clip(audio, -1.0, 1.0) * 32767).astype("<i2").tobytes())
"""


def log(msg):
    try:
        os.makedirs(os.path.dirname(LOG), exist_ok=True)
        with open(LOG, "a") as f:
            f.write("%s %s\n" % (time.strftime("%F %T"), msg))
    except OSError:
        pass


def token():
    state = os.environ.get("TELEGRAM_STATE_DIR") or os.path.expanduser("~/.claude/channels/telegram")
    try:
        for line in open(os.path.join(state, ".env")):
            if line.startswith("TELEGRAM_BOT_TOKEN="):
                return line.split("=", 1)[1].strip().strip('"')
    except OSError:
        return None
    return None


def send_voice(tok, chat_id, ogg, reply_to):
    boundary = uuid.uuid4().hex
    parts = []
    fields = {"chat_id": str(chat_id)}
    if reply_to:
        fields["reply_to_message_id"] = str(reply_to)
    for k, v in fields.items():
        parts.append(('--%s\r\nContent-Disposition: form-data; name="%s"\r\n\r\n%s\r\n' % (boundary, k, v)).encode())
    parts.append(('--%s\r\nContent-Disposition: form-data; name="voice"; filename="reply.ogg"\r\n'
                  'Content-Type: audio/ogg\r\n\r\n' % boundary).encode())
    parts.append(open(ogg, "rb").read())
    parts.append(("\r\n--%s--\r\n" % boundary).encode())
    req = urllib.request.Request(
        "https://api.telegram.org/bot%s/sendVoice" % tok, data=b"".join(parts),
        headers={"Content-Type": "multipart/form-data; boundary=%s" % boundary})
    return json.load(urllib.request.urlopen(req, timeout=60)).get("ok")


def render_and_send(text, chat_id, reply_to):
    tok = token()
    if not tok:
        log("SKIP no-token")
        return
    with tempfile.TemporaryDirectory(prefix="honey-voice-") as tmp:
        pcm, ogg = os.path.join(tmp, "reply.pcm"), os.path.join(tmp, "reply.ogg")
        t0 = time.time()
        r = subprocess.run([KITTEN_PY, "-c", SYNTH, MODEL, VOICE, SPEED, pcm],
                           input=text.encode(), capture_output=True, timeout=600)
        if r.returncode != 0:
            log("FAIL synth rc=%d %s" % (r.returncode, r.stderr.decode(errors="replace").strip().splitlines()[-1:]))
            return
        r = subprocess.run(["ffmpeg", "-v", "error", "-y", "-f", "s16le", "-ar", "24000", "-ac", "1",
                            "-i", pcm, "-c:a", "libopus", "-b:a", "32k", ogg], capture_output=True, timeout=120)
        if r.returncode != 0:
            log("FAIL ffmpeg rc=%d" % r.returncode)
            return
        try:
            ok = send_voice(tok, chat_id, ogg, reply_to)
        except Exception as e:
            log("FAIL send %s" % e.__class__.__name__)
            return
        log("OK voice=%s chars=%d secs=%.1f sent=%s" % (VOICE, len(text), time.time() - t0, ok))


def main():
    if os.environ.get("HONEY_VOICE_OFF") or not VOICE or not os.path.exists(KITTEN_PY):
        return
    try:
        data = json.loads(sys.stdin.read() or "{}")
    except ValueError:
        return
    ti = data.get("tool_input") or {}
    text, chat_id = (ti.get("text") or "").strip(), ti.get("chat_id")
    if not text or not chat_id:
        return
    if MAX_CHARS and len(text) > MAX_CHARS:
        text = text[:MAX_CHARS]
    # Detach: the reply has already gone out; the voice note follows it.
    if os.fork() > 0:
        return
    os.setsid()
    if os.fork() > 0:
        os._exit(0)
    devnull = os.open(os.devnull, os.O_RDWR)
    for fd in (0, 1, 2):
        os.dup2(devnull, fd)
    try:
        render_and_send(text, chat_id, ti.get("reply_to"))
    finally:
        os._exit(0)


if __name__ == "__main__":
    main()
#+END_SRC

"""The Honey subset of HelmCortex's whisper-transcribe, for hosts without HelmCortex.

Same call shape as the canonical FORGE/bin/whisper-transcribe that
claude-hook-voice-transcribe runs (--model TIER --out PATH AUDIO), so the hook
reaches it through $WHISPER_TRANSCRIBE. It keeps the canonical model source,
cache path and pinned SHA-256, the ffmpeg 16 kHz decode and the whisper-cli
call with its CPU retry; it leaves out the resident daemon, loop detection and
tier escalation. Output: a transcript file with the same YAML front matter.
"""
import argparse
import hashlib
import os
import shutil
import subprocess
import sys
import tempfile
import urllib.request
from datetime import datetime, timezone
from pathlib import Path

MODEL_CACHE_DIR = Path.home() / ".cache" / "whisper-cpp" / "models"
MODEL_BASE_URL = "https://huggingface.co/ggerganov/whisper.cpp/resolve/main"
# Pins copied from the canonical whisper-transcribe (verified 2026-07-03).
MODEL_SHA256 = {"small": "1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b"}
MODEL_FILENAMES = {"small": "ggml-small.bin"}


def model_path(tier):
    name = MODEL_FILENAMES[tier]
    path = MODEL_CACHE_DIR / name
    if path.exists():
        return path
    MODEL_CACHE_DIR.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(".part")
    urllib.request.urlretrieve("%s/%s" % (MODEL_BASE_URL, name), tmp)
    digest = hashlib.sha256(tmp.read_bytes()).hexdigest()
    if digest != MODEL_SHA256[tier]:
        tmp.unlink()
        sys.exit("model %s failed its SHA-256 pin (got %s)" % (name, digest))
    tmp.rename(path)
    return path


def main():
    ap = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    ap.add_argument("audio")
    ap.add_argument("--model", default="small", choices=sorted(MODEL_FILENAMES))
    ap.add_argument("--out", required=True)
    ap.add_argument("--timeout", type=float, default=470)
    args = ap.parse_args()
    cli = shutil.which("whisper-cli")
    if cli is None or shutil.which("ffmpeg") is None:
        sys.exit("whisper-cli or ffmpeg missing (agent Guix profile / system ffmpeg)")
    model = model_path(args.model)
    with tempfile.TemporaryDirectory(prefix="honey-whisper-") as tmp:
        wav = Path(tmp) / "in.wav"
        subprocess.run(["ffmpeg", "-v", "error", "-y", "-i", args.audio, "-ar", "16000", "-ac", "1",
                        "-c:a", "pcm_s16le", str(wav)], check=True, timeout=120)
        stem = Path(tmp) / "out"
        cmd = [cli, "-m", str(model), "-f", str(wav), "-otxt", "-of", str(stem), "-nt"]
        try:
            subprocess.run(cmd, check=True, timeout=args.timeout, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        except subprocess.CalledProcessError as err:
            if err.returncode >= 0:
                raise
            subprocess.run(cmd + ["-ng"], check=True, timeout=args.timeout,
                           stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        text = (stem.with_suffix(".txt")).read_text().strip()
    front = "---\nsource: %s\nmodel: %s\ngenerated_at: %s\n---\n" % (
        os.path.basename(args.audio), args.model, datetime.now(timezone.utc).isoformat(timespec="seconds"))
    Path(args.out).write_text(front + text + "\n")


if __name__ == "__main__":
    main()

#!/sbin/openrc-run
# Honey Telegram Claude bot (generated by agents-bots-honey.org; source of truth: DotCortex).
# Runs honey-<bot> --telegram inside its own detached tmux session as agent-claude.
# Observe: su -l agent-claude -c 'tmux attach -t honey-<bot>' (Ctrl-b d detaches).
# Control: XDG_RUNTIME_DIR=/run/honey-<bot> claude-warmctl list (as agent-claude).

bot="${RC_SVCNAME#honey-}"
name="${RC_SVCNAME}"
# The bots run as agent-claude (ruling 2026-09-26); /etc/conf.d/honey-<bot> may override.
: "${bot_user:=agent-claude}"
description="Honey ${bot} Telegram Claude bot (claude-warm as ${bot_user})"

bot_home="$(getent passwd "${bot_user}" | cut -d: -f6)"
bot_session="${RC_SVCNAME}"
bot_cwd="${bot_home}/honey-work/${bot}"
# An agent account is not stowed: run the launcher from its own DotCortex checkout.
bot_launcher="${bot_home}/DotCortex/honey/.local/bin/${RC_SVCNAME}"
bot_log="/var/log/${RC_SVCNAME}.log"
xdg="/run/${RC_SVCNAME}"
bot_pidfile="${xdg}/${RC_SVCNAME}.pid"
bot_path_add="${bot_home}/.local/bin:${bot_home}/.npm-global/bin:${bot_home}/.guix-extra-profiles/agent/agent/bin"

depend() {
    use net dns
    after net elogind dbus
}

start_pre() {
    case "${bot}" in
        opus|sonnet|haiku) ;;
        *) eerror "unknown Honey bot service name: ${RC_SVCNAME}"; return 1 ;;
    esac
    checkpath -d -m 0700 -o "${bot_user}:${bot_user}" "${xdg}"
    checkpath -f -m 0640 -o "${bot_user}:${bot_user}" "${bot_log}"
}

bot_pid() {
    local pid
    [ -r "${bot_pidfile}" ] || return 1
    pid="$(tr -dc '0-9' < "${bot_pidfile}")"
    [ -n "${pid}" ] || return 1
    [ "$(stat -c %U "/proc/${pid}" 2>/dev/null)" = "${bot_user}" ] || return 1
    tr '\0' ' ' < "/proc/${pid}/cmdline" 2>/dev/null | grep -q 'claude-warm' || return 1
    echo "${pid}"
}

start() {
    ebegin "Starting ${description} (tmux: ${bot_session})"
    su -l "${bot_user}" -c "export XDG_RUNTIME_DIR='${xdg}' PATH=\"\${PATH}:${bot_path_add}\"; \
        tmux new-session -d -s '${bot_session}' -c '${bot_cwd}' \
        -e XDG_RUNTIME_DIR='${xdg}' -e PATH=\"\${PATH}\" \
        'exec ${bot_launcher} --telegram' \
        && tmux pipe-pane -o -t '${bot_session}' 'cat >> ${bot_log}'"
    eend $? "Failed to start ${RC_SVCNAME}"
}

stop() {
    local pid i=0
    ebegin "Stopping ${description}"
    pid="$(bot_pid)"
    if [ -n "${pid}" ]; then
        kill -TERM "${pid}" 2>/dev/null
        while kill -0 "${pid}" 2>/dev/null && [ $i -lt 10 ]; do
            sleep 1; i=$((i+1))
        done
        kill -0 "${pid}" 2>/dev/null && kill -KILL "${pid}" 2>/dev/null
    fi
    rm -f "${bot_pidfile}"
    su -l "${bot_user}" -c "tmux kill-session -t '${bot_session}'" 2>/dev/null
    eend 0
}

status() {
    if bot_pid >/dev/null; then
        einfo "${RC_SVCNAME} supervisor is running (pid $(bot_pid))"
        return 0
    fi
    einfo "${RC_SVCNAME} is not running"
    return 3
}

BOTS = {"opus": "claude-opus-5-5", "sonnet": "claude-sonnet-4-6", "haiku": "claude-haiku-4-5-20251001"}
PERSONAS = {"opus": "Bunta", "sonnet": "Sasuke", "haiku": "Shoukichi"}


class Home:
    def __init__(self, plugin_enabled=True, boundary=True, account=True):
        self.tmp = tempfile.TemporaryDirectory()
        self.home = Path(self.tmp.name) / "home"
        self.bin = Path(self.tmp.name) / "bin"
        self.xdg = Path(self.tmp.name) / "run"
        self.record = Path(self.tmp.name) / "record.json"
        for path in (self.home, self.bin, self.xdg):
            path.mkdir()
        (self.home / ".claude").mkdir()
        if account:
            (self.home / ".claude.json").write_text(json.dumps({"oauthAccount": {"accountUuid": "test-account"}}))
        (self.home / ".claude/settings.json").write_text(
            json.dumps({"enabledPlugins": {"telegram@claude-plugins-official": plugin_enabled}}))
        plugin = self.home / ".claude/plugins/cache/claude-plugins-official/telegram/0.0.6"
        plugin.mkdir(parents=True)
        (plugin / ".mcp.json").write_text(json.dumps({"mcpServers": {"telegram": {"command": "bun"}}}))
        (plugin / "server.ts").write_text("")
        npm_bin = self.home / ".npm-global/bin"
        npm_bin.mkdir(parents=True)
        self.script(npm_bin / "bun", "exit 0\n")
        self.script(self.bin / "claude-warm", (
            "import json, os, sys\n"
            f"json.dump({{'argv': sys.argv[1:], 'cwd': os.getcwd(), 'pid': os.getpid(),"
            " 'agent': os.environ.get('CLAUDE_WARM_HERDR_AGENT'),"
            " 'state': os.environ.get('TELEGRAM_STATE_DIR'), 'path': os.environ['PATH'],"
            " 'guard': {k: v for k, v in os.environ.items() if k.startswith('CLAUDE_WARM_PRESERVATION_')}},"
            f" open({str(self.record)!r}, 'w'))\n"), shebang="#!/usr/bin/env python3\n")
        for bot in BOTS:
            state = self.home / f".claude/channels/telegram-{bot}"
            state.mkdir(parents=True)
            (state / ".env").write_text("TELEGRAM_BOT_TOKEN=dummy-test-value\n")
            work = self.home / "honey-work" / bot
            work.mkdir(parents=True)
            if boundary:
                (work / "CLAUDE.md").write_text((SHARE / f"CLAUDE.{bot}.md").read_text())

    @staticmethod
    def script(path, body, shebang="#!/bin/sh\n"):
        path.write_text(shebang + body)
        path.chmod(0o755)

    def run(self, bot, *args):
        env = {"HOME": str(self.home), "PATH": f"{self.bin}:/usr/bin:/bin",
               "XDG_RUNTIME_DIR": str(self.xdg)}
        return subprocess.run([str(BIN / f"honey-{bot}"), *args], capture_output=True,
                              text=True, env=env)

    def recorded(self):
        return json.loads(self.record.read_text())

    def close(self):
        self.tmp.cleanup()


class LauncherTests(unittest.TestCase):
    def test_each_bot_launches_its_telegram_warm_session(self):
        box = Home()
        try:
            agents = set()
            for bot, model in BOTS.items():
                result = box.run(bot, "--telegram")
                self.assertEqual(result.returncode, 0, result.stderr)
                rec = box.recorded()
                self.assertEqual(rec["argv"], ["--model", model, "--permission-mode", "acceptEdits",
                                               "--allowedTools=mcp__plugin_telegram_telegram",
                                               "--settings=" + str(SHARE / "lib") + "/../claude-settings.json",
                                               "--channels", "plugin:telegram@claude-plugins-official"])
                self.assertEqual(rec["cwd"], str(box.home / "honey-work" / bot))
                self.assertEqual(rec["state"], str(box.home / f".claude/channels/telegram-{bot}"))
                self.assertEqual(rec["agent"], f"honey-{bot}-bot")
                self.assertIn(str(box.home / ".npm-global/bin"), rec["path"].split(":"))
                self.assertTrue(rec["path"].startswith(str(box.bin)), "PATH must be appended to")
                pidfile = box.xdg / f"honey-{bot}.pid"
                self.assertEqual(pidfile.read_text().strip(), str(rec["pid"]))
                agents.add(rec["agent"])
            self.assertNotIn("honey-opus", agents, "collides with Honey's existing warm consort")
        finally:
            box.close()

    def test_gillean_usage_guard_is_bound(self):
        import hashlib
        box = Home()
        try:
            result = box.run("sonnet", "--telegram")
            self.assertEqual(result.returncode, 0, result.stderr)
            guard = box.recorded()["guard"]
            self.assertEqual(len(guard), 18, sorted(guard))
            digest = "sha256:" + hashlib.sha256(b"test-account").hexdigest()
            self.assertEqual(guard["CLAUDE_WARM_PRESERVATION_ACCOUNT_HASH"], digest)
            self.assertEqual(guard["CLAUDE_WARM_PRESERVATION_AUTHORITY_IDENTITY"], "kikin-kushi")
            self.assertEqual(guard["CLAUDE_WARM_PRESERVATION_TELEMETRY_HOST"], "honey-metsatron")
            self.assertTrue(guard["CLAUDE_WARM_PRESERVATION_LEDGER_ROOT"].endswith("/claude-gillean"))
            self.assertTrue(guard["CLAUDE_WARM_PRESERVATION_BRIDGE"].endswith(
                "/skills-mirror/FORGE/bin/fleet-preservation"))
            self.assertNotIn("test-account", json.dumps(guard))
        finally:
            box.close()

    def test_guard_is_inert_but_bot_runs_before_login(self):
        box = Home(account=False)
        try:
            result = box.run("haiku", "--telegram")
            self.assertEqual(result.returncode, 0, result.stderr)
            self.assertIn("usage guard inert", result.stderr)
            self.assertEqual(box.recorded()["guard"], {})
        finally:
            box.close()

    def test_personas_in_identity_files(self):
        for bot, name in PERSONAS.items():
            text = (SHARE / f"CLAUDE.{bot}.md").read_text()
            self.assertTrue(text.startswith(f"# CLAUDE.md - {name} (honey-{bot}, @honey_{bot}_bot, {BOTS[bot]})"))
            self.assertIn("## Identity", text)
            self.assertIn("# Honey boundary law", text)
            self.assertIn(name, (BIN / f"honey-{bot}").read_text())

    def test_plain_run_has_no_channel(self):
        box = Home()
        try:
            result = box.run("haiku")
            self.assertEqual(result.returncode, 0, result.stderr)
            self.assertEqual(box.recorded()["argv"], ["--model", BOTS["haiku"]])
        finally:
            box.close()

    def test_model_override(self):
        box = Home()
        try:
            env_run = subprocess.run([str(BIN / "honey-sonnet")], capture_output=True, text=True,
                                     env={"HOME": str(box.home), "PATH": f"{box.bin}:/usr/bin:/bin",
                                          "HONEY_SONNET_MODEL": "claude-sonnet-x"})
            self.assertEqual(env_run.returncode, 0, env_run.stderr)
            self.assertEqual(box.recorded()["argv"], ["--model", "claude-sonnet-x"])
        finally:
            box.close()

    def test_refuses_without_boundary_law(self):
        box = Home(boundary=False)
        try:
            result = box.run("opus", "--telegram")
            self.assertNotEqual(result.returncode, 0)
            self.assertIn("boundary law", result.stderr)
            self.assertFalse(box.record.exists())
        finally:
            box.close()

    def test_refuses_without_enabled_plugin(self):
        box = Home(plugin_enabled=False)
        try:
            result = box.run("opus", "--telegram")
            self.assertNotEqual(result.returncode, 0)
            self.assertIn("not enabled", result.stderr)
            self.assertNotIn("dummy-test-value", result.stdout + result.stderr)
            self.assertFalse(box.record.exists())
        finally:
            box.close()


class ServiceTests(unittest.TestCase):
    def scripts(self):
        return {bot: (OPENRC / f"honey-{bot}").read_text() for bot in BOTS}

    def test_three_identical_scripts(self):
        texts = set(self.scripts().values())
        self.assertEqual(len(texts), 1)

    def test_script_rules(self):
        text = next(iter(self.scripts().values()))
        self.assertTrue(text.startswith("#!/sbin/openrc-run\n"))
        self.assertNotRegex(text, r"\bneed\s+net\b")
        self.assertIn("use net dns", text)
        self.assertNotRegex(text, r"(^|[\s;'\"])PATH=['\"]?/", "PATH must only be appended to")
        self.assertIn('PATH=\\"\\${PATH}:', text)
        self.assertIn(': "${bot_user:=agent-claude}"', text)
        self.assertIn("/DotCortex/honey/.local/bin/", text)
        self.assertNotIn("/home/gille", text)
        result = subprocess.run(["sh", "-n", str(OPENRC / "honey-opus")], capture_output=True, text=True)
        self.assertEqual(result.returncode, 0, result.stderr)

    def test_boundary_law_names_the_vault_and_no_addresses(self):
        text = "".join((SHARE / f"CLAUDE.{bot}.md").read_text() for bot in BOTS)
        self.assertIn("Secret Vault", text)
        self.assertIsNone(re.search(r"\b\d{1,3}(\.\d{1,3}){3}\b", text))


if __name__ == "__main__":
