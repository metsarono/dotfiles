#+TITLE: Universal PTY hold-with-timeout: the approval gate through the PTY owner
#+PROPERTY: header-args :mkdirp yes :comments no

The Admiral's design and word (Telegram 6257-6259, 2026-10-12): the
hold-with-timeout must run through the PTY owner, universal across
harnesses — no vendor-plugin patch, no second bot. This file is the
canonical source for =approval_hold_pty.py= and its tests.

* How it works

- PRESENT (fresh presence stamp): the gate returns the native ask
  exactly as today. The harness's own relay shows it. Nothing in any
  plugin changes.
- TIMEOUT THROUGH THE PTY OWNER: the process owning the session's PTY
  (claude-warm for Claude seats) records a permission prompt with a
  screen identity (full visible request hash plus marker position). If the SAME prompt
  is still on screen after =unattended.hold_timeout_minutes=
  (default 10), it answers NO through the PTY, writes the request into
  the smart queue (same file and API as approval-queue, reason
  =hold_timeout=, deduped by the queue's own upsert) and stamps the
  ledger.
- AWAY: unchanged; the gate defers to the queue at once.

* Hard rules (test-enforced)

- Deny-ONLY, structurally: a profile whose deny sequence contains
  Enter, newline, y or Y is rejected at construction. The holder can
  never confirm anything.
- Only to the EXACT prompt it timed: identity re-checked under the
  owner lock, with the child barrier-paused, the screen drained and
  re-classified immediately before the write. Any change (new prompt,
  user typing, prompt gone, compaction, recovery) aborts without
  writing. The Admiral answering first makes the prompt disappear; the
  timer then does nothing.
- A test proves it can never write to a newer prompt or into typed
  input (test-approval-pty-hold.py).

* Profiles are data, not forks

A harness plugs in by adding a =HoldProfile=: prompt markers, an
identity function, and deny keys. Claude Code is the first profile
(~claude-code~, deny key: ESC — the dialog's own "esc to cancel" cue
the screen classifier already trusts). =fixture-dialog= proves the
interface is not Claude-specific.

- Herdr panes: a profile over the Herdr screen protocol.
- The Emacs integration: a profile over the Emacs process's PTY
  classification (the compaction supervisor already reads it).
- Codex/OpenCode TUIs: a profile over their idle-supervisor
  classifiers (agents-codex-idle-supervisor.org,
  agents-opencode-idle-supervisor.org carry the same screen feed
  shape claude-warm exposes: =_visible_text()=).

#!/usr/bin/env python3
"""Deny a timed permission prompt through its PTY owner, then record it.

Profiles carry harness-specific recognition and a single cancellation key.
The owner supplies the shared lock, acknowledged process-tree barrier,
bounded screen drain, pending-input check and attributed screen classifier.
"""
from __future__ import annotations

from collections import namedtuple
import hashlib
import math
import os
import re


def _deny_keys(keys):
    # One cancellation key only: a second key could reach a dismissed dialog's
    # successor. Arbitrary printable bytes and terminal sequences are refused.
    if not isinstance(keys, (tuple, list)) or len(keys) != 1:
        raise ValueError("profile requires one deny key")
    if not isinstance(keys[0], bytes) or keys[0] not in (b"\x1b", b"n"):
        raise ValueError("profile deny key must be ESC or n")
    return tuple(keys)


class HoldProfile(namedtuple("ProfileData", "name prompt_markers deny_keys marker_flags required_markers")):
    """Immutable harness profile; construction and every write validate keys."""
    __slots__ = ()

    def __new__(cls, name, prompt_markers, deny_keys, marker_flags=re.IGNORECASE,
                required_markers=()):
        if not isinstance(name, str) or not name:
            raise ValueError("profile name")
        def markers(values, required=False):
            if (not isinstance(values, (list, tuple)) or required and not values
                    or any(not isinstance(value, str) or not value for value in values)):
                raise ValueError("profile prompt markers")
            return tuple(value.lower() for value in values)
        return super().__new__(cls, name, markers(prompt_markers, True),
                               _deny_keys(deny_keys), marker_flags, markers(required_markers))

    def matches(self, visible):
        if not isinstance(visible, str) or not visible:
            return False
        lowered = visible.lower()
        return (any(marker in lowered for marker in self.prompt_markers)
                and all(marker in lowered for marker in self.required_markers))

    def identity(self, visible):
        """Bind all visible request text and marker position, including context
        above a generic confirmation question and choices below it."""
        if not self.matches(visible):
            return None
        lowered = visible.lower()
        position = min(lowered.index(marker) for marker in self.prompt_markers if marker in lowered)
        digest = hashlib.sha256(visible.encode("utf-8", "replace")).hexdigest()
        return f"{digest}@{position}"


CLAUDE_CODE_PROFILE = HoldProfile(
    "claude-code", ("do you want to proceed?", "would you like to proceed?", "allow command?"),
    (b"\x1b",), required_markers=("esc to cancel",))
FIXTURE_PROFILE = HoldProfile("fixture-dialog", ("fixture dialog:",), (b"n",))
PROFILES = {profile.name: profile for profile in (CLAUDE_CODE_PROFILE, FIXTURE_PROFILE)}


def deny_bytes(profile):
    return b"".join(_deny_keys(profile.deny_keys))


def hold_timeout_seconds(unattended_section, default_minutes=10):
    raw = unattended_section.get("hold_timeout_minutes", default_minutes) if isinstance(unattended_section, dict) else default_minutes
    if isinstance(raw, bool) or not isinstance(raw, (int, float)) or not math.isfinite(raw) or raw <= 0:
        raw = default_minutes
    return float(raw) * 60


class PtyHoldTimer:
    """Time one exact screen; changed or absent prompts reset the deadline."""
    def __init__(self, timeout):
        if isinstance(timeout, bool) or not isinstance(timeout, (int, float)) or not math.isfinite(timeout) or timeout <= 0:
            raise ValueError("hold timeout")
        self.timeout = float(timeout)
        self.clear()

    def record(self, visible, profile, now):
        identity = profile.identity(visible)
        if identity is None:
            self.clear()
            return False
        if identity == self._identity:
            return False
        self._identity = identity
        self._first_seen = float(now)
        return True

    def expired(self, now):
        return (self._identity is not None and self._first_seen is not None
                and float(now) >= self._first_seen + self.timeout)

    def identity(self):
        return self._identity

    def clear(self):
        self._identity = None
        self._first_seen = None


def _owner_busy(owner):
    return bool(getattr(owner, "compacting", False)
                or getattr(owner, "recovery_pending", False)
                or getattr(owner, "recovery_awaiting", False)
                or getattr(owner, "mailcortex_input_dirty", True)
                or getattr(owner, "status", None) not in {"active", "idle"})


def deny_expired_prompt(owner, timer, profile, read_screen, now, queue_write):
    """One bounded deny write, only after all owner guards succeed.

    Missing guards, acquisition failures, pending input/output, changed screens
    and write errors abort. No spinning or replay of a failed write. The queue
    callback runs after the barrier releases, with the identity already cleared.
    """
    expected = timer.identity()
    lock = getattr(owner, "mailcortex_admission_lock", None)
    if lock is None or expected is None or not timer.expired(now()):
        return False
    with lock:
        if timer.identity() != expected or not timer.expired(now()):
            return False
        written = False
        try:
            pending = getattr(owner, "_hold_input_pending", None)
            barrier = getattr(owner, "_mailcortex_barrier", None)
            drain = getattr(owner, "_mailcortex_refresh_screen", None)
            if not all(callable(guard) for guard in (pending, barrier, drain)):
                timer.clear()
                return False
            if _owner_busy(owner) or pending():
                timer.clear()
                return False
            with barrier():
                if drain() or _owner_busy(owner) or pending():
                    timer.clear()
                    return False
                visible = read_screen()
                if profile.identity(visible) != expected:
                    timer.record(visible, profile, now())
                    return False
                # No callback or state-file I/O between the final drain/input
                # check and the single write. The acknowledged tree is paused.
                data = deny_bytes(profile)
                fd = owner.master_fd
                if os.get_blocking(fd):
                    raise ValueError("PTY deny requires a nonblocking owner descriptor")
                if drain() or _owner_busy(owner) or pending():
                    timer.clear()
                    return False
                if os.write(fd, data) != len(data):
                    raise OSError("partial PTY deny write")
                written = True
                timer.clear()
        except (OSError, ValueError, AttributeError, RuntimeError, TypeError):
            timer.clear()
            if not written:
                return False
            # A failed resume acknowledgement does not erase an already
            # completed deny. Preserve its request once and report the fault.
            logger = getattr(owner, "_guard_log", None)
            if callable(logger):
                logger("pty-hold-resume-failed")
        try:
            queue_write(expected)
        except Exception:
            # The deny landed. Never repeat it because recording failed.
            logger = getattr(owner, "_guard_log", None)
            if callable(logger):
                logger("pty-hold-queue-failed")
        return True

    def deny_owner(self, visible, pid=None):
        """A fake PTY owner carrying the wake-seam contract, with a REAL child
        reader on the PTY: it reads the deny bytes from its stdin and writes
        them to its stdout, so the master read returns exactly what the
        holder wrote (the proof the write landed)."""
        import contextlib
        import pty
        import threading
        master, slave = pty.openpty()
        os.set_blocking(master, False)
        # raw-mode slave: no ECHO (ECHOCTL renders ESC as '^['), no ICANON
        # (a lone ESC is not a line; canonical mode would block the child's
        # read forever). The master then sees ONLY the reader child's
        # stdout: exactly the bytes the holder wrote.
        import termios
        attrs = termios.tcgetattr(slave)
        attrs[3] &= ~(termios.ECHO | termios.ECHOCTL | termios.ICANON)
        attrs[1] &= ~termios.OPOST
        termios.tcsetattr(slave, termios.TCSANOW, attrs)
        reader = subprocess.Popen(
            [sys.executable, "-c",
             "import os\n"
             "import time\n"
             "deadline = time.monotonic() + 5.0\n"
             "data = b''\n"
             "while time.monotonic() < deadline:\n"
             "    chunk = os.read(0, 16)\n"
             "    if chunk:\n"
             "        data += chunk\n"
             "    if data:\n"
             "        break\n"
             "os.write(1, data)\n"],
            stdin=slave, stdout=slave, stderr=slave, start_new_session=True)
        os.close(slave)
        def reap():
            if reader.poll() is None:
                reader.kill()
            reader.wait(timeout=5)
        self.addCleanup(reap)

            master_fd=master,
            mailcortex_admission_lock=threading.RLock(),

            mailcortex_input_dirty=False,
        )
        owner.pid = pid or reader.pid
        owner._mailcortex_barrier = contextlib.nullcontext
        owner._mailcortex_refresh_screen = lambda: False
        owner._hold_input_pending = lambda: False
        return owner, master, None

    # ------------------------------------------------------------- queue
    def read_master(self, master, expect_len, deadline_s=2.0):
        """Read the PTY master until expect_len bytes arrive or deadline."""
        import select
        written = bytearray()
        deadline = time.monotonic() + deadline_s
        while time.monotonic() < deadline and len(written) < expect_len:
            ready, _, _ = select.select([master], [], [], max(0.0, deadline - time.monotonic()))
            if not ready:
                continue
            try:
                chunk = os.read(master, 4096)
            except OSError:
                break
            if chunk:
                written.extend(chunk)
        return bytes(written)

    def _queue_write(self, visible):
        items = []
        if self.queue_file.exists():
            items = json.loads(self.queue_file.read_text())
        items.append({"schema": "dotcortex.approval.queue.v2",
                      "seat": "fixture-seat", "reason": "hold_timeout",
                      "request": {"screen_text_snippet": visible[:120]}})
        self.queue_file.write_text(json.dumps(items))
        # ledger stamp
        with open(self.ledger, "a") as fh:
            fh.write(json.dumps({"ts": time.time(), "action": "hold_timeout_denied",
                                 "screen_text_snippet": visible[:120]}) + "\n")
        return True

    def pty_owner(self):
        """A real PTY whose child echoes what the supervisor writes.

        The slave is fully raw: no ECHO/ICANON, no OPOST, and no ICRNL, so
        the master observes the exact dismiss byte (b"\\r") the supervisor
        wrote instead of the line discipline's CR-to-NL translation."""
        import pty
        import termios
        master, slave = pty.openpty()
        os.set_blocking(master, False)
        attrs = termios.tcgetattr(slave)
        attrs[0] &= ~(termios.ICRNL | termios.INLCR | termios.IGNCR)
        attrs[1] &= ~termios.OPOST
        attrs[3] &= ~(termios.ECHO | termios.ECHOCTL | termios.ICANON)
        termios.tcsetattr(slave, termios.TCSANOW, attrs)
        reader = subprocess.Popen(
            [sys.executable, "-c",
             "import os\n"
             "import time\n"
             "deadline = time.monotonic() + 5.0\n"
             "data = b''\n"
             "while time.monotonic() < deadline:\n"
             "    chunk = os.read(0, 16)\n"
             "    if chunk:\n"
             "        data += chunk\n"
             "    if data:\n"
             "        break\n"
             "os.write(1, data)\n"],
            stdin=slave, stdout=slave, stderr=slave, start_new_session=True)
        os.close(slave)
        def reap():
            if reader.poll() is None:
                reader.kill()
            reader.wait(timeout=5)
        self.addCleanup(reap)
        return master, reader.pid

    def read_master(self, master, expect_len, deadline_s=2.0):
        import select
        written = bytearray()
        deadline = time.monotonic() + deadline_s
        while time.monotonic() < deadline and len(written) < expect_len:
            ready, _, _ = select.select([master], [], [], max(0.0, deadline - time.monotonic()))
            if not ready:
                continue
            try:
                chunk = os.read(master, 4096)
            except OSError:
                break
            if chunk:
                written.extend(chunk)
        return bytes(written)

    def master_quiet(self, master, seconds=0.2):
        """True when no further PTY bytes arrive. The fixture child exits
        right after echoing its byte, so a closed slave (EOF) is quiet,
        not a second key."""
        import select
        ready, _, _ = select.select([master], [], [], seconds)
        if not ready:
            return True
        try:
            return not os.read(master, 4096)
        except OSError:
            return True

    def ledger_records(self, action=None):
        path = self.base / ".local/state/dotcortex/pty-hold-ledger.jsonl"
        if not path.exists():
            return []
        records = [json.loads(line) for line in path.read_text().splitlines() if line.strip()]
        return [record for record in records
                if action is None or record.get("action") == action]

* claude-warm seam

The supervisor (agents-claude-idle-supervisor.org) feeds every screen
state through =_hold_maybe_record= and fires =_hold_expire= in its run
loop. The seam reuses the mail-wake lock
(=mailcortex_admission_lock=; plain claude-warm now creates it first)
and its acknowledged, crash-safe process-tree barrier. Both owners use
the attributed screen model; a menu selector is distinguished from editable
input inside =prompt_input_state=. Pending terminal input, output or IPC
refuses the write. Queue recording follows the resume acknowledgement.

The queue holds the full rendered request as a =PTYPermission= snapshot,
bound to its session and screen identity. It is evidence for human review;
no executable tool arguments are inferred from the screen. Recording failures
appear in the owner guard log, and the private ledger links the queue ID.

Known non-permission blocking dialogs (claude-warm's
=KNOWN_BLOCKING_DIALOGS=) are dismissed through this same guarded seam with
the entry's own safe key, but only after a short settle while the seat is
otherwise idle: the autocompact prompt (2026-10-16, Bunta's seat frozen
2.5 h) receives Enter for its highlighted "Keep auto" default. Each
fingerprint requires the dialog's heading, question, highlighted default
and its own footer cues together, never loose words; a reworded dialog
falls through to =dialog_unknown= — one ledger record with a screen
snippet, never a key. Permission prompts never enter this path: they keep
the 10-minute AFK hold and the Desk queue unchanged.
