* Piper TTS on the phone (Q1 verdict: NATIVE-ARM64)
The ruled recipe: piper via pip on Termux's own python, with Termux's Bionic =python-onnxruntime= symlinked over the glibc wheel pip drags in. Idempotent; safe to re-run after piper upgrades (re-asserts the symlink).

#+BEGIN_SRC bash :tangle termux/.local/bin/termux-piper-apply :shebang "#!/data/data/com.termux/files/usr/bin/bash"
# ~/DotCortex/termux/.local/bin/termux-piper-apply
set -euo pipefail

echo "== termux piper apply =="

python -c "import onnxruntime" 2>/dev/null || {
  echo "!! Termux python-onnxruntime not importable — run termux-pkg-apply first"
  exit 1
}

# python -m pip, never the bare pip shim: Termux python major upgrades leave
# /usr/bin/pip pointing at the removed interpreter (bad shebang), while the
# module lane always matches the live python (bitten live, 2026-08-16)
#
# piper 1.7 ships no Android wheel — AND the PyPI sdist ships NO C SOURCES
# at all (no CMakeLists.txt, no espeakbridge.c): building from PyPI yields a
# py3-none-any wheel whose synthesis dies on `ImportError: espeakbridge`,
# while sox plays the zero bytes with a clean exit (silent phone, 2026-08-16).
# The only true source is the git repo, which carries the CMake build: it
# vendors espeak-ng statically (ExternalProject clone, needs network + git)
# and compiles espeakbridge on-device into a cp39-abi3 android_arm64 wheel.
# Proven recipe (S24, 2026-08-16): Termux toolchain from pkg (ninja/cmake/
# clang/git, in the manifest), the build backends piper imports (setuptools +
# skbuild), and --no-build-isolation so the build uses them instead of an
# isolated venv that tries to pip-compile ninja and dies.
python -m pip install setuptools wheel scikit-build
python -m pip install --no-cache-dir --no-deps --no-build-isolation --upgrade \
  "piper-tts @ git+https://github.com/OHF-voice/piper1-gpl@v1.7.0"
python -m pip install --no-build-isolation "pathvalidate>=3,<4"

# pip resolves an onnxruntime wheel linked against glibc; it cannot dlopen on
# Bionic. Point pip's install at Termux's own native module instead
# (documented workaround, rhasspy/piper#814).
SITE="$(python -c 'import site; print(site.getsitepackages()[0])')"
NATIVE="$(python - <<'PY'
import onnxruntime, os, sys
d = os.path.dirname(onnxruntime.__file__)
print(d)
PY
)"
PIP_ORT="$SITE/onnxruntime"
if [ -d "$PIP_ORT" ] && [ "$PIP_ORT" != "$NATIVE" ]; then
  rm -rf "$PIP_ORT"
  ln -s "$NATIVE" "$PIP_ORT"
  echo "symlinked Bionic onnxruntime over pip's glibc wheel"
fi

# The artifact is the evidence: a pure-python install passes the import above
# and still cannot speak. Assert the compiled bridge is physically on disk.
python - <<'PY'
import os, piper
d = os.path.dirname(piper.__file__)
so = [f for f in os.listdir(d) if f.startswith("espeakbridge") and f.endswith(".so")]
assert so, f"espeakbridge.so MISSING from {d} — pure-python wheel installed; rebuild from git"
assert os.path.isdir(os.path.join(d, "espeak-ng-data")), "espeak-ng-data missing"
print(f"piper native OK: {so[0]}")
PY
python -c "from piper import PiperVoice; print('piper importable')"
echo "Done. Voices download to ~/.local/share/piper on first use (or fetch manually)."
#+END_SRC

* Speak on the phone (working primitive)
=termux-tts-say= is the phone's speaking primitive: text on stdin or argv → piper → phone speakers through PulseAudio. Voice model path defaults to the fleet-standard Amy but any =.onnx= piper voice works. This is the substrate the generic =tts-synth=/=tts-play= contract will formalize once the HelmCortex identity membrane lands; until then this one script is the honest whole of it.

#+BEGIN_SRC bash :tangle termux/.local/bin/termux-tts-say :shebang "#!/data/data/com.termux/files/usr/bin/bash"
# ~/DotCortex/termux/.local/bin/termux-tts-say
set -euo pipefail

MODEL="${TERMUX_TTS_MODEL:-$HOME/.local/share/piper/en_US-amy-medium.onnx}"
[ -f "$MODEL" ] || {
  echo "termux-tts-say: no voice model at $MODEL — set TERMUX_TTS_MODEL or place a piper .onnx there" >&2
  exit 1
}

# One audio authority (2026-08-29): never mint a private daemon. pulseaudio
# --start BYPASSES client.conf autospawn=no (proven live on this phone), so
# the old --check||--start fallback here was itself the stray-daemon vector.
# Wait for the runit-supervised daemon to claim the socket (boot race), then
# proceed; if it never comes, the play stage fails loudly downstream.
for _ in $(seq 1 20); do pulseaudio --check 2>/dev/null && break; sleep 0.5; done

if [ $# -gt 0 ]; then TEXT="$*"; else TEXT="$(cat)"; fi
# piper 1.7 CLI: -m + --output-raw (the 1.4-era --model/--output_raw silently
# produced zero bytes while sox exited 0 — the first phone speech was silence
# with a clean exit code, 2026-08-16). pipefail + visible stderr so a dead
# stage can never again masquerade as success.
set -o pipefail
printf '%s' "$TEXT" | python -m piper -m "$MODEL" --output-raw \
  | sox -t raw -r 22050 -e signed -b 16 -c 1 - -d
#+END_SRC

The consort voice family (Bella, Luna, Kiki, Jasper, Rosie — the pvox kitten bank) rendered fleet-side only, because kittentts pulls =misaki[en]= which pins Python ≤3.12 and bare Termux/Bionic cannot hold that stack. This chapter, ruled 2026-08-17 ("my phone has more horsepower for rendering on device than the rest of the fleet" — and Q8 agrees: kitten ~0.4–0.9 RTF on the S24), installs a uv-managed Python 3.12 venv with the SAME kittentts 0.8.1 wheel the HelmCortex conda env pins, plus a one-shot synth script. # ~/DotCortex/termux/.local/bin/termux-kitten-apply
set -euo pipefail

echo "== termux kitten apply (enclave) =="

  command -v uv >/dev/null || { curl -LsSf https://astral.sh/uv/install.sh | sh; }

  # misaki whose chain drags torch + nvidia wheels onto the phone (bitten
  # live 2026-08-17, 107-package resolution for a 25MB model). The conda

  # curated-transformers) DECLARES torch, but the kitten synth path never
  # imports it — the fleet conda env runs exactly this shape: curated pair
  # present, torch absent. Strip the dead weight (torch + nvidia + triton
  # is hundreds of MB of phone storage) to mirror the proven state.

    torch triton $(uv pip list --python "$HOME/kitten-venv/bin/python" 2>/dev/null | awk "/^nvidia-/ {print \$1}") 2>/dev/null || true
  uv cache prune >/dev/null 2>&1 || true

  # one-shot synth: text on stdin, headered WAV on stdout (never raw PCM).
  # Sentence-chunked like the fleet daemon (kitten degrades on very long
  # single inputs); wordless chunks dropped and failed chunks skipped, never
  # fatal — the same laws the fleet pvox learned 2026-08-17. Markdown
  # cleanup is NOT here: the caller (fleet hook) cleans via `pvox clean`,
  # one source of truth.
  cat > "$HOME/kitten-say.py" <<"PY"
import argparse, contextlib, io, os, re, sys, wave
import numpy as np

def chunks(s, maxc=300):
    parts = re.split(r"(?<=[\.\?\!])\s+", s)
    out, buf = [], ""
    for t in parts:
        t = t.strip()
        if not t:
            continue
        if len(buf) + len(t) + 1 <= maxc:
            buf = (buf + " " + t).strip() if buf else t
        else:
            if buf:
                out.append(buf)
            buf = t
            while len(buf) > maxc:
                out.append(buf[:maxc])
                buf = buf[maxc:]
    if buf:
        out.append(buf)
    return [c for c in out if re.search(r"\w", c)]

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--voice", default="Bella")
    ap.add_argument("--speed", type=float, default=1.0)
    ap.add_argument("--stream", action="store_true",
                    help="raw s16le 24k PCM to stdout per chunk (local pipe to a player with explicit rate flags)")
    args = ap.parse_args()
    text = sys.stdin.read().strip()
    if not text:
        return
    from kittentts import KittenTTS
    # fp32, NOT int8, on this phone — measured on the S24 2026-08-17:
    # int8 RTF 0.95 (playback catches the renderer -> audible gaps between
    # chunks), fp32 RTF 0.64 with identical 2.8s cached load. Q8 called it:
    # int8 quantization is SLOWER than full precision on ARM.
    m = KittenTTS(os.environ.get("KITTEN_MODEL", "KittenML/kitten-tts-nano-0.8-fp32"))

    def synth(ck):
        try:
            # stdout is the audio transport in both stream and WAV modes.
            # KittenTTS 0.8.1 prints generation diagnostics to stdout, so
            # quarantine all library chatter on stderr or SoX interprets the
            # text bytes as signed 16-bit PCM (full-scale static).
            with contextlib.redirect_stdout(sys.stderr):
                try:
                    return m.generate(ck, voice=args.voice, speed=args.speed)
                except TypeError:
                    return m.generate(ck, voice=args.voice)
        except Exception as e:
            print(f"[kitten-say] chunk skipped ({e}): {ck[:60]!r}", file=sys.stderr)
            return None

    if args.stream:
        # streaming: each chunk plays while the next renders — first audio in
        # seconds instead of after the whole reply (RTF<1, so playback of one
        # chunk outlasts the render of the next and the lead only grows)
        for ck in chunks(text):
            audio = synth(ck)
            if audio is None:
                continue
            pcm = np.clip(np.asarray(audio), -1.0, 1.0)
            sys.stdout.buffer.write((pcm * 32767).astype("<i2").tobytes())
            sys.stdout.buffer.flush()
        return

    pieces = []
    for ck in chunks(text):
        audio = synth(ck)
        if audio is not None:
            pieces.append(np.asarray(audio))
    if not pieces:
        return
    pcm = np.clip(np.concatenate(pieces), -1.0, 1.0)
    pcm16 = (pcm * 32767).astype("<i2").tobytes()
    out = io.BytesIO()
    with wave.open(out, "wb") as w:
        w.setnchannels(1); w.setsampwidth(2); w.setframerate(24000)
        w.writeframes(pcm16)
    sys.stdout.buffer.write(out.getvalue())

if __name__ == "__main__":
    main()
PY
  # torch in this venv is always wrong (fleet parity: kitten runs without
  # it) — its presence means resolver drift or a polluted venv from a
  # failed round; fail loud instead of importing a broken half-install

#+BEGIN_SRC bash :tangle termux/.local/bin/termux-kitten-say :shebang "#!/data/data/com.termux/files/usr/bin/bash"
# ~/DotCortex/termux/.local/bin/termux-kitten-say
# text (stdin or argv) -> enclave kitten render -> phone speakers
set -euo pipefail

VOICE="${KITTEN_VOICE:-Bella}"
SPEED="${KITTEN_SPEED:-1.0}"
while [ $# -gt 0 ]; do
  case "$1" in
    --voice) VOICE="$2"; shift 2 ;;
    --speed) SPEED="$2"; shift 2 ;;
    --wav-out) WAV_OUT="$2"; shift 2 ;;
    -h|--help) echo "usage: termux-kitten-say [--voice V] [--speed S] [--wav-out F] [text]"; exit 0 ;;
    *) break ;;
  esac
done

if [ $# -gt 0 ]; then TEXT="$*"; else TEXT="$(cat)"; fi
[ -n "$TEXT" ] || exit 0

emit_receipt() {
  [ -n "${PVOX_SPEAKER_ID:-}" ] && [ -n "${PVOX_PLAYBACK_ID:-}" ] || return 0
  command -v pvox-speech-receipt >/dev/null 2>&1 || return 0
  pvox-speech-receipt "$1" "$PVOX_SPEAKER_ID" "$PVOX_PLAYBACK_ID" || true
}

if [ -n "${WAV_OUT:-}" ]; then
  W="$WAV_OUT"
  printf '%s' "$TEXT" | proot-distro login debian -- bash -lc \
    "\$HOME/kitten-venv/bin/python \$HOME/kitten-say.py --voice '$VOICE' --speed '$SPEED'" > "$W"
  [ -s "$W" ] || { echo "termux-kitten-say: empty render" >&2; rm -f "$W"; exit 1; }
  echo "$W"
else
  # STREAMING play (fix 2026-08-17, "waited over 2 minutes" — the render
  # queue): each sentence chunk plays while the next renders, so first audio
  # lands in seconds even on a 2000-char reply. Raw PCM with explicit rate
  # flags is lawful here — one machine, one pipe, rate stated (the
  # WAV-with-header law governs transport ACROSS hosts). The queue lock
  # wraps the WHOLE pipeline: two concurrent says would otherwise interleave
  # into pulse as overlapping voices, and serializing render+play also stops
  # concurrent renders fighting for the big cores.
  # One audio authority (2026-08-29): wait for the supervised daemon, never
  # mint one — pulseaudio --start bypasses autospawn=no (proven live); the
  # old --check||--start fallback was the stray-daemon vector. If the daemon
  # never comes, sox fails loudly and the truth log below records it.
  for _ in $(seq 1 20); do pulseaudio --check 2>/dev/null && break; sleep 0.5; done
  command -v termux-wake-lock >/dev/null 2>&1 && termux-wake-lock 2>/dev/null || true
  # Lock lives OUTSIDE $TMPDIR (2026-08-29): Termux clears $PREFIX/tmp
  # whenever Android restarts the app, and a swept lock file means two
  # concurrent says hold DIFFERENT inodes — zero mutual exclusion, and the
  # overlapping-voices bug returns through the back door (bitten live,
  # msgs 1313+1316 playing over each other). ~/.cache survives app restarts.
  # A detached reply is no longer useful after waiting five minutes behind
  # another play. Five minutes covers one measured max-length (~4k-char)
  # Kitten reply without admitting an unbounded stale backlog; the previous
  # two-minute bound expired valid replies while that single play still held
  # the queue. Expire only after this bounded grace window.
  mkdir -p "$HOME/.cache" 2>/dev/null || true
  # One lock for both the on-device Kitten and shipped-WAV relay lanes.
  exec 9>"$HOME/.pvox-reply-play.lock"
  emit_receipt queued
  # Ruling 2026-10-02 (Mètsàtron): a voice must never expire while it waits its turn. The five-minute bound above
  # dropped replies queued behind a few long ones, so the wait is now a four-hour runaway guard, not a policy.
  LOCK_WAIT="${PVOX_REPLY_LOCK_WAIT:-14400}"
  if ! flock -w "$LOCK_WAIT" 9; then
    emit_receipt player_exited
    command -v termux-wake-unlock >/dev/null 2>&1 && termux-wake-unlock 2>/dev/null || true

* PCM start gate for truthful StarFox speech timing

The on-device renderer can take seconds before it emits sound. This gate
forwards its 24 kHz signed 16-bit mono PCM byte-for-byte and emits
=player_started= only when the first non-silent sample arrives. Empty or
silence-only renders never claim audible playback. After that boundary it
quantizes 200 ms RMS windows into a bounded 0–100 envelope and streams those
levels through the validated receipt helper. The audio loop never waits for a
new helper process per window: one helper remains open for the playback.

#+BEGIN_SRC python :tangle termux/.local/bin/pvox-pcm-start-gate :shebang "#!/data/data/com.termux/files/usr/bin/python3"
"""Forward signed 16-bit PCM and emit truthful start plus bounded RMS levels."""

from array import array
import math
import os
import subprocess
import sys


DEFAULT_WINDOW_SAMPLES = 4_800  # 200 ms at 24 kHz: five visual updates/second.


def level_from_energy(total: int, count: int) -> int:
    if not count or total <= 0:
        return 0
    rms = math.sqrt(total / count)
    if rms < 8:
        return 0
    dbfs = 20 * math.log10(min(rms / 32768.0, 1.0))
    # Speech mostly occupies -50..-10 dBFS. Quantize and bound before it leaves
    # the phone; the HUD needs an envelope, never raw audio or text.
    return max(0, min(100, round((dbfs + 50.0) * 2.5)))


class LevelSink:
    def __init__(self, speaker: str | None, playback: str | None):
        self.speaker = speaker
        self.playback = playback
        self.process: subprocess.Popen[str] | None = None

    def start(self) -> None:
        if not self.speaker or not self.playback or os.environ.get("PVOX_LEVELS_OFF"):
            return
        try:
            self.process = subprocess.Popen(
                ["pvox-speech-receipt", "levels", self.speaker, self.playback],
                stdin=subprocess.PIPE,
                text=True,
                stdout=subprocess.DEVNULL,
                stderr=subprocess.DEVNULL,
            )
        except OSError:
            self.process = None

    def emit(self, level: int) -> None:
        if not self.process or not self.process.stdin:
            return
        try:
            self.process.stdin.write(f"{level}\n")
            self.process.stdin.flush()
        except (BrokenPipeError, OSError):
            self.close()

    def close(self) -> None:
        process, self.process = self.process, None
        if not process:
            return
        if process.stdin:
            try:
                process.stdin.close()
            except OSError:
                pass
        try:
            process.wait(timeout=1)
        except subprocess.TimeoutExpired:
            process.terminate()
            try:
                process.wait(timeout=1)
            except subprocess.TimeoutExpired:
                process.kill()
                process.wait()


def emit_started(speaker: str | None, playback: str | None) -> None:
    if not speaker or not playback:
        return
    try:
        subprocess.run(
            ["pvox-speech-receipt", "player_started", speaker, playback],
            check=False,
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
        )
    except OSError:
        pass


def main():
    speaker = os.environ.get("PVOX_SPEAKER_ID")
    playback = os.environ.get("PVOX_PLAYBACK_ID")
    try:
        window_samples = max(240, int(os.environ.get("PVOX_LEVEL_WINDOW_SAMPLES", DEFAULT_WINDOW_SAMPLES)))
    except ValueError:
        window_samples = DEFAULT_WINDOW_SAMPLES
    started = False
    sink = LevelSink(speaker, playback)
    energy = sample_count = 0
    carry = b""
    try:
        # read1 returns the first available chunk; read(4096) could wait for a
        # full buffer and add visible latency to short streamed sentences.
        while chunk := sys.stdin.buffer.read1(4096):
            analysis = carry + chunk
            usable = len(analysis) - (len(analysis) % 2)
            carry = analysis[usable:]
            samples = array("h")
            samples.frombytes(analysis[:usable])
            if sys.byteorder != "little":
                samples.byteswap()
            for sample in samples:
                if not started and sample:
                    started = True
                    emit_started(speaker, playback)
                    sink.start()
                if started:
                    energy += sample * sample
                    sample_count += 1
                    if sample_count >= window_samples:
                        sink.emit(level_from_energy(energy, sample_count))
                        energy = sample_count = 0
            # Analysis is observational: preserve every input byte and flush
            # promptly so the meter cannot add buffering to the audio path.
            sys.stdout.buffer.write(chunk)
            sys.stdout.buffer.flush()
        if started and sample_count:
            sink.emit(level_from_energy(energy, sample_count))
    finally:
        sink.close()


if __name__ == "__main__":
    main()
#+END_SRC
