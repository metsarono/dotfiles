* Decision (Admiral, Telegram 2002/2005/2518)

"Let's get the terminal up and running." The Admiral wants the Logseq web
terminal published in the Caddy. Chosen security (option A): tailnet-only
publication plus a password credential that he sets himself.

The terminal is the SAME ttyd instance the Logseq side panel uses (logseq.org):
one server on a unix socket, one patched index (Shift+Enter handling and
websocket tracking, owned by =logseq-ttyd-index= — never forked here). The
Caddy gate fronts it; Logseq reaches it through the same gate.

Fix round 2 (2026-10-16, rulings R-DOCK-16/R-DOCK-17): the Centre dock must
open the Terminal as a direct VUE icon launcher in a floating BeOS window.
Basic auth was the blocker twice over — an iframe subresource cannot surface a
401 challenge, and the dock's =inspect_apps= health probe read the 401 as
"health refused", so Terminal never earned a window. The gate now serves a
small login page (=caddy-terminal-authd= below) that checks the SAME bcrypt
hash =caddy-terminal-passwd= writes (the Admiral never re-sets his password)
and grants a cookie session that works inside the Centre's iframe. The hash
file format is unchanged, so the existing live hash survives cut-over.

- ttyd has NO TCP PORT, ever. It listens on a UNIX socket only:
  =$HOME/.local/state/caddy-terminal/run/terminal.sock=, created mode 0600
  inside a 0700 directory owned by metsatron. No local agent user on Kikin
  can traverse to the socket, and there is no port for any user to reach.
  This is the fix-round-1 law (Bunta review 2026-10-15): the previous
  loopback TCP listener on 7681 was an unauthenticated operator shell
  reachable by every local agent user — not acceptable behind the
  agent-user isolation the Admiral set up. ttyd 1.7.7 supports it natively:
  =-i /path.sock= binds a unix socket (=-U user:group= exists but is not
  needed — the process already runs as metsatron; umask 077 makes the socket
  owner-only at birth, and the launcher then forces 0600).
- The credential NEVER rides a command line. ttyd runs without =-c= (=-c= is
  visible in =ps=, and agent users exist on Kikin). Authentication is the
  gate's login form (=caddy-terminal-authd=), whose bcrypt hash lives in a
  0600 machine-local file written by =caddy-terminal-passwd=. DotCortex
  carries no hash: the public repo never stores secrets (same law as the
  obsidian-web gate in =app.org=). The same file the old basic_auth import
  read is what authd parses today — the Admiral's live hash survives.
- The gate site lives in the machine-local Caddyfile of the unprivileged
  FileBrowser Caddy instance (=$HOME/.local/state/filebrowser/caddy/.Caddyfile=,
  =auto_https off=, =admin off=), the same lane the FileBrowser :9090 and
  OnlyOffice :9092 fronts use. =tailscale serve= publishes the gate as
  =https://<tailnet-host>:7682= — no new tailnet listener owned by anything but
  tailscaled.
- Supervision: the =filebrowser-supervise= shape (a flock-singleton supervisor
  that respawns the daemon forever), started by the user crontab =@reboot=
  plus a =*/2= liveness entry. No root anywhere.

CLOSED (fix round 1): the residual risk of the first draft — "any LOCAL user
on Kikin can reach the terminal without a password" — is gone. ttyd no longer
has any TCP listener; the only entry is the Caddy gate (basic_auth for the
tailnet, bearer path token for the Logseq side panel), and the socket itself
is 0600 in a 0700 metsatron-only directory. No listener gives an
unauthenticated shell to another local user.

* Launcher: caddy-terminal-serve

Plain foreground launcher for the supervisor to own, mirroring =filebrowser-serve=
(the cron contract owns liveness, the launcher owns config/socket). Reuses the
patched index via =logseq-ttyd-index= (logseq.org) and the same theme options
the Logseq side panel gets.

NO TCP PORT. ttyd binds a unix socket in a 0700 run directory; =umask 077=
makes the socket owner-only the instant libwebsockets creates it, and the
launcher then forces mode 0600 explicitly (fix round 1 — no local agent user
may reach the operator's shell). =--check= is the single liveness probe the
supervisor and =logseq-db= share: exit 0 means the socket answers, 3 means
down. Never fork this probe.

The launcher does not =exec= ttyd directly: it starts ttyd in the background,
waits for the socket file to appear, forces 0600, then blocks in =wait= —
same foreground semantics for the supervisor, plus the chmod window.

#+name: caddy-terminal-serve
#+BEGIN_SRC bash :tangle all/.local/bin/caddy-terminal-serve :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# caddy-terminal-serve — foreground ttyd launcher for the Caddy web terminal.
# Same ttyd, same patched index as the Logseq side panel (logseq.org).
# Unix socket only: no TCP port for any local user to reach (fix round 1).
set -euo pipefail

TAG="caddy-terminal-serve"
TTYD_BIN="${CADDY_TERMINAL_TTYD:-$HOME/.local/bin/ttyd}"
INDEX_TOOL="${CADDY_TERMINAL_INDEX:-$HOME/.local/bin/logseq-ttyd-index}"
STATE_DIR="${CADDY_TERMINAL_STATE:-$HOME/.local/state/caddy-terminal}"
RUN_DIR="${CADDY_TERMINAL_RUN_DIR:-$STATE_DIR/run}"
SOCKET="${CADDY_TERMINAL_SOCKET:-$RUN_DIR/terminal.sock}"
FONT_SIZE="${CADDY_TERMINAL_FONT_SIZE:-16}"
FONT_FAMILY="${CADDY_TERMINAL_FONT_FAMILY:-SFMono Nerd Font, monospace}"
# Single executable, no arguments (kept one word for the ttyd command line).
# Tests override this to keep their scratch terminals inert.
COMMAND="${CADDY_TERMINAL_COMMAND:-zsh}"
CURL_BIN="${CADDY_TERMINAL_CURL:-curl}"

[ -x "$TTYD_BIN" ] || { echo "$TAG: missing $TTYD_BIN" >&2; exit 69; }
[ -x "$INDEX_TOOL" ] || { echo "$TAG: missing $INDEX_TOOL (tangle logseq.org and stow)" >&2; exit 69; }

socket_alive() {
  [ -S "$SOCKET" ] || return 1
  "$CURL_BIN" -s --max-time 2 --unix-socket "$SOCKET" -o /dev/null http://localhost/ 2>/dev/null
}

if [ "${1:-}" = "--check" ]; then
  [ "$#" -eq 1 ] || { echo "$TAG: --check takes no other arguments" >&2; exit 2; }
  # Read-only probe for the supervisor and logseq-db: 0 = live, 3 = down.
  socket_alive || exit 3
  exit 0
fi
[ "$#" -eq 0 ] || { echo "Usage: $TAG [--check]" >&2; exit 2; }

# umask 077: libwebsockets creates the socket as 0777 & ~umask, so it is
# owner-only from birth; 0600 is forced below once it exists. The 0700 run
# directory is the outer wall — no other local user can traverse to it.
umask 077
mkdir -p "$RUN_DIR"
chmod 700 "$STATE_DIR" "$RUN_DIR"

if socket_alive; then
  echo "$TAG: socket already live: $SOCKET" >&2
  exit 0
fi
# Stale socket file left by a dead ttyd blocks the fresh bind — remove it
# only after the liveness probe failed (never a live listener's file).
[ -S "$SOCKET" ] && rm -f "$SOCKET"

TTYD_INDEX="$("$INDEX_TOOL")" || { echo "$TAG: index build failed" >&2; exit 1; }

"$TTYD_BIN" -W -i "$SOCKET" -I "$TTYD_INDEX" \
  -t "fontSize=$FONT_SIZE" -t "fontFamily=\"$FONT_FAMILY\"" "$COMMAND" &
ttyd_pid=$!
for _ in $(seq 1 50); do
  [ -S "$SOCKET" ] && break
  kill -0 "$ttyd_pid" 2>/dev/null || break
  sleep 0.1
done
if [ -S "$SOCKET" ]; then
  chmod 0600 "$SOCKET"
  wait "$ttyd_pid"
else
  wait "$ttyd_pid" || true
  echo "$TAG: ttyd exited without creating $SOCKET" >&2
  exit 1
fi
#+END_SRC

chmod +x ~/DotCortex/all/.local/bin/caddy-terminal-serve
#+END_SRC

* Supervisor: caddy-terminal-supervise

The =filebrowser-supervise= shape: flock singleton, host guard, respawn forever.
One addition the filebrowser lane does not need: the Logseq launcher
(=logseq-db=) may legitimately have started ttyd first. The supervisor adopts
any live socket and only spawns the launcher when the socket is down — one
owner at a time, whoever got there first, and the supervisor always outlives a
crash. Liveness is the launcher's own =--check= probe (single owner, never
duplicated); a socket FILE left by a dead ttyd is not "alive" — the probe
connects through it, so stale files fall through to a respawn and the
launcher clears them.

Fix round 2: the same script also supervises the gate's auth verifier. A
second instance runs with =CADDY_TERMINAL_SUPERVISE_LAUNCHER= pointed at
=caddy-terminal-authd= and =CADDY_TERMINAL_SUPERVISE_LOCK= at its own lock
file, so both daemons respawn independently under one script, one flock each.

#+name: caddy-terminal-supervise
#+BEGIN_SRC bash :tangle linux/.local/bin/caddy-terminal-supervise :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

TAG="caddy-terminal-supervise"
EXPECTED_HOST=""
DELAY=15
RETRY_SECONDS=5
ADOPT_SECONDS=30
LAUNCHER="${CADDY_TERMINAL_SUPERVISE_LAUNCHER:-$HOME/.local/bin/caddy-terminal-serve}"
SOCKET="${CADDY_TERMINAL_SOCKET:-$HOME/.local/state/caddy-terminal/run/terminal.sock}"
# The lock is parameterised so the same script can supervise the gate's
# auth verifier (caddy-terminal-authd) with its own lock file and launcher.
LOCK_FILE="${CADDY_TERMINAL_SUPERVISE_LOCK:-}"
HOSTNAME_BIN="${CADDY_TERMINAL_SUPERVISE_HOSTNAME_BIN:-hostname}"

while [ "$#" -gt 0 ]; do
  case "$1" in
    --expected-host) [ "$#" -ge 2 ] || { echo "$TAG: --expected-host requires a value" >&2; exit 2; }; EXPECTED_HOST="$2"; shift ;;
    --delay) [ "$#" -ge 2 ] || { echo "$TAG: --delay requires a value" >&2; exit 2; }; DELAY="$2"; shift ;;
    --retry-seconds) [ "$#" -ge 2 ] || { echo "$TAG: --retry-seconds requires a value" >&2; exit 2; }; RETRY_SECONDS="$2"; shift ;;
    --adopt-seconds) [ "$#" -ge 2 ] || { echo "$TAG: --adopt-seconds requires a value" >&2; exit 2; }; ADOPT_SECONDS="$2"; shift ;;
    -h|--help|help) echo "Usage: $TAG --expected-host HOST [--delay N] [--retry-seconds N] [--adopt-seconds N]"; exit 0 ;;
    *) echo "$TAG: unknown argument: $1" >&2; exit 2 ;;
  esac
  shift
done

[ -n "$EXPECTED_HOST" ] || { echo "$TAG: --expected-host is required" >&2; exit 2; }
CURRENT_HOST="$($HOSTNAME_BIN -s)"
[ "$CURRENT_HOST" = "$EXPECTED_HOST" ] || { echo "$TAG: wrong host ($CURRENT_HOST != $EXPECTED_HOST), nothing to do" >&2; exit 1; }
[ -x "$LAUNCHER" ] || { echo "$TAG: launcher is not executable: $LAUNCHER" >&2; exit 69; }

LOG_DIR="${CADDY_TERMINAL_STATE:-$HOME/.local/state/caddy-terminal}"
mkdir -p "$LOG_DIR"
exec 9>"${LOCK_FILE:-$LOG_DIR/supervisor.lock}"
if ! flock -n 9; then
  # Boot watchdog and liveness poll may meet; only one supervisor owns the service.
  exit 0
fi

log() { printf '%s %s %s\n' "$(date -Is)" "$TAG" "$*" >> "$LOG_DIR/supervisor.log"; }

# Liveness is the launcher's --check probe (curl through the unix socket):
# no TCP port exists, and a stale socket file from a dead ttyd reads as down.
alive() { "$LAUNCHER" --check 2>/dev/null; }

log "supervisor starting (host=$CURRENT_HOST, launcher=$LAUNCHER, socket=$SOCKET)"

# Boot path: give the machine a moment, then own the terminal forever,
# respawning on death — filebrowser-supervise shape.
sleep "$DELAY"
adopted=0
while :; do
  if alive; then
    if [ "$adopted" -eq 0 ]; then
      log "terminal socket already live; adopting existing ttyd"
      adopted=1
    fi
    sleep "$ADOPT_SECONDS"
    continue
  fi
  adopted=0
  # 9>&- — never leak the lock fd to the daemon: an orphaned ttyd holding
  # fd 9 would hold the flock and silently bar a fresh supervisor from
  # adopting it (observed live, 2026-10-15).
  "$LAUNCHER" 9>&- >> "$LOG_DIR/service.log" 2>&1 || true
  log "service exited, respawning in ${RETRY_SECONDS}s"
  sleep "$RETRY_SECONDS"
done
#+END_SRC

chmod +x ~/DotCortex/linux/.local/bin/caddy-terminal-supervise
#+END_SRC

* Cron contract: caddy-terminal-cron-apply

User crontab only — no root, unlike the /etc/cron.d filebrowser contract.
Idempotent: replaces only its own managed block, leaves every other entry
alone. =--remove= strips the block (and clears an otherwise empty crontab).

* Credential helper: caddy-terminal-passwd

The Admiral sets the credential himself; he never edits config by hand.
Prompts twice on the tty (blind), hashes with =caddy hash-password= (bcrypt)
via stdin — the plaintext never appears on any command line or in any file —
and writes the 0600 snippet =caddy-terminal-authd= parses (same file the
old basic_auth import read; format unchanged, so the Admiral's live hash
survives the round-2 cut-over). Re-running it simply replaces the hash:
authd re-reads the file on every login attempt, so NO gate restart is needed
for a new password — the next login uses it immediately.

#+BEGIN_SRC bash :tangle all/.local/bin/caddy-terminal-passwd :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)

# Only the hash is stored; the plaintext never reaches a command line, a file,

echo "caddy-terminal-passwd: bcrypt hash written to $AUTH_FILE (0600)" >&2
echo "Restart the Caddy gate instance (FileBrowser front) to apply, then reload the page." >&2

* Session verifier: caddy-terminal-authd

Fix round 2 (R-DOCK-16/R-DOCK-17): Basic auth cannot work inside the Centre's
iframe — an iframe subresource gets a dead 401, no native prompt. The gate
replaces =basic_auth= with a tiny login page backed by this verifier, a
stdlib-Python HTTP server on a unix socket (0600, metsatron-only, same walls
as the ttyd socket). Nothing new is installed: it needs only Python 3 and
=bcrypt= (both already on the fleet core profile).

It serves, through the gate:

- =GET /healthz= — the dock's unauthenticated health probe. =200 ok= when the
  ttyd socket answers, =503 down= otherwise. No other detail of any kind.
- =GET /login= — the login page (single password field; one user, one hash).
- =POST /login= — checks the password against the bcrypt hash
  =caddy-terminal-passwd= writes (the SAME =terminal-auth= file the old
  basic_auth import read — the Admiral never re-sets his password). The POST
  must carry the gate's OWN Origin (=CADDY_TERMINAL_ORIGINS=, default exactly
  =https://kikin-kushi.sphinx-draco.ts.net:7682= — fix round 3): any other
  Origin, or none, answers =403= before the password is read, without
  counting toward lockout. This replaces the missing CSRF token. On
  success it mints a session and answers =303= to the gate root with a
  =Secure; HttpOnly; SameSite=None; Partitioned= (CHIPS) cookie, so the
  session survives inside the Centre's cross-origin iframe. On failure it
  counts the client and, past the limit, locks the client out for a window —
  even a correct password is refused during lockout. The password exists
  only in the POST body: never logged, never echoed, never on a command line.
- =GET /logout= — drops the session and expires the cookie.
- =GET /check= — the =forward_auth= target for the terminal route: =204= with
  a valid, unexpired session cookie; =303 /login= otherwise. The terminal
  root therefore never 401s — without a cookie it is the login page.

Sessions are random 256-bit tokens stored in a 0600 JSON file with absolute
expiry timestamps, so a verifier restart does not log the Admiral out and a
stolen cookie dies at the deadline even if its Max-Age were replayed. The
cookie is host-only (no Domain attribute) — cookies cannot be port-scoped by
spec; the session only ever validates on the gate's own socket.

=caddy-terminal-authd --check= is the supervisor probe (0 = socket answers,
3 = down), same contract as the launcher.

MESSAGES = {
    'error': '<p>Wrong password.</p>',
    'locked': '<p>Too many attempts — locked, try again later.</p>',
    'auth': '<p>Sign in to open the terminal.</p>',
    'expired': '<p>Session expired — sign in again.</p>',
    'loggedout': '<p>Signed out.</p>',
}

_lock = threading.Lock()
_failures = collections.defaultdict(collections.deque)  # client key -> failure timestamps
_lockouts = {}  # client key -> locked-until epoch


def read_hash():
    """Parse the caddy-terminal-passwd file (basic_auth snippet shape)."""
    try:
        with open(AUTH_FILE, encoding='utf-8') as handle:
            for line in handle:
                fields = line.split()
                if len(fields) >= 2 and fields[1].startswith('$2'):
                    return fields[0], fields[1]
    except OSError:
        pass
    return None, None


def load_sessions():
    try:
        with open(SESSION_FILE, encoding='utf-8') as handle:
            value = json.load(handle)
        now = time.time()
        return {token: expiry for token, expiry in value.items() if expiry > now}
    except (OSError, ValueError, AttributeError):
        return {}


def save_sessions(sessions):
    directory = os.path.dirname(SESSION_FILE) or '.'
    handle = tempfile.NamedTemporaryFile('w', encoding='utf-8', dir=directory,
                                         prefix='.authd-sessions.', delete=False)
    try:
        json.dump(sessions, handle)
        handle.close()
        os.chmod(handle.name, 0o600)
        os.replace(handle.name, SESSION_FILE)
    except OSError:
        handle.close()
        os.unlink(handle.name)
        raise


_sessions = load_sessions()


def client_key(headers):
    forwarded = headers.get('X-Forwarded-For', '')
    match = re.match(r'\s*([0-9a-fA-F.:]+)', forwarded)
    return match.group(1) if match else 'local'


def remember_failure(key):
    now = time.time()
    with _lock:
        queue = _failures[key]
        queue.append(now)
        while queue and now - queue[0] > FAILURE_WINDOW:
            queue.popleft()
        if len(queue) >= MAX_FAILURES:
            _lockouts[key] = now + LOCKOUT_SECONDS
            queue.clear()


def lockout_remaining(key):
    with _lock:
        until = _lockouts.get(key, 0)
        if until <= time.time():
            _lockouts.pop(key, None)
            return 0
        return int(until - time.time()) + 1


def ttyd_alive():
    try:
        with socket.socket(socket.AF_UNIX, socket.SOCK_STREAM) as probe:
            probe.settimeout(1.0)
            probe.connect(TTYD_SOCKET)
            probe.sendall(b'GET / HTTP/1.0\r\n\r\n')
            return probe.recv(12).startswith(b'HTTP/')
    except OSError:
        return False


def cookie_attributes(max_age):
    return f'{COOKIE}=; Path=/; Max-Age={max_age}; Secure; HttpOnly; SameSite=None; Partitioned'


def issue_cookie(token):
    return (f'{COOKIE}={token}; Path=/; Max-Age={SESSION_SECONDS}; '
            'Secure; HttpOnly; SameSite=None; Partitioned')


class Handler(BaseHTTPRequestHandler):
    protocol_version = 'HTTP/1.1'

    def log_message(self, format, *args):  # noqa: A002 — stdlib signature
        sys.stderr.write('caddy-terminal-authd: %s %s\n' % (self.address_string(), format % args))

    def address_string(self):
        return client_key(self.headers)

    def _respond(self, status, body=b'', content_type='text/html; charset=utf-8', headers=()):
        self.send_response(status)
        for name, value in headers:
            self.send_header(name, value)
        if status != 204:
            self.send_header('Content-Type', content_type)
            self.send_header('Content-Length', str(len(body)))
        self.send_header('Cache-Control', 'no-store')
        self.end_headers()
        if self.command != 'HEAD' and status != 204:
            self.wfile.write(body)

    def _redirect(self, location, headers=()):
        self._respond(303, b'', 'text/plain; charset=utf-8',
                      [('Location', location), *headers])

    def do_GET(self):  # noqa: N802 — stdlib naming
        self._serve()

    def do_HEAD(self):  # noqa: N802
        self._serve()

    def _serve(self):
        path = urlsplit(self.path).path
        if path == '/healthz':
            if ttyd_alive():
                self._respond(200, b'ok\n', 'text/plain; charset=utf-8')
            else:
                self._respond(503, b'down\n', 'text/plain; charset=utf-8')
            return
        if path == '/login':
            query = parse_qs(urlsplit(self.path).query, keep_blank_values=True)
            note = next((MESSAGES[name] for name in query if name in MESSAGES), '')
            self._respond(200, PAGE.replace('{msg}', note).encode('utf-8'))
            return
        if path == '/logout':
            token = self._session_token()
            with _lock:
                if token in _sessions:
                    del _sessions[token]
                    save_sessions(_sessions)
            self._redirect('/login?loggedout', [('Set-Cookie', cookie_attributes(0))])
            return
        if path == '/check':
            token = self._session_token()
            with _lock:
                valid = token in _sessions
                if valid and _sessions[token] <= time.time():
                    del _sessions[token]
                    save_sessions(_sessions)
                    valid = False
                if valid:
                    self._respond(204)
                else:
                    self._respond(303, b'', 'text/plain; charset=utf-8',
                                  [('Location', '/login?auth')])
            return
        self._respond(404, b'not found\n', 'text/plain; charset=utf-8')

    def _session_token(self):
        try:
            cookie = SimpleCookie(self.headers.get('Cookie', ''))
            morsel = cookie[COOKIE]
            return morsel.value if morsel.value else None
        except (CookieError, KeyError):
            return None

    def do_POST(self):  # noqa: N802
        # Drain the body BEFORE any early return: a pooled keep-alive
        # connection with unread bytes desyncs the next request.
        try:
            declared = int(self.headers.get('Content-Length', '0'))
        except ValueError:
            declared = 0
        if declared > MAX_BODY:
            self.close_connection = True
        body = self.rfile.read(min(declared, MAX_BODY)) if declared > 0 else b''
        if urlsplit(self.path).path != '/login':
            self._respond(404, b'not found\n', 'text/plain; charset=utf-8')
            return
        # Fix round 3: cross-site request forgery is the missing CSRF token.
        # The login POST is only ever issued by the gate's own page inside the
        # Centre iframe, so every other Origin — or none — is refused BEFORE
        # the password is read (refusals never count toward lockout: an
        # attacker must not be able to lock the Admiral out with junk
        # Origin headers). The password is never logged either way.
        origin = self.headers.get('Origin')
        if origin not in ORIGINS:
            self.log_message('POST /login refused: Origin %s', (origin or '<missing>')[:200])
            self._respond(403, b'bad origin\n', 'text/plain; charset=utf-8')
            return
        key = client_key(self.headers)
        remaining = lockout_remaining(key)
        if remaining:
            # Throttled: even a correct password is refused during lockout.
            self._respond(429, b'locked\n', 'text/plain; charset=utf-8',
                          [('Retry-After', str(remaining)), ('Location', '/login?locked')])
            return
        try:
            password = parse_qs(body.decode('utf-8', 'replace')).get('password', [''])[0]
        except ValueError:
            password = ''
        user, hash_value = read_hash()
        if not hash_value or not password:
            remember_failure(key)
            self._redirect('/login?error')
            return
        try:
            # bcrypt reads at most the first 72 bytes; the comparison itself
            # is the only place the password is used, and it is never stored.
            matched = bcrypt.checkpw(password.encode('utf-8')[:72], hash_value.encode('ascii'))
        except ValueError:
            matched = False
        if not matched:
            remember_failure(key)
            self._redirect('/login?error')
            return
        with _lock:
            _failures.pop(key, None)
            token = secrets.token_urlsafe(32)
            _sessions[token] = time.time() + SESSION_SECONDS
            save_sessions(_sessions)
        self._redirect('/', [('Set-Cookie', issue_cookie(token))])


class UnixAuthdServer(ThreadingHTTPServer):
    address_family = socket.AF_UNIX
    daemon_threads = True

    def server_bind(self):
        if os.path.lexists(self.server_address):
            os.unlink(self.server_address)
        self.socket.bind(self.server_address)
        try:
            os.chmod(self.server_address, 0o600)
        except OSError:
            pass
        self.server_name = 'caddy-terminal-authd'
        self.server_port = 0


def alive():
    try:
        with socket.socket(socket.AF_UNIX, socket.SOCK_STREAM) as probe:
            probe.settimeout(2.0)
            probe.connect(SOCKET)
            probe.sendall(b'GET /login HTTP/1.0\r\n\r\n')
            return probe.recv(12).startswith(b'HTTP/')
    except OSError:
        return False


if __name__ == '__main__':
    if len(sys.argv) == 2 and sys.argv[1] == '--check':
        sys.exit(0 if alive() else 3)
    if len(sys.argv) != 1:
        sys.stderr.write('Usage: caddy-terminal-authd [--check]\n')
        sys.exit(2)
    umask = os.umask(0o077)
    os.makedirs(os.path.dirname(SOCKET) or '.', mode=0o700, exist_ok=True)
    try:
        server = UnixAuthdServer(SOCKET, Handler)
    finally:
        os.umask(umask)
    sys.stderr.write('caddy-terminal-authd: listening on %s\n' % SOCKET)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass

* Token helper: caddy-terminal-token

The Logseq side panel cannot type a password. Logseq is Electron: the ttyd
panel is an iframe, and Electron surfaces HTTP 401 challenges through the
session's =login= event — a native Basic-auth dialog does NOT appear for
iframe subresources, and the plugin renderer cannot register a session
=login= handler. Routing the panel through the basic_auth gate would render
the panel as a dead 401 page. So the panel gets its own authenticated route
on the SAME gate: a 256-bit random path token. The URL
=http://127.0.0.1:7680/<token>/= is a bearer credential — but the gate still
binds =127.0.0.1=, so the token is worthless off-box, and the token file is
0600 in metsatron's home, unreadable by agent users. This was the second
option Bunta's review explicitly sanctioned ("if Electron's webview can't
handle basic auth... a long random path token stored 0600, documented").

=caddy-terminal-token= owns the token and the Caddy snippet the gate imports:
it creates the token on first run, never rotates silently (=--rotate= is
explicit), and prints the ready-to-paste URL for the Logseq plugin's
"Terminal URL" setting. Rotating or re-running requires restarting the Caddy
gate instance (admin off) and re-pasting the URL in Logseq.

#+name: caddy-terminal-token
#+BEGIN_SRC bash :tangle all/.local/bin/caddy-terminal-token :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# caddy-terminal-token — bearer path token for the Logseq side panel's gate route.
# The token is a credential: 0600, never committed, never in DotCortex source.
set -euo pipefail

TAG="caddy-terminal-token"
STATE_DIR="${CADDY_TERMINAL_STATE:-$HOME/.local/state/caddy-terminal}"
TOKEN_FILE="$STATE_DIR/terminal-token"
ROUTE_FILE="$STATE_DIR/terminal-token-route"
SOCKET="${CADDY_TERMINAL_SOCKET:-$STATE_DIR/run/terminal.sock}"
GATE_URL="${CADDY_TERMINAL_GATE_URL:-http://127.0.0.1:7680}"

print_url() {
  printf '%s/%s/\n' "$GATE_URL" "$(cat "$TOKEN_FILE")"
}

case "${1:-}" in
  -h|--help|help)
    echo "Usage: $TAG [--print] [--rotate]"
    echo "  (default) create the token if missing, then print the panel URL"
    echo "  --print   only print the current URL; fails if no token exists"
    echo "  --rotate  force a fresh token (old one dies at the next gate restart)"
    exit 0 ;;
  --print) ;;
  --rotate) ;;
  '') ;;
  *) echo "$TAG: unknown argument: $1" >&2; exit 2 ;;
esac
[ "$#" -le 1 ] || { echo "$TAG: one argument at most" >&2; exit 2; }

umask 077
mkdir -p "$STATE_DIR"
chmod 700 "$STATE_DIR"

if [ ! -f "$TOKEN_FILE" ] || [ "${1:-}" = "--rotate" ]; then
  # 32 bytes from the kernel CSPRNG -> 64 hex chars (256 bits).
  TOKEN="$(od -An -N32 -tx1 /dev/urandom | tr -d ' \n')"
  TMP="$(mktemp "$STATE_DIR/.terminal-token.XXXXXXXX")"
  printf '%s\n' "$TOKEN" > "$TMP"
  chmod 600 "$TMP"
  mv "$TMP" "$TOKEN_FILE"
  # Snippet the gate site imports FIRST (before its catch-all handle):
  # handle_path strips the token prefix, so ttyd sees clean /, /token, /ws paths.
  TMP="$(mktemp "$STATE_DIR/.terminal-token-route.XXXXXXXX")"
  {
    printf '# Managed by %s. Bearer-token route for the Logseq side panel (fix round 1).\n' "$TAG"
    printf '# Import order matters: this must be the first handle in the gate site.\n'
    printf 'handle_path /%s/* {\n' "$TOKEN"
    printf '\treverse_proxy unix/%s\n' "$SOCKET"
    printf '}\n'
  } > "$TMP"
  chmod 600 "$TMP"
  mv "$TMP" "$ROUTE_FILE"
fi

[ -f "$TOKEN_FILE" ] || { echo "$TAG: no token at $TOKEN_FILE" >&2; exit 1; }
echo "$TAG: paste this URL into the Logseq ttyd plugin's Terminal URL setting:" >&2
print_url
echo "$TAG: token and Caddy route snippet live in $STATE_DIR (0600)" >&2
if [ -f "$ROUTE_FILE" ]; then
  echo "Restart the Caddy gate instance for the route snippet to take effect." >&2
fi
#+END_SRC

* Gate site (machine-local Caddyfile, not in DotCortex)

Decided ports: gate 7680 (loopback), tailnet 7682 (tailscale serve) — ttyd
has no port; it is a unix socket behind the gate. The site block is appended
to the unprivileged FileBrowser Caddy instance's machine-local
=$HOME/.local/state/filebrowser/caddy/.Caddyfile= (back it up first;
=auto_https off= and =admin off= stay), and the instance is restarted. The
hash file and the token-route snippet are imported, never inlined.

Six details verified live (2026-10-15/16) and load-bearing:

- =bind 127.0.0.1= is REQUIRED. Without it a host-IP site address binds the
  port on every interface — the gate briefly listened on the LAN and tailnet
  during testing. Caddy's =bind= directive pins the listener to loopback.
- No Host matcher (=http://:7680=). =tailscale serve= forwards its own Host
  header; a =127.0.0.1= host matcher would miss those requests. The listener
  is loopback-only, so wildcard Host is safe — only tailscaled can reach it.
- The token route import must come FIRST. =handle= blocks are mutually
  exclusive and evaluated in order; the token =handle_path= claims its prefix
  before the path-specific handles and the bare authenticated catch-all.
  Both proxy routes carry the websocket upgrade natively.
- The =Content-Security-Policy: frame-ancestors= site header is what R-DOCK-17
  rides on: it applies to every response of the site — including =/healthz= —
  so the dock's =inspect_apps= reads =frame-ancestors= off the health probe
  and reports frame=allowed for the Centre origin and nothing else. No
  =X-Frame-Options= is ever emitted (it would shadow the CSP).
- =/healthz=, =/login= and =/logout= are deliberately OUTSIDE the
  =forward_auth= catch-all: the dock's health probe is unauthenticated (it
  only ever learns ok/not), and the login page must be reachable without a
  session. Everything else — the ttyd index, =/token=, =/ws= — requires the
  session cookie via =forward_auth= against the verifier socket.
- =SameSite=None= means the cookie rides along on cross-site requests, and
  CHIPS does not help here: every page under =*.sphinx-draco.ts.net= shares
  the Centre's top-level site, so the partition key is identical and the
  cookie is theirs too. =frame-ancestors= stops framing but says nothing
  about WebSockets, and ttyd runs =-W= (writable): without an Origin check
  any sibling tailnet page the Admiral has open could open
  =wss://…:7682/ws= with his cookie and get a writable shell — cross-site
  WebSocket hijacking. Fix round 3 closes it at the gate with two guards,
  both named matchers evaluated BEFORE the handles (order matters: =handle=
  blocks are mutually exclusive, first match wins):
  - =/ws= requires the Origin header to be EXACTLY
    =https://kikin-kushi.sphinx-draco.ts.net:7682= — the ttyd page's own
    origin inside the iframe. Browsers always send Origin on a WebSocket
    upgrade, so missing or any other Origin answers =403=.
  - =/ws= is the writable shell; =/token= is only reached by the ttyd
    page's own same-origin =fetch()=, which browsers do NOT attach an
    Origin header to (=Origin= is a forbidden header — page JS cannot add
    it), so =/token= refuses any Origin that is present-but-different (the
    cross-site hijacker always sends one) and allows the honest
    missing-Origin fetch. A browser attacker cannot both omit Origin and
    read the response, and this ttyd ignores token values anyway; the
    guard is defence-in-depth for a future ttyd with real credentials.

#+BEGIN_EXAMPLE
http://:7680 {
	bind 127.0.0.1

		path /ws
		not header Origin https://kikin-kushi.sphinx-draco.ts.net:7682
	}

* Verification

Live checks (Kikin, run by the builder; recorded in the handoff report).
The round-1 core: NO listener gives an unauthenticated shell to another
local user. The round-2 core: the dock's health probe is 200 unauthenticated,
the root without a session is the login page, and the session works inside
the Centre iframe (HelmCortex =FORGE/tests/test_caddy_terminal_window.py=
proves all of this against a scratch instance).

1. No TCP listener for ttyd at all: =ss -H -tln "( sport = :7681 )"$ returns
   nothing for the supervised instance (a pre-fix Logseq ttyd may linger
   until reboot — find it by PID and kill it, never by name).
2. Socket hygiene: =stat -c '%a %U'=
   =~/.local/state/caddy-terminal/run/= is =700 metsatron=, and the socket
   file is =600 metsatron= (=srw-------=). Agent users cannot traverse the
   directory — that plus the absence of any port is the isolation property.
   As an agent user (Bunta, outside the sandbox):
   =sudo -u agent-vibe curl --unix-socket=
   =/home/metsatron/.local/state/caddy-terminal/run/terminal.sock=
   =http://localhost/= fails with permission denied.
3. No session: =curl -s -o /dev/null -w '%{http_code}' -L=
   =http://127.0.0.1:7680/= lands on the LOGIN PAGE (200 with the form) —
   never a 401. =curl -I http://127.0.0.1:7680/= shows the =303= to
   =/login?auth= from the forward-auth check.
4. Health probe (dock lane): =curl -s -o /dev/null -w '%{http_code}'=
   =http://127.0.0.1:7680/healthz= returns 200 with NO credential and body
   =ok= only; killing ttyd flips it to =503= =down=. The response carries
   =Content-Security-Policy: frame-ancestors= naming ONLY the Centre origin.
5. With session: =curl -c jar -d 'password=...' -H 'Origin:
   https://kikin-kushi.sphinx-draco.ts.net:7682'
   http://127.0.0.1:7680/login= saves the cookie (=Secure; HttpOnly;
   SameSite=None; Partitioned=), then the ttyd index loads (200) and a
   websocket echo round-trips through the gate (=/token=, then =/ws= with
   the tty= subprotocol). =/logout= drops the session and the root is the
   login page again. The curl Origin header stands in for the iframe's
   page origin — through the tailnet the browser sends it on its own.
6. Throttle: five wrong passwords in a row lock the client out — further
   POSTs to =/login= answer =429= with =Retry-After=, even with the right
   password, until the lockout window passes. (POSTs with a wrong or
   missing Origin answer =403= instead and never count toward the
   lockout.)
7. Token route (Logseq lane): =curl -s -o /dev/null -w '%{http_code}'=
   =http://127.0.0.1:7680/<token>/= returns 200 with NO credential, and a
   websocket echo round-trips through it too. A wrong token gets 401.
8. =curl http://<tailnet-ip>:7680= is refused (=bind 127.0.0.1=).
9. Killing the ttyd PID: the supervisor respawns it within its retry window,
   the socket comes back 0600, and the gate is 200 again. Same contract for
   the authd lane (=caddy-terminal-authd --check=).
10. CSWSH (fix round 3) — a websocket handshake to =/ws= through the gate
    with a session cookie answers =101= ONLY when Origin is exactly
    =https://kikin-kushi.sphinx-draco.ts.net:7682=; Origin
    =https://other.sphinx-draco.ts.net=, any other Origin, or none at all
    answers =403=. Same shape for the login POST (=403= unless the Origin
    is exact) — and =/token= answers =403= for every present-but-wrong
    Origin while the ttyd page's own missing-Origin fetch keeps working.
    The scratch suite (=FORGE/tests/test_caddy_terminal_window.py=) proves
    all of it against a scratch gate, cookie included.
